## 今月の要点

- **件数が過去最多級**。Microsoft の月例の更新が約1,415件（Critical 約70件）、Oracle の定例アップデート（CPU）が固有のCVEで1,209件と、どちらも1回で1,000件を超えた。NVD上の10月の公開数は、26日までで14,007件。
- **悪用が確認されたもの**は、CISAのカタログ（KEV）に10月だけで26件追加された。Ivanti Connect Secure、Fortinet FortiMail、Citrix NetScaler、Palo Alto PAN-OS、Cisco Secure Email Gateway、Atlassian の Data Center 製品、Windows Shell（Microsoft の月例のゼロデイ）など、**ネットワークの境界に置く機器**が目立つ。
- **eMudhra の中間CA証明書の秘密鍵の漏えい**（10/17に判明）への対応が各所で続いた。Java は 10/21 と 10/24 の2回（[CVE-2026-91403](../Java/2026/10/21/CVE-2026-91403.md)・[CVE-2026-114820](../Java/2026/10/24/CVE-2026-114820.md)）、Python（[CVE-2026-115557](../Python/2026/10/24/CVE-2026-115557.md)）、Go（[CVE-2026-111943](../Go/2026/10/21/CVE-2026-111943.md)）、Node.js、Apple、MongoDB Compass、HCL BigFix など。
- **PHP**: PHP本体の「PHP2Shell」（[CVE-2026-109618](../PHP/2026/10/21/CVE-2026-109618.md)・[CVE-2026-109619](../PHP/2026/10/21/CVE-2026-109619.md)、認証なしのリモートコード実行）、Laravel の TokenGuard のなりすまし（[CVE-2026-114509](../PHP/2026/10/19/CVE-2026-114509.md)）、Symfony の ReDoS など。
- **Python**: Django の定例リリース（10/06、4件）、Django REST framework（10/21、3件）、Pillow 13.0.0（38件）、aiohttp 3.14.4（7件）。
- **Node.js**: Node.js 本体の10件（10/21、Brotli の範囲外書き込みを含む）、Next.js 8件、Vite 6件、undici 3件、body-parser・multer（リクエスト1つでプロセスが落ちる）。
- **Java**: Oracle CPU の Java SE 約50件、Tomcat 8件（Critical 3件）、Struts 4件（OGNLの注入によるリモートコード実行、CVSS 9.8）。
- **Go** は 10/08 の定例リリースで16件（HTTP/2 まわりが多い）。**.NET** は Microsoft の月例で46件（ASP.NET Core の HTTPリクエストスマグリング 2件が Critical）。
