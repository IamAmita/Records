# ベルゲン

**ベルゲン（Bergen）**は、ノルウェー西部の港湾都市で、首都オスロに次ぐ国内第2の都市。フィヨルド地方の玄関口にあたり、**ヴェストラン県**の県庁所在地である。

人口は約29万5,000人。11世紀に建設され、13世紀にはノルウェー王国の首都として栄えた。14世紀からはドイツ商人の**ハンザ同盟**の商館が置かれ、北ノルウェーの干しダラ（ストックフィッシュ）と穀物の交易で北欧有数の商業都市となり、1830年代までノルウェー最大の都市だった。ハンザ商人の木造倉庫群**ブリッゲン**は世界遺産に登録されている。現在は石油・ガス、水産・養殖、海運などの「海の産業」の一大拠点で、作曲家グリーグの故郷、雨の多い「七つの山に囲まれた町」としても知られる。

### 名前

古ノルド語の「ビョルグヴィン（Bjǫrgvin）」に由来する。前半は「山」、後半は「牧草地」を表し、「山あいの牧草地」を意味する。1918年に古い名前「ビョルグヴィン」に戻す運動が起きたが、市名は変わらず、教区の名前だけがビョルグヴィン教区に改められた。

### 人口

* 2026年第2四半期の人口は29万5,009人。2025年は出生3,054人・死亡2,041人で、転入超過は114人にとどまった。2030年に30万1,936人、2050年に32万5,773人になると推計されている。
* 人口の推移は、1951年15万5,517人、1972年21万1,970人、2000年22万9,496人、2020年28万3,929人（いずれも現在の市域）。
* 市街地（tettsted）ベルゲンの人口は27万3,626人で、市の人口の94%が住む（2025年）。周辺の自治体を含む都市圏の人口は約47万人。

### 行政の仕組み

* 2000年から、国の議院内閣制にならった**市議会内閣制（parlamentarisme）**をとる。議員67人の市議会（bystyre）が、市政府（byråd）の首班を選び、首班が7人の市政委員（byråd）を率いて行政を担う。市長（ordfører）は議会の議長と儀礼的な役割を受け持つ。
* 2022年10月、児童福祉の不祥事をめぐって労働党の首班ロゲル・ヴァルハンメルに不信任案が可決され、市政府が総辞職した。2023年の地方選挙後は保守党のクリスティーネ・メイエルが首班となった。
* 2026年9月、メイエルが3年で首班を退き、同月25日に保守党・進歩党・中央党の3党によるロードランの市政府が発足した。
* 市域は、ベルゲンフス・オースタ・フィリングスダーレン・ラクセヴォーグ・イトレビュグダ・ファナ・オーサネ・アルナの8区に分かれる。

### 市域の変遷

* 1915年にオースタを編入し、1972年1月1日には周辺のアルナ・ファナ・ラクセヴォーグ・オーサネの4自治体を合併して現在の市域となった。
* それまでベルゲンは単独で県と同格の扱いだったが、1972年の合併でホルダラン県に組み込まれた。2020年1月1日、ホルダラン県とソグン・オ・フィヨーラネ県が統合されてヴェストラン県となった。

## 地理

### 位置と地形

ノルウェー西岸、ベルゲン半島に位置する。沖のアスコイ島・ホルスノイ島・ソトラ島が、北海の荒波から町を守っている。

* 市の中心部は、天然の良港である入り江**ヴォーゲン（Vågen）**を囲むように広がり、北側は湾ビュフィヨルデンに面する。ヴォーゲンの入口はベルゲンフス要塞が守る。
* 中心部は**七つの山（De syv fjell）**に囲まれている。最も高いのはウルリケン山（643m）で、フロイエン山にはケーブルカー、ウルリケン山にはロープウェーで登ることができる。市内の最高地点はグルフィェレット（988m）。
* 周囲にはラウネフィヨルデン、サールフスフィヨルデン、ソールフィヨルデンなどのフィヨルドが入り込み、市内には15の自然保護区がある。

### 気候

暖流の北大西洋海流の影響を受けた西岸海洋性気候で、緯度が高いわりに冬は温暖である。一方、海からの湿った風が山にぶつかるため、ヨーロッパの都市の中でも特に雨が多い。

* 年平均気温は8.4℃、年降水量は2,488.8mm（気象庁の世界の平年値から計算）。東京の年降水量（1,598.2mm）の約1.6倍にあたる。
* 最も寒い2月の平均気温は2.3℃、最も暖かい7月は15.5℃で、冬でも平均気温は氷点下にならない。
* 降水量は秋から冬に多く、12月は290.0mm、最も少ない5月でも108.8mm。1mm以上の雨が降る日は年に約200日ある。
* 観測史上の最高気温は33.4℃（2019年7月26日）、最低気温は−16.3℃（1987年1月）。

## 歴史

### 建設 ― オーラヴ3世の町

* 1020〜30年代にはすでに交易の集落があったが、伝承では1070年にオーラヴ3世（オーラヴ・キュレ）が町を建てたとされる。
* 1100年ごろに建てられた聖母マリア教会（マリア教会）は、市内に残る最も古い建物である。

### 王国の首都

* 13世紀、ベルゲンはノルウェー王国の首都として栄え、王の居城が置かれた。
* ホーコン5世の時代（1299〜1319年）に、王の拠点はオスロへ移った。

### ハンザ同盟の商館 ― 干しダラの交易

* 1350年ごろ、北ドイツの商人の連合**ハンザ同盟**がベルゲンに商館（コントール）を開いた。商館はヴォーゲンの東岸のブリッゲン地区を拠点に、北ノルウェーの干しダラの輸出と穀物の輸入を独占した。
* ハンザの海外商館は4つあったが、建物が今も残るのはベルゲンのブリッゲンだけである。
* 1754年、ドイツ人の商館は閉じられ、建物はノルウェー国籍の商人に引き継がれた。
* ベルゲンは1830年代にクリスチャニア（現在のオスロ）に抜かれるまで、ノルウェー最大の都市だった。

### 大火と再建

* 1702年の大火では町の大部分（8分の7とも、9割ともいわれる）が焼け、ブリッゲンも被害を受けた。ブリッゲンは、元の区画と建築方法を守って再建された。
* 1837年に自治体となった。
* 1916年の大火では中心部の約300棟が焼けた。焼け跡には広い街路と石造りの建物が整えられた。

### 近代化 ― 鉄道と学術

* 1909年11月27日、オスロ方面と結ぶ**ベルゲン線**が開通し、ホーコン7世がヴォス駅で開通を宣言した。山岳地帯を越える路線で、最も高い地点は標高1,237mに達する。
* 1917年ごろから、気象学者ヴィルヘルム・ビヤークネスらによって、天気予報の基礎となる前線の理論を生んだ「**ベルゲン学派**」の研究が進められた。
* 1918年、フロイエン山へのケーブルカー**フロイバーネン**が開業した。

### 第二次世界大戦 ― ヴォーゲンの大爆発

* 1940年4月9日、ドイツ軍のノルウェー侵攻の初日にベルゲンは占領された。
* 1944年4月20日、ベルゲンフス要塞前の岸壁で、ドイツ軍に徴用されていたオランダの船**フォールボーデ号**が積荷の爆薬とともに爆発した。約160人が死亡し（158人とする資料もある）、約5,000人が負傷した。周辺の住宅の多くが壊れ、王の広間ホーコンスハレンや旧税関、ブリッゲンも大きな被害を受けた（のちに修復）。

### 戦後 ― 学術と文化の都市へ

* 1936年に**ノルウェー経済大学（NHH）**、1946年に**ベルゲン大学**が創立された。
* 1953年、国際的な音楽・舞台芸術の祭典**ベルゲン国際フェスティバル**が始まった。
* 1955年と1958年の火災でブリッゲンの一部が焼け、その跡地の発掘調査で中世の遺物が大量に見つかった。調査が終わった1979年、ブリッゲンは**ユネスコの世界遺産**に登録された。
* 1955年にフレスラン空港が開港し、1963年には海軍の主要基地ホーコンスヴェルンが開設された。
* 1972年の合併で市域が大きく広がった。1978年にはコンサートホール「グリーグホール」が開館した。
* 1986年、ノルウェーで初めて、市内に入る車から料金を取る**有料道路の環（ボムリング）**を設けた。
* 2000年、ヨーロッパ文化首都の一つに選ばれ、同じ年に市議会内閣制を導入した。
* 2010年6月22日、路面電車型の**ベルゲン・ライトレール（Bybanen）**が開業し、2013年・2017年に延伸された。2020年にはヴェストラン県の県庁所在地となった。

## 経済

### 規模

ヴェストラン地方最大の都市として、周辺から多くの通勤者を集める。

* 市外から通勤してくる人は4万5,294人、市外へ通勤する人は2万543人で、流入が大きく上回る（2025年）。
* 学生は4万人以上で、ノルウェー有数の学生の町でもある。
* 市によると、ベルゲン地域にはノルウェーで最も豊かで多様な「海の産業」が集積し、国の支援を受ける産業クラスターの密度も国内で最も高い。

### 主な産業

| 分野 | 内容 |
| --- | --- |
| 石油・ガス | 市の最大の基幹産業。北海の油田・ガス田の開発・運用を支える企業が集まり、海底設備（サブシー）技術の国際的な拠点でもある |
| 水産・養殖 | 世界最大のサーモン養殖会社モウィ（Mowi）が本社を置く。漁業局（Fiskeridirektoratet）や海洋研究所など、国の水産の行政・研究機関も集まる |
| 海運 | 多くの船会社が本社を置く。ベルゲン港は貨物・旅客ともにノルウェーで最も取扱いの多い港の一つ |
| 再生可能エネルギー | 海洋・海事の分野とともに、国内外で先導的な地位にある |
| 防衛 | 市の南西部にあるホーコンスヴェルン基地は、ノルウェー海軍の主要基地で、北欧最大級の海軍基地とされる |
| 観光 | ブリッゲン、魚市場、フロイエン山などを目当てに、クルーズ船や鉄道・フィヨルド観光の旅行者が訪れる |
| 教育・研究 | ベルゲン大学、ノルウェー経済大学、西ノルウェー応用科学大学などが集まる |

ほかに金融、メディア、小売、文化産業も重要な産業とされる。

### 観光

* 2024年は市内の宿泊者数が過去最高を記録した。
* ベルゲンはノルウェーで最もクルーズ船が多く寄港する港で、2024年は328回の寄港があった。2025年のクルーズ客は68万人を超え、国内で最も多かった。
* 混雑を抑えるため、クルーズ船の寄港は1日4隻・乗客8,000人までに制限されている（2022年から）。4隻目には停泊中にエンジンを止めて陸から電気を受ける「陸上電力」の利用が義務づけられている。
* 港の**魚市場（フィスケトルゲ）**は、古くからの名物として多くの観光客を集める。

### 交通

* **フレスラン空港**は市の中心から南西約18kmにあり、2024年の利用者は655万2,286人で、オスロ空港に次ぐノルウェー第2の空港である。2017年に新しいターミナルビルが開業した。
* 鉄道はオスロとを結ぶベルゲン線の終点で、フィヨルド観光で知られるフロム線への乗り継ぎ駅ミュルダールにも通じる。
* 市内の公共交通の柱は**ベルゲン・ライトレール**で、中心部から南の空港まで延びる。中心部から北部のオーサネまでの第5期区間の計画が進められている。
* ベルゲンからは、ノルウェー北端のキルケネスまで沿岸を北上する沿岸急行船**フッティルーテン**が出航する。
* 市の周りの島々や周辺の自治体とは、4つの大きな橋で結ばれている。

### 課題

* **観光の集中** … 夏にはクルーズ船の客が中心部に集中し、ブリッゲン周辺の混雑や環境への負荷が問題になっている。寄港の制限や陸上電力の義務化が進められている。
* **石油産業への依存** … 最大の基幹産業である石油・ガスは、原油価格やエネルギー転換の影響を受けやすい。再生可能エネルギーなどの新しい「海の産業」への転換が課題となっている。
* **雨と地形** … 雨が多く、急な斜面に住宅地が広がるため、大雨による浸水や土砂崩れへの備えが欠かせない。
* **人口の伸び悩み** … 2025年の転入超過は114人にとどまり、2026年第2四半期には人口が417人減った。
* **市政の安定** … 2022年の不信任可決による市政府の総辞職や、2026年の首班の交代など、市政府の交代が続いている。

## 出典

数値は各出典の公表時点のもの（2026年10月確認）。東京の降水量との比較、王の居城、ブリッゲンが東岸にあること、ホーコンスハレンの名称、ベルゲン学派の業績の内容（前線の理論）、ウルリケン山のロープウェー、ライトレールが空港まで延びていること、ミュルダール・フロム線、フッティルーテン、海洋研究所、魚市場が古くからの名物であること、課題（観光の集中・人口・市政の安定を除く）には、個別の出典を付けていないものがある。2025年のクルーズ客数は二次資料による。
