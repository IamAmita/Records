# ロングイヤービーン

**ロングイヤービーン（Longyearbyen）**は、ノルウェー領**スヴァールバル諸島**の中心地。諸島最大の島スピッツベルゲン島の西岸、北緯78度13分に位置する、世界で最も北にある町の一つである。スヴァールバル総督（Sysselmesteren）や地方評議会（lokalstyre）が置かれ、諸島の行政・交通・経済の拠点となっている。

人口は約2,500人。1906年にアメリカの石炭会社が炭鉱町として建設し、創業者の名から「ロングイヤー・シティ」と呼ばれた。1916年からはノルウェーの石炭会社**ストーレ・ノシュケ**の企業城下町として約100年にわたり石炭とともに歩んだが、2025年にノルウェー最後の炭鉱が操業を終え、現在は**観光と北極研究**が町を支えている。スヴァールバル条約によって締約国の国民が平等な経済活動の権利を持つため、住民の3分の1以上が外国籍という国際色の強い町でもある。

### 名前

アメリカの実業家**ジョン・マンロー・ロングイヤー**（1850〜1922年）にちなむ。建設当初は英語で「ロングイヤー・シティ（Longyear City）」と呼ばれ、1926年にノルウェー語で「ロングイヤーの町」を意味するロングイヤービーン（by＝町、byen＝その町）に改められた。日本語では「ロングイェールビーン」「ロングイェールビエン」「ロングイヤービン」などとも書かれる。

### 人口

* 統計はロングイヤービーンと研究基地の町ニーオーレスンを合わせて集計されており、住民の大部分はロングイヤービーンに住む。2026年1月1日時点では2,512人で、66か国の国籍の人が暮らしていた。
* 2025年1月1日時点の2,556人のうち、ノルウェー人は1,626人（63.6%）。外国籍ではフィリピン人（127人）が長く2位だったタイ人（113人）を抜いて最多となり、ドイツ人（94人）、ロシア人（67人）が続く。
* 住民の入れ替わりが非常に激しく、2025年初めの住民のうち1年後も住んでいたのは8割弱にとどまる（ノルウェー本土の自治体では転出は5%前後）。
* 同じスヴァールバルにはロシアの炭鉱町**バレンツブルク**などもあり、そちらの人口は392人（2026年1月、ピラミーデンと合わせて）。

### 行政の仕組み

* スヴァールバルは1925年のスヴァールバル法によってノルウェーの一部となったが、本土の県・市町村の制度には含まれない。国の出先機関である**スヴァールバル総督**が県知事と警察本部長の役割を兼ね、司法・警察・環境保護などを担う（2021年に名称をSysselmannenからSysselmesterenに改めた）。
* 町の運営は、2002年1月1日に発足した**ロングイヤービーン地方評議会**が担う。それまでのスヴァールバル評議会に代わるもので、議員は15人、任期は4年。教育・保育、道路・上下水道、電気・熱の供給、土地利用計画など、本土の市町村に近い仕事をする。
* 2023年10月9日の選挙では自由党が最も多くの票を集め、自由党と保守党の協力によってアウネヴィークが議長となった。それまでは2015年から労働党のアリル・オルセンが議長を務めていた。この選挙から、外国籍の住民が選挙権を得るには**本土の市町村に3年以上住んでいたこと**が条件となり、住民の約3分の1が投票できなくなった（有権者1,420人、投票率56.9%）。

## 地理

### 位置と地形

スピッツベルゲン島の西岸、大きな湾**イースフィヨルデン**から南東に入り込んだ入り江**アドヴェントフィヨルデン**の南西岸に位置する。

* 町は、アドヴェントフィヨルデンに注ぐ**ロングイヤー川**の谷（ロングイヤーダーレン）に沿って細長く広がる。谷の東には広い谷**アドヴェントダーレン**が開け、炭鉱の多くはこの谷沿いに掘られた。
* 町の中心から北西約5kmのホテルネセットに空港がある。対岸には、かつての炭鉱町アドヴェント・シティやヨルトハムンの跡が残る。
* 周囲の山の斜面は雪崩や土石流が起きやすく、宅地にできる土地は限られている。
* 北極点までは約1,300km（緯度から計算）。

### 永久凍土

* 地面は深くまで凍った**永久凍土**で、遺体が分解されないことから、1950年以降、町の墓地への埋葬は行われていない。
* 建物の多くは、凍土が溶けて地盤が沈むのを防ぐため、地面に打ち込んだ杭の上に建てられている。

### 白夜と極夜

* 太陽が沈まない**白夜**は4月20日ごろから8月23日ごろまで、太陽が昇らない**極夜**は10月26日ごろから2月15日ごろまで続く。
* 周りを山に囲まれているため、極夜が明けても町に日が差すのは3月上旬になってからである。

### 気候

ツンドラ気候に属するが、北大西洋海流（暖流）の影響で、同じ緯度のほかの地域に比べると冬の寒さは穏やかである。雨や雪は非常に少ない。

* 年平均気温は−3.9℃、年降水量は207.2mm（気象庁の世界の平年値から計算）。降水量は東京の約7分の1しかない。
* 最も暖かい7月の平均気温は7.0℃。最も寒いのは3月で−12.1℃、1月は−10.9℃である。
* 観測史上の最高気温は21.7℃（2020年7月）、最低気温は−46.3℃（1986年3月）。
* 地球上で最も温暖化が速い地域の一つで、スヴァールバルの年平均気温は1971〜2017年に4.0℃上がった（冬は約7℃）。今世紀末までにさらに7〜10℃上がるという予測もある。

### 自然とホッキョクグマ

* スヴァールバルには約3,000頭とされる**ホッキョクグマ**が生息し、町の近くに現れることもある。
* 町の外に出る人は、ホッキョクグマから身を守る知識と、追い払うための道具（信号弾など）を持つことが法律で義務づけられている。総督は、主な備えとしてライフル銃を携帯するよう勧めている。

## 歴史

### 前史 ― 捕鯨と探検の島

* スヴァールバルには先住民がおらず、1596年にオランダのバレンツが到達したことで知られるようになった。17世紀には各国の捕鯨基地が置かれ、その後も狩猟や探検の拠点として利用された。
* 19世紀末には観光も始まり、1896年にはノルウェーの船会社が観光航路を開いた。1899年には、ノルウェー人のセーレン・サカリアッセンが初めて商業的に石炭を採掘した。

### 建設 ― ロングイヤー・シティ

* アメリカの実業家ロングイヤーは、1901年に観光客としてスヴァールバルを訪れ、石炭の可能性に目をつけた。1906年、仲間のフレデリック・エイヤーらとボストンに**アークティック石炭会社（Arctic Coal Company）**を設立し、桟橋や住宅を建てて採掘を始めた（建設の年は資料によって1905年とするものもある）。
* 町は「ロングイヤー・シティ」と呼ばれた。経営はアメリカ人だったが、労働者の多くはノルウェー人だった。

### ストーレ・ノシュケの企業城下町

* 1916年、ノルウェーの投資家が**ストーレ・ノシュケ・スピッツベルゲン石炭会社（Store Norske）**を設立し、アークティック石炭会社の土地と事業を買い取った。
* 1920年2月9日、パリで**スヴァールバル条約**が結ばれ、ノルウェーの主権が認められた。条約は1925年8月14日に発効し、同年のスヴァールバル法で総督が置かれた。1926年、町の名前はロングイヤービーンに改められた。
* 町の住宅・商店・病院などはすべてストーレ・ノシュケが運営し、炭鉱で働く人とその家族だけが暮らす「会社の町」だった。

### 第二次世界大戦 ― 町の焼失

* 1941年、スヴァールバルの住民は連合国の作戦で島外へ避難させられ、その際に施設の一部が破壊された。
* 1943年9月8日、戦艦ティルピッツなどからなるドイツ海軍の艦隊がスヴァールバルを攻撃し（ツィトロネラ作戦）、ロングイヤービーンはほぼ全焼した。焼け残った建物はわずか4棟だった。
* 1945年6月27日、本土から戦後最初の船が到着した。

### 戦後の再建と石炭の時代

* 戦後、町は再建され、1946年にはニュービーエン地区が造られた。1948年には石炭の年産が48万tに達した。
* 1948年に地元紙「スヴァールバルポステン」が創刊され、1958年にはスヴァールバル教会が献堂された。
* 1975年、ノルウェー政府がストーレ・ノシュケの株式の99.9%を持つ国営企業となった（2015年に100%）。

### 普通の町へ

* 1975年に**スヴァールバル空港**が開港した。それまでは本土との交通は船だけで、船が通えるのは年に最大7か月だったため、冬の間は外の世界から切り離されていた。
* 1989年、ストーレ・ノシュケが担っていた町の運営が別会社に分けられ、企業城下町から普通の町への移行が始まった。2002年には地方評議会が発足し、住民が町の運営を担うようになった。
* 1993年、北極の自然科学を教える**スヴァールバル大学センター（UNIS）**が30人の学生で開校した。
* 1996年8月29日、ロシアの炭鉱町へ労働者らを運んでいたヴヌコヴォ航空のチャーター機が空港近くのオペラ山に墜落し、乗っていた141人全員が死亡した。ノルウェー史上最悪の航空事故である。
* 2008年、世界中の作物の種子を保管する**スヴァールバル世界種子貯蔵庫**が開設された。

### 炭鉱の終わりと新しい課題

* 2015年12月に雪崩で2人が死亡し、10棟の住宅が全壊・大破した。2017年2月にも雪崩で寮2棟が被害を受けた。危険な斜面にあるリア地区では、2019年12月から140戸の住宅の取り壊しが始まった。
* 2020年3月4日、町の南東にあった大炭鉱スヴェアの最後の坑道が閉鎖された。2023年10月には町の石炭火力発電所が止められ、ディーゼル発電に切り替えられた。
* 町に残った最後の炭鉱「**第7鉱**」は、2023年秋に閉山する予定だったが、ロシアのウクライナ侵攻によるエネルギー危機で延長され、**2025年6月30日**に操業を終えた。2026年に坑内の片付けを終えて坑口が封鎖され、100年以上続いたノルウェーによるスヴァールバルでの石炭採掘は終わった。
* 2024年5月、政府は国会にスヴァールバル白書を提出し、ロングイヤービーンを「ノルウェーの町」として維持し、国の管理を強める方針を示した。国会はこれを了承し、町をこれ以上大きくしないという方針も支持した。

## 経済

### 規模

町単独の統計はないが、ノルウェー統計局によると、スヴァールバルにある337の事業所の売上高は合計約57.7億クローネ、雇用は1,705.4人年（フルタイム換算）だった（2025年）。

### 主な産業

| 分野 | 内容 |
| --- | --- |
| 観光 | 宿泊・飲食業の雇用は327人年、売上高は約6.6億クローネ（2025年）。犬ぞり、スノーモービル、氷河・クルーズなどのツアーが中心 |
| 研究・教育 | スヴァールバル大学センター、ノルウェー極地研究所の支所、EISCATスヴァールバル・レーダー、衛星地上局SvalSat、世界種子貯蔵庫など。教育分野の雇用は200.5人年（2025年） |
| 運輸・物流 | 空港・港を通じた本土との輸送。運輸・保管業の売上高は約9.4億クローネ（2025年） |
| 行政 | 総督府、地方評議会などの公的機関 |
| 鉱業（終了） | 1916年から2025年までに15の炭鉱が操業した。年産は2007年に410万tでピークを迎え、2025年の第7鉱の閉山で終わった |

### 観光

* 町の宿泊者数は1995年からの約25年で5倍近くに増え、2019年に約16万7,000泊の過去最高を記録した。新型コロナで落ち込んだ後、2024・2025年はほぼ2019年並みに回復した。
* 船で訪れる観光客も多く、通常のクルーズ船で年約4万人、少人数の探検クルーズで約2万8,000人（2025年）が訪れる。
* 観光客の増加を受け、政府は宿泊1泊につき60クローネ、クルーズ客1人につき180クローネの**訪問者負担金**を徴収する案を2026年に示した。

### 研究と教育

* スヴァールバル大学センター（UNIS）は北極の生物学・地質学・地球物理学・工学の4分野を教え、学生は本国の大学の単位として取得する。世界各国から年に数百人の学生が学ぶ。
* 町の近くの山の上にある**EISCATスヴァールバル・レーダー**は、オーロラや超高層大気を観測するレーダーで、日本も国立極地研究所を中心に共同研究に参加している。
* **世界種子貯蔵庫**は、世界の作物の種子を「最後の保険」として保管する施設で、2025年末時点で131機関から137万8,238点の種子が預けられている。

### 税制と暮らし

* スヴァールバルは本土とは別の税の地域で、所得税は賃金に対して8%と低く、付加価値税（本土は25%）がかからない。
* スヴァールバル条約により、締約国の国民はビザや労働許可なしに住み、働くことができる。ただし、生活の手段がない人を支える福祉の制度はほとんどない。

### 交通

* **スヴァールバル空港**（滑走路2,483m）からSASとノルウェー・エアシャトルがオスロ・トロムソとの間を毎日結ぶ。2024年の利用者は18万4,030人で、統計のある2015年以降で最多だった。
* 町の道路は約50kmしかなく、ほかの集落とはつながっていない。冬は住民の数より多いスノーモービルが主な移動手段となり、夏は船も使われる。

### 日本との関係

* 日本は1920年のスヴァールバル条約の**原署名国**で、日本人もノルウェー人と同じように住み、事業を営む権利を持つ。
* 日本は1990年代半ばにEISCAT科学協会に加盟し、EISCATスヴァールバル・レーダーの2基目のアンテナの建設費を出した。国立極地研究所と名古屋大学が中心となって、日本の研究者の観測を支えている。

### 課題

* **炭鉱後の町づくり** … 町の成り立ちだった石炭産業が終わり、観光と研究への依存が高まっている。2026年には野党の進歩党の党首が炭鉱の再開を訴えるなど、方向性をめぐる議論も続く。
* **エネルギー** … 石炭火力の停止後は輸入したディーゼルに頼っている。太陽光発電と蓄電池の導入が進められているが、再生可能エネルギーへの転換はまだ途上である。
* **住宅と自然災害** … 雪崩や土砂災害の危険がない土地が少なく、住宅が不足している。温暖化による永久凍土の融解も、建物や道路に影響を与えている。
* **人口の定着** … 住民の入れ替わりが激しく、外国籍の住民の選挙権も制限された。政府は「ノルウェーの家族が暮らす町」を目指しているが、住宅費・生活費の高さが課題となっている。
* **観光の負荷** … クルーズ船の寄港や観光客の増加が、自然環境や町のサービスに負担をかけている。
* **国際関係** … ロシアの炭鉱町を抱えるスヴァールバルは、北極をめぐる国際政治の最前線でもあり、ノルウェー政府は国の管理を強める政策を進めている。

## 出典

数値は各出典の公表時点のもの（2026年10月確認）。総督府・ノルウェー政府の一部の資料は直接開けなかった（検索結果で照合した）。日本語の別表記、北極点までの距離、建物の杭基礎、ホッキョクグマの頭数、1596年のバレンツの到達と17世紀の捕鯨、戦艦ティルピッツの参加、2021年の総督の名称変更、地方評議会の仕事の内容、所得税率が現在も8%であること（出典は2005年度の告示）、福祉制度、東京の降水量との比較、課題には、個別の出典を付けていないものがある。
