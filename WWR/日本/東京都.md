# 東京都

**東京都（とうきょうと、Tokyo Metropolis）**は、日本の関東地方南部に位置する都道府県の一つ。都道府県のうち唯一の「都」であり、国会・中央省庁・最高裁判所・皇居が置かれる日本の事実上の首都である。

人口は約1,430万人で全国最多（全国の約1割強）。周辺3県（埼玉・千葉・神奈川）と合わせた**東京圏**には約3,690万人（2020年国勢調査）が暮らし、世界最大級の都市圏を形成している。政治・経済・文化・情報の中枢機能が集中する一方、西部には2,000m級の山地、南方には亜熱帯の小笠原諸島までを含み、巨大都市と豊かな自然の両面を持つ。

### 「首都」としての位置づけ

日本の法律には「首都は東京である」と直接定めた規定はない。しかし国会議事堂・首相官邸・中央省庁（霞が関）・最高裁判所という三権の中枢と皇居が都内（千代田区）に集まっており、事実上の首都として扱われている。

### 都制と特別区

東京都は「都」という独自の自治制度をとる。

* 1943年、戦時体制の下で**東京府と東京市が廃止・統合**され、東京都が誕生した。
* 旧東京市の区域にあたる23区は**特別区**と呼ばれ、一般の市と同様に区長・区議会を持つ。ただし上下水道・消防など、大都市として一体的に運営すべき事務は都が担う（**都区制度**）。
* 区部には「東京市」にあたる市が存在せず、都が「広域自治体」と「大都市の行政主体」の両方の役割を持つ点が、他の道府県と大きく異なる。

## 地理

### 位置と境界

関東平野の南西部に位置し、南東は東京湾に面する。本土部分は東西約90km・南北約25kmの東西に細長い形をしている。

* **東** … 江戸川を境に千葉県
* **北** … 埼玉県
* **西** … 山梨県
* **南** … おおむね多摩川を境に神奈川県

これに加えて、本土から南へ約1,000km以上にわたる太平洋上の島々も東京都に属する。日本の排他的経済水域（EEZ）の約38%は、東京都の島々によって確保されている。

### 地形

西から東へ、**山地 → 丘陵・台地 → 低地**と標高が下がっていく。

| 地形区分 | 主な範囲 | 特徴 |
| --- | --- | --- |
| **関東山地** | 奥多摩町・檜原村など西多摩 | 都の最高峰**雲取山（2,017m）**がある。多摩川の源流域。都の面積の約3分の1は森林 |
| **丘陵** | 多摩丘陵・狭山丘陵など | 多摩ニュータウンなど大規模住宅開発の舞台となった |
| **武蔵野台地** | 多摩東部〜区部西部 | 関東ローム層に覆われた洪積台地。その東端部がいわゆる**「山の手」** |
| **東部低地** | 区部東部（江東・墨田・江戸川・葛飾など） | 荒川・隅田川・江戸川がつくった沖積低地で、いわゆる**「下町」**。かつての地下水汲み上げによる地盤沈下で、海抜ゼロメートル地帯が広がる |

武蔵野台地の東縁は小河川に刻まれて起伏が多い。渋谷・四谷・市谷など「谷」のつく地名や、坂の多い街並みはこの地形に由来する。

### 河川と東京湾

* **多摩川** … 山梨県に源を発し、多摩地域を東へ流れて東京湾に注ぐ。下流は神奈川県との境界。
* **荒川・隅田川** … もとは荒川の下流が現在の隅田川だった。洪水対策として1930年に**荒川放水路**（現在の荒川本流）が完成した。
* **江戸川** … 利根川の分流で、千葉県との境界。
* **東京湾** … 江戸時代から埋め立てが続き、お台場・豊洲・羽田空港周辺など湾岸部の多くは人工の土地である。

水道の水源は利根川・荒川水系が約8割、多摩川水系が約2割。多摩川上流には都民の水がめである小河内ダム（奥多摩湖）がある。

### 島しょ部

* **伊豆諸島** … 伊豆大島・利島・新島・式根島・神津島・三宅島・御蔵島・八丈島・青ヶ島など。活火山の島が多く、2000年の三宅島噴火では全島避難が約4年半に及んだ。
* **小笠原諸島** … 本土の南約1,000km。一度も大陸と陸続きになったことのない海洋島で、固有種の多い独自の生態系を持ち、2011年に**世界自然遺産**に登録された。本土との定期交通は、おおむね6日に1便・片道約24時間の船便（おがさわら丸）のみである。
* 日本最東端の**南鳥島**と最南端の**沖ノ鳥島**も東京都（小笠原村）に属する。

### 気候

区部・多摩地域は太平洋側気候（温暖湿潤気候）に属する。

* 東京（千代田区）の年平均気温は15.8℃、年降水量は1,598.2mm（1991〜2020年の平年値）。
* 夏は高温多湿で、都市化による**ヒートアイランド現象**が顕著。近年は猛暑日（最高気温35℃以上）も増えている。
* 冬は乾燥した晴天が多い。降雪は年に数回程度だが、わずかな積雪でも交通が乱れやすい。
* 多摩西部の山間部は区部より冷涼。小笠原諸島は亜熱帯で、年平均気温は20℃を超える。

## 歴史

### 先史・古代

* 旧石器時代から人が暮らし、縄文時代の貝塚が数多く残る。1877年にアメリカ人モースが発掘した**大森貝塚**は、日本の近代考古学発祥の地とされる。
* 1884年に本郷弥生町（現・文京区）で発見された土器が、「弥生土器」「弥生時代」という名称の由来となった。
* 律令制下では**武蔵国**の一部で、国府は現在の府中市、国分寺は国分寺市に置かれた。当時の中心は今の区部ではなく多摩地域だった。

### 中世 ― 江戸の始まり

* 平安時代末期、秩父氏の一族がこの地に拠って**江戸氏**を名乗った。「江戸」は「入り江の入口（戸）」を意味するという説がよく知られる。
* 1457年、扇谷上杉氏の家宰**太田道灌**が江戸城を築いた。
* 戦国時代には小田原を本拠とする**後北条氏**の支配下に入った。

### 近世 ― 江戸幕府の本拠地

* 1590年、豊臣秀吉の命で**徳川家康**が関東に移封され、江戸城に入った。
* 1603年に家康が征夷大将軍となり江戸幕府を開くと、江戸は全国政治の中心となった。諸大名を動員した「天下普請」により、神田山を切り崩して日比谷入江を埋め立てるなど、大規模な都市改造が行われた。
* 参勤交代の制度化で全国の大名屋敷が集まり、18世紀には武家・町人あわせて**人口100万人前後**と、世界有数の大都市に成長した。
* 経済の中心「天下の台所」が大坂だったのに対し、江戸は巨大な消費都市であり、歌舞伎・浮世絵・出版などの町人文化が花開いた。
* 1657年の**明暦の大火**で市街の大半が焼失した。これを機に火除地や広小路を設けるなど、防火を意識した都市計画が進められた。

### 近代 ― 「東京」の誕生

* 1868年、江戸城が新政府軍に明け渡され（**江戸城無血開城**）、同年「江戸」は**「東京」（東の京）**と改称されて東京府が置かれた。
* 1869年に明治天皇が東京に移り、政府機関も移転した（**東京奠都**）。以後、東京は近代日本の首都となる。
* 1872年の新橋〜横浜間の鉄道開業、銀座煉瓦街、丸の内のオフィス街など、西洋式の近代都市づくりが進んだ。
* 1889年に**東京市**（当初15区）が発足。1893年には三多摩（現在の多摩地域）が神奈川県から東京府へ移管された。
* 1923年の**関東大震災**では、火災を中心に甚大な被害を受けた（震災全体の死者・行方不明者は約10万5千人）。その後の**帝都復興事業**で幹線道路・橋梁・公園・区画整理が整備された。
* 1932年に周辺の町村を編入して35区となり、「大東京」が成立した。

### 戦中・戦後

* 1943年、東京府と東京市を廃止して**東京都**が設置された。
* 1945年3月10日の**東京大空襲**では一夜で約10万人が死亡し、度重なる空襲で市街地の多くが焼失した。
* 1947年、35区が22区に再編され、同年に練馬区が板橋区から分離して現在の**23区**となった。
* 1962年に人口が1,000万人を突破。1964年の**東京オリンピック**に合わせて東海道新幹線・首都高速道路・東京モノレールなどが整備され、高度経済成長の象徴となった。
* 急速な成長の裏で、大気汚染・水質汚濁・交通渋滞・住宅難などの都市問題が深刻化した。

### 現代

* 1980年代後半のバブル経済期には地価が異常に高騰し、その崩壊後は長い停滞期に入った。
* 1991年、都庁が丸の内から**新宿**の新庁舎へ移転した。
* 1995年、地下鉄サリン事件が発生した。
* 2000年の都区制度改革で、特別区が「基礎的な地方公共団体」と法的に位置づけられた。
* 2011年の東日本大震災では、交通機関の停止により大量の帰宅困難者が発生した。
* 2021年、新型コロナウイルス感染症の影響で1年延期された**東京2020オリンピック・パラリンピック**が、大半の会場で無観客で開催された。

## 経済

東京は日本経済の中枢であり、世界有数の経済都市である。

### 規模

* **都内総生産**は名目で約125兆円（2023年度）、国内総生産の21.0%を占める。ドル換算では一国の経済規模と比べても上位に入る。
* 1人あたり都民所得は全国平均を大きく上回る。ただし、本社所在地に企業の所得が計上される分が含まれている点に注意が必要である。
* 都の財政規模も大きく、一般会計予算は9兆6,530億円（2026年度当初予算案）。都道府県で唯一、地方交付税（普通交付税）を受けない**不交付団体**であり続けている。

### 産業構造

* 都内総生産の約9割を**第三次産業**が占め、卸売・小売、金融・保険、不動産、情報通信、専門・科学技術サービスなどの比重が大きい。
* 中央官庁の所在地であることから、上場企業や大企業の約半数、外資系企業の大半が都内に本社を置く。この**本社機能・中枢管理機能の集積**が東京経済の最大の特徴である。
* 出版・新聞・放送・広告・アニメなどの**情報・コンテンツ産業**も集中している。アニメ制作会社は特に杉並区・練馬区など区部西部に多い。

### 地域ごとの経済の顔

| 地区 | 性格 |
| --- | --- |
| 丸の内・大手町・日本橋 | 大企業本社と金融の中心。日本銀行本店、東京証券取引所（兜町）が立地する |
| 霞が関・永田町 | 中央省庁・国会などの行政・政治の中枢 |
| 新宿・渋谷・池袋 | 副都心。巨大ターミナル駅を中心にオフィス・商業が集積する。新宿駅は1日平均乗降客数世界一としてギネス世界記録に認定されている |
| 銀座 | 高級ブランド店・百貨店が並ぶ商業地 |
| 秋葉原 | 電気街から、アニメ・ゲームなどサブカルチャーの街へと性格を変えた |
| 臨海副都心（お台場・豊洲など） | 埋立地に開発された新都心。2018年に築地から移転した豊洲市場がある |
| 大田区・墨田区など | 町工場が集まる精密加工・ものづくりの集積地 |
| 多摩地域 | 大学・研究開発拠点、電機・機械などの工場、首都圏のベッドタウン |

### 製造業・農林水産業

* 製造業の比重は小さいが、大田区の**町工場**群は高度な加工技術で知られる。墨田区・台東区などには皮革・履物・金属加工といった地場産業が残り、印刷・出版関連も都市型の産業として発達した。
* 都内でも農業は営まれており、江戸川区の**小松菜**（地名の小松川が名の由来）、練馬大根、東京うどなどが知られる。都市農地は防災空間・緑地としての役割も担う。
* 島しょ部では漁業（キンメダイなど）や、くさや・明日葉（あしたば）などの特産品がある。かつて東京湾の魚介は「江戸前」として、寿司・天ぷらなど江戸の食文化を支えた。

### 交通・観光

* 東京駅は新幹線網の起点で、羽田空港（大田区）は国内線最大の拠点。2010年以降は国際線も拡充された。JR・東京メトロ・都営地下鉄・私鉄が世界でも類を見ない密な鉄道網を形成している。
* 浅草・皇居周辺・渋谷・新宿・東京スカイツリー（2012年開業、高さ634m）などに国内外から多くの人が訪れ、近年は訪日外国人旅行者（インバウンド）が経済の大きな柱になっている。

### 課題

* **東京一極集中** … 人口・企業・資金が東京圏に集中し続け、地方との格差や、首都直下地震などの災害時に国家機能が一斉に損なわれるリスクが問題視されている。
* **少子高齢化** … 若年層の転入は多いものの出生率は全国最低水準で、合計特殊出生率は2023年に初めて1を下回り（0.99）、2024年は0.96と全国（1.15）を大きく下回る。
* **生活コストと都市基盤** … 住宅費・地価の高さ、高度成長期に整備されたインフラの老朽化、ヒートアイランドなどの課題を抱えている。
