# 日本の行政区分

日本の地方行政は、**都道府県**（広域自治体）と**市町村**（基礎自治体）の**2層制**を基本とする。都道府県は47、市町村は1,718（市792・町743・村183）で、これに東京都の**特別区（23区）**を加えた「市区町村」は1,741になる。

地方自治法では、都道府県と市町村を「普通地方公共団体」、特別区や一部事務組合などを「特別地方公共団体」として区別している。市町村は人口規模などに応じて「指定都市」「中核市」などに分かれ、大きな市ほど都道府県の仕事の一部を担う。一方、よく使われる「東北地方」「近畿地方」などの**地方区分**や、住所に残る**郡**には、行政上の権限はない。

## 概要

| 項目 | 内容 |
| --- | --- |
| 制度 | 都道府県・市町村の2層制（地方自治法） |
| 広域自治体 | 47都道府県（1都・1道・2府・43県） |
| 基礎自治体 | 1,718市町村（市792・町743・村183）＋特別区23 |
| 大都市の特例 | 指定都市20（行政区175）、中核市62、施行時特例市23 |
| 数値の基準 | 市町村数は2026年時点（2018年10月以降変化なし） |

### 行政区分の階層

```
国
└─ 都道府県（47）……… 広域自治体
    ├─ 市（792）……… 基礎自治体
    │   └─ 行政区（指定都市のみ。175）※自治体ではない
    ├─ 町（743）
    ├─ 村（183）
    └─ 特別区（東京23区のみ）
```

* 都道府県と市町村は上下関係ではなく、役割の違う対等な自治体とされる。
* 住所では「○○県○○郡○○町」のように**郡**が使われるが、郡は町村をまとめた地理上の名称で、役所や議会はない（後述）。

## 都道府県

### 都・道・府・県の違い

| 種別 | 数 | 該当 | 特徴 |
| --- | --- | --- | --- |
| **都** | 1 | 東京都 | 1943年に東京府と東京市を統合して成立。旧東京市の区域に特別区（23区）を置き、上下水道・消防など大都市として一体的に運営すべき仕事を都が担う（**都区制度**）。 |

## 市町村

### 市・町・村の違い

* **市** … 地方自治法では、人口5万人以上、中心市街地の戸数が全体の6割以上などの要件がある。ただし、合併の際の特例で人口3万人程度でも市になった例が多い。
* **町** … 町になる要件は都道府県の条例で定める（人口・市街地の割合など）。
* **村** … 特に要件はない。
* 市・町・村の間で権限の差はほとんどなく、主な違いは市に福祉事務所の設置が義務づけられていることなどに限られる。

### 大都市の特例

人口の多い市には、都道府県の仕事の一部が移される。

| 区分 | 要件 | 数 | 主な特徴 |
| --- | --- | --- | --- |
| **指定都市**（政令指定都市） | 人口50万人以上（実際にはおおむね70万人以上）で政令で指定 | 20 | 都道府県とほぼ同じ権限を持つ。市内を**行政区**（計175）に分ける。 |
| **中核市** | 人口20万人以上 | 62 | 保健所の設置など、福祉・保健・都市計画の権限の多くを持つ。 |
| **施行時特例市** | 旧特例市制度（2015年廃止）の対象だった市 | 23 | 旧特例市としての権限を引き続き持つ経過措置。 |

* **指定都市（20）** … 札幌、仙台、さいたま、千葉、川崎、横浜、相模原、新潟、静岡、浜松、名古屋、京都、大阪、堺、神戸、岡山、広島、北九州、福岡、熊本。最初の指定は1956年の5市（大阪・名古屋・京都・横浜・神戸）で、最も新しいのは2012年の熊本市。
* 指定都市の**行政区**は市役所の出先として置かれる区で、区長は市の職員、区議会はない。東京23区の**特別区**が独立した自治体（区長は選挙で選ばれ、区議会がある）であるのとは性格が異なる。

### 郡

* **郡**は明治期の郡区町村編制法（1878年）で置かれ、1890年の郡制で郡会を持つ自治体となったが、1921年の法律で郡制の廃止が決まり（1923年施行）、1926年には郡役所も廃止された。
* 現在は町村の所在を示す地理上の名称として住所に残るだけで、行政上の権限はない。市は郡に属さない。
* 平成の大合併で郡内の町村がすべて市に合併し、消滅した郡も多い。

### その他の区分

* **北海道の総合振興局・振興局** … 道の出先機関で、9つの総合振興局と5つの振興局がある（2010年に旧14支庁から再編）。
* **東京都の支庁** … 島しょ部に大島・三宅・八丈・小笠原の4支庁を置く。
* **北方領土** … 歯舞群島・色丹島・国後島・択捉島には、日本の行政上、色丹村・泊村・留夜別村・留別村・紗那村・蘂取村の6村があるとされる（北海道根室振興局の管内）。ロシアが実効支配しているため、1,718の市町村数には含まれない。
* **竹島** … 日本は島根県隠岐の島町に属するとしているが、韓国が実効支配している。

## 地方区分

「北海道地方」「東北地方」などの地方区分は法律に定められたものではなく、地理の教科書や統計でよく使われる慣習的な区分である。

| 地方 | 都道府県 | 補足 |
| --- | --- | --- |
| 北海道 | 北海道 | |
| 東北 | 青森・岩手・宮城・秋田・山形・福島 | 新潟県を含めることもある |
| 関東 | 茨城・栃木・群馬・埼玉・千葉・東京・神奈川 | 山梨県を含めた「首都圏」もよく使われる |
| 中部 | 新潟・富山・石川・福井・山梨・長野・岐阜・静岡・愛知 | 北陸・甲信越・東海などに細分される |
| 近畿 | 三重・滋賀・京都・大阪・兵庫・奈良・和歌山 | 三重県は東海に含めることもある。「関西」とほぼ同じ範囲 |
| 中国 | 鳥取・島根・岡山・広島・山口 | 日本海側の山陰、瀬戸内海側の山陽に分かれる |
| 四国 | 徳島・香川・愛媛・高知 | 中国地方とあわせて「中国・四国」とすることもある |
| 九州 | 福岡・佐賀・長崎・熊本・大分・宮崎・鹿児島・沖縄 | 沖縄を分けて「九州・沖縄」とすることも多い |

国の出先機関や電力会社などは、それぞれ独自の区分で地域を分けており、範囲は必ずしも一致しない。

## 歴史

### 古代〜近世 ― 令制国と藩

* 古代律令制のもとで、全国は**五畿七道**に分けられ、その下に約60余りの**国**（令制国）と**郡**が置かれた。「武蔵」「摂津」「筑前」などの旧国名は、現在も地名や呼び名に残っている。
* 江戸時代には、幕府の直轄地（天領）と大名の領地（藩）が入り組んで存在した。

### 明治 ― 廃藩置県と府県統合

* 1871年の**廃藩置県**で、藩が廃止されて県が置かれた。当初は3府302県にのぼったが、同年中に3府72県に統合され、その後も統廃合を繰り返した。
* 1888年に香川県が愛媛県から分かれて**3府43県**となり、これが現在の府県の枠組みの元になった。北海道は1886年に**北海道庁**が置かれ、府県とは別の扱いだった。

### 市町村合併の歴史

市町村の数は、3度の大規模な合併で大きく減った。

| 時期 | 合併前 | 合併後 | 背景 |
| --- | --- | --- | --- |
| **明治の大合併** | 71,314（1888年） | 15,859（1889年） | 市制・町村制の施行。小学校の運営などに必要な規模（約300〜500戸）を目安に統合 |
| **昭和の大合併** | 9,868（1953年） | 3,472（1961年） | 町村合併促進法。新制中学校を運営できる規模（人口約8,000人）を目安に統合 |
| **平成の大合併** | 3,232（1999年3月） | 1,727（2010年3月） | 地方分権の受け皿づくりと財政基盤の強化。合併特例債などで合併を促した |

* 平成の大合併の後も小規模な合併が続き、2014年に**1,718**となった。2018年10月に福岡県那珂川町が市制を施行して市792・町743・村183となり、以後は変わっていない。

### 戦後の地方自治

* 1943年、戦時体制のもとで東京府と東京市が統合されて**東京都**が誕生した。
* 1947年の日本国憲法・地方自治法の施行で、都道府県知事が公選制となり、北海道は「道」として府県と同格の自治体になった。
* 1956年に**指定都市**制度、1995年に**中核市**制度、2000年に**特例市**制度（2015年廃止）が始まり、大都市への権限移譲が進んだ。
* 1972年に沖縄が日本に復帰し、沖縄県が置かれて現在の**47都道府県**となった。

## 課題

* **人口減少と小規模町村** … 人口1万人未満の町村が多数あり、職員や財源の不足が課題となっている。合併に代わり、近隣の市町村が連携して行政サービスを担う「連携中枢都市圏」「定住自立圏」などの広域連携が進められている。
* **道州制の議論** … 都道府県を廃止・統合して、より広い「道」や「州」を置く**道州制**が2000年代を中心に議論されたが、実現の見通しは立っていない。
* **大都市制度** … 指定都市と道府県の二重行政の解消をめぐり、大阪都構想や、指定都市を道府県から独立させる「特別自治市」の構想などが議論されている。

## 出典

数値は各出典の公表時点のもの（2026年10月確認）。都道府県別の市町村数は2019年5月時点の一覧によるが、2018年10月以降に市町村数の変化はなく、2026年時点の全国の合計（1,718）と一致する。地方区分や令制国、郡制の沿革などの通説的な事項には、個別の出典を付けていないものがある。
