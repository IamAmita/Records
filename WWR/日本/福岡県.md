# 福岡県

**福岡県（ふくおかけん、Fukuoka Prefecture）**は、九州の北部に位置する県。県庁所在地は福岡市。

人口は約507万人で全国9位、九州7県の中では最多である。福岡市・北九州市という2つの政令指定都市を持ち、九州の行政・経済・交通の中心となっている。朝鮮半島や中国大陸に近いことから、古代から大陸との交流の玄関口として栄え、大宰府・鴻臚館・博多の港がその役割を担った。近代には筑豊・三池の炭田と官営八幡製鐵所によって日本の重工業化を支え、現在は商業・サービス業の集積に加えて、自動車・半導体産業や「あまおう」に代表される農業でも知られる。

### 4つの地域

県は大きく4つの地域に分けられ、それぞれ異なる性格を持つ。

| 地域 | 主な都市 | 特徴 |

| **福岡地域** | 福岡市・糸島市・宗像市・太宰府市など（県北西部） | 九州の中枢機能と第3次産業の中心。世界遺産「神宿る島」宗像・沖ノ島がある |

## 地理

### 位置

九州の北部に位置し、三方を海に囲まれている。

* **北** … 玄界灘・響灘に面する。関門海峡を隔てて本州の山口県と向かい合い、関門トンネル・関門橋で結ばれている。
* **東** … 周防灘に面し、大分県と接する。
* **南** … 熊本県と接する。
* **西** … 佐賀県と接し、南西部は有明海に面する。

朝鮮半島の釜山までは約200kmで、東京より大陸のほうが近い。この地理的条件が、古代から現代まで続く福岡とアジアとの深い結びつきの背景になっている。

### 地形

* **山地** … 東部には英彦山（ひこさん）などの山地、南部には耳納山地や、大分県との境に県の最高峰・**釈迦岳（約1,230m）**がそびえる。県土の約45%を森林が占める。
* **平野** … 南西部の**筑紫平野**は九州最大の平野で、有明海に面する干拓地も広がる。北部には福岡平野・直方平野などがある。
* **河川** … 九州最大の河川である**筑後川**が筑紫平野を潤して有明海に注ぐ。北部では遠賀川が筑豊地域を流れて響灘に注ぐ。

### 海と島

* **玄界灘** … 対馬海流が流れる好漁場で、マダイなどの漁業が盛ん。沖合には、島全体が御神体とされる**沖ノ島**がある。
* **有明海** … 干満の差が大きい内海で、ノリの養殖が盛ん。
* 福岡市の**博多湾**には志賀島・能古島などがあり、志賀島は「漢委奴国王」の金印が発見された場所として知られる。

### 気候

大部分は日本海側気候と太平洋側気候の中間的な性格を持ち、比較的温暖である。

* 福岡（福岡市）の年平均気温は17.3℃、年降水量は1,686.9mm（1991〜2020年の平年値）。
* 梅雨期から夏にかけて雨が多く、近年は2017年の九州北部豪雨など、線状降水帯による豪雨災害がたびたび発生している。
* 冬は日本海からの季節風の影響で曇りの日が多いが、平野部の積雪は少ない。

## 歴史

### 古代 ― 大陸への玄関口

* 弥生時代には大陸から稲作や金属器がいち早く伝わった。福岡平野には「奴国（なこく）」と呼ばれるクニがあったとされる。
* 1784年に志賀島で発見された**金印「漢委奴国王」**は、57年に後漢の光武帝が奴国の王に与えたものと考えられており、国宝として福岡市博物館に収蔵されている。
* 4世紀以来、玄界灘の沖ノ島では航海の安全を祈る国家的な祭祀が行われた。沖ノ島と宗像大社などは、2017年に**「神宿る島」宗像・沖ノ島と関連遺産群**として世界文化遺産に登録された。
* 663年の白村江の戦いで唐・新羅の連合軍に敗れたのち、大宰府を守るために664年に**水城（みずき）**、665年に**大野城**が築かれた。
* **大宰府**は九州全体を治め、外交・防衛を担う役所で、「遠の朝廷（とおのみかど）」と呼ばれた。博多には外国使節を迎える**鴻臚館**が置かれた。901年には菅原道真が大宰府に左遷され、その墓所の上に現在の太宰府天満宮が建てられた。

### 中世 ― 国際貿易港・博多

* 博多は日宋貿易・日明貿易の拠点として栄え、中国の商人も住む国際的な港町となった。
* 1274年（**文永の役**）と1281年（**弘安の役**）の2度、元・高麗の軍が博多湾に襲来した（元寇）。鎌倉幕府は文永の役の後、博多湾沿岸約20kmにわたって石垣の**元寇防塁**を築いた。
* 戦国時代には大友氏・龍造寺氏・島津氏などが争い、博多の町はたびたび戦火に見舞われた。

### 近世 ― 福岡藩と城下町

* 1600年の関ヶ原の戦いの功により、**黒田長政**が筑前国に入った。長政は1601年に**福岡城**の築城に着手し、黒田家の故郷である備前国福岡（現在の岡山県）にちなんで、この地を「福岡」と名づけた。
* こうして、那珂川を挟んで西に武士の町「福岡」、東に商人の町「博多」が並ぶ双子都市が生まれた。
* 現在の県域には、福岡藩のほか、小倉藩・久留米藩・柳川藩などが置かれた。江戸時代には木ろう、博多織、久留米絣などの生産が盛んになった。

### 近代 ― 石炭と鉄の時代

* 1871年の廃藩置県で、旧藩をもとに8つの県が置かれた。同年に福岡県・小倉県・三潴県の3県に統合され、1876年に3県が統合されて、ほぼ現在の県域が確定した。
* 1889年に**福岡市**が誕生した。市名をめぐって「福岡」派と「博多」派が対立し、市会で1票差で「福岡」に決まった。博多の名は、駅名や区名として残っている。
* **筑豊炭田**・**三池炭鉱**（大牟田市）の石炭が日本の近代化を支えた。三池炭鉱は1889年に三井に払い下げられ、採掘が本格化した。
* 石炭と、中国大陸からの鉄鉱石の輸入の便を背景に、1897年に**官営八幡製鐵所**が設立され、1901年に操業を開始した。北九州は日本の重工業の中心地となった。八幡製鐵所と三池炭鉱・三池港は、2015年に**明治日本の産業革命遺産**として世界文化遺産に登録された。

### 戦後

* 1950年代末からのエネルギー革命で石炭産業は衰退した。1959〜60年には三池炭鉱で大規模な労働争議（**三池争議**）が起き、1963年には炭じん爆発事故で458人が亡くなった。三池炭鉱は1997年に閉山した。
* 1963年、門司・小倉・若松・八幡・戸畑の5市が合併して**北九州市**が誕生し、同年、九州初の政令指定都市となった。
* 1972年、**福岡市**が政令指定都市となった。1975年に山陽新幹線が博多まで開通した。
* 1989年に福岡市でアジア太平洋博覧会が開かれた。

### 現代

* 2005年に**九州国立博物館**（太宰府市）が開館した。同年には福岡県西方沖地震が発生した。
* 2011年に九州新幹線（鹿児島ルート）が全線開業し、博多駅が九州の新幹線網の起点となった。
* 2017年の九州北部豪雨では、朝倉市などで大きな被害が出た。
* 福岡市では、天神・博多駅周辺の大規模な再開発が進められている。

## 経済

福岡県は九州最大の経済圏であり、九州の経済・行政・交通の中枢を担う。

### 規模と産業構造

* **県内総生産**は名目で20兆1,872億円（2022年度）で、九州7県の中で最大。
* 産業別では**第3次産業が79.0%**を占め、第2次産業は19.4%（2022年度）。
* 県内企業の99.8%を中小企業が占める。

### 都市ごとの経済の顔

| 都市・地域 | 性格 |
| --- | --- |
| 福岡市 | 九州の中枢都市。国の出先機関や企業の九州支社が集まる「支店経済」の都市で、卸売・小売・サービス業・情報通信業が盛ん。天神・博多駅周辺で再開発が進む |
| 北九州市 | 鉄鋼・化学・機械などの「ものづくりの街」。公害を克服した経験から、環境・リサイクル産業にも力を入れる |
| 京築・筑豊地域（苅田町・宮若市など） | 自動車工場とその関連企業の集積地 |
| 久留米市 | ゴム工業の発祥地として知られ、筑後地域の中心都市 |
| 大牟田市 | 三池炭鉱を基盤とした化学工業の街 |

### 製造業 ― 鉄鋼から自動車・半導体へ

* 北九州の鉄鋼・化学などの基礎素材産業に加え、県内には自動車の完成車工場が3つある（苅田町の日産自動車九州・日産車体九州、宮若市のトヨタ自動車九州）。1976年に日産自動車が苅田町で生産を始めたのをきっかけに工場の立地が相次ぎ、部品・車両開発・組込みソフトウェアなどの関連産業も集まって、北部九州は国内有数の自動車産業の集積地となった。
* 半導体関連産業も北九州地域を中心に集積している。

### 農林水産業

* 筑紫平野を中心に米・麦の生産が盛んで、水田の割合が高い。
* いちごの産出額は全国2位で、ブランドいちご**「あまおう」**は販売単価日本一を長年続けている。
* 八女市の**八女茶**、ラーメン用小麦「ラー麦」、たけのこ（全国1位）なども知られる。
* 水産業では玄界灘のマダイ、有明海のノリ養殖が盛ん。博多の名物「辛子明太子」は水産加工品として全国に知られる。

### 交通・国際交流

* **博多駅**は山陽新幹線・九州新幹線の結節点で、九州各地への交通の拠点となっている。
* **福岡空港**は都心に近く、国内線・国際線ともに九州最大の空港である。
* **博多港**は韓国・釜山との定期航路を持つ国際旅客港で、外国航路の乗降人員は約120万人（2024年）にのぼる。
* アジアに近い地の利を生かし、留学生や外国人観光客の受け入れ、アジア諸国との経済交流が進められている。

### 課題

* **地域間の格差** … 人口は福岡市とその周辺に集中する一方、筑豊地域や筑後地域の一部では人口減少と高齢化が進んでいる。
* **産業の転換** … 石炭産業の衰退後、旧産炭地の雇用や地域経済の再生が長年の課題となってきた。
* **防災** … 線状降水帯による豪雨災害が相次いでおり、治水・土砂災害対策が求められている。
