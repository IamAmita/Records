# 大阪府

**大阪府（おおさかふ、Osaka Prefecture）**は、日本の近畿地方の中央部に位置する府。府庁所在地は大阪市。都道府県のうち「府」は大阪府と京都府の2つだけである。

面積は全国で2番目に小さい一方、人口は約876万人で、東京都・神奈川県に次ぐ全国3位。古代には難波宮が置かれ、江戸時代には「天下の台所」と呼ばれた商業の中心地として栄えた。現在も西日本最大の経済圏の中核であり、中小企業を中心とするものづくりの集積、関西国際空港を玄関口とする国際交流、2025年の大阪・関西万博などで知られる。

## 地理

### 位置と地形

近畿地方の中央部に位置し、西は大阪湾に面して、残る三方を山地に囲まれている。府域は北から南へやや弓なりに湾曲した形をしている。

* **北** … 北摂山地を境に京都府・兵庫県と接する。
* **東** … 生駒山地・金剛山地を境に奈良県と接する。
* **南** … 和泉山脈を境に和歌山県と接する。
* **西** … 大阪湾に面し、湾岸部は大部分が埋立地や港湾・工業地帯になっている。

山地に囲まれた内側には**大阪平野**が広がり、府の人口の大部分が平野部に住む。府内の最高地点は奈良県との境にある金剛山の山腹で、標高は1,053m。

平野の中央には上町台地が南北に延びる。大阪城・難波宮跡・四天王寺など古い歴史を持つ場所は、この台地上やその縁に集まっている。その東側の河内平野は、かつて海や湖（河内湖）だった場所が淀川・大和川の土砂で埋まってできた低地である。

### 旧国

現在の府域は、近代以前の3つの国にまたがる。

* **摂津国**（東部）… 大阪市の大部分と北大阪地域。摂津国の西部は現在の兵庫県に属する。
* **河内国** … 府の東部。北河内・中河内・南河内地域。
* **和泉国** … 府の南西部。堺市・泉州地域。

「河内」「泉州」などの地域名は、今もこの旧国名に由来している。

### 河川

* **淀川** … 琵琶湖を水源とし、京都府から流れ込んで大阪湾に注ぐ。府民の重要な水源である。明治時代に洪水対策として新淀川が開削された。
* **大和川** … 奈良盆地から流れ出る川。江戸時代の1704年に、河内平野を北へ流れていた流路を西へ付け替える工事が行われ、現在の流れになった。大阪市と堺市の境界になっている。

### 臨海部

大阪湾岸では明治以降に埋め立てが進み、港湾と重化学工業の地帯（阪神工業地帯の一部）が形成された。

* 泉州沖の人工島には**関西国際空港**がある。1994年9月に、世界初の完全な人工島による海上空港として開港した。
* 大阪市の人工島**夢洲**では2025年に大阪・関西万博が開かれ、統合型リゾート（IR）の建設も進められている。

### 気候

瀬戸内海式気候に属し、比較的温暖で降水量が少ない。

* 大阪（大阪市中央区）の年平均気温は17.1℃、年降水量は1,338.3mm（1991〜2020年の平年値）。
* 夏は蒸し暑く、都市部ではヒートアイランド現象により熱帯夜が多い。
* 冬は温暖で、平野部の積雪はまれである。

## 歴史

### 古代 ― 古墳と難波

* 古墳時代の最盛期（4世紀後半〜5世紀後半）には、大阪湾沿岸の平野に巨大な古墳が築かれた。日本最大の前方後円墳である仁徳天皇陵古墳（大山古墳、堺市）を含む**百舌鳥・古市古墳群**（堺市・羽曳野市・藤井寺市の49基）は、2019年に世界文化遺産に登録された。
* 現在の大阪市一帯は**難波（なにわ）**と呼ばれ、大陸や朝鮮半島との交流の窓口となる港だった。
* 593年、聖徳太子によって**四天王寺**が建立された。645年、大化の改新ののち孝徳天皇が都を**難波長柄豊碕宮（前期難波宮）**に移した。

### 中世 ― 自治都市堺と石山本願寺

* 南部の**堺**は、室町時代から戦国時代にかけて日明貿易・南蛮貿易の港として栄えた。有力商人（会合衆）が町を治める自治都市で、鉄砲の生産地としても知られ、千利休などの茶人を生んだ。
* 1496年、浄土真宗の蓮如が、現在の大阪城がある場所に大坂坊舎（のちの**石山本願寺**）の建立に着手した。周辺の寺内町が大坂の町の原型となった。本願寺は織田信長と約10年にわたって争い（石山合戦）、1580年に明け渡された。

### 近世 ― 大坂城と「天下の台所」

* 本願寺の跡地に**豊臣秀吉**が1583年から**大坂城**を築き、城下町大坂を整えた。
* 1615年の大坂夏の陣で豊臣家が滅亡した。その後、江戸幕府は城を再建し、大坂を幕府の直轄地とした。
* 江戸時代の大坂は全国の物資が集まる商業都市として発展し、**「天下の台所」**と呼ばれた。中之島周辺には諸藩の蔵屋敷が並び、年貢米や特産物が取引された。1730年には幕府が**堂島米会所**を公認し、組織的な先物取引所の先駆けとして世界的に知られている。
* 1704年には**大和川の付け替え**が行われ、旧流路の跡地が新田として開発された。
* 経済力を背景に、井原西鶴の浮世草子、近松門左衛門の人形浄瑠璃（現在の文楽）などの町人文化が花開いた。

### 近代 ― 府の成立と「大大阪」

* 1868年に**大阪府**が置かれた。南部は**堺県**とされ、堺県はその後周辺の県や奈良県を合併して大きな県となったが、1881年に大阪府へ編入された。1887年には大和地方が分離して奈良県が再び置かれ、現在の府域がほぼ定まった。
* 1889年に大阪市が誕生した。繊維工業を中心に近代工業が発達し、大阪は「東洋のマンチェスター」と呼ばれた。
* 1925年に大阪市が周辺町村を編入し、面積・人口ともに東京市を抜いて日本最大の都市となった（**「大大阪」**の時代）。1931年には市民の寄付で大阪城天守閣が復興され、1933年に地下鉄、1937年に御堂筋が完成した。

### 戦中・戦後

* 1945年3月13日深夜〜14日未明の第1次大阪大空襲では3,987人が亡くなった。大阪への空襲は大小50回を超え、市街地の多くが焼失した。
* 1956年に大阪市が政令指定都市となった。高度経済成長期には臨海部の工業化と、千里ニュータウン（1962年入居開始）など郊外の住宅開発が進んだ。
* 1970年、吹田市の千里丘陵で**日本万国博覧会**が開催され、約6,422万人が訪れた。跡地は万博記念公園となっている。
* 1994年に**関西国際空港**が開港した。

### 現代

* 高度経済成長期以降、企業の本社機能が東京へ移る動きが続き、相対的な地位の低下（「地盤沈下」）が長年の課題となった。
* 2001年に大阪市此花区でユニバーサル・スタジオ・ジャパンが開業した。2006年には堺市が政令指定都市に移行した。
* 2010年代以降は、地域政党の大阪維新の会が府政・大阪市政を担い、大阪都構想を掲げた。2015年・2020年の住民投票はいずれも否決された。
* 2019年に百舌鳥・古市古墳群が世界遺産に登録された。
* 2025年4〜10月、大阪市の夢洲で**大阪・関西万博（2025年日本国際博覧会）**が開催され、一般来場者数は2,500万人を超えた。

## 経済

大阪府は西日本最大の経済圏であり、関西経済の中核を担う。

### 規模

* **府内総生産**は名目で43兆1,477億円（2022年度）で、国内総生産の7.6%を占める。全国では東京都に次ぐ規模である。
* 府の経済の中でも大阪市の比重は大きく、市内総生産は名目で21兆3,279億円（2022年度）と府の約半分を占める。

### 中小企業とものづくり

* 府内企業の**99.6%は中小企業**で、中小企業の数は東京都に次いで多い。製造品出荷額等でも中小規模の事業所が6割を占め、中小企業が大阪経済の土台になっている。
* 民営事業所に占める製造業の割合は全国平均より高く、ものづくりの集積度が高い。
* 地域ごとの代表的な産業

| 地域 | 主な産業 |
| --- | --- |
| 大阪市 | 卸売・商業・金融・サービス。船場の繊維問屋、「くすりの町」道修町の製薬会社 |
| 東大阪市・八尾市など | 金属加工・機械部品などの町工場が密集する、全国有数の中小製造業の集積地 |
| 門真市・守口市など（北河内） | 電機産業の拠点 |
| 堺市・泉北臨海部 | 鉄鋼・石油化学などの臨海工業。伝統の刃物や自転車関連産業 |
| 泉州地域 | タオル・綿織物などの繊維産業、関西国際空港を拠点とする物流 |
| 北大阪地域 | 大学・研究機関・医薬品・バイオ関連の研究開発拠点 |

### 金融・商業

* 大阪市北浜の**大阪取引所**は、江戸時代の堂島米会所の伝統を引き継ぐ取引所で、2014年に東京証券取引所のデリバティブ市場を統合し、日経225先物などを扱う日本のデリバティブ取引の中心となっている。
* 梅田（キタ）・難波（ミナミ）を二大拠点として、商業・オフィスが集積している。

### 観光・国際交流

* 大阪城・道頓堀・通天閣・ユニバーサル・スタジオ・ジャパン・百舌鳥・古市古墳群などに国内外から多くの人が訪れる。2019年の訪日外国人客数は約1,230万人にのぼった。
* 関西国際空港はアジアをはじめ世界各地と結ばれ、24時間運用の国際拠点空港として旅客・貨物の両面で関西の玄関口となっている。
* 2025年の大阪・関西万博の会場跡地である夢洲では、国際会議場・ホテル・カジノなどからなる**統合型リゾート（IR）**の計画が2023年に国の認定を受け、2025年4月に建設工事に着手した。

### 課題

* **本社機能の流出と東京との格差** … 大阪発祥の大企業でも本社機能を東京へ移す例が多く、経済の相対的な地位の回復が長年の課題である。
* **二重行政** … 府と大阪市の役割分担をめぐる議論が続き、都構想の否決後も府市連携のあり方が問われている。
* **人口減少・高齢化** … 府の人口は減少局面にあり、郊外のニュータウンでは住民の高齢化と住宅の老朽化が進んでいる。
* **防災** … 南海トラフ地震による津波や高潮が想定され、大阪湾岸の低地での対策が求められている。
