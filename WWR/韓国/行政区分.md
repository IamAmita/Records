# 韓国の行政区分

大韓民国（韓国）の地方行政は、**広域自治団体**（特別市・広域市・道など）と**基礎自治団体**（市・郡・自治区）の**2層制**を基本とする。2026年7月1日に光州広域市と全羅南道が統合されて**全南光州統合特別市**が発足し、広域自治団体は17から16になった。基礎自治団体は227（市75・郡82・自治区70）である。

基礎自治団体の下には、自治体ではない行政単位として**邑（ウプ）・面（ミョン）・洞（トン）**が置かれ、住民サービスの窓口となっている。道の区分は、朝鮮王朝の**八道**と、1896年に定められた**13道**に由来しており、北朝鮮の道と共通の起源を持つ。

## 概要

| 項目 | 内容 |
| --- | --- |
| 制度 | 広域自治団体・基礎自治団体の2層制（地方自治法） |
| 広域自治団体 | 16（特別市1・統合特別市1・広域市5・特別自治市1・道5・特別自治道3） |
| 基礎自治団体 | 227（市75・郡82・自治区70） |
| 下位の行政単位 | 邑・面・洞（約3,500） |
| 大都市の特例 | 特例市5（水原・高陽・龍仁・昌原・華城） |
| 数値の基準 | 2026年7月1日（全南光州統合特別市の発足・仁川の区再編の後） |

### 行政区分の階層

```
国
└─ 広域自治団体（16）
    ├─ 特別市・広域市・統合特別市
    │   ├─ 自治区 ── 洞
    │   └─ 郡 ──── 邑・面 ── 里
    ├─ 道・特別自治道
    │   ├─ 市 ──── （一般区）── 洞・邑・面
    │   └─ 郡 ──── 邑・面 ── 里
    └─ 特別自治市（世宗）── 洞・邑・面（基礎自治団体なし）
```

* **自治区**は特別市・広域市・統合特別市の区で、区長・区議会を持つ基礎自治団体である。
* 人口50万人以上の市には、自治体ではない**一般区**（行政区）を置くことができる（例: 水原市の4区）。日本の指定都市の行政区にあたる。
* 済州特別自治道と世宗特別自治市には基礎自治団体がなく、**1層制**となっている。済州道の済州市・西帰浦市は、市長を道知事が任命する**行政市**である。
* 洞・里の下には、さらに**統（トン）・班（パン）**という住民組織の単位がある。

### 全南光州統合特別市（2026年）

* 2026年3月に国会で特別法が可決され、**2026年7月1日**に光州広域市と全羅南道が統合されて発足した。韓国で初めての広域自治団体どうしの行政統合である。
* 正式名称は「全南光州統合特別市」、略称は**光州特別市**。人口は約320万人、面積は約12,363km²。
* 1986年に光州が直轄市として全羅南道から分離して以来、約40年ぶりに再び一つの自治体となった。
* 旧光州広域市の5区（東区・西区・南区・北区・光山区）は自治区として残り、旧全羅南道の5市（木浦・麗水・順天・羅州・光陽）と17郡もそのまま基礎自治団体となっている。
* 地域間の対立を和らげるため、庁舎を**光州（旧光州市庁）・務安（旧全南道庁）・順天（東部庁舎）**の3か所に分散している。
* 市長は長官級の待遇を受け、副市長は4人（次官級）。初代市長は2026年6月の地方選挙で選ばれた閔亨培（ミン・ヒョンベ）。
* 大邱・慶尚北道、大田・忠清南道の統合特別法も国会に提出されたが、地元の反対などから2026年2月に審議が保留され、成立していない。

### 特例市

* 人口100万人以上の市は**特例市**として、一般の市より多くの権限と、名称上の特別な地位を持つ。
* 2022年1月13日に水原市・高陽市・龍仁市（以上、京畿道）・昌原市（慶尚南道）の4市が特例市となり、2025年1月1日に京畿道華城市が5番目の特例市となった。
* 特例市は道に属したまま、日本の指定都市に近い権限を持つ（道から独立した広域市とは異なる）。

### 邑・面・洞

| 単位 | 置かれる場所 | 特徴 |
| --- | --- | --- |
| **邑** | 市・郡 | 人口2万人以上の都市的な地区。郡の中心地（郡庁所在地）の多くが邑。 |
| **面** | 市・郡 | 農漁村部の単位。 |
| **洞** | 市・自治区 | 都市部の単位。住民サービスを行う「行政洞」と、住所表示に使う「法定洞」がある。 |
| **里** | 邑・面の下 | 集落の単位。 |

* 邑・面・洞は全国に約3,500ある。いずれも基礎自治団体の出先機関で、議会はない。

### 仁川の区再編（2026年）

* 2026年7月1日、仁川広域市は1995年以来31年ぶりに区を再編し、**2郡8区から2郡9区**となった。
* 中区（内陸部）と東区を統合して**済物浦区**、中区の永宗島地域を分けて**永宗区**を新設した。
* 西区は京仁アラ運河を境に分割され、北側が**黔丹区**、南側が**西海区**（旧西区から改称）となった。

## 歴史

### 朝鮮王朝の八道と13道制

* 朝鮮王朝は全国を**八道**（京畿・忠清・全羅・慶尚・江原・黄海・平安・咸鏡）に分けた。各道の名は、道内の主要な2つの邑の名を合わせたもの（例: 慶州＋尚州＝慶尚）が多い。
* 1895年に一時23府制となったが、翌**1896年に13道制**に改められ、忠清・全羅・慶尚・平安・咸鏡の5道が南北に分割された。この13道が、現在の韓国・北朝鮮の道の原型である。

### 解放後 ― 道と直轄市の整備

* 1946年、ソウルが京畿道から分離して特別市となり、同年、済州島が全羅南道から分かれて**済州道**となった。
* 1963年、**釜山**が直轄市として慶尚南道から分離した。
* 1981年に**大邱・仁川**、1986年に**光州**、1989年に**大田**が直轄市となった。
* 1995年、直轄市は**広域市**に改称された。同時に、市と周辺の郡を統合する**都農複合形態の市**が多数誕生した。
* 1997年、**蔚山**が慶尚南道から分離して広域市となった。

### 地方自治の再開と特別自治体

* 地方議会は1961年の軍事クーデター後に停止されていたが、1991年に再開され、1995年に首長の直接選挙が始まった。
* 2006年、**済州特別自治道**が発足し、道内の市・郡は基礎自治団体ではなくなった。
* 2010年、馬山・昌原・鎮海の3市が統合して新しい**昌原市**となった。
* 2012年、行政機能の分散を目的に**世宗特別自治市**が発足した。
* 2023年6月に江原道が**江原特別自治道**、2024年1月に全羅北道が**全北特別自治道**となった。2023年7月には慶尚北道軍威郡が大邱広域市に編入された。
* 2024年1月、京畿道富川市が2016年に廃止した一般区（遠美区・素砂区・梧亭区）を復活させた。
* 2026年7月、**全南光州統合特別市**の発足と仁川の区再編により、現在の16広域自治団体・227基礎自治団体の体制となった。

### 以北5道

* 韓国政府は、1945年8月時点の行政区域に基づき、北朝鮮地域を**黄海道・平安南道・平安北道・咸鏡南道・咸鏡北道**の「**以北5道**」として扱い、行政安全部所属の**以北5道委員会**に名目上の道知事を置いている。
* 軍事境界線の北側となった京畿道・江原道の一部の市・郡も「未収復市郡」として扱われる。
* 北朝鮮の現在の行政区分は[北朝鮮の行政区分](../北朝鮮/行政区分.md)を参照。

## 課題

* **地方の人口減少と首都圏集中** … 首都圏に人口の半数以上が集中し、地方では「消滅危機」とされる郡が多い。政府は人口減少地域として89の市・郡・区を指定し、支援を行っている。
* **広域行政統合** … 地方の競争力を高めるため、広域自治団体どうしを統合する「メガシティ」構想が進められている。全南光州が初めて実現したが、大邱・慶北、大田・忠南は地元の合意が得られず、保留となっている。
* **行政区域と生活圏のずれ** … 人口が急増した新都市地域では、仁川の区再編や富川の一般区復活のように、区域の見直しが続いている。
