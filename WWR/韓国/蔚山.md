# 蔚山（蔚山広域市）

**蔚山（ウルサン、울산、Ulsan）**は、大韓民国の南東部、日本海（韓国では東海）に面する都市。正式名称は**蔚山広域市**で、道に属さない広域市として、道と同格の広域自治体になっている。

人口は約109万人。韓国最大級の重化学工業都市で、現代自動車、HD現代重工業、SKエナジーなどの大規模な工場が集まる。自動車・造船・石油精製・石油化学を中心に韓国の高度経済成長を支え、「韓国の産業首都」と呼ばれる。一方、市域の西には標高1,000m級の山々、中央には太和江、東には海岸があり、広大な農山村地域も含んでいる。

先史時代の捕鯨などを描いた**盤亀台岩刻画**が残り、近代にも長生浦が捕鯨基地として栄えたことから、鯨との関係が深い都市でもある。盤亀台岩刻画と川前里岩刻画を含む「盤亀川の岩刻画」は、2025年にユネスコ世界文化遺産に登録された。

### 韓国における位置づけ

* ソウル特別市のほかに6つある、道と同格の**広域市**の一つ。
* 1962年に韓国で最初の特定工業地区に指定され、重化学工業を中心とする輸出型工業都市へ急速に成長した。
* 周辺の釜山広域市・慶尚南道とあわせた「釜山・蔚山・慶南（プウルギョン）」地域は、首都圏に次ぐ大きな経済圏を形成している。
* 行政区画は、中区・南区・東区・北区の4区と、市域の約7割を占める蔚州郡からなる。工業・市街地だけでなく、農村、山地、海岸を広く含む都市である。

## 地理

### 位置

朝鮮半島の南東端に位置し、東は日本海に面する。

* **北** … 慶尚北道慶州市と接する。
* **西** … 慶尚北道清道郡、慶尚南道密陽市と接する。
* **南** … 釜山広域市機張郡、慶尚南道梁山市と接する。
* **東** … 日本海と蔚山湾に面する。

釜山の北約50km、慶州の南約30kmにあり、韓国南東部の臨海工業地域の中央に位置する。高速道路、鉄道、空港、港湾がそろい、釜山・慶州・浦項などの工業都市とも結びついている。

### 地形

* 市の中央を**太和江（テファガン）**が西から東へ流れ、北から来る東川と合流して蔚山湾に注ぐ。市街地は太和江の中・下流域を中心に形成されている。
* 河口部には、かつて農業地帯だった三山平野がある。工業化と市街地の拡大により、現在は商業・住宅・工業用地へ転換されている。
* 西部には迦智山、神仏山、肝月山などの標高1,000m級の山々が連なる。これらは周辺の山々とあわせて**嶺南アルプス**と呼ばれる。
* 東部の海岸には蔚山湾、方魚津、長生浦、温山、亭子などの港があり、大王岩公園、艮絶串、鎮下海水浴場などの海岸景観も見られる。
* 天然の良港、豊富な工業用水、大規模工場の建設に適した硬い地盤が、臨海工業都市の形成を支えた。

### 港

**蔚山港**は、蔚山本港、温山港、尾浦港、蔚山新港などからなる韓国最大の産業港の一つである。

* 原油、石油製品、液体化学品などの**液体バルク貨物**では韓国最大の取扱拠点である。
* 周囲の製油所・石油化学工場と専用埠頭やパイプラインで結ばれ、原料の輸入と製品の輸出を担う。
* 自動車の輸出、造船所への資材の搬入、完成した船舶の引き渡しにも利用される。
* 2024年の総貨物取扱量は約1億9,947万トンで、前年より3.6%増加した。

### 気候

海に面しているため、韓国の内陸部と比べて温暖な気候である。

* 年平均気温は14.1℃、1月平均は2.0℃、8月平均は25.9℃。
* 冬は比較的温暖で降雪が少ない。
* 夏は高温多湿で、梅雨や台風による大雨の影響を受けることがある。

## 歴史

### 先史時代 ― 盤亀川の岩刻画

* 蔚州郡を流れる盤亀川（行政上の名称は大谷川）沿いには、**盤亀台岩刻画**と**川前里岩刻画**が残る。
* 盤亀台岩刻画には鯨、亀、魚、サメ、鹿、虎、イノシシなど約300点の図像が刻まれている。船に乗った人々による捕鯨の過程も描かれ、先史時代の海洋漁労文化を示す貴重な資料となっている。
* 岩刻の伝統は紀元前5000年頃から9世紀頃まで、約6,000年にわたって続いたとされる。
* 2か所の岩刻画を含む「**盤亀川の岩刻画**」は、人間の創造性と長期間続いた文化的伝統を示すものとして、2025年にユネスコ世界文化遺産へ登録された。

### 古代〜朝鮮時代

* 三韓時代には辰韓に属し、その後、新羅の領域となった。新羅時代には屈阿火県が置かれた。
* 高麗時代には河曲・東津・虞風の3県が統合され、興麗府となった。
* 1413年、朝鮮王朝の太宗の時代に「蔚州」から**蔚山郡**へ改称された。
* 1597〜1598年の慶長の役（韓国では丁酉再乱）では、日本軍が加藤清正の設計による**蔚山倭城**を築いた。朝鮮・明の連合軍が二度にわたって攻撃し、城内の日本軍を極度の飢餓状態に追い込んだが、城を落とすことはできなかった。蔚山は日本軍が築いた南海岸の城郭線の東側の重要拠点だった。
* 戦後の1598年、蔚山は行政上の地位が都護府に引き上げられ、1895年に再び蔚山郡となった。

### 近代

* 1914年、彦陽郡が蔚山郡へ編入された。
* 1931年に蔚山面が蔚山邑へ、1936年に方魚津面が方魚津邑へ昇格した。
* 長生浦は20世紀に韓国を代表する捕鯨港となった。1986年に商業捕鯨が停止されると地域は衰退したが、その後は鯨博物館や鯨文化村などを中心とする文化・観光地区へ転換された。

### 工業都市への転換

* **1962年1月27日**、蔚山は韓国最初の特定工業地区に指定された。同年6月、蔚山郡の一部が蔚山市へ昇格した。
* 1964年に韓国初の大規模製油所である蔚山製油所が完成した。
* 1968年に現代自動車の工場が操業を始め、同年から石油化学工業団地の建設が進められた。
* 1970年代初めには現代造船所（現在のHD現代重工業）が建設され、自動車・造船・石油化学の三大産業が形成された。
* 全国から労働者が移住し、農漁村だった地域に大規模工場、住宅地、道路、港湾が急速に建設された。蔚山は韓国の輸出型工業化を象徴する都市となった。

### 広域市と環境再生

* 1985年に中区・南区が設置され、1988年には方魚津出張所が東区となった。
* 1995年、蔚山市と蔚山郡が統合された。
* 1997年7月15日、慶尚南道から分離して**蔚山広域市**となり、北区と蔚州郡が設置された。
* 急速な工業化は大気・水質汚染をもたらし、太和江は一時「死の川」と呼ばれた。その後、下水処理施設の整備、排水規制、生態復元が進み、サケや渡り鳥が戻る河川となった。2019年には太和江一帯が韓国第2号の**国家庭園**に指定された。

## 経済

蔚山は人口規模に対して工業生産・輸出額が非常に大きく、韓国で最も製造業への依存度が高い地域の一つである。

### 規模

* **地域内総生産（GRDP）**は名目で93兆9,561億ウォン（2024年、暫定値）。実質経済成長率は3.4%だった。
* **1人あたりGRDP**は8,519万4,000ウォン（2024年、暫定値）で、韓国の全国平均を大きく上回る。
* 2025年の輸出額は約**868億4,100万ドル**。石油製品、自動車、非鉄金属、船舶、化学製品などが主要な輸出品である。
* 2024年には、従業者10人以上の製造業事業所が1,860か所あった。

### 三大産業

| 分野 | 内容 |
| --- | --- |
| 自動車 | 現代自動車の大規模生産拠点を中心に、完成車、エンジン、部品、輸送・輸出施設が集積する。2024年の生産額は約71.4兆ウォンで、韓国の自動車生産額の24.2%を占めた |
| 造船・海洋 | 東区のHD現代重工業・尾浦造船所を中心とする世界有数の造船集積地。大型商船、特殊船、エンジン、海洋設備を生産する。2024年の生産額は約17.4兆ウォンで、国内シェアは23.7% |
| 石油精製・石油化学 | SKエナジー、S-OILなどの製油・化学企業が蔚山・尾浦国家産業団地と温山国家産業団地に集まる。2024年の石油化学生産額は約132.0兆ウォンで、国内シェアは29.1% |

### 産業団地と企業

* **蔚山・尾浦国家産業団地**は、自動車、造船、石油精製、石油化学を中心とする韓国最大級の臨海工業団地である。
* 南部の**温山国家産業団地**には、石油化学のほか、銅、亜鉛などの非鉄金属や基礎素材の企業が集まる。
* 巨大企業の完成品工場だけでなく、部品、機械、化学材料、港湾運送、保守・修理などの企業が近接し、大規模な産業クラスターを形成している。

### 新しい産業

化石燃料と重化学工業への依存度が高いため、脱炭素化は蔚山経済にとって大きな課題である。市は既存産業の高度化と並行して、次の分野を新たな成長産業として育成している。

* 水素の製造・輸送・利用を結びつける**水素経済**
* 電気自動車、水素燃料電池車、自動運転などの未来型自動車
* 浮体式洋上風力などの再生可能エネルギー
* 二次電池と先端化学材料
* バイオ、ゲノム、3Dプリンティング
* 造船技術を応用した洋上設備と環境対応船

### 課題

* **産業の集中** … 自動車・造船・石油化学への依存度が高く、世界景気、原油価格、海運・造船市況、主要輸出国の政策の影響を受けやすい。
* **脱炭素化** … 製油・石油化学などの炭素排出量が多い産業を維持しながら、低炭素型の生産設備とエネルギーへ転換する必要がある。
* **人口減少と高齢化** … 2026年7月の総人口は約111.7万人（外国人を含む）、65歳以上は約21.3万人だった。若者の流出と高齢化の進行は、産業人材と都市の持続性に関わる課題となっている。
* **産業と環境の両立** … 太和江の再生は成果を上げたが、大規模工業地帯の大気・水質管理、事故・災害対策を継続する必要がある。
