# ソウル（ソウル特別市）

**ソウル（서울、Seoul）**は、大韓民国の首都で、正式名称は**ソウル特別市**。韓国で唯一の「特別市」であり、道と同格の広域自治体として、自治体の中で最も高い地位に置かれている。

人口は約929万人で、韓国最大の都市。朝鮮半島の中西部、漢江の下流域に位置する。14世紀末に朝鮮王朝の都「漢陽（漢城）」となってから600年以上にわたって朝鮮半島の中心であり続け、現在も韓国の政治・経済・文化の中枢となっている。周辺の京畿道・仁川広域市とあわせた**首都圏**には、韓国の人口と経済の約半分が集中する。

### 「ソウル」という名前

「ソウル」は漢字のない固有の朝鮮語で、王のいる都を意味する言葉に由来するとされる。そのため、日本語でも漢字表記はなく、カタカナで書かれる。

この地の呼び名は、時代によって次のように変わってきた。

| 時期 | 名称 |
| --- | --- |
| 高麗時代 | 南京（ナムギョン） |
| 朝鮮時代（1394〜1910年） | 漢陽（ハニャン）、漢城府（ハンソンブ） |
| 日本統治期（1910〜1945年） | 京城府（けいじょうふ） |
| 1946年〜 | ソウル（1946年にソウル特別自由市、1949年にソウル特別市） |

### 首都圏への集中

* ソウルと京畿道・仁川広域市からなる首都圏は、2024年の地域内総生産で全国の52.8%を占める。
* 政府機関の一部は、首都機能の分散のために中部の世宗特別自治市へ移転したが、大統領府・国会・大企業の本社などは今もソウルに集まっている。

## 地理

### 位置と地形

朝鮮半島の中西部に位置し、周囲を京畿道に囲まれている。西に隣接する仁川を経て黄海に通じる。

* 市の中央を**漢江**が東から西へ流れ、市域を北側の「江北（カンブク）」と南側の「江南（カンナム）」に分けている。
* 周囲を山に囲まれた盆地状の地形で、北に**北漢山**、南に冠岳山などがそびえる。
* 朝鮮時代の都城は、北岳山・仁王山・南山・駱山の4つの山を結ぶ城壁（漢陽都城）で囲まれていた。この風水に基づいた立地が、都が置かれた理由の一つとされる。

### 市域の拡大

朝鮮時代の都は漢江の北側の城壁の内側に限られていたが、20世紀に入って市域が大きく広がった。

* 1963年、周辺の京畿道の町村を大規模に編入し、面積は約268km²から約605km²へと2倍以上になった。現在の江南区・瑞草区・松坡区などの漢江の南側の地域は、このとき編入された。
* 1970年代には「永東（ヨンドン）開発」と呼ばれる江南の大規模な区画整理が進められ、高層マンションとオフィス街が広がる現在の江南が形成された。

### 気候

大陸性の気候で、夏と冬の寒暖差が大きい。

* ソウルの年平均気温は12.8℃、年降水量は1,417.9mm（1991〜2020年の平年値）。
* 冬は大陸からの季節風で寒さが厳しく、氷点下の日が多い。
* 夏は高温多湿で、梅雨（長馬、チャンマ）の時期を中心に雨が集中する。

## 歴史

### 古代 ― 百済の都

* 新石器時代から人が暮らし、漢江沿いの岩寺洞などに遺跡が残る。
* 紀元前18年に建国されたとされる**百済**は、漢江流域の慰礼城を都とした。百済は475年に高句麗に都を奪われて南へ移り、その後、この地は高句麗、続いて新羅の支配下に入った。
* 高麗時代には、1067年に「南京」とされ、副都の一つとして重視された。

### 朝鮮王朝の都 ― 漢陽

* 1392年に朝鮮を建国した**李成桂（太祖）**は、1394年に都を開京（開城）から**漢陽**へ移した。翌1395年に名称を漢城府と改め、正宮の**景福宮**を建てた。
* 都は城壁で囲まれ、王宮・宗廟（王家の祖先を祀る廟）・官庁・市場が整えられた。**宗廟**は1995年、**昌徳宮**は1997年にユネスコの世界文化遺産に登録されている。
* 1592年から7年にわたる壬辰倭乱（文禄・慶長の役）で、景福宮をはじめ都の多くが焼失した。景福宮は19世紀に再建されるまで、270年余り廃墟のままだった。
* 1897年に大韓帝国が成立し、漢城はその首都となった。電車や鉄道などの近代的な設備が導入され始めた。

### 日本統治期 ― 京城

* 1910年の韓国併合により、漢城府は**京城府**と改められ、京畿道の一部とされた。景福宮の正面には朝鮮総督府の庁舎が建てられた。
* 1919年には、ソウルのタプコル公園を中心に**三・一独立運動**が起こった。

### 解放と朝鮮戦争

* 1945年の解放とともに、京城は「ソウル」と呼ばれるようになった。1946年に京畿道から分離して**ソウル特別自由市**となり、1949年に**ソウル特別市**となった。
* 1950年に朝鮮戦争が始まると、ソウルは北朝鮮軍に占領され、その後も占領と奪還が繰り返されて、市街地の多くが破壊された。

### 高度成長 ― 漢江の奇跡

* 1960年代以降、韓国は「**漢江の奇跡**」と呼ばれる急速な経済成長を遂げ、ソウルには全国から人口が流入した。
* 1963年の市域拡大と、1970年代の江南開発により、ソウルは漢江の両岸に広がる巨大都市になった。地下鉄1号線が1974年に開業し、交通網も整えられた。
* 1988年に**ソウルオリンピック**が開かれ、韓国の発展を世界に示した。

### 現代

* 1990年代以降は、人口が首都圏の新都市（京畿道）へ流出し、ソウル市の人口は1,000万人を下回って減少が続いている。
* 2002年には日韓共催のサッカー・ワールドカップが開かれた。
* 2005年、都心の高架道路を撤去して**清渓川（チョンゲチョン）**を約5.8kmにわたって復元した。都市再生の事例として国際的に知られている。
* 2012年に世宗特別自治市が発足し、中央官庁の一部が移転した。

## 経済

ソウルは韓国経済の中枢であり、大企業の本社、金融機関、情報通信産業、文化産業が集中している。

### 規模

* **地域内総生産（GRDP）**は名目で約575兆ウォン（2024年）で、京畿道（約651兆ウォン）に次いで韓国の広域自治体で2位。
* 首都圏（ソウル・京畿道・仁川）は、全国の地域内総生産の52.8%を占める（2024年）。

### 産業構造

* 製造業の比重は小さく、金融・保険、情報通信、専門サービス、卸売・小売、文化・観光などのサービス業が経済の中心である。
* サムスン・LG・SKなど大企業グループの本社機能や、外資系企業の韓国拠点の多くがソウルに置かれている。

### 地区ごとの経済の顔

| 地区 | 性格 |
| --- | --- |
| 光化門・鍾路・中区（都心） | 景福宮・大統領府に近い歴史的な中心地。官庁・大企業本社・報道機関が集まる |
| 汝矣島（ヨイド） | 漢江の中洲。国会議事堂のほか、証券会社・放送局が集まる「韓国のウォール街」 |
| 江南・瑞草 | 1970年代以降に開発された新都心。テヘラン路にはIT企業やスタートアップが集積する |
| 明洞・東大門 | 明洞はショッピング街、東大門は衣料品の卸売市場とファッションの街 |
| 龍山・梨泰院 | 交通の要衝。国際色の強い繁華街を持つ |

### 文化産業・観光

* K-POP・ドラマ・映画などの**韓流（ハルリュ）**コンテンツの制作拠点が集まり、文化産業はソウルの重要な輸出産業となっている。
* 景福宮・昌徳宮などの王宮、明洞・弘大（ホンデ）などの繁華街に、日本をはじめ世界中から観光客が訪れる。

### 交通

* 首都圏の空の玄関口は、仁川広域市にある**仁川国際空港**。ソウル市内の**金浦空港**は国内線と、東京（羽田）・大阪（関西）などとの近距離国際線を扱う。
* 地下鉄・広域鉄道の路線網は世界有数の規模で、KTX（高速鉄道）がソウル駅から釜山などの地方都市と結んでいる。

### 課題

* **一極集中** … 人口・企業・大学・資金が首都圏に集中し、地方との格差が国全体の課題となっている。
* **住宅価格の高騰** … 江南を中心にマンション価格が高騰し、若年層の住宅取得が難しくなっている。
* **少子化と人口流出** … ソウルの出生率は韓国の中でも特に低く、住宅費の高さなどから周辺の京畿道への人口流出も続いている。
