# テンプレート

WWRの各地域のページは、次の4つの項目で構成する。

1. **概要**
2. **地理**
3. **歴史**
4. **経済**

各項目の後に、参照した資料をまとめた**出典**を置く。

## 各項目に書くこと

| 項目 | 内容 |
| --- | --- |
| 概要 | 正式名称・国内での位置づけ・面積・人口・行政区画・首長などの基本情報。名前の由来など、その地域を知るうえで前提となる事柄 |
| 地理 | 位置と地形、河川・海・島などの特徴的な自然、気候 |
| 歴史 | 古代から現代までを時代順に。見出しは「時代 ― 特徴」の形にする |
| 経済 | 経済の規模、主な産業、交通・観光、課題 |
