# ウラジオストク

**ウラジオストク（Владивосток、Vladivostok）**は、ロシア連邦の極東、日本海に面した港湾都市。**沿海地方**の行政の中心地で、2018年からはロシア極東全体を管轄する**極東連邦管区**の中心都市でもある。

人口は約59万人（市域）で、ロシア極東を代表する都市の一つ。1860年に軍の拠点として建設され、ロシア海軍の**太平洋艦隊**の本拠地、シベリア鉄道の終着駅、ロシアの太平洋側の玄関口として発展した。日本の新潟から約800kmと近く、明治以降は多くの日本人が暮らした。ソ連時代には軍事上の理由から外国人の立ち入りが禁じられた「閉鎖都市」だったが、1992年に開放され、現在はアジア太平洋地域との経済交流の拠点づくりが進められている。

### 名前

ロシア語で「ヴラジ（владеть、支配する）」と「ヴォストーク（восток、東）」を組み合わせた名前で、「東方を支配せよ」という意味とされる。ロシアが東アジアへ進出する拠点として建設された経緯を表している。日本では明治時代から「浦潮（うらじお）」「浦塩斯徳」などと書かれた。

### 人口

* 2025年1月1日時点の人口は、市域で59万1,628人、周辺の島や集落を含むウラジオストク都市管区で62万5,630人。
* 市域の人口では、2025年に同じ極東のハバロフスク（61万5,600人）に抜かれた。都市管区で比べると、ウラジオストクのほうが多い。

### 沿海地方

* ウラジオストクを中心都市とする沿海地方は、ロシア極東の南東端に位置する。北はハバロフスク地方、西から南西は中国と北朝鮮に接し、東から南は日本海に面する。

## 地理

### 位置と地形

ロシア極東の南端、日本海に突き出したムラヴィヨフ・アムールスキー半島の先端に位置する。

* 市の中心は、半島の南端にある細長い入り江**金角湾（ゾロトイ・ログ湾）**を囲むように広がる。天然の良港で、ロシアの太平洋側の主要な港となった。
* 市域は丘陵が多く、坂の多い街並みが特徴。旧市街には帝政ロシア時代の欧風建築が残り、アジアにありながらヨーロッパ的な景観を持つ。
* 市の南には**ルースキー島**があり、2012年に本土との間に巨大な斜張橋（ルースキー島連絡橋）が架けられた。

### 日本との距離

* 日本海を挟んで日本と向かい合い、新潟・富山などの日本海側の都市と近い。成田空港などからの直行便で日本と結ばれていた時期もあり、「日本から一番近いヨーロッパ」とも呼ばれた。

### 気候

冬は寒く乾燥し、夏は湿度が高い季節風（モンスーン）型の気候である。

* ウラジオストクの年平均気温は4.2℃、年降水量は856.9mm（気象庁の世界の平年値から計算）。
* 最も寒い1月の平均気温は−11.9℃で、金角湾も凍ることがある。最も暑い8月は20.0℃。
* 降水は7〜8月に集中し、春から初夏には海霧が出やすい。

## 歴史

### 建設 ― 東方の拠点

* 1858年のアイグン条約と1860年の北京条約により、清からウスリー川以東の地域（現在の沿海地方）がロシアに割譲された。
* 1860年7月2日、ロシア海軍の輸送船「マンジュール号」が金角湾に入り、上陸した兵士たちが軍の拠点を築いた。これがウラジオストクの始まりである。
* 1871年にロシア極東の主要な港となり、1880年に市となった。1890年には沿海州の州都となった。

### シベリア鉄道の起点

* 1891年、ロシアの皇太子ニコライ（のちの皇帝ニコライ2世）が出席して、ウラジオストクで**シベリア鉄道**の起工式が行われた。ニコライはこの直前に日本を訪れ、大津事件で負傷している。
* シベリア鉄道は、ウラジオストクとモスクワを結ぶ世界最長の鉄道となり、ウラジオストクはその終着駅となった。

### 日本人の街

* 1876年、日本はウラジオストクに貿易事務館を開いた（1909年に総領事館となる）。以後、商人・職人などの日本人が増え、1919年には在留登録者だけで5,915人の日本人が暮らしていた。市内には日本人街が形成された。

### ロシア革命とシベリア出兵

* 1917年のロシア革命後、日本はアメリカなどとともにシベリアへ軍を送る**シベリア出兵**を行い、1918年にウラジオストクに上陸した。日本は最大で約7万2,000人の兵力を派遣し、他国が撤兵した後も駐留を続けたが、1922年10月25日にウラジオストクから撤兵した。
* 撤兵後、ウラジオストクはソ連の支配下に入った。

### ソ連時代 ― 閉鎖都市

* ウラジオストクは太平洋艦隊の本拠地として、軍事上の重要性が高まった。
* 1958年ごろから、ウラジオストクは**閉鎖都市**とされ、外国人の立ち入りが禁じられた（閉鎖が始まった年は資料によって異なる）。

### 開放と極東の中心へ

* 1991年9月、ロシアのエリツィン大統領が外国人の訪問を認める大統領令に署名し、1992年からウラジオストクは外国人に開放された。
* 2012年9月、ロシアで初めての**APEC（アジア太平洋経済協力）首脳会議**がルースキー島で開かれ、これに合わせて金角湾横断橋やルースキー島連絡橋、極東連邦大学のキャンパスなどが建設された。
* 2015年に**ウラジオストク自由港**の制度が設けられ、同年から毎年、極東開発をテーマとする国際会議**東方経済フォーラム**が開かれている。
* 2018年12月、極東連邦管区の中心都市がハバロフスクからウラジオストクへ移された。

## 経済

### 規模

* ロシア連邦統計局が初めて推計した、ウラジオストク都市管区の**都市総生産**は約1.16兆ルーブル（2024年）で、前年比4.5%増。ロシア極東の都市で最大であり、ハバロフスク（約8,729億ルーブル）、ユジノサハリンスク（約7,143億ルーブル）を上回った。

### 主な産業

| 分野 | 内容 |
| --- | --- |
| 運輸・物流 | 港湾とシベリア鉄道を生かした物流がロシア極東経済の柱。沿海地方では、運輸・保管業と卸売・小売業が地域総生産の3分の1以上を占める |
| 漁業・水産加工 | 日本海・オホーツク海の水産資源を背景とした漁業と水産加工 |
| 造船・軍事 | 太平洋艦隊の本拠地。沿海地方には、ロシアで最初の大型船の造船所がある |
| 観光・国際会議 | 東方経済フォーラムなどの国際会議の開催地。中国・韓国などアジアからの観光客を集める |

### ウラジオストク自由港

* 外国からの投資の誘致と輸出の促進を目的に、税制の優遇や通関手続きの簡素化などを行う特別な経済制度。沿海地方には、これに加えて4つの「先行発展区域（優先的に開発を進める経済特区）」も置かれている。

### 日本との関係

* 新潟市・函館市・秋田市と姉妹都市の関係にある。秋田市とは1992年6月に提携した。新潟港とウラジオストク商業港も、1992年11月に姉妹港の協定を結んでいる。
* 2022年のロシアによるウクライナ侵攻以降、日本とロシアの関係は大きく悪化し、経済・人的な交流は縮小している。

### 課題

* **人口の伸び悩み** … ロシア極東全体で人口の流出が続いており、ウラジオストクも市域の人口でハバロフスクに抜かれた。
* **国際関係の影響** … 経済制裁の影響で、日本・欧米との貿易や投資は大きく減り、中国との結びつきが強まっている。
