# ハバロフスク

**ハバロフスク（Хабаровск、Khabarovsk）**は、ロシア連邦の極東、アムール川の中流域に位置する都市。**ハバロフスク地方**の行政の中心地である。

人口は約61.6万人（市域）で、ウラジオストクと並ぶロシア極東最大級の都市。2025年には市域の人口でウラジオストクを上回った。1858年に軍の拠点として建設され、17世紀にこの地域を探検したエロフェイ・ハバロフにちなんで名づけられた。アムール川とウスリー川の合流点の近くにあり、中国との国境まで約30kmと近い。2018年まで、ロシア極東全体を管轄する極東連邦管区の中心都市だった。日本とは、第二次世界大戦後のシベリア抑留と深く結びついた土地であり、新潟市とは1965年から姉妹都市の関係にある。

### 名前

17世紀半ばにアムール川流域を探検したロシアの探検家**エロフェイ・ハバロフ**にちなむ。1858年の建設時は「ハバロフカ」と呼ばれ、1893年に「ハバロフスク」と改められた。

### 極東の中心都市としての地位

* 2002年から2018年まで、ハバロフスクはロシア極東全体を管轄する**極東連邦管区**の中心都市だった。
* 2018年12月13日、プーチン大統領の大統領令によって、極東連邦管区の中心はウラジオストクへ移された。
* 一方で、2025年1月時点の市域の人口ではハバロフスク（61万5,600人）がウラジオストク（59万1,628人）を上回った。周辺を含む都市管区で比べると、ウラジオストクのほうが多い。

### ハバロフスク地方

* ハバロフスクを中心都市とするハバロフスク地方は、面積約78.8万km²で、日本の国土の約2倍の広さがある。人口は約127.4万人（2025年1月）。
* オホーツク海に面し、広大な森林と鉱物資源を持つ。

## 地理

### 位置と地形

ロシア極東の南部、アムール川の右岸（東岸）に位置する。

* 市街地は、アムール川に沿って南北に細長く広がる。川沿いの丘陵に、帝政ロシア時代の建物が残る旧市街がある。
* 市の南西でアムール川と**ウスリー川**が合流する。この合流点にある**大ウスリー島**は、長く中国とソ連・ロシアの間の国境紛争の対象だったが、2004年の協定に基づき、2008年10月に島の西半分が中国に引き渡された。これにより中ロの国境が最終的に確定した。
* 中国の黒竜江省との国境まで約30kmで、ロシアの都市の中でも特に中国に近い。

### アムール川

* ハバロフスクを流れる**アムール川**（中国名は黒竜江）は、全長約4,400kmの大河で、中国との国境をなしながらオホーツク海へ注ぐ。ハバロフスクの暮らしと歴史はこの川と強く結びついている。

### 気候

大陸性の気候で、冬の寒さが非常に厳しく、夏は比較的暑い。

* ハバロフスクの年平均気温は1.2℃、年降水量は643.4mm（気象庁の世界の平年値から計算）。
* 最も寒い1月の平均気温は−19.2℃で、冬はアムール川が凍結する。最も暑い7月は21.6℃。
* 夏と冬の気温差は約40℃に達する。降水は7〜8月に集中する。

## 歴史

### 建設 ― アムール川の軍事拠点

* 17世紀半ば、ロシアの探検家エロフェイ・ハバロフがアムール川流域を探検した。
* 1858年5月31日（一般に認められている建設日）、第13シベリア歩兵大隊のヤーコフ・ジャチェンコ大尉が率いる兵士たちが、アムール川の岸に軍の拠点を築き、「ハバロフカ」と名づけた。同年のアイグン条約で、アムール川左岸がロシア領と認められている。
* 1880年に市となり、1893年に「ハバロフスク」と改められた。

### シベリア鉄道とアムール鉄橋

* 1913〜1916年に、シベリア鉄道の最後の区間となる、アムール川に架かる鉄道橋（**アムール鉄橋**）がハバロフスクに建設された。全長約2,600m、高さ64mの巨大な橋で、「アムールの奇跡」と呼ばれた。
* 現在は、下段を鉄道（単線）、上段を自動車（2車線）が通る2層の橋になっている。アムール鉄橋は、ロシアの5,000ルーブル紙幣に描かれている。

### シベリア抑留と日本人

* 1945年8月のソ連の対日参戦後、旧日本軍の軍人などがソ連各地に連行され、強制労働に従事させられた（**シベリア抑留**）。ハバロフスク地方にも多くの収容所が置かれ、多くの日本人が命を落とした。
* 1949年12月、ハバロフスクで、細菌兵器の開発に関わった旧日本軍の関係者12人を被告とする軍事裁判（**ハバロフスク裁判**）が開かれた。
* 1995年7月31日、日本政府はハバロフスク市に、抑留中に亡くなったすべての人々を慰霊する**日本人死亡者慰霊碑**を建てた。敷地は約5,000m²で、建築家の菊竹清訓が設計した。慰霊の対象となる抑留中の死亡者は約5万5,000人とされる。

### 日本との交流

* 1965年、新潟市とハバロフスク市は姉妹都市の関係を結んだ。
* 新潟とハバロフスクの間には航空路が開かれ、2003年には開設30周年を迎えた。新潟県とハバロフスク地方も1990年から交流を続けている。

### 現代

* ソ連崩壊後もハバロフスクはロシア極東の行政の中心地であり続けたが、2018年に極東連邦管区の中心がウラジオストクに移された。
* 2020年には、ハバロフスク地方の知事が逮捕されたことに抗議する大規模な市民のデモが続いた。

## 経済

### 規模

* ロシア連邦統計局が初めて推計した、ハバロフスクの**都市総生産**は約8,729億ルーブル（2024年）で、ロシア極東の都市ではウラジオストク（約1.16兆ルーブル）に次ぐ規模。
* ハバロフスク地方の地域総生産は、ロシア全体の約0.9%を占める（2024年）。

### 主な産業

ハバロフスク地方では、運輸、卸売・小売、建設、製造業、鉱業が地域総生産の約半分を占める。

| 分野 | 内容 |
| --- | --- |
| 運輸・物流 | シベリア鉄道とアムール川の水運が交わる交通の要衝。ロシア極東の物流の拠点 |
| 製造業 | 機械製造、冶金、石油精製など |
| 林業・木材加工 | 広大な森林を背景とした伐採と木材加工 |
| 鉱業 | 金属鉱石などの採掘 |

### 課題

* **人口の流出** … ロシア極東全体で人口の流出と減少が続いている。
* **中国への依存** … 欧米・日本との経済関係が縮小するなか、隣接する中国との貿易・投資への依存が強まっている。
