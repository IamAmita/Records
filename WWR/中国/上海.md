# 上海（上海市）

**上海（シャンハイ、上海、Shanghai）**は、中華人民共和国の東部、長江の河口に位置する**直轄市**。北京・天津・重慶と並ぶ4つの直轄市の一つで、省と同格の行政単位である。

常住人口は約2,485万人で、中国最大の経済都市。面積は約6,341km²で、日本の群馬県とほぼ同じ広さに、群馬県の10倍以上の人々が暮らす。19世紀半ばの開港後、欧米と日本の租界が置かれて「東洋のパリ」とも呼ばれる国際都市に成長した。1990年の浦東開発以降は中国の改革開放の象徴となり、現在は世界最大のコンテナ港と中国最大の金融市場を抱える。日本とのつながりも深く、在留邦人数は中国の都市で最も多い。

### 人口の構成

* 常住人口約2,485万人のうち、上海に戸籍を持つ人は約1,511万人、他の地域から移り住んだ人（外来常住人口）は約975万人で、人口の約4割を外から来た人が占める（2025年末）。
* 2025年の出生率は1,000人あたり4.31人と低く、死亡数が出生数を上回る「自然減」が続いている。人口の増加は、他の地域からの流入によって支えられている。

### 政治における位置づけ

* 1921年に中国共産党の第1回全国代表大会が開かれた地であり、上海市の共産党トップは歴代、国の最高指導部に入ることが多い。前任の上海市党書記である李強は、現在の国務院総理（首相）である。

## 地理

### 位置と地形

中国の東部、長江が東シナ海に注ぐ河口の南岸に位置する。

* **北・東** … 長江の河口と東シナ海に面する。
* **西・南** … 江蘇省・浙江省と接し、両省とあわせた「長江デルタ」地域は中国最大の経済圏を形成している。
* 市域のほとんどは長江がつくった平坦な三角州で、標高が低い。
* 市の中心を**黄浦江**が流れる。西岸の**浦西**は租界時代からの旧市街で、川沿いの**外灘（バンド）**には20世紀初めの欧風建築が並ぶ。東岸の**浦東**は1990年以降に開発された新市街で、陸家嘴（りくかし）の金融街に超高層ビルが林立する。
* 長江の河口には、中国で3番目に大きい島とされる**崇明島**がある。

### 気候

亜熱帯の気候で、夏は高温多湿、冬は寒くて乾燥する。

* 上海の年平均気温は16.6℃、年降水量は1,111.9mm（気象庁の世界の平年値〔宝山の観測所〕から計算）。
* 最も暑い7月の平均気温は28.8℃、最も寒い1月は5.0℃。
* 6月から8月にかけて、梅雨と台風の影響で雨が多い。

## 歴史

### 開港以前

* 宋代から元代にかけて、長江河口の港町として発展し、元代の1292年に**上海県**が置かれた。
* 明・清代には、綿織物の生産と海運の拠点として栄えたが、規模の大きな都市ではなかった。

### 開港と租界

* アヘン戦争後の南京条約により、1843年に上海は外国との貿易のために**開港**した。開港の年に上海にいた外国人は、わずか25人だった。
* 1845年にイギリスの租界が設けられ、1848年にアメリカ、1849年にフランスが続いて租界を設けた。イギリスとアメリカの租界はのちに合併して**共同租界**となった。
* 租界は中国の主権が及ばない外国人の自治区域で、欧米の銀行・商社が集まった。上海は東アジア最大の貿易・金融都市に成長し、「東洋のパリ」「魔都」とも呼ばれた。
* 共同租界の北部の虹口（ホンキュウ）地区には多くの日本人が住み、日本人社会が形成された。

### 革命と戦争

* 1921年7月、上海のフランス租界で**中国共産党の第1回全国代表大会**が開かれた。会場の跡は現在、記念館となっている。
* 1932年の**第一次上海事変**、1937年の**第二次上海事変**で、日本軍と中国軍が上海で激しく戦った。第二次上海事変は日中戦争の全面化のきっかけとなり、上海は日本軍に占領された。
* 1949年、中国共産党の軍が上海を制圧した。

### 改革開放 ― 浦東開発

* 1990年4月18日、中国政府は**浦東の開発・開放**を発表した。それまで農地が広がっていた黄浦江の東岸に、金融・貿易・工業の拠点が次々に建設された。
* 1990年12月19日、中華人民共和国で最初の証券取引所である**上海証券取引所**が開業した。
* 2010年、**上海国際博覧会（上海万博）**が開かれ、246の国と国際機関が参加し、延べ7,308万人が訪れた。
* 2013年には中国で最初の自由貿易試験区が上海に設けられた。

## 経済

### 規模

* **地区生産総値（GDP）**は56,708.71億元（2025年）で、前年比5.4%の成長となった。中国の都市で最大である。
* 第3次産業（サービス業）が79.3%を占める（2025年）。
* 1人あたりの地区生産総値は228,434元（2025年）で、中国全体（99,665元）の約2.3倍。

### 港湾と空港

* **上海港**の2025年のコンテナ取扱量は5,506.25万TEUで、過去最多を更新し、16年連続で世界一となった。東シナ海の島に建設された**洋山深水港**が、その重要な一部を担っている。
* 浦東・虹橋の2つの空港の旅客数は、合計で延べ約1億3,515万人（2025年）。

### 金融

* 上海証券取引所をはじめとする金融市場の取引総額は、4,058.95兆元（2025年）にのぼる。
* 交通銀行、中国太平洋保険などの大手金融機関が本社を置く。

### 主な産業と企業

| 分野 | 主な企業 |
| --- | --- |
| 自動車 | 上海汽車集団（SAIC。フォルクスワーゲン、GMとの合弁会社を持つ）、新興の電気自動車メーカーNIO（蔚来汽車） |
| 鉄鋼・造船・海運 | 中国宝武鋼鉄集団（中国最大の鉄鋼メーカー）、中国船舶集団、中国遠洋海運集団（COSCO） |
| 半導体 | 中芯国際集成電路（SMIC、中国最大の半導体受託生産メーカー） |
| 航空機 | 中国商用飛機（COMAC。旅客機C919を製造） |
| IT・ネット | 拼多多（PDD）、携程集団（Trip.com）、生成AIのミニマックス |

### 貿易と日本

* 2025年の輸出入総額は6,304億ドル（前年比5.0%増）。主な輸出先はEU・ASEAN・香港・米国・日本の順で、日本への輸出は174億ドル、日本からの輸入は362億ドルだった。
* 中国にある日系企業の拠点約3万2,000のうち、約2万3,000が上海を中心とする華東地域にある。
* 上海の在留邦人数は3万1,733人（2025年10月）で、海外の都市では世界5位、中国では最多である。ただし前年比8.5%減と、減少が続いている。

### 観光

* 2025年には国内から延べ約4億1,644万人、海外から延べ約936万人の観光客が訪れた。
* 外灘、豫園、浦東の超高層ビル群、上海ディズニーランド（2016年開業）などが人気を集める。

### 課題

* **少子高齢化** … 出生率が非常に低く、人口の自然減が続いている。
* **賃金と生活費** … 2025年の平均賃金の伸び率は1.2%と、3年連続で過去最低となった。一方で住宅価格などの生活費は高い。
* **外資・日系企業の動向** … 日本からの投資額や在留邦人数が減少傾向にある。
