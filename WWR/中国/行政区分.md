# 中国の行政区分

中華人民共和国の行政区画は、**省級・地級・県級・郷級**の**4層制**が実際の基本である。憲法は「省 → 県 → 郷」の3層を原則としているが、1980年代以降、県の上に**地級市**を置いて周辺の県を管轄させる「市が県を管轄する（市管県）」制度が全国に広がり、4層が定着した。

最上位の**省級行政区**は34で、23の省（台湾省を含む）、5つの自治区、4つの直轄市、2つの特別行政区からなる。2025年末時点で、地級行政区は333、県級行政区は2,845、郷級行政区は38,721ある。少数民族の多い地域には、自治区・自治州・自治県などの**民族自治地方**が置かれている。

## 概要

| 項目 | 内容 |
| --- | --- |
| 制度 | 省級・地級・県級・郷級の4層制（憲法上は省・県・郷の3層） |
| 省級 | 34（省23・自治区5・直轄市4・特別行政区2） |
| 地級 | 333（地級市293・地区7・自治州30・盟3） |
| 県級 | 2,845（市轄区976・県級市397・県1,301・自治県117・旗49・自治旗3・特区1・林区1） |
| 郷級 | 38,721（街道9,148・鎮21,554・郷6,910・蘇木153・民族郷955・民族蘇木1） |
| 数値の基準 | 2025年末（中国大陸。省級の数は台湾・香港・マカオを含む） |

### 行政区分の階層

```
中央（国務院）
└─ 省級（34）……… 省・自治区・直轄市・特別行政区
    └─ 地級（333）……… 地級市・地区・自治州・盟
        └─ 県級（2,845）……… 市轄区・県級市・県・自治県・旗など
            └─ 郷級（38,721）……… 街道・鎮・郷・民族郷・蘇木
                └─ 村民委員会・居民委員会（自治組織。行政区画ではない）
```

* **直轄市**には地級がなく、市の下に直接、区・県が置かれる（例: 重慶市の26区・12県）。
* **海南省・湖北省・河南省・新疆**などには、地級を経ずに省が直接管轄する県級市・県（**省直管県**）もある。
* 郷級の下の**村民委員会**（約48万）と**居民委員会**（約12万）は住民の自治組織とされるが、実際には末端の行政を担っている。

## 省級行政区

### 種別

| 種別 | 数 | 特徴 |
| --- | --- | --- |
| **省** | 23 | 標準的な最上位区分。日本の都道府県よりはるかに大きく、多くは人口数千万人規模。中国は台湾を「台湾省」として数に含めている。 |
| **自治区** | 5 | 少数民族の自治を行う省級の地域。主席は自治を行う民族から選ぶと定められている。 |
| **直轄市** | 4 | 中央が直接管轄する大都市。北京・天津・上海・重慶。 |
| **特別行政区** | 2 | 香港・マカオ。**一国二制度**のもとで独自の法制度・通貨・出入境管理を持つ。 |

* 「地級」欄で内訳のないものは、すべて地級市。
* **略称**は自動車のナンバープレートや鉄道路線名、新聞の見出しなどで広く使われる。古代の国名や川・山の名に由来するものが多い（例: 山東の「魯」は春秋時代の魯国、河南の「豫」は古代の豫州）。
* 地級行政区が最も多いのは広東省・四川省（各21）。人口が最も多い省は広東省（1億人超）、面積が最も広いのは新疆ウイグル自治区（約166万km²）。
* **台湾**について、中華人民共和国は「台湾省」として自国の省級行政区に含めているが、実際には中華民国（台湾）政府が統治しており、中華人民共和国の行政は及んでいない。

### 特別行政区

* **香港**（1997年に英国から返還）と**マカオ**（1999年にポルトガルから返還）は、返還後50年間は資本主義の制度を維持するとされ、それぞれ**基本法**のもとで高度な自治を認められている。
* 香港は18の区（区議会がある）、マカオは澳門半島・タイパ島・コロアン島などからなる。

## 地級行政区

| 種別 | 数 | 特徴 |
| --- | --- | --- |
| **地級市** | 293 | 中心の市街地（市轄区）と、周辺の県・県級市を管轄する。日本の「市」よりも、県に近い広さと人口を持つ。 |
| **地区** | 7 | 省の出先機関（行政公署）が管轄する区域。かつては全国にあったが、大半が地級市に転換された。現在は新疆・チベット・黒竜江にのみ残る。 |
| **自治州** | 30 | 少数民族の自治を行う地級の地域。雲南（8）・青海（6）・新疆（5）に多い。 |
| **盟** | 3 | 内モンゴル自治区の伝統的な区分。地区に相当する。 |

### 副省級市・計画単列市

* **副省級市**（15） … 地級市のうち、市の幹部が省の副長官級の待遇を受ける大都市。ハルビン・長春・瀋陽・大連・済南・青島・南京・杭州・寧波・厦門・武漢・広州・深圳・成都・西安。
* **計画単列市**（5） … 大連・青島・寧波・厦門・深圳。国の経済計画・財政上は省から独立して扱われ、省級に近い経済管理権限を持つ。いずれも省都ではない沿海の港湾都市である。

## 県級・郷級行政区

### 県級

| 種別 | 数 | 特徴 |
| --- | --- | --- |
| **市轄区** | 976 | 地級市・直轄市の都市部の区。 |
| **県級市** | 397 | 県から昇格した都市。地級市の管轄下にあることが多い。 |
| **県** | 1,301 | 農村部を中心とする伝統的な単位。秦の郡県制以来、2,000年以上続く。 |
| **自治県** | 117 | 少数民族の自治を行う県。 |
| **旗・自治旗** | 49・3 | 内モンゴル自治区の県にあたる単位。 |
| **特区・林区** | 1・1 | 貴州省の六枝特区、湖北省の神農架林区。 |

* 県は中国で最も安定した行政単位で、「郡県治、天下安（郡や県が治まれば、天下は安定する）」という言葉がある。
* 近年は都市化に伴い、県を地級市の区に改める「**撤県設区**」や、県を県級市に昇格させる「**撤県設市**」が進んでいる。

### 郷級

* **街道**（都市部。区・市の出先機関である街道弁事処）、**鎮**（町。商工業の中心となる集落）、**郷**（農村）、**民族郷**、内モンゴルの**蘇木**がある。
* 都市化と合併で郷が鎮や街道に改められ、郷級行政区の数は減少が続いている。

## 民族自治地方

* 中国は55の少数民族を公認しており、少数民族が集まって住む地域に**民族区域自治**を認めている。
* 民族自治地方は、省級の**自治区**（5）、地級の**自治州**（30）、県級の**自治県・自治旗**（120）の3段階からなる。
* 5つの自治区は、内モンゴル（1947年）・新疆ウイグル（1955年）・広西チワン族（1958年）・寧夏回族（1958年）・チベット（1965年）。
* 自治地方は、自治条例の制定や言語の使用などで一定の自治権を持つが、党と中央政府の指導下にあり、実際の自治の範囲は限られている。

統計や地域政策では、**東部・中部・西部・東北**の4区分が使われる。

* **中部**（6） … 山西・安徽・江西・河南・湖北・湖南

## 歴史

### 前近代 ― 郡県制と行省

* 紀元前221年に中国を統一した秦は、全国を36郡に分けてその下に県を置く**郡県制**をしいた。県は以後、2,000年以上にわたって地方行政の基本単位となった。
* 元朝は中央の中書省の出先として各地に**行中書省（行省）**を置いた。これが「省」の起源である。
* 明・清の時代に省の区域がほぼ固まり、清代には内地の18省（本部十八省）が成立した。現在の省の多くは、この区域を受け継いでいる。

### 中華人民共和国の成立後

* 1949年の建国時、全国は華北・東北・華東・中南・西南・西北の**6大行政区**に分けられ、その下に省・直轄市などが置かれた。
* 1954年に大行政区が廃止され、省級行政区が最上位の区分となった。1955年には熱河省・西康省が廃止された。
* 1958年に天津市が河北省に編入されたが、1967年に再び直轄市となった。
* 1983年以降、**地区を地級市に改め、市が周辺の県を管轄する**制度（市管県）が全国に広がり、事実上の4層制が定着した。
* 1988年、**海南省**が広東省から分離して設置された。
* 1997年、**重慶市**が四川省から分離して4番目の直轄市となった。同年に香港、1999年にマカオが返還され、特別行政区となった。
* 2012年、南シナ海の西沙・中沙・南沙諸島を管轄するとして、海南省に地級市の**三沙市**が置かれた（周辺国と領有権を争っている）。

## 課題

* **層の多さと権限の集中** … 地級市が周辺の県の資源を中心部に集める傾向があるとの批判から、省が県を直接管轄する「**省直管県**」の改革が一部の省で試みられている。
* **都市化と区画変更** … 撤県設区による市域の拡大が相次いだため、民政部は過度な区画変更を抑える方針を示している。また、行政区画コードの管理を厳格にする「行政区画コード管理弁法」が2025年9月に施行された。
* **民族地域の統治** … 新疆・チベットなどの民族自治地方では、中央の統制強化と自治の実態をめぐって国際的な批判がある。

## 出典

数値は各出典の公表時点のもの（2026年10月確認）。区画地名網（xzqh.org）は確認時に証明書の期限切れで接続できなかったため、2025年末の各級の数は検索結果での照合にとどまる。省級行政区ごとの地級の内訳は、全国の合計（333）と一致することを確認した。略称・省都、副省級市・計画単列市の一覧、地域区分、歴史の通説的な事項（年号など）には、個別の出典を付けていないものがある。
