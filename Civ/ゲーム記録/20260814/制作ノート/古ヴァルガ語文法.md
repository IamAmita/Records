# 古ヴァルガ語 文法

紀元前3400年頃、語根が増えたことで、古ヴァルガ語は「単語を並べるだけの言語」から**文章を作れる言語**へと発展する。

この時代の言語なので、後世のヴァルガ語ほど複雑ではなく、**短い助詞を名詞の後ろに置き、接続詞も短い**という設計とする。語彙は[辞書](古ヴァルガ語辞書.md)を参照。

---

## 1. 基本語順

古ヴァルガ語は、

> **主語 ― 目的語 ― 動詞（SOV）**

を基本とする。

**Vam elga na set.**
→ 我々は、遠方の土地に、住み着く。

修飾語は基本的に名詞の**前**に置く。

* **kel gar**（良い＋道具）→ 良い道具
* **el ga**（彼方の＋土地）→ 遠方の土地

これは、これまで作ってきた複合語（Kelgar, Elga …）とも相性がよい。

古ヴァルガ語は **SOV・後置詞型・複合語を好む言語**として固定する。

---

## 2. 助詞

助詞は名詞の後ろに置く。かなり短い。

| 助詞 | 機能 | 日本語 |
| --- | --- | --- |
| **a** | 主題 | ～は |
| **i** | 主格 | ～が |
| **u** | 目的格 | ～を |
| **na** | 場所・到達点 | ～に、～へ |
| **ta** | 起点 | ～から |
| **de** | 所有・所属 | ～の |
| **ki** | 手段 | ～で、～を使って |
| **so** | 同伴 | ～と共に |
| **ra** | 方向 | ～の方へ |
| **en** | 内部 | ～の中で |
| **al** | 上・表面 | ～の上に |
| **ne** | 否定 | ～ではない、～ない |

※ 助詞 **al** は、当初 *or* を検討したが名詞 **Or（冬）** と同音のため改めた。

### a ― 「～は」（主題）

**Vam a Varga de vam.** → 我々はヴァルガの民である。
**Vam a Varga.** → 我々はヴァルガだ。（より原始的な言い方）

### i ― 「～が」（主格）

動作の主体を明確にする。

**Elsetar i elgadar tek.** → 開拓者が新集落を作る。
（Elsetar〔開拓者〕／ i 〔が〕／ Elgadar〔新集落〕／ Tek〔作る〕）

### u ― 「～を」（目的格）

**Gartek i urgar u tek.** → 道具職人が石器を作る。
（SOVなので動詞 Tek は最後）

目的語が動詞の直前に置かれ文脈から明らかな場合、**uは省略されることがある**（特に格言・宣言・詩的な定型句）。**Elsetar i gadar tek.**（開拓者が集落を作る）のようにuを伴わない形も、**Elsetar i gadar u tek.**のようにuを伴う形も、共に正しいVargan語として並存する。これは「短い助詞を好む」という古ヴァルガ語の性格上、動詞に直接先行する目的語では格標示の冗長性が許容されることを示す。

### na ― 「～に・～へ」（到達点）

エルセタルの時代に頻用される。

**Elsetar i elga na gan.** → 開拓者が遠方の土地へ越えていく。
**Vam elga na set.** → 我々は遠方の土地に定住する。

### ta ― 「～から」（起点）

**Varga ta elga na gan.** → ヴァルガから遠方の土地へ行く。

### de ― 「～の」（所有・所属）

**Varga de kar** → ヴァルガの戦士
**Organ de gar** → オルガンの道具
**Vam de ga** → 我々の土地

### ki ― 「～で」（手段）

**Urvak i vakar ki vakur u vak.** → 投石兵が投石器で投石弾を投げる。
（Urvak i 〔投石兵が〕／ Vakar ki 〔投石器で〕／ Vakur u 〔投石弾を〕／ Vak 〔投げる〕）

### so ― 「～と共に」（同伴）

**Kar so Urvak har.** → カルはウルヴァクと共に戦う。
**Elgan so Elsetar gan.** → エルガンは開拓者と共に進む。

### al ― 「～の上に」（上・表面）

**Tur al gadar.** → 丘の上に集落がある。

---

## 3. 助詞の一語化（造語法）

頻繁に使われる「名詞＋de＋名詞」は、やがて一語（複合語）になる。

> **Vam de ga**（我々の土地）が繰り返されるうちに → **Vamga**

つまり古ヴァルガ語には、

> **助詞を使った表現 → 頻用される → 一語になる**

という造語法がある。これは、これまで作ってきた複合語（Kaldor, Kellor, Mekragor …）を自然に説明できる。

## 4. 接続詞

接続詞も短い。文と文をつなぐ。

| 接続詞 | 意味 |
| --- | --- |
| **ka** | そして |
| **ma** | しかし |
| **va** | または |
| **to** | だから、それゆえ |
| **ke** | なぜなら |
| **nu** | もし |
| **da** | そのとき |
| **ya** | ～だが、それでも |
| **se** | ～するとき |
| **til** | ～まで、～に至るまで |

※ **da** は当初 *dan* を検討したが、名詞 **Dan（与える）** と同音のため **da** とした。
※ **til** は当初 *an* を検討したが、接尾辞 **-an**（集団的活動）と同形のため改めた。場所・時間の両方に使える。

### ka ― 「そして」

**Kar har, ka Urvak vak.** → カルは戦い、そしてウルヴァクは石を投げる。

口承・物語と相性がよい。「オルガンは来た。そして人々を集めた。そして冬を越えた。」のような語り。

### ma ― 「しかし」

**Or har, ma vam gan.** → 冬は襲う。しかし我々は越える。
（詩的に：「冬は我らを襲う。されど我らは越える。」）

### to ― 「だから」

**Or kel ne, to vam ortal tek.** → 冬は良くない。だから我々はオルタルを作る。

### ke ― 「なぜなら」

**Vam ortal tek, ke or gan.** → 我々は冬の備蓄を作る。なぜなら冬を越えるためだ。

### nu ― 「もし」（条件）

**Nu ortal ne, vam gan ne.** → もしオルタルがなければ、我々は冬を越せない。

### til ― 「～まで」（到達限界）

場所にも時間にも使える。

**Kor til gan.** → 山まで進む。
**Or til set.** → 冬まで留まる。

---

## 5. 否定 ― ne

否定語は **ne（ネ）**。動詞の前に置く。

**Vam ne har.** → 我々は戦わない。
**Vam ne ber.** → 我々は交換しない。

名詞にも使える。

**Nek a vam ne.** → 異邦人は我々ではない。

---

## 6. 疑問

疑問詞には共通して **-ai** が付く。既存の語根（Nar〔火〕, Ga〔土地〕, Tor〔前〕, Mel〔所有〕）との衝突を避けるため、疑問系は別系統とする。

| 疑問詞 | 意味 |
| --- | --- |
| **Kai** | 何 |
| **Nai** | 誰 |
| **Gai** | どこ |
| **Tai** | いつ |
| **Kei** | なぜ |
| **Mai** | どれほど、いくつ |

後世の言語学者はこれを、**-ai＝未知・疑問を表す古い文法要素**と分析する。

## 7. 例文 ― 最初のエルセタルの出発

紀元前3400年、最初のエルセタルが新天地へ出発するときの言葉。

> **Vam a Varga.**
> **Varga ta elga na gan.**
> **Ka elga na set.**
> **Ma elga a nekga ne.**
> **Elsetar i gadar tek.**
> **To elga a vamga.**

訳：

> 我らはヴァルガである。
> ヴァルガより彼方の地へ越える。
> そして彼方の地に留まる。
> だが、その地はもはや異邦の地ではない。
> 開拓者が集落を築く。
> ゆえに彼方の地は、我らの土地となる。

これまで単独で作ってきた **Varga / Elgan / Kar / Ortal / Haran / Elsetar / Vamga** などが、ここで初めて一つの言語として繋がる。
