かなり整理が進んでるので、ここからは「保留を維持する理由が強いもの」以外は確定していいと思う。特に**中期ヴァルガ語への移行が正式決定した**ことで、435年以降の語彙を一気に処理できるようになった。

俺なら、以下の内容で確定する。

## 1. 中期ヴァルガ語の造語規則を先に固定する

中期ヴァルガ語は古ヴァルガ語を破壊するほど変化させず、

> **語根は古語を継承するが、長い複合語ほど縮約しやすい**

という段階にする。

基本的には、

* 2語根程度の透明な複合語は維持
* 3語根以上では弱い母音や同種音が脱落
* 宗教・政治・学術語では、710年のルネサンス以降に古語形へ戻る「復古語」もある
* 日常語と専門語で発音差が生じる

とする。

たとえば古い **Sairkanar** のような語も、日常発音では *Sarkanar* に近づく一方、祭祀では古典形 **Sairkanar** が維持される、くらい。

これなら「古語から1200年経っているのに全然変化しない」問題を解消しつつ、既存語彙も壊さない。

# 2. 「成人」は一語化しない

**Kam案は不採用**でいいと思う。

Varganでは「成人」は制度によって分割する。

身体的成熟、Kev取得、契約能力、婚姻資格、政治参加資格はそれぞれ別。

したがって日本語の「成人」に完全対応する一般語は存在せず、

> **「何について一人前なのか」を明示する**

文化にする。

これは世界観的にもかなり面白い。

「18歳になったから全部成人」のような一元的発想ではなく、

> このHumはKevを持つ資格はあるが、Kanrinへはまだ参加できない

という社会になる。

# 3. 封建制度はSulkes / Vekkesで確定

これはかなり出来がいいので採用していい。

### **Sulkes**

Sul（従う）＋Kes（約束）

**封臣側が主君に負う契約。**

### **Vekkes**

Vek（守る）＋Kes

**主君側が封臣に負う保護契約。**

そして両者をまとめた封建契約そのものを、

### **Sulvekkes**

とする。

意味は、

> **服従と保護を相互に約束する契約。**

これならVarganの封建制が単なる上下服従ではなく、**Kesによる双務関係**だと語形だけで分かる。

そこから、

**Sulkesar**
＝Sulkesを結んだ者 → 封臣

**Vekkesar**
＝Vekkesを負う者 → 封主

と派生させられる。

既存のGalorarは社会階層、Sulkesar/Vekkesarは**契約上の地位**なので両立する。

一人のGalorarが上位者にはSulkesar、下位者にはVekkesarということもある。

これは封建制としてかなり使いやすい。

# 4. 「未知」は **Elsen** で確定

これは既存語根からかなり綺麗に作れる。

### **Elsen**

El（彼方）＋Sen（知・理解）

直訳すると、

> **知の彼方**

意味は、

> **まだ知られていない、現在のSenの外にあるもの。**

重要なのは「理解不能」という意味ではないこと。

Elsenは、

> **今は知らないが、Senすることが可能なもの**

を指す。

だから、

**Elsen Ga**
＝未知の土地

**Elsen Mar**
＝未知の海

**Elsen Nek**
＝未知の異民族

と使える。

大航海時代Varganの思想に非常によく合う。

# 5. 「発見」は **Sendar** にする

既存のSenを中心にしたい。

### **Sendar**

Sen＋Dar

本来の直訳は、

> **知を与える／知の中へ渡す**

そこから中期ヴァルガ語で、

> **未知だったものを共同体のSenへ加える**
> ＝発見する

という専門的意味が成立した、とする。

### **Sendaran**

発見・新発見

### **Sendarar**

発見者

とできる。

これなら、

> 「メキシコ文明をVargarがSendarした」

とは言えても、

> 「Vargarがメキシコ文明を存在させた」

という意味にはならない。

Vargan的「発見」の哲学がそのまま語になる。

Gamet（測量）＋Kad（記録）

### **Gamkad**

まで縮まってもいい。

学術文書ではGametkad、船乗りはGamkad。

ルネサンスらしい文語／口語差になる。

# 8. 「風」は古語根を補完する

風はVargarが古代から絶対に知っていたので借用語にはできない。

新たに古語根として、

### **Zur**

**風**

を追加するのを推す。

短いCVCで既存古語根とも馴染みやすい。

そこから、

**Zurmar**
＝海風

**Zurran**
＝風の通り道・風路

**Zurved**
＝風向

が作れる。

755年頃の貿易風利用を受けて、

### **Setzur**

Set（定まる・固定する系の既存意味に合わせるなら）
＝恒常風

としたいところだけど、Setの正確な基本語義との衝突確認が必要なので、ここだけは辞書確認後に決める方がいい。

したがって現時点では**Zur＝風だけ確定**して、恒常風・季節風・貿易風はZur複合語として後から分けるのが安全。

Elsen（未知）＋Harket（部隊・まとまり）

> **未知をSenするために組織された集団**

### **Elsenran**

「未知への旅」

### **Elsenranar**

俺なら、

**Elsenran**
＝探検

**Elsenranar**
＝探検者

**Elsenranam**
＝探検隊

# 11. 投資は **Meldar** で確定

これはかなりVarganらしい。

### **Meldar**

Mel（所有する）＋Dar（与える）

本来、

> **自分の所有物を外へ出す**

という意味。

620年頃から、

> **将来の増大を期待してMelgarを事業へ差し出す**

という経済専門語へ意味変化したとする。

### **Meldaran**

投資

### **Meldarar**

投資家・出資者

と派生。

これが非常にいいのは、

> Dar＝与える

という古い倫理語が、資本主義的な「投資」に変化していること。

「今Darすることで、将来より大きなものを得る」という意味変化が620年の原始的蓄積と一致する。

### **Vun**

# 13. 馬・鯨・ウミガメは古語根として補完

ここは設定上「715年に知った」扱いにしない。

俺なら以下を採用する。

| 語       | 意味   | 理由                  |
| ------- | ---- | ------------------- |
| **Esh** | 馬    | 短い古語根。軍事・交通派生がしやすい  |
| **Mor** | 鯨    | Marとの関連を後世に民間語源化できる |
| **Kum** | ウミガメ | 古い沿岸語彙として扱いやすい      |

ただし**Mor**は既存語に海・水系のMorが存在しているなら衝突するので、そこだけ辞書照合が必要。

衝突するなら鯨は、

### **Wor**

に変えるのを推す。

馬は**Esh**、ウミガメは**Kum**でかなり使いやすい。

捕鯨は、

### **Worhar**

では「鯨と戦う」になりすぎるので、

狩猟語根が既存ならそこから作るべき。

つまり生物名だけ先に確定でいい。

# 15. 新宗教の「天」は **Toraru**

### **Toraru**

Tor（大いなる・高い）＋Aru

として専門化。

ある宗派は最高神。

ある宗派は宇宙秩序。

ある宗派は不可知の超越者。

全員が**Toraru**という同じ語を使う。

今の方針と非常に相性がいい。

# 18. 「使徒」は **Taldarar → Taldar**

ここは中期ヴァルガ語化を利用すると綺麗。

古語的には、

**Tal**
＝糧

**Dar**
＝与える

**-ar**
＝行為者

なので、

> Tal＋Dar＋ar
> → **Taldarar**

「糧を与える者」。

ところが中期ヴァルガ語で重複する /ar/ が縮約し、

### **Taldar**

となった。

意味は、

> **天の教えと糧を世界へ運ぶ使徒**

へ専門化。

これはかなり強い語だと思う。

普通の「施しをする人」ではなく、新宗教固有の称号になった。

そして教義「この世界に糧を」と直結する。
