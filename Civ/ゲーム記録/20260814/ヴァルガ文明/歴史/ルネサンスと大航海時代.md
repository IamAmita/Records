# ルネサンスと大航海時代（西暦710年頃）

西暦710年頃、[前500年から続いてきた探検時代](多中心化するヴァルガン.md)が成熟し、Varganに二つの変革がほぼ同時に訪れる。**内側では古典の再発見（ルネサンス）、外側では世界そのものの再発見（大航海時代）**である。どちらも根底には古くからの**Sen（知ること）**という価値観があり、710年は文化が単に華やかになった時代というより、**「これまで正しいとされてきた世界像を、自分たちで改めて確かめる」**という知的態度が急速に広がった時代として位置づけられる。

## なぜ710年にルネサンスが起こるのか

Varganには古典を再発見する材料が大量に蓄積されている。[前900年頃に完成したSilga大図書館](../技術と知識/シルガ大図書館.md)を筆頭に、710年時点で1600年以上にわたる文献の蓄積があり、Vargaには古い建築・神話・碑文、[Munga](../地理/ムンガ.md)には祖先の記憶、[Samarga](../地理/サマルガ.md)には政治文書、[Ruvan](../地理/ルヴァン.md)には新宗教の文献と外国文化が残る。Varganは「古典が失われた文明」ではなく、**古典は存在していたが、あまりにも長い歴史の中で意味が分からなくなっていた文明**である。ここで学者たちが古文書を読み直し始める。

### 古ヴァルガ語が「古典語」になる

古ヴァルガ語は、この時代にはもはや日常語ではない。前500年からでも1200年以上、前4000年代の語彙なら3000〜4000年以上を経ており、710年頃のSenarにとって**古ヴァルガ語は研究しなければ読めない古典語**になっている。古文書の校訂、古語辞典、文法書、古代碑文の解読、古典文学の現代語訳、神話の再編纂、歴史年代の整理――Vargan自身の手による、いわば「古ヴァルガ語辞書」の編纂事業がここで始まる。

### Organ神話の体系化

Darsairの血を引くOrgan、Ragarとの戦い、幾度も訪れた冬、神々と人間が協力してRagarへ立ち向かった物語、Ragonを終わらせ人々を再び冬へ向かわせないよう導いたOrganの伝承――こうした[Vargan神話](../社会と文化/ヴァルガ神話.md)が古典研究によって体系化される。それまで地方ごとに異なっていた神話が「Varga古典神話」として編集され、現代的な意味での体系的な神話集がここで初めて成立する。

### 新宗教と古典復興の関係

[435年に成立したRuvan宗教](../社会と文化/新宗教の成立.md)は710年時点ですでに275年の歴史を持ち、社会に定着している。古典研究者が古代のDarsair信仰を単純に迷信と否定するとは限らず、むしろ宗教知識人から「古代Vargarも、不完全ながら天の真理の一部をSenしていたのではないか」という解釈が現れる可能性がある。Darsair・Organ・Ragar・Ragon・Orが新宗教の神学から再解釈される一方、「古いSair信仰を勝手に新宗教へ組み込むな」という反論も生じ、古典学と神学の間に大きな論争が育っていく。

## 大航海時代への道筋

[前2500年頃からの3000年以上の航海史](../技術と知識/航海とガレー船.md)、[前500年以降の探検時代](多中心化するヴァルガン.md)、Ruvan成立後の西方との接触増加、[680年のVargaの王立動植物苑](../技術と知識/王立動植物苑.md)――710年以前のVarganはすでに「遠くに未知の世界が存在する」ことを十分理解していた。問題は、そこへ安定して到達できるかどうかだった。

## キャラック相当船 ― 外洋航海の技術的現実化

710年頃、大型帆走船が複数同時に建造されたことで、航海の性質そのものが変わる。[前2500年頃のガレー船相当](../技術と知識/航海とガレー船.md)、[前1500年頃のカドリレーム相当（フェルハルナヴ）](../政治と軍事/クメール支援戦争エルヴェクハル.md)はいずれも沿岸・近海を前提とした船だったが、710年頃の船は**長期間陸地を見ずに航海できる船**――史実のキャラック船に相当する存在である。

Vargan型の外洋帆船は、大型の帆走船で櫂への依存が大幅に低下し、数十人規模以上の乗員を長期間収容し、水・穀物・塩蔵食品を大量に搭載し、交易品や採集標本を積める大型船倉と荒天に耐える高い船体を持ち、外洋での長期航行を前提とした修繕資材、星・太陽・方位を利用した航海技術、航海記録・地図を管理する専門職を備える。重要なのは一隻の試作船ではなく**複数建造された**ことであり、これは冒険家が偶然大型船を作ったのではなく、**Vargan社会が外洋航海を継続的事業として開始した**ことを意味する。

### 原始的蓄積が航海を可能にする

外洋航海には大型船・船員・食料・水・航海器具・武装・修理資材・数か月から数年分の給金という莫大な費用がかかり、一人の船乗りでは到底用意できない。しかし[620年頃の原始的蓄積](../政治と軍事/原始的蓄積.md)以降、Varganでは資本を集積して大規模事業へ投入することが政策的に肯定されており、商人が出資し、有力者が資材を提供し、政府が港湾・造船所を整備し、多数の専門職人が雇われるという流れで大型船が建造される条件が整う。原始的蓄積からおよそ90年、ちょうど成果が現れ始める時期である。

### 「投資」概念の完成

商人が航海団へ資本を出し、航海団は外国から香料・宝石・珍しい植物などを持ち帰り、利益を出資者へ分配する――失敗すれば出資者は損失を負う。**危険を引き受けて資本を出し、成功時の利益を分配する**というこの仕組みは、[620年の原始的蓄積で必要性が指摘されながら語形が確定していなかった「投資」](../言語/未確定事項.md)という経済概念が、実際の制度として結実したものである。ここから共同出資・海上保険・信用・為替が発達する余地が生まれ、Vargan経済は近世的な性格を帯びていく。

### Varga産ハードウッドという戦略資源

[Vargaでは古くから銀とハードウッドが産出してきた](../地理/ヴァルガ本土.md)。外洋航海時代を迎えると、建築材・家具・武器・小型船などに使われてきたこの良質な木材が、大型船の船体・竜骨・マストへ大量に投入される戦略資源として価値を増す。政治首都の座を失って久しいVargaは、**造船資材の供給地**として再び国家的重要性を高めていく。680年に世界の動植物を集める施設が完成していることも相まって、Vargaは「船を造るための木材を送り出し、航海者が持ち帰った世界を受け入れる都市」という独特の位置を占めるようになる。

## Varganらしい大航海の目的

[500年頃に確立した非参戦原則](../政治と軍事/非参戦原則.md)を持ち、軍事大国でもないVarganにとって、大航海は最初から征服を第一目的としない。むしろ異なる目的を持つ四者が海へ出る。

* **Senar** ― 未知の世界を知りたい
* **Berar** ― 新しい交易路・商品を求める
* **使徒** ― 「この世界に糧を」を未知の人々へ届けたい
* **Organ** ― 外国との関係を築き、Varganの国益を広げたい

この四者が同じ船に乗ることすらある。海賊・未知の敵対勢力・船上反乱への備えとして弓兵・槍兵に相当する護衛も同乗するが、彼らの役割はあくまで**航海団のVek（防衛）**であって、未知の土地を征服することではない。一隻の船が交易船・探検船・研究船・使節船・布教船を兼ねる、Varganらしい複合的な編成になる。

### 「発見」とは何か

航海者が島へ到達しても、そこにはすでに人が住んでいることが多い。これを「我々が発見した土地」と呼べるのかという問題が、[Ruvanという地名を現地語から借用した前例](../地理/ルヴァン.md)や「この世界に糧を」という普遍宗教の存在を背景に、比較的早い段階で議論の対象になる。ここから、**「Senしていなかったこと」と「存在していなかったこと」は違う**という思想が育つ。Varganにとっての「発見」とは、無主の土地を見つけることではなく、**Varganの知識体系に初めて加わること**を意味する――これは後の植民・領有思想に大きな影響を与える視点である。

### 「この世界に糧を」の対象が広がる

435年当時の「世界」は、実際にはVargarが知っている世界に限られていた。710年、航海者がこれまで誰も知らなかったGaとHumを発見すると、使徒は「この世界とは、我々が知っている世界だけではなかった」と気づく。「未知のHumにも啓示は適用されるのか」という問いに対し、福音主義者は「適用される」と答え、使徒が航海に同行するようになる。

一方でVarganの非参戦外交の伝統から、「教えを受け入れないなら武力で従わせる」方向には向かいにくい。むしろ「**糧は与えるものであり、押し付けるものではない**」という原則が宗教内部で成立し、啓示を受け取るかどうかは相手に委ねるという**布教倫理**が育っていく。もっとも、現実には商人や政治家が現地勢力へ圧力をかけることもあり、理想と現実の矛盾は残り続ける。

## 風・海流・星を記録する

ガレー船の時代と決定的に違うのは、外洋では人力に頼れないことである。季節風・恒常風・海流・嵐の季節・星の位置・太陽高度を体系的に記録する必要が生まれ、航海者は「この季節に西へ向かえばこの風が吹く」という経験則を記録し、次の航海者がそれを読んで修正する。**経験知→記録→比較→法則化**という循環が710年代から数十年をかけて成立し、これがルネサンスの知的態度と合流していく。

[前900年頃から巨大図書館を持つSilga](../技術と知識/シルガ大図書館.md)は、この過程で航海知識の集積地としての役割を新たに担う。航海団は帰還すると航路・海流・風・星・海岸線・港・民族・言語・動植物を報告し、SenarがそれをSilgaで整理して、次の航海団へ最新版の世界地図として返す。航海するたびに地図が更新されるという感覚は、それまでの世界観になかったものであり、**「世界についての知識は完成していない」**ことが社会的に理解され始める契機になる。

### 船団という組織

複数の外洋帆船を保有するようになると、一隻ずつ送り出すのではなく、大型船・補給船・小型高速船を組み合わせた**船団**として運用されるようになる。一隻が損傷しても他船が救助できるという実利に加え、船長のほかに航海長・記録官・交易責任者・使徒代表・医療担当・通訳・外交担当が乗り組む、恒久的な組織としての「航海団」が形づくられていく。これがVargan初の本格的な海洋組織になる。

## 知識の循環 ― 航海・研究・王立動植物苑

[680年に完成したVargaの王立動植物苑](../技術と知識/王立動植物苑.md)は、大航海時代と強く結びつく。航海者が持ち帰る未知の植物・鳥・動物・種子・鉱物がVargaで飼育・栽培・記録され、SilgaのSenarが研究する。**航海→標本→Varga→研究→Silga→書物→次の航海**という知識循環がここに生まれ、Vargan科学革命の前段階を形づくる。

### 探検語彙の確定

710年以降、以前から保留されていた[探検語彙](../言語/未確定事項.md)――地図・海岸・海峡・半島・方位・星・天測・航海者・探検隊・未知・発見・海流・風・外洋などを本格的に確定すべき時期を迎え、中核となる語群はすでに確定している。**Elsen（未知、el＋sen＝「知の彼方」）**は無知（Senの否定）ではなく「まだSenされていないだけで、いずれSenできるもの」を指し、そこから**Sendar（発見する、sen＋dar）／Sendaran（発見）／Sendarar（発見者）**が派生する。「VargarがメキシコをSendarした」とは言えても「Vargarがメキシコを存在させた」という意味にはならない、Vargan的な発見の哲学がそのまま語形になっている。地理・航海の道具としては**Elmar（外洋、el＋mar）**、**Gametkad（地図、gamet＋kad。中期口語ではGamkadに縮約）**、**Margamkad（海図、mar＋gamkad）**が確定し、地図はもはや単なる道の記録ではなく、**世界をSenするための道具**になっていく。探検そのものを指す語も**Elsenran（探検）／Elsenranar（探検者）**（elsen＋ran）に確定したが、探検隊という集合名詞は対応する接尾辞がないため、当面「Elsenran so Elgan（未知への旅をする旅人たち）」のような句で表現する。新古語根**Vez（風）**が確定し、キャラック相当の大型外洋帆船そのものも**Veznav（帆船、vez＋nav）**として確定した。恒常風・季節風・海流などの航海気象語彙は、Vezの複合語として整備できる見込みだが、個別の語形はまだ保留している。

## ルネサンスと大航海の相互加速

古典研究者が古い航海記録を読み、「西方に島がある」という記述を見つける。航海者がそれを確かめに行き、実際に島を発見する。古典の記述の一部は正しく、別の部分は誤りだったと判明する。ここから**「古典だから正しいとは限らない」**という実証的な態度が育ち、観察と実測が重視されるようになる。ルネサンスは単なる古典崇拝ではなく、**古人をSenし、古人を疑い、自分で確かめる**という思想へ進む――これは後の科学革命につながる重要な段階である。

### 天の啓示と自然観察

この実証的態度は、[天の啓示](../社会と文化/新宗教の成立.md)との関係も問い直す。当初は「天の啓示は絶対であり、自然研究とは別」と整理されるが、やがて「天が作った世界をSenすることも、天をSenする一つの方法ではないか」という思想が現れる。これにより、宗教が自然研究を阻害するとは限らず、**世界を観察すること自体が宗教的価値を持つ**という学派まで成立しうる。

## 「海が道になった年」

古代Vargarにとって海は魚を得る場所であり、やがて沿岸都市を結ぶ場所となり、探検時代には遠方へ向かう場所になった。そして710年頃から、**世界と世界を結ぶRan（道）**になる。陸上のRan、河川の航路に続いて、今度は外洋そのものが巨大な道として認識される。

| 領域 | 710年頃の転換 |
| --- | --- |
| 技術 | キャラック相当の大型外洋帆船 |
| 経済 | 620年以来の資本蓄積による大型航海事業の実現 |
| 学問 | 天文・地理・気象・地図学の急成長 |
| 交易 | 近隣文明との交易から遠洋交易へ |
| 宗教 | 使徒が既知世界の外へ進出 |
| 外交 | 未知の文明との直接接触の急増 |
| 政治 | 海外でVarganを誰が代表するのかという新しい問題 |
| 思想 | 古典に書かれた世界像を観察によって検証する態度 |

## 探検時代の終わり

前500年から710年までを「探検の時代――既知世界を広げる時代」とすれば、710年以降は「大航海・再生の時代――世界そのものを体系的に理解し直す時代」になる。単に船が遠くまで行くようになったからではなく、**Senの方法そのものが変わった**ことが本質である。

## 位置づけ

```
古代 ― 世界の中でVamがどう生き残るか
   ↓
探検時代（前500年〜） ― Vamの外には何があるのか
   ↓
435年以降 ― 世界へ何をDarすべきなのか
   ↓
620年以降 ― 世界へより多くDarするため、どう富を生み出すのか
   ↓
710年以降 ― そもそも「世界」とは何なのか
```

ここからVarganは、古典学・歴史学・地理学・天文学・航海術・自然学・金融・芸術が一斉に発達する段階へ入る。710年は政治的な革命というより**認識の革命**として位置づけられる。古典を読み直す者と、未知の海へ船を出す者は一見正反対の方向を向いているが、実際には同じことをしている――**「まだ知らないものを、自らSenしに行く」**。これが710年以降のVarganを象徴する精神である。

その最初の成果は早くも訪れる。[わずか5年後の西暦715年頃、別文明を挟んだ北方に最初の飛び地ナイランが成立する](../地理/ナイラン.md)。「海が道になった」ことで、陸上の領土的連続性を必要としない新しい領域観が現実の居住地として結実する。そしてさらに35年後の[西暦750年頃、東方の海の先で既知文明圏の外にあるメキシコ文明と遭遇する](東海遭遇.md)。探検の時代が、既知世界を広げる段階から、世界そのものの広さを実感する段階へと移る。

この古典再発見の運動は、およそ115年後の[西暦825年頃に古典復興の本格化](古典復興の本格化.md)として結実し、古典学が独立した学問分野になり、古ヴァルガ語が教育で継承される「古典語」として標準化されるまでに成熟していく。
