# 年表

日ノ本の出来事を、年の順に並べたもの。年はゲーム内の年を使っている。

## 古代

| 年 | 出来事 |
|---|---|
| 前4000年 | 卑弥呼に率いられた倭人の家族たちが、葦原中国の、砂漠を流れる川が湖に注ぐほとりに住みつく。のちの平安京。村の中心に、卑弥呼の家と日を祀る場所を置く。もう一つの大地・秋津島と接し、西に鳴神岳がそびえるところ |
| 前3975〜前3950年 | 川辺の小さな畑で大麦を育て、ほとりのギョリュウを切るようになる。村の外を見て回る者たちが出る |
| 前3925年 | 石切り場の野営地で、分け前が払われずに働き手たちが仕事をやめ、倭人が間に立って話をつける |
| 前3925〜前3900年 | 西と東で、まだ誰も住んでいない川の岸をいくつも見つける |
| 前3875年 | 倭人の家々が氏族ごとに長を立て、長たちの合議で物事を決めるようになる。祀りは卑弥呼が担う。道具作りを専らにする家が現れる |
| 前3875年 | 西の野営地で、舌禍で隠れていた詩人を、倭人がとりなして迎え入れさせる |
| 前3850年 | 湖に舟を出し、網で魚を捕るようになる。東の地で、火を噴く山ランギトトを見る |
| 前3825年 | 獣を飼いならし、群れで飼うようになる |
| 前3800年 | 東の地で、冬至の日に光が奥を照らす古い塚を見つけ、日と星の動きを記す場所とする。暦の始まり |
| 前3775年 | 舟に帆を張るようになる |
