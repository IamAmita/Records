# ラーナ人

**ラーナ人（ラーナ）**は、[ナムリア](../地理/ナムリア.md)を中心に形成された民族。古い言葉で**「河の民」「水辺に生きる者」**くらいの意味だったとされる。最初から「民族」として自己を認識していたわけではなく、「我々」「この河のほとりに住む者」程度の言葉が、後世になって民族名として解釈されたものである。

## 海から来た祖先

ラーナ人の祖先は内陸の農耕民ではなく、**カヌーを操る沿岸漁撈民**だった。漁撈・貝類採集・狩猟・植物採集・初歩的な栽培・沿岸航海を組み合わせ、季節ごとにいくつもの野営地を移動する生活を送っていた。完全な遊牧民でも、完全な農耕民でもない。

## 定住化の過程 ― 「移住して来た」のではなく「気づけば住んでいた」

**豊かな土地を見つけて移住した、という説明は弱い。** 実態は、移動生活をしていた人々が何世代もかけて徐々に定住化したというもの。

小河川の河口は、狩猟採集・漁撈民にとって非常に魅力的な立地だった。海・汽水域・淡水・湿地・森林という複数の生態系が狭い範囲に集まり、食料源が分散するため、何か一つが不漁でも別のものを食べられる。

| 時期 | 状態 |
| --- | --- |
| 前1600年頃 | 沿岸漁撈民が河口を季節的に利用 |
| 前1500年頃 | 毎年利用される野営地になる |
| 前1400年頃 | 貝塚・墓地・半恒久的な小屋が成立 |
| 前1300年頃 | 初歩的な稲作が始まる |
| **前1200年頃** | **年間を通じて居住する家族が多数派になる** |
| 前1100年頃 | 水田・穀物倉・共同墓地が成立 |

稲作は、外部の農耕民との接触（交易・婚姻・移住）を通じて学んだと考えられる。稲作には播種・水管理・雑草除去・収穫・貯蔵が伴うため、田を作った者はそこから離れにくくなる。しかも米は保存できる。この性質が、**季節的野営地 → 半定住集落 → 恒久集落**という変化を後押しした。

ただし全員が同時に定住したわけではない。前1200年頃のナムリアには定住民と移動民が混在しており、定住者の割合が徐々に増えていった。**「ナムリア建設の日」は存在しない。** 考古学的には「少なくとも紀元前1200年頃には恒常的な集落が存在した」としか判断できず、一方ラーナ人の伝承では「大河が初めて海へ辿り着いた日に、祖先はナムリアを築いた」という一夜の建国神話として語られる。この**神話（一夜にして生まれた故郷）と考古学（数百年かけていつの間にか生まれた集落）の二重構造**が、ナムリアの「いつかも分からない頃」という始まりの語り口をかたち作っている。

## 金・ルビーとの出会い

定住化とほぼ並行して、ラウ川上流のカルダ山地から流れてくる砂金・ルビーとの出会いが起きる。誰かが川底の輝く粒や赤い石に気づき、装飾品としての加工が始まり、やがて上流への進出の動機になった。→ [ラウ川とカルダ山地](../地理/ラウ川とカルダ山地.md)

## 民族としての自己認識 ― アルナリアの起源

数百年が経ち、「ナムリア以外を故郷としていた時代」を知る者がいなくなった頃、初めて「我々は何者なのか」という問いが生まれる。これが後世にいう**「アルナリアの起源」**（前1000年頃成立）。実際には数百年かけて緩やかに定住した歴史が、口承では「海を渡ってきた祖先が河口に降り立ち、黄金と赤き石を神々の徴と見てこの地に定めた」という単純化された建国神話に置き換えられている。

## 政治的共同体への発展

* 前1050〜950年頃：[首長制の成立](../政治と軍事/寡頭制とナムリア盟約.md)。年長者や有力な家の代表者による合議から、富を集めて再分配できる個人（アル）への権力集中が始まる
* 前850年頃：[寡頭制・ナムリア盟約の成立](../政治と軍事/寡頭制とナムリア盟約.md)。有力氏族「ナムリア五家」が政治権力を分有する体制へ

前1200年頃には「河口に住み着いた数十家族」に過ぎなかったラーナ人は、こうして数百年かけて、首長・戦士・商人・祭司・職人がいる複合社会へと変わっていった。→ [年表](年表.md)
