# 技術発展の順序 ― 陶器・畜産・帆走術

[定住化の過程 → 考察_定住化の過程.md](考察_定住化の過程.md)

三択（陶磁器・畜産・帆走術）なら、**陶磁器 → 畜産 → 帆走術**の順が一番自然。ただし「陶磁器」を厳密に**陶器・土器を含む焼き物技術**という意味で扱うのが前提。磁器そのものなら圧倒的に後世になる。

---

## 1位：陶器・土器

ナムリアの生活環境と非常に相性がいい。定住が進み、米・魚介類・植物資源を利用するなら、

* 米や種子の貯蔵
* 水の保存
* 煮炊き
* 魚介類の調理
* 塩の製造・保存
* 発酵食品
* 穀物酒

など、容器の需要がものすごく大きい。しかも原料になる**粘土が河川・沖積地で手に入りやすい**。

技術的にも、

> 粘土を成形する → 乾燥させる → 火に入れると硬くなる

という段階なので、金属加工や高度な航海技術より遥かに早く成立できる。史実でも土器は農耕社会より古い例すらあり、日本の縄文土器は1万年以上前まで遡る。

だからナムリアで紀元前1200年頃に定住が成立するなら、**土器技術は定住以前から知っていてもまったくおかしくない**。むしろ、

> ナムリアに定住したから土器を発明した

ではなく、

> **すでに簡単な土器を作れる人々がナムリアへやってきて、定住化によって土器生産が高度化した**

とした方が自然。

---

## 2位：畜産

これは少し微妙。ナムリアの環境は、**畜産にものすごく向いている土地ではない。** 熱帯雨林、湿地、マングローブ、小河川。広大な草原がない。だから牛・羊・馬を大量に飼育する牧畜文明にはなりにくい。

ただし、**豚・鶏**あたりなら非常に相性がいい。特に豚。森林資源を利用できるし、人間の食物残渣も食べる。定住集落の周辺で飼いやすい。鶏も同様。

だからナムリアの畜産は、

> 羊の群れを追う牧人

みたいなものではなく、

> **家の周りを豚と鶏が歩いている**

というタイプになる。さらに稲作が発達した後なら、水牛も重要になってくる。ただし水牛を水田耕作に本格利用するのは、初期集落より後でいい。

---

## 3位：帆走術

ここは面白いところ。**舟そのものは、むしろ三つの中でも最古級**でいい。ナムリアの祖先を沿岸漁撈民とするなら、

> 丸木舟 → 櫂による航行 → より大型の舟 → 帆走

となる。だから、**航海技術 ≠ 帆走術**として分けたい。

ナムリア成立以前から祖先は舟を知っている。川を渡る。沿岸を移動する。魚を捕る。島へ渡る。しかし、それは基本的に**櫂で漕ぐ舟**。帆を張って風力を本格的な推進力として利用する技術は、その後に発達する。

---

## 技術史として並べると

三択だけを並べるより、**舟 → 土器 → 畜産 → 帆走**くらいがナムリアには合う。

| 時代 | 技術 |
| --- | --- |
| 前1600年以前 | 丸木舟・漁網・石器・簡単な土器 |
| 前1500年頃 | 土器製作の高度化 |
| 前1400～1300年 | 豚・鶏などの飼育 |
| 前1300年頃 | 稲作拡大 |
| 前1200年頃 | 恒常的定住 |
| 前1000～800年 | 大型舟・造船技術発達 |
| **前800～600年** | **帆走技術が普及** |
| 前700～500年 | 海上交易本格化 |

ただし、ここは世界設定次第で**帆走をもっと早めても全然いい**。特にナムリア人を「海から来た民族」にするなら、

**帆走術 → ナムリア発見 → 定住**

という順番すら成立する。その場合、彼らは単なる沿岸漁撈民ではなく、すでにかなり優秀な海洋民族だったことになる。

---

## 結論・分岐案

三択の答えだけなら、

> **陶器が最初。次に畜産。帆走術が最後。**

が史実寄り。

ただ、ナムリア文明の個性を強くするなら、**畜産より帆走を先にする案**もかなり推せる。

**陶器 → 帆走 → 畜産**

として、「家畜を増やすより先に海を渡ることを覚えた人々」にすると、熱帯河口・マングローブ・海という地理条件と非常によく噛み合う。
