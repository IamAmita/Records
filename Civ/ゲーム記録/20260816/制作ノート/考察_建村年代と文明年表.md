# ナムリアの建村年代と文明史年表

[民族と文明の命名 → 考察_民族と文明の命名.md](考察_民族と文明の命名.md) ｜ [地理条件の史実整合性 → 考察_地理条件と史実整合性.md](考察_地理条件と史実整合性.md)

前提を「ラーナ人がこの地に最初の恒常的な農耕集落を築いた時期」とするなら、**紀元前2500～2000年ごろ**がかなり収まりがいいと思う。

ただ、「原初の居住地」を何と定義するかで年代は大きく変わる。

| 想定年代 | その頃のナムリア | 評価 |
| --- | --- | --- |
| 紀元前6000～4000年 | 漁撈・採集中心の小集落 | かなり古い。伝説的な始祖時代向き |
| 紀元前4000～3000年 | 初期農耕＋漁撈集落 | 「文明の黎明」として面白い |
| **紀元前2500～2000年** | **稲作を行う恒常的集落** | **一番おすすめ** |
| 紀元前1500～1000年 | 稲作村落が拡大、金属器も登場 | かなり史実寄り |
| 紀元前500年以降 | 鉄器・交易・都市化 | すでに「原初」という感じは弱い |

東南アジアをモデルにするなら、稲作農耕民の本格的な展開は概ね紀元前2千年紀に入ってからと考えるのが無難。だから、史実への寄せ方を優先するなら紀元前2000～1500年くらいでもいい。

ただ、この世界の「文明史の始点」にしたいなら、少し遡らせて**紀元前2400年ごろ**を推す。

---

## 紀元前2400年頃のナムリア

この時点では「アルナリア文明」なんてものはまだ存在しない。人口もせいぜい**数十～数百人程度**。

* 大河の自然堤防上に高床式の家を建てる
* 周囲の湿地で原始的な稲作を行う
* 舟で魚を獲る
* 森から木材や果実を採る

金やルビーは存在しているけど、まだ鉱山を開発しているわけじゃない。川原で「妙に重く輝く黄色い粒」や「美しい赤い石」が見つかる程度。

鉄鉱床も存在する。しかし、**鉄を作る技術はまだない**。

つまり、

> ~~紀元前2400年頃――ナムリア建村。~~

ではなく、後世の歴史書なら、

> **紀元前2400年頃と推定――ナムリア最古層。**

くらいになる。これが重要。

---

## 「建国」ではなく「積み重なり」

本人たちは「今日からナムリアを建国するぞ」とやったわけじゃない。最初は数家族が住み着いただけかもしれない。そこへ別の家族がやってきて、子供が生まれ、水田が増えて、何世代も経つうちに村になった。だから後世のラーナ人にも**正確な建設年は分からない**。

伝承では、

> 「大河が初めて海へ辿り着いた日に、祖先はナムリアを築いた」

とか言われている。一方、現代の考古学者は炭化米、杭、土器、炉跡などを年代測定して、

> **「少なくとも紀元前2400～2300年には恒常的な集落が存在した」**

と判断している。この**伝承の年代（神話的）と考古学の年代（実証的）の二重構造**がかなり自然で、使いやすい。

## 文明史年表（草案）

| 年代 | 出来事 |
| --- | --- |
| 前2400年頃 | ナムリア最古層（考古学上の推定） |
| 前2000年頃 | 稲作村落として成長 |
| 前1600年頃 | 周辺にラーナ系集落が拡散 |
| 前1200年頃 | 青銅・金加工 |
| 前900年頃 | 上流交易路成立 |
| 前700～500年頃 | 鉄器普及 |
| 前500年頃 | ナムリア都市化 |
| 前300年頃 | アルナリア文明最盛期 |

**約2000年かけて「湿地の村」が「黄金とルビーの都市文明」へ変わる歴史**にするとかなり史実らしくなる。

## 世界史上の位置づけ

「前2400年」を始点にすると、エジプトでは古王国、メソポタミアではシュメール都市国家が栄えていた頃になる。つまり世界の別地域では既に大都市や文字が存在しているのに、ラーナ人はまだ熱帯の河口で小さな稲作集落を営んでいる。

この**文明発達の地域差**も、後々の世界史を作るうえではかなり使いやすい。
