# カナダ／ウィルフリッド・ローリエ：古典時代 T61〜T120 の行動記録

Civ6 の Logs フォルダから取り出した、ゲーム上の出来事の記録。解釈は入れず、ログにあることだけを書く。ログから割り出したものは、そう書いてある。

* プレイヤー0：カナダ／ウィルフリッド・ローリエ（人間）
* ゲーム：2026-11-22 18:37 ごろに始めた新しいゲーム（net_message_debug.log）。ログには T241 まで残っている
* 範囲：古典時代 T61〜T120（18:49〜19:23 ごろに遊んだ）。ゲーム内の年は 紀元前1600年〜西暦100年
* ゲーム内の年：ログには出ないので、ゲーム速度（標準、GameCoreAppConfig.log）と、本体の GameSpeeds.xml の「1ターンで進む年数」から計算した。T1 が紀元前4000年で、はじめの75ターンは1ターンで40年ずつ進む。ターンごとの見出しと、まとめの各項目に書いた
  * T116 は計算ではちょうど0年になる。ゲーム画面でどう表示されるか（西暦0年か）は確かめていない
* この日の2つ目のゲーム。1つ目（17:20〜18:37、T1〜T196、同じくカナダ）は別のゲームで、同じ Logs に入っている
* ログの取得：2026-11-22 21:16 ごろ（ゲームを閉じたあと）。生ログはリポジトリの外（Civ生ログ/Civ6/20261122_Logs.zip）に置いてある
* 年の計算の確かめ：同じ計算で T249 は西暦1690年になり、別のゲームの手動セーブ名「パチャクティ 249 西暦1690年」（ゲーム画面の年がそのまま入る）と合う
* 作成：[civ6_record.py](../../../ゲームログ解析/スクリプト/civ6_record.py)。名前はゲーム本体の日本語テキストから引いた
* ターンの数え方：技術・社会制度・生産・人口の変化は、そのターンの始めに起きたもの。都市の建設・政体・使節などの操作は、そのターンのうちに行ったもの

### ログについて

* 技術：net_message_debug.log に残る「研究の選択」の順番を、Player_Stats.csv で技術の数が増えたターンに割り当てた（割り出し）。社会制度：AI_GovtPolicies.csv で、自国の候補から消えたターン（割り出し。完了数とすべて合う）
* 生産：City_BuildQueue.csv で、生産量が必要量に達したもの。ゴールドや信仰で買ったものは出てこない
* 他国の遺産の持ち主：都市名の既定の文明と、都市の移り変わり（Cultural_Identity.csv）から推した
* ログに残らないもの：どの社会政策を入れたか、取引の提案にどう答えたか、労働者が作った施設の種類、ユニットの移動、都市ごとの人口、戦闘の勝ち負け、部族の村の中身
