# 町ごとの建造物

[町々](../アヘル文明/地理/町々.md)を書くための考察。作者に「町ごとの建造物を基に、町ごとの特徴や役割、暮らしぶりの違いを整理してほしい」と頼まれた（2026-11-03）。町の特徴・役割・暮らしの読み替えは、作者の委任を受けて Claude が決めた。

* 数字は、[古代](../ゲームログ/01_古代の時代_T001-T134.md)・[探検の時代](../ゲームログ/02_探検の時代_T001-T102.md)・[近代の時代](../ゲームログ/03_近代の時代_T001-T060.md)の行動記録の「〇〇：××を建設」「資源「〇〇」を確保」「遺産「〇〇」が完成」「〇〇：××が完成」「人口：」の行から数えた
* 建造物と改善（農場、漁船、鉱山など）は分けて数えた。シティホールは数えていない
* 建て替え（Historian の OVERBUILDING）、購入だけの行、専門家の配置は数えていない
* 資源は、確保の行のすぐあとに建てた改善の町に結びつけた。改善を建てなかった資源（古代の染料、近代のトレドの大理石など）は、町に結びつかないことがある

## 3. 記事で決めたこと

| 決めたこと | もとにしたもの |
|---|---|
| ワセトは「新しいものが最初に来る町」 | 2章の表。52種のうち39種がワセトが最初 |
| ワセトは商人と開拓の出発地 | 商人14、開拓者9、移住者4 |
| ケメヌは信仰と学びの町、のちに鉄の町 | 遺産11（祈りと学びが多い）、製鉄所が最初、韮山反射炉 |
| ティニスは塩と墓と宮の町 | 塩（古代 T38）、遺産（ペトラ、テオドリック廟、アスキアの墓、エル・エスコリアル、ホワイト・タワー） |
| ゲブツは東の海辺の守りと祈りの町 | 古代の襲撃（鮮卑 T68、弥生 T97・T108・T119）、メジャイ（T113）、寺院系の遺産、士官学校が最初 |
| メンネファーは星と絹と鉄の町 | ムンド・ペルディド、絹（T83）、鉄（T112）、資源の種類が最も多い |
| ペル・アトゥムは海の幸の港、タ・ネチェルへの門 | 漁船15、遺産なし、財宝輸送隊の解散地点（探検 T87・T99）、テネメントが最初 |
| イプは金とヒスイの鉱山の町、芸術の町にもなる | 鉱山7、ゴールド・ヒスイ、ベジャス・アルテス宮殿、都市公園が最初 |
| ジャネトは畑と守りと訳す学びの町 | 農場11・漁船なし、太古の防壁、知恵の館、華城、近代のソンガイの攻撃 |
| ジェデトは海の向こうの富の町 | 建造物の一括購入（探検 T69・T84）、財宝輸送隊2、鉄道駅が最初 |

| ネケブからアケトアテンへ家族を送った | ネケブの開拓者（近代 T11）のあと、T15 にアケトアテンを建設 |
| 工場・長屋・大きな店の暮らしは本国の大きな町から始まった | 工場（ワセト、ティニス）、テネメント（ペル・アトゥム）、デパート（ティニス、メンネファー） |

## 4. 確かめて直したこと

記事を書いたあと、2章の表と照らして次の点を直した。

* 「マアトの教えの神殿はアケトアテンを除くすべての町に建った」としていたが、近代の西の大陸の町々にも建っていないので、「探検の時代までに開かれた町にはすべて建ち、近代に開かれた町には建てられなかった」とした
* 「本国の町々はどこも城壁で囲まれた」としていたが、中世の防壁はワセト、ケメヌ、ティニス、ゲブツ、メンネファーの5つだけなので、町の名を挙げた
* 「新しい町には、まず倉・レンガの作業場・木を挽く作業場が建てられた」を、開かれてすぐにそろうようになったジャネト（古代 T106）からのこととした
* 「古代の青銅の多くはケメヌのスズから」は言い過ぎなので、「法の時代からは近くでスズが掘られた」とした（青銅器は T53、ケメヌのスズは T86）
