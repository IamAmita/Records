探検の時代（T1〜T102）を5ターンずつ歴史にする（作者の依頼、2026-11-03）。その前に、時代全体にかかわる年代と名前を決めておく。名前・年代・読み替えは、作者の委任を受けて Claude が決めた（2026-11-03）。

* 探検の時代は、ターンが1から数え直しになる。古代のノートと混ざらないように、ノートはこのフォルダに置く
* ノートの形は古代と同じ。「ゲームで起きたこと／年代／名前／読み替え／歴史／年表」
* 文明はログの上ではエジプトのまま（[行動記録](../../ゲームログ/02_探検の時代_T001-T102.md)の見出しを参照）。タメン人の歴史として、そのまま続ける

## 1. 年代

古代の終わりを前1000年頃とした。タメン人は古代のうちに、史実より数百年早く、大地は丸いと説いていた（史実では前500〜前250年頃）。探検の時代のタメン人は、ゲームの上でもどの国よりずっと研究が早い。T101 の技術の数は 24 で、2位のアッバースの 13 の倍近い。そこで、史実との差はさらに広がるとみる。

## 2. 時代全体の名前

| 名前 | 中身 | 由来 |
|---|---|---|
| 富める家々の集まり | 金権政治 | 家の長たちの集まりの席が、生まれではなく、富を納める家に開かれた形。ゲームの説明にも「商家が安全と繁栄を担ってくれるなら、王がいる必要はあるだろうか」とある |
| 組合の祭り | 金権政治の祝宴（ゲーム上の「ギルド記念日」） | 富める家々と職人の組合が開く祭り |
| マアトの教え | ユダヤ教（自文明の宗教） | エジプトの言葉で「正しい秩序」。ゲームで選ばれた宗教の名前は、タメン人の歴史にそぐわないので、作中の名前を決めた |
| 教えを説く者 | 伝道師 | |
| 黄金のホルス | エジプトの社会政策「黄金のホルスI」 | ゲーム上の名前をそのまま神の名に使う。隼の姿の神で、黄金の像で祀られる |
| タ・ネチェル | オセアニア大陸 | エジプトの言葉で「神の地」。史実のエジプトでは、プントなど遠い国をこう呼んだ |
| 西の大陸 | 北アメリカ大陸、南アメリカ大陸 | 二つは座標の y が違うだけで、どちらが南北かは分からない。作中ではまとめて「西の大陸」と呼び、分けるときは「アメリカの人々の住む大陸」などと書く |
| 宝の船団 | 財宝輸送隊 | タ・ネチェルの富を本国へ運ぶ船団 |
| シナブン山 | ペル・アトゥムの近くの火山 (79,27) | ゲーム上の名前をそのまま使う（Game_RandomEvents.csv の LOC_VOLCANO_SINABUNG_NAME）。ハウネ山と違って名前の食い違いがない |

* 他の文明の宗教は、ゲーム上の名前で呼ぶ（ブガンダのヒンドゥー教、フランス帝国の神道など）。文明の名前もゲーム上の名前を使っているので、それに合わせる。歴史の文では「フランス帝国の教え」のように書き、名前は制作ノートに残す
* 探検の時代に創始された宗教（Game_Religion.csv）：エジプト ユダヤ教（T15）、ブガンダ ヒンドゥー教（T26）、アメリカ 東方正教会（T28）、ノルマン イスラム教（T31）、アッバース シク教（T43）、ソンガイ 儒教（T43）、フランス帝国 神道（T64）、漢 カトリック（T65）、戦国日本 道教（T69）、スペイン ゾロアスター教（T76）
* 遺産の作中の名前は、ノートごとに決める

## 3. 時代を通した筋

ログから見える、探検の時代の大きな流れ。ノートを書くときの手がかりにする。

* **富める家々の国**：T2 に金権政治。王を置かない国のまま、商いで富んだ家々が政を握る
* **マアトの教え**：T15 に創始。T38 から自国の町を改宗させ、T42 からは他の国の町へ広める。T74 に、25の居住地を改宗させる（レガシー「天の国」）。T88 にはフランス帝国がワセトを改宗させ、T89 に「分裂」、T95 に「改革権」と、教えをめぐる争いが続く
* **海へ**：T45 造船、T46 キャラック船、T51 に誰よりも早く世界をひと回りする（レガシー「ライムと乾パン」）。T56 にタ・ネチェルを望み、T69 にジェデトを開く。T86〜T91 にベフデト、ネケブ、クヒトと、タ・ネチェルに町が増える。T87・T99 に宝の船団が本国へ着く
* **かつての敵と手を結ぶ**：古代の終わりや探検の時代の初めに斥候を襲ってきた独立勢力（ジュンガリア、エテルキョズ、ロスキレ）と、のちに友好を結び、宗主になる。ジェデトを襲ったオノンダガとも、最後には友好を結ぶ
* **学び**：天文学（T2）、教育（T38）、火薬と F=ma（T77）、地動説と微積分（T80）、啓蒙思想（T86）
* **城の国**：T84 から、各地に城壁を築き続ける（T93 にレガシー「城の国」）。大きな国との戦争は、この時代もない
* **探られる国**：同盟を結んでいる国も含めて、ノルマン、フランス帝国、アッバースがタメン人の技や秘密を探り続ける
