## 古代（前4400〜1000年頃）

| 年代 | 出来事 |
|---|---|
| 前4400年頃 | 季節ごとにアヘル河の岸辺へ来ていたタメン人の一部が、増水の届かない高い所に住みつき、ワセトの村ができる |
| 前4400〜4300年頃 | 増水が引いた泥に種をまく畑作が定着する。村の外を見て回る者たちが出る |
| 前4300年頃〜 | ナツメヤシを子株から増やすようになる。人口が増える |
| 前4300年頃 | 道の上で殺し合って死んだ二人の商人の品を、ワセトの者が親族に返す。「持ち主が死んでも、品物はその家のもの」という先例として語り継がれる |
| 前4200年頃 | 舟で川に出て、網で魚を捕るようになる |
| 前4100年頃 | 家畜の群れが増え、草場を季節ごとに移るようになる |
| 前4000年頃 | 西の平原のソンガイの人々と出会い、品物の交換と、互いの土地の行き来が始まる |
| 前4000年頃 | 有力な家の長たちが集まって物事を決めるようになる。道具作りを専らにする家が現れる |
| 前4000〜3900年頃 | アヘル河に沿って遠い流域まで旅し、ブガンダの人々と出会う。東の砂漠のアッバースの人々とも出会う |
| 前3900年頃 | 遠い流域で、流れ者の射手たちの腕前を見る |
| 前3900〜3800年頃 | 舟にむしろの帆を張るようになる |
| 前3800年頃 | 東のメギドの敵意に備え、若者たちが投石器を持つ。ワセトの近くでハウネ山を見つける |
| 前3800年頃 | 西の地で荒らされた墓に行き会い、宝を家来たちから取り上げて持ち帰る。窯で焼いた硬い壺を作るようになる |
| 前3700年頃 | ソンガイと、争いのときに助け合う約束を結ぶ |
| 前3700年頃 | 水の神イメルを祀るようになり、イメルに仕える者が置かれる。船着き場を設ける。遠い流域の人々から星の見方を学ぶ |
| 前3700年頃 | 西の地の織物職人の秘伝を、伝統を重んじて断る。メギドへ贈り物を送る |
| 前3600〜3500年頃 | 遠い流域の職人たちを雇う。石を加工する技が広がる。新しい村を開く家族たちが支度を始める |
| 前3500年頃 | ワセトの外れで、家の長たちを葬る石の墓山の造営が始まる |
| 前3500〜3400年頃 | 遠い地で、誇り高い弓の狩人たちや、海岸を測る測量の者たちに出会う |
| 前3400年頃 | ワセトの家族たちが、アヘル河の岸にケメヌを開く。ワセトで初めての大祭が開かれる。ハウネ山が噴火する |
| 前3400年頃 | 増水の水を土手で囲った畑にとどめるようになる。メギドの舟が塩の海に現れ、投石兵が追い払う |
| 前3400年頃 | 東の海辺で、難破船から逃れた人々を助けずに立ち去る |
| 前3400〜3300年頃 | 遠い地で、野火で焼けた庭園の再建を手伝う |
| 前3300年頃 | アッバースと地図を分け合う。ブガンダの人々がタメン人の技をひそかに持ち帰る。はるか西のスペイン、フランス帝国と出会う |
| 前3300年頃 | 家の長たちの集まりが、初めていくさの長を選ぶ |
| 前3300〜3200年頃 | ワセトの墓山が完成する。東のアッバースと同盟を結ぶ |
| 前3200年頃 | 持ち主の家を記すしるしから、文字が使われ始める |
| 前3200〜3100年頃 | ワセトで、文字を刻んだ大石柱を立てる工事が始まる |
| 前3100年頃 | ワセトの東の砂漠の岸にティニスが開かれ、塩が取れる |
| 前3100年頃 | 増水の神ハピを祀り、一年を三つの季節に分ける。最初の季節を増水の季節アケトとする。ワセトとティニスに大きな倉が建つ |
| 前3100年頃 | 遠い地でチーズの作り方を学ぶ。ノルマン、ダル・ティシット、サマルカンドの人々と出会う |
| 前3100〜3000年頃 | 重さを秤で量って品物の値を決めるようになる。死者の心がアヌビスの秤にかけられると信じられるようになる |
| 前3000年頃 | 二度目の大祭 |
| 前3000年頃 | ワセトの大石柱が完成し、集まりの取り決めと増水の高さ、古い先例が刻まれる |
| 前3000〜2900年頃 | かつて敵対していたメギドが、タメン人を頼るようになる |
| 前2900年頃 | 徐羅伐の舟が塩の海でタメン人の舟を襲い、タメン人の戦いの舟がこれを沈める。ワセトで万国の門の工事が始まる |
| 前2900年頃 | チャン・チャン、メサ・ヴェルデ、チャンパ、漢の人々と出会う |
| 前2900年頃 | アヘル河の「大水」。ワセトの近くの畑と家々が沈み、多くの人が死ぬ。倉を守るため、見張りの兵メジャイが雇われる |
| 前2900〜2800年頃 | 青銅を作るようになる。スズは遠くから運ばれる |
| 前2800年頃 | ワセトの万国の門が完成する。東の砂漠の海辺にゲブツが開かれる。ケメヌに初めて弓の兵が置かれる |
| 前2800年頃 | 遠い西の海で、沈んだ船の聖なる品を直し、海を鎮める |
| 前2800〜2700年頃 | 荷車を使うようになる。ケメヌがワセトに次ぐ大きな町になる |
| 前2700年頃 | 遠い地でガラス作りの技を学ぶ |
| 前2700年頃 | 塩の海で、ラージャグリハの舟を沈める |
| 前2700〜2600年頃 | ワセトの墓山のまわりに、焼き物の兵の像が並べられる。弓の兵が投石兵に代わる |
| 前2600年頃 | ワセトにイメルの祭壇が設けられる。船着き場で大きな像の工事が始まる |
| 前2600〜2500年頃 | ケメヌの段々の庭が完成する |
| 前2500年頃 | 太陽の神アメン・ラーを祀るようになる。自分たちの土地をケメット（黒い土地）と呼ぶようになる |
| 前2500年頃 | ダル・ティシットがタメン人を頼るようになり、植物の繊維で書く物を作る技を得る。鮮卑がゲブツを襲う。アッバースとの同盟が途切れる |
| 前2500年頃 | ずっと東のノルマン、漢と、同時に同盟を結ぶ |
| 前2500〜2400年頃 | 舟が沖へ出て海を渡るようになる。町に広場ができる。三度目の大祭 |
| 前2400年頃 | ワセトの船着き場に、イメルの大像が立つ |
| 前2400年頃 | ケメヌに城壁の町と大広間ができる。タメン人の大工事が七つを数える |
| 前2400〜2300年頃 | チャン・チャンがタメン人を頼るようになる |
| 前2300年頃 | 家の長たちの集まりが、取り決めと先例をまとめて書かれた法とする。ワセトに書の蔵が建つ |
| 前2300年頃 | 遠い地で、ブドウ畑を作ることを勧める |
| 前2300〜2200年頃 | ゲブツの弓兵がチャンパの舟を沈める。ワセトにもてなしの館ができる |
| 前2200年頃 | ケメヌに神託の祠が完成する |
| 前2200〜2100年頃 | ワセトに家の長の墓（マスタバ）が造られ始める。東の平原にメンネファーが開かれる。はるか西のスペインへの交易の道が開かれる |
| 前2100年頃 | 工学と娯楽が広まる。ティニスの岩山に神殿を彫る工事が始まる。アッバースと再び同盟を結ぶ。戦国日本と出会う |
| 前2000年頃 | ワセトに死者の神殿が建つ。ケメヌの近くでスズが掘られ始める |
| 前1900年頃 | 祭りと祀りの作法が定められ、四度目の大祭。他のどの国よりも多くの決まりごとが整う |
| 前1900〜1800年頃 | 人は生まれた家の務めを継ぐと定められる。町に住む者が町の一員とされる。ケメヌに太陽の鳥の堂が完成する |
| 前1800年頃 | ワセトの岸に灯台が建つ。ワセトで大競技場の工事が始まる |
| 前1800年頃 | サマルカンドがタメン人を頼るようになり、頼ってくる町が四つになる。ゲブツが大きな町になる |
| 前1700年頃 | ハウネ山が噴火する。アヘル河の二度目の大きな水害で、多くの人が亡くなる |
| 前1700年頃 | ティニスの近くの岩の神殿が完成する。兵に決まった訓練を課すようになる |
| 前1700〜1600年頃 | ケメヌの大鐘が鋳られる。ワセトに大競技場ができる |
| 前1600年頃 | 町ごとに兵を出すことが定められる。弥生がゲブツを襲う |
| 前1550年頃 | 遠い西で病がはやっているという話が伝わり、病の兆しを見分ける者たちが町に置かれる。「疫病の時代」の始まり |
| 前1550〜1500年頃 | ハウネ山が大きく噴火する |
| 前1500年頃 | ゲブツに後の世の寺が完成する。スペインの都で疫病が確かめられる |
| 前1500年頃 | ワセトに、家の長たちの集まりの宮「大いなる家」が完成する。冥界ドゥアトの富が信じられ、墓や神殿に富が納められる |
| 前1500年頃 | 西のソンガイが、タメン人の兵の様子をひそかに探り始める |
| 前1500〜1450年頃 | 読み書きが広まる。五度目の大祭 |
| 前1450年頃 | ティニスに一枚岩の墓が完成する。ケメヌ、ゲブツ、ティニスにも家の長の墓と死者の神殿が建つ |
| 前1450〜1400年頃 | ワセトに学びの館が完成する。西の境にジャネトが開かれる |
| 前1400年頃 | 数の学びが進み、専門の務めを持つ者が育つ。アッバースへの交易路が開かれる |
| 前1400〜1350年頃 | ジャネトに城壁が築かれ、弓兵が集められる。ブガンダ、アッバースの商人がタメン人の町へ交易路を開く。弥生がゲブツを襲う |
| 前1350年頃 | ワセトに市場ができる。ソンガイの都への交易路が開かれる |
| 前1350年頃 | 戦国日本と同盟を結ぶ。ノルマンの商人がゲブツへ交易路を開く |
| 前1350〜1300年頃 | 知恵そのものを問う「知を愛する者」たちが現れる。硬貨が使われ始める。メンネファーで鉄の鉱石が見つかる |
| 前1300年頃 | 疫病が周りの国々に広がる中、家の長たちの集まりが神々を捨てた者を裁き、祭壇での祀りを命じる。いくさの長と兵がケメヌに置かれる |
| 前1300年頃 | ケメヌに太陽の基壇、ゲブツに聖なる塚が完成する。ソンガイの商人がジャネトへ交易路を開く |
| 前1250年頃 | ケメヌに書の大館が完成する。六度目の大祭 |
| 前1250〜1200年頃 | 商いの取り決めが整う。病の手当ての術が学ばれる。さまざまな考えを説く者たちが並び立つ |
| 前1200年頃 | 弥生がゲブツを襲う。ゲブツに堀の大神殿が完成する。ワセトに闘技の場ができる |
| 前1200年頃 | 鉄を作るようになる。知られている技のすべてに通じる |
| 前1200〜1150年頃 | ケメヌに大土壇が築かれる |
| 前1150年頃 | メンネファーに星の広場、ワセトに賢者の館ができる。疫病がティニスの近くに及ぶが、亡くなった人は少ない |
| 前1150年頃 | 病は悪い気から起こると考えられ、病の出た所から人を移す |
| 前1100年頃 | ワセトに大きな浴場ができる。七度目の大祭。書かれた物語や歌が好まれる |
| 前1050年頃 | ずっと東の海辺でチャンパの舟を沈め、ゲブツの近くで弥生の兵を討つ。はるか西の果てに大きな陸地を見る |
| 前1050年頃 | ずっと東の熱帯の海辺にペル・アトゥムが開かれる。疫病がタメン人の町では大きく広がらないまま収まる |
| 前1050〜1000年頃 | 星の広場の者たちが星の図を作り、大地は丸いと説く。ティニスから移った家族たちがメンネファーに住みつく |
| 前1000年頃 | 各地に市場、闘技の場、書の蔵が建つ。ティニスの近くで銀が掘られる。タメン人の古代の終わり |

## 探検の時代（前1000年頃〜700年頃）

| 年代 | 出来事 |
|---|---|
| 前1000年頃 | 古い庭園や兵舎、祭壇が新しい造りに建て直される。ずっと東の四つの国との同盟が続く |
| 前1000〜950年頃 | 家の長たちの集まりの席が、富を納める家々に開かれる（富める家々の集まり）。星の動きを数で表す学びと、富の動きを考える学びが生まれる |
| 前950年頃 | ワセトに屋根のある市ができる。各地に石切りの作業場ができる。ペル・アトゥムでタカラガイが集められる |
| 前950年頃 | シナブン山が大きく火を噴く。星の位置から地図を作るようになる。ワセトに星見の塔が建つ。富める家々と職人たちの最初の大祭 |
| 前950〜900年頃 | 古代の書き物が読み直され、写し直される（古い世の学びの見直し） |
| 前900年頃 | 歯車と水の仕掛けが作られる。各地に屋根のある市ができる |
| 前900〜850年頃 | ワセトに石の埠頭ができる。河の水車で麦をひき、木を挽くようになる |
| 前800年頃 | 旅する者たちが、はるか西の大陸の岸にたどり着く。富める家々が畑を耕す者に貸すようになる |
| 前750年頃 | ワセトの神官たちの中から、世の正しい秩序を説くマアトの教えが生まれる |
| 前750年頃 | かつてのメギドとサマルカンドの地のダマスカス、タブリーズがタメン人を頼る。各地にマアトの教えの神殿が建つ。遠い国々との取り決めが実を結ぶ |
| 前750〜700年頃 | 商いで国に富を集めることが第一とされる。ワセトに旅の宿ができる。二度目の組合の祭り。ティニスで泥の大墓の工事が始まる |
| 前700年頃 | ジャネトで香辛料が採れる。ノルマンの人々がタメン人の技をひそかに持ち帰る |
| 前700年頃 | 石の城が築かれるようになる。マアトの教えが書き物にまとめられ、天から告げられた教えと説かれる。ソンガイとスペインへ交易の道が開かれる。シナブン山が火を噴く |
| 前650年頃 | ワセトとケメヌに城の牢が設けられる。アッバースへ交易の道が開かれる。ティニスに泥の大墓が完成する |
| 前650年頃 | 職人たちが組合を作る。ワセトに組合の館と大きな窯ができる。天から告げられた言葉が、マアトの教えの書に記される |
| 前650〜600年頃 | ゲブツに白鷺の城が完成する。ノルマンとブガンダへ交易の道が開かれる |
| 前600年頃 | シナブン山が大きく火を噴き、ペル・アトゥムが建て直される。メンネファーで骨の社の工事が始まる。ノルマン、戦国日本との同盟が解かれる |
| 前600〜550年頃 | 富める家々の集まりが町々への命令を強める。富める家々が家のしるしを旗や盾に描く。三度目の組合の祭り |
| 前500年頃 | ティニスの前の海で鯨が捕られる。富める家々が金で兵を雇い入れる。ペル・アトゥムが東の大きな町になる |
| 前450年頃 | かつて斥候を討ったロスキレへ友好の使いを送る。漢との同盟が解かれ、同盟国はアッバースだけになる |
| 前450年頃 | 戦国日本とフランス帝国の都へ交易の道が開かれる。ワセトの市に、どの国よりも多くの品が集まる |
| 前400年頃 | 人が富によって分けられるようになる。神殿に富を納める考えが重んじられなくなる。メンネファーに骨の社が完成する |
| 前300年頃 | アヘル河がワセトの近くであふれる。学びの段階と、修めたしるしが定められる。マアトの教えがメンネファーに広まる |
| 前250年頃 | 一人ひとりの正しい行いを重んじ、誰もが教えの書を読むべきだとする、教えの改めが起きる。ガラマがタメン人を頼る |
| 前250〜200年頃 | マアトの教えが、ほかの神々を迎え入れる。大船渡とゲブツにマアトの教えが広まる。黄金のホルスの像が祀られる。メンネファーに百八の塔の僧院が完成する |
| 前200〜150年頃 | ワセト、ケメヌ、ティニスに学舎が建つ。大きな船の造り方が整う |
| 前150年頃 | 海の向こうに町を開くことが考えられる。大きな帆船が海に出る。マアトの教えが東のノルマンの町ルーアンに広まる |
| 前150〜100年頃 | ゲブツにマアトの大堂が完成する。ワセトに大きな造船所ができる。法で裁く者のために、目を助けるガラスを作らせる。四度目の組合の祭り |
| 前100年頃 | 金属を溶かして形に流す技が進む。マアトの教えがティニスに広まる。フランス帝国が集まりの秘密を探り始める |
| 前100年頃 | タメン人の船の一団が、どの国よりも早く世界をひと回りし、大地が丸いことを確かめる。役人が集まりの務めを分けて担う。西の大陸でアメリカの人々に出会う |
| 前100〜50年頃 | 富める家々の集まりの在り方を定めた「根本の定め」ができる。遠い国々の都に使いが常に置かれる。五度目の組合の祭り |
| 前50年頃 | マアトの教えがブガンダの町ナカソンゴラに届く。ワセトとケメヌで二つの大工事が始まる |
| 前50年頃 | ペル・アトゥムのずっと東に、大きな陸地タ・ネチェルを望む。漢の都へ交易の道が開かれる |
| 1年頃 | ワセトに段の聖山、ケメヌに高塔の寺が完成する。ヴェネツィアがタメン人を頼る。マアトの教えがジャネトに広まる |
| 50年頃 | ティニスに宮と僧院が完成する。トゥクメがタメン人を頼り、頼ってくる町が五つになる。ペル・アトゥムで海の向こうへ渡る支度が始まる |
| 50年頃 | ワセトに珍獣の園と見晴らしの館ができる。マアトの教えがアッバースの町ケルアン、ソンガイの町ルラミに広まる |
| 100年頃 | 海の向こうの町々を本国から治める仕組みが考えられる。ワセトに閉ざされた宮が完成する。マアトの教えがブガンダの都カンパラに広まる。西の大陸の向こうに、もう一つの大陸を見る |
| 150年頃 | かつて斥候を討ったロスキレがタメン人を頼る。ワセトで海の向こうに町を開く家族たちが集められる |
| 150年頃 | ジャネトに知恵の館が完成する。マアトの教えがアッバースの都バグダッド、ソンガイの都ガオに届く。フランス帝国が集まりの秘密を手に入れる |
| 150〜200年頃 | アウダグストがタメン人を頼る。遠い海で、疫病の船の聖なる品を売る |
| 200年頃 | 海を越えてタ・ネチェルにジェデトが開かれ、すぐにホデノショニに襲われる。ワセトに病人の家と両替の館ができる。どの国よりも早く八つの町にマアトの教えの神殿がそろう |
| 200年頃 | タメン人の土地はどの国の命令にも従わないと定められる（主権） |
| 200年頃 | ジェデトの兵がホデノショニの兵を撃ち退ける。アルルと于山国がタメン人を頼り、頼ってくる町が九つになる。絵や像が館に飾られて人々に見せられる |
| 250年頃 | ジャネトに金の塔が完成する。マアトの教えに改めた町が二十五を数える。戦国日本と再び同盟を結ぶ。六度目の組合の祭り |
| 300年頃 | ジェデトの兵がホデノショニの兵を退け続ける |
| 300年頃 | ジェデトが大きな町になる。マアトの教えがスペインの町コルドバに広まる |
| 350年頃 | どの国よりも早く火の薬を作る。物の動きが力と重さで決まると示される。はるか西の海で、ングル・マプの舟と撃ち合う |
| 350〜400年頃 | ティニスに白い塔が完成する。ホデノショニが再びジェデトを襲う |
| 400年頃 | 大地が太陽のまわりを回ると説かれ、限りなく小さく分けて量る数の術が編み出される。ワセトで石を放つ大筒が造られる |
| 400年頃 | ジェデトで宝の船団が仕立てられる。町に住む富める人々（町衆）が力を強める。マアトの教えに従わない町が冷たく扱われる。はるか西の海で、ングル・マプの私掠の舟を沈める |
| 450年頃 | ワセト、ケメヌ、ゲブツで城壁が築かれ始める。富める家々の集まりの座は神々が授けたものと説かれる。ングル・マプへ友好の使いを送る。七度目の組合の祭り |
| 500年頃 | 人の理の光で世を照らすべきだとする「光の思想」が起こる。タ・ネチェルにベフデト、アジア側の東にイプが開かれる。宝の船団がペル・アトゥムに着く |
| 500〜550年頃 | すべての国と交易の道を結ぶ。フランス帝国の教えがワセトに広まる |
| 550年頃 | 教えをめぐって本国の町々が乱れる。シナブン山が大きく火を噴く。戦国日本、アッバースとの同盟が解かれ、ノルマンと再び同盟を結ぶ |
| 550年頃 | タ・ネチェルにネケブとクヒトが開かれ、タ・ネチェルの町が四つになる。エテルキョズがタメン人を頼る |
| 550〜600年頃 | 本国の町々が、いくつもの城壁で囲まれる（城の国）。ジェデトで二つ目の宝の船団が仕立てられる。イプで金が掘られる |
| 600年頃 | 富める家々の集まりが、町々の教えを改めさせる権を定める。引き戻された町で、ほかの教えの建物が壊される |
| 600年頃 | タ・ネチェルの町々で、自ら耕す者が増える。ネケブが珊瑚の海へ出る拠点を設ける。八度目の組合の祭り |
| 600〜650年頃 | 畑を三つに分けて耕すやり方が広まり、タメン人の数が古代の終わりの倍を超える。かつてジェデトを襲ったオノンダガと友好を結ぶ。二つ目の宝の船団がペル・アトゥムに着く |
| 650年頃 | ベフデトとイプが大きな町になる。はるか西の海で、ブアンサの舟と撃ち合う |
| 650年頃 | ジュンガリアがタメン人を頼り、頼ってくる町が十一になる |
| 700年頃 | ベフデトで三つ目の宝の船団が仕立てられる。はるか西の海でブアンサの舟を沈める。タメン人の探検の時代の終わり |

## 近代の時代（700年頃〜850年頃）

| 年代 | 出来事 |
|---|---|
| 700年頃 | 富める家々の集まりが、家の長の一人を大いなる家の座に据える。タメン人に初めて王が立ち、ヒミコと名乗る。国の務めは役人たちが担う |
| 700〜710年頃 | 火で湯を沸かして動かす釜が作られる。生き物を集めて分ける学びと、町の暮らしの苦しみを考える学びが起こる。ワセトで大きな学び舎の工事が始まる |
| 710年頃 | ヒミコが立って初めての大祭。アッバースと再び同盟を結ぶ。兵の動かし方を学びとして教えるようになる |
| 720年頃 | ケメヌとティニスに鉄の炉ができる。漢と再び同盟を結ぶ。ケメヌで赤い砦、ティニスで湯の館の工事が始まる |
| 720〜730年頃 | 火の釜で動く機械で、布や鉄の品が大量に作られるようになる。国の在り方を論じる学びが起こる。フランス帝国、戦国日本と同盟を結び、同盟国が五つになる |
| 740年頃 | タ・ネチェルのいちばん東にアケトアテンが開かれる。ジャネト、ベフデト、クヒトで大工事が始まる。ケメヌの近くで竜巻が起きる |
| 740年頃 | 古代のメギドとサマルカンドの地に興ったモナコとオヨ・イレが、三たびタメン人を頼る。古いケメットの決まりが改められる。ケメヌの近くで竜巻 |
| 750年頃 | 雷の力を銅の線に流して使う術が編み出される。人々が町に集まる。ワセトの大学が完成する。ジャネトの近くで竜巻 |
| 760年頃 | ヒミコのもとに、町の一員たちが選んだ者の集まり（民の集まり）が置かれる。誰でも思うことを書き、語ってよいと定められる。ゲブツにいくさの学び舎ができる |
| 760年頃 | ケメヌに赤い砦、ティニスに湯の館が完成する。パンサンがタメン人を頼る。ゲブツの近くで激しい雷雨 |
| 770年頃 | ジャネトに花の城壁が完成し、西の境の守りが固くなる。一人ひとりの自由と自由な商いを重んじる考えが広まる |
| 780年頃 | タ・ネチェルのジェデトに最初の鉄の道が敷かれる。油を燃やして動く釜が作られる。イプの近くでタシケントの兵と戦う |
| 790年頃 | メンネファー、ティニス、ワセト、ケメヌが鉄の道で結ばれ始める。役人の務めと位が細かく定められる |
| 790〜800年頃 | セケト・アアルにスウェネト、アメンテトにネケンが開かれる。ネケンで燃える水がくみ上げられる。本国の町々に鉄の道の駅が増える |
| 800年頃 | ワセトの近くでアヘル河が大きくあふれる。通貨が金を拠りどころとするようになる。ソンガイがタメン人の富を損なおうと企てる |
| 805年頃 | 声や合図を線なしで遠くへ送る術が編み出される。ジェデトで鉄の塔の工事が始まる |
| 805〜810年頃 | 各地にいくさの学び舎と港ができる。西の大陸の町々で新しい町を開く家族たちが集められる。ゲブツの近くで竜巻 |
| 815年頃 | 世界の国々が商いと声で一つに結ばれ始める。クヒトに草葺きの大墓、ベフデトに山の金の寺が完成し、この時代の大工事が六つを数える。遠い海でタウンジーの戦船を沈める |
| 820年頃 | 工場で品物を同じ形で大量に作るようになる。アメンテトにザウとペル・ハトホル、セケト・アアルにアブが開かれる |
| 825年頃 | ブハラがタメン人を頼る。ワセトに声の館ができる |
| 830年頃 | ソンガイと都市国家エチオピアが、タメン人にいくさを挑む。タメン人が大きな国からいくさを挑まれた初め。同盟国と頼ってくる町々がソンガイにいくさを告げる |
| 830年頃 | スペインもタメン人にいくさを挑み、同盟国がソンガイとスペインにいくさを告げる。セケト・アアルでソンガイの兵がスウェネトを攻める。ティニスの近くで古代の遺跡が掘られる |
| 830〜835年頃 | 鉄の車が初めて戦いに出る。どの国よりも早く空を飛ぶ機械を作る。戦船が鋼の戦船に造り替えられる |
| 835〜838年頃 | ソンガイの兵が大筒を引いてジャネトを攻めるが、花の城壁と兵が防ぐ |
| 840年頃 | ワセトに初めての工場が建つ。ソンガイの兵がジャネトを攻め続けるが、ジャネトは落ちない |
| 840〜845年頃 | ジェデトに鉄の塔が完成する。セケト・アアルにハットワレットが開かれる。インデイスラン・ナカーがタメン人を頼り、頼ってくる町が七つになる。鋼の戦船がソンガイの戦船を沈める |
| 845年頃 | 鋼の戦船が塩の海を越えて、スペインの町セビーリャとトレドを撃ち始める。暮らしをよくしていこうとする考えが広まる。ティニスに大きな店ができる |
| 845年頃 | 数を速く計算する機械が作られる。ケメヌに火を返す炉が完成する。鋼の戦船がスペインのセビーリャとトレドの守りを撃ち破る |
| 845〜850年頃 | タメン人がスペインのトレドとセビーリャを奪う。タメン人が他の国の町を奪った初め。ブガンダがタメン人を非難する。ネケブに白い霊廟が完成する |
| 850年頃 | イプに芸術の宮が完成する。ジャネトは最後まで落ちない。ティニスに二つ目の工場が建つ。工場の品が鉄の道と港で世界じゅうへ運ばれ、タメン人の国が世界の富と商いの中心になる。タメン人の近代の時代の終わり |
