# 歴史年表

[← アヘル文明](../アヘル.md) ｜ [年表（出来事ごと）](年表.md)

タメン人の始まりから探検の時代の終わり（前4400年頃〜700年頃）までを、古代の五つの時代と、探検の時代の四つの時代に分けた年表。時代の名前は、後の世の人々の呼び方による。年代はどれもおおよそのもの。出来事ひとつひとつは[年表](年表.md)にある。太字は、時代の流れを変えた出来事。

## 時代区分

### 古代（前4400〜1000年頃）

| 時代 | 年代 | あらまし |
|---|---|---|
| [村の時代](#村の時代) | 前4400〜3500年頃 | アヘル河の岸にワセトの村ができ、畑作と漁が始まる。家の長たちの集まりが物事を決めるようになり、水の神イメルが祀られる |
| [墓山の時代](#墓山の時代) | 前3500〜2900年頃 | ケメヌとティニスが開かれ、ワセトに墓山が築かれる。文字が使われ始め、増水の神ハピと三つの季節、アヌビスの秤が信じられる |
| [青銅の時代](#青銅の時代) | 前2900〜2300年頃 | 大水のあと、青銅を作るようになる。ゲブツが開かれ、大工事が七つを数える。国をケメットと呼び、太陽の神アメン・ラーを祀る |
| [法の時代](#法の時代) | 前2300〜1550年頃 | 取り決めと先例が書かれた法になる。メンネファーが開かれ、生まれた家の務めを継ぐ定めなど、決まりごとが整う |
| [疫病の時代](#疫病の時代) | 前1550〜1000年頃 | 遠い西から疫病が広がる。大いなる家と学びの館ができ、知を愛する者たちが現れる。鉄を作り、大地は丸いと説かれる |

### 探検の時代（前1000年頃〜700年頃）

| 時代 | 年代 | あらまし |
|---|---|---|

## 村の時代

**前4400〜3500年頃**

季節ごとにアヘル河の岸辺へ来ていたタメン人の一部が、増水の届かない高い所に住みついた。人々は増水が引いた泥に種をまき、舟で魚を捕り、家畜を連れて草場を移った。やがて有力な家の長たちが集まって物事を決めるようになり、アヘル河に沿って遠い流域まで旅をした。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 前4400年頃 | **ワセトの村ができる** | 増水が引いた泥に種をまく畑作が定着する | |
| 前4300年頃 | 殺し合って死んだ二人の商人の品を、親族に返す。「持ち主が死んでも、品物はその家のもの」という先例になる | ナツメヤシを子株から増やす | |
| 前4200〜4100年頃 | 家畜の群れが増え、草場を季節ごとに移る | 舟と網で魚を捕る | |
| 前4000年頃 | **有力な家の長たちが集まって物事を決めるようになる**。道具作りを専らにする家が現れる | | 西の平原のソンガイと出会い、品物の交換が始まる |
| 前4000〜3900年頃 | | | アヘル河の遠い流域でブガンダと、東の砂漠でアッバースと出会う |
| 前3900〜3800年頃 | 東のメギドの敵意に備え、若者たちが投石器を持つ。ワセトの近くでハウネ山を見つける | 舟にむしろの帆を張る。窯で焼いた硬い壺を作る | 西の地で荒らされた墓に行き会い、宝を取り上げて持ち帰る |
| 前3700年頃 | 西の地の織物職人の秘伝を、伝統を重んじて断る（「家の技はその家のもの」） | **水の神イメルを祀り、仕える者を置く**。船着き場を設ける。遠い流域の人々から星の見方を学ぶ | ソンガイと、争いのときに助け合う約束を結ぶ。メギドへ贈り物を送る |
| 前3600〜3500年頃 | 新しい村を開く家族たちが支度を始める | 遠い流域の職人たちを雇い、石を加工する技が広がる | |

## 墓山の時代

**前3500〜2900年頃**

ワセトの外れで、家の長たちを葬る石の墓山の造営が始まった。ワセトの家族たちはケメヌを、のちにティニスを開いた。持ち主の家を記すしるしから文字が生まれ、ワセトには文字を刻んだ大石柱が立った。増水の神ハピを祀って一年を三つの季節に分け、死者の心はアヌビスの秤にかけられると信じられた。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 前3500年頃 | | **ワセトで墓山の造営が始まる** | 遠い地で、誇り高い弓の狩人たちや、海岸を測る者たちに出会う |
| 前3400年頃 | **ケメヌが開かれる**。初めての大祭。ハウネ山が噴火する | 増水の水を土手で囲った畑にとどめる | メギドの舟を投石兵が追い払う。東の海辺で、難破船から逃れた人々を助けずに立ち去る |
| 前3400〜3300年頃 | | | 遠い地で、野火で焼けた庭園の再建を手伝う |
| 前3300年頃 | **家の長たちの集まりが、初めていくさの長を選ぶ** | | アッバースと地図を分け合う。ブガンダの人々がタメン人の技をひそかに持ち帰る。はるか西のスペイン、フランス帝国と出会う |
| 前3300〜3200年頃 | | 墓山が完成する | **アッバースと同盟を結ぶ** |
| 前3200年頃 | | **持ち主の家を記すしるしから、文字が使われ始める**。大石柱の工事が始まる | |
| 前3100年頃 | **ティニスが開かれ、塩が取れる**。ワセトとティニスに大きな倉が建つ | **増水の神ハピを祀り、一年を三つの季節に分ける**。最初の季節は増水の季節アケト。遠い地でチーズの作り方を学ぶ | ノルマン、ダル・ティシット、サマルカンドと出会う |
| 前3100〜3000年頃 | | 重さを秤で量って品物の値を決める。死者の心はアヌビスの秤にかけられると信じられる | |
| 前3000年頃 | 二度目の大祭 | ワセトの大石柱が完成し、集まりの取り決めと増水の高さ、古い先例が刻まれる | かつて敵対していたメギドが、タメン人を頼るようになる |
| 前2900年頃 | | ワセトで万国の門の工事が始まる | 徐羅伐の舟を塩の海で沈める。チャン・チャン、メサ・ヴェルデ、チャンパ、漢と出会う |

## 青銅の時代

**前2900〜2300年頃**

アヘル河の大水が、ワセトの近くの畑と家々を沈めた。その後、タメン人は青銅を作るようになり、東の砂漠の海辺にゲブツを開いた。ワセトとケメヌでは大工事が続き、七つを数えた。自分たちの土地をケメット（黒い土地）と呼び、太陽の神アメン・ラーを祀るようになったのも、このころである。舟は沖へ出て海を渡り、ずっと東のノルマン、漢と同盟を結んだ。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 前2900年頃 | **アヘル河の「大水」**。多くの人が死に、倉を守る見張りの兵メジャイが雇われる | | |
| 前2900〜2800年頃 | | **青銅を作るようになる**。スズは遠くから運ばれる | |
| 前2800年頃 | **ゲブツが開かれる**。ケメヌに初めて弓の兵が置かれる | ワセトの万国の門が完成する | 遠い西の海で、沈んだ船の聖なる品を直し、海を鎮める |
| 前2800〜2700年頃 | ケメヌがワセトに次ぐ大きな町になる | 荷車を使う | |
| 前2700年頃 | | 遠い地でガラス作りの技を学ぶ | 塩の海で、ラージャグリハの舟を沈める |
| 前2700〜2600年頃 | 弓の兵が投石兵に代わる | 墓山のまわりに、焼き物の兵の像（土の兵）が並べられる | |
| 前2600年頃 | | ワセトにイメルの祭壇。イメルの大像の工事が始まる | |
| 前2600〜2500年頃 | | ケメヌの段々の庭が完成する | |
| 前2500年頃 | **自分たちの土地をケメット（黒い土地）と呼ぶようになる** | **太陽の神アメン・ラーを祀る** | ダル・ティシットがタメン人を頼り、植物の繊維で書く物を作る技を得る。鮮卑がゲブツを襲う。アッバースとの同盟が途切れる。**ずっと東のノルマン、漢と同盟を結ぶ** |
| 前2500〜2400年頃 | 町に広場ができる。三度目の大祭 | 舟が沖へ出て海を渡る | |
| 前2400年頃 | | ワセトの船着き場にイメルの大像が立つ。ケメヌに城壁の町と大広間ができる。**大工事が七つを数える** | |
| 前2400〜2300年頃 | ある家の長が、一時ほかの長たちより重んじられる。ただし王にはならない | | チャン・チャンがタメン人を頼る |

## 法の時代

**前2300〜1550年頃**

家の長たちの集まりは、それまでの取り決めと先例をまとめ、書かれた法とした。法の初めには、「品物はその家のもの」「家の技はその家のもの」という古い考えが置かれた。東の平原にメンネファーが開かれ、祭りと祀りの作法、町の一員の定め、生まれた家の務めを継ぐ定めと、決まりごとが整っていった。終わりのころにはハウネ山の噴火と二度目の大きな水害が続き、兵の訓練と、町ごとに兵を出す定めが生まれた。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 前2300年頃 | **取り決めと先例をまとめて、書かれた法とする**。余った穀物を倉から人々に配る仕組みができる | ワセトに書の蔵が建つ | 遠い地で、ブドウ畑を作ることを勧める |
| 前2300〜2200年頃 | ワセトにもてなしの館ができる | | ゲブツの弓兵がチャンパの舟を沈める |
| 前2200年頃 | | ケメヌに神託の祠が完成する | |
| 前2200〜2100年頃 | **東の平原にメンネファーが開かれる**。ワセトに家の長の墓（マスタバ）が造られ始める | | はるか西のスペインへの交易の道が開かれる |
| 前2100年頃 | | 工学と娯楽が広まる。ティニスの岩山に神殿を彫る工事が始まる | アッバースと再び同盟を結ぶ。戦国日本と出会う |
| 前2000年頃 | ケメヌの近くでスズが掘られ始める | ワセトに死者の神殿が建つ | |
| 前1900年頃 | 他のどの国よりも多くの決まりごとが整う | 祭りと祀りの作法が定められる。四度目の大祭 | |
| 前1900〜1800年頃 | **人は生まれた家の務めを継ぐと定められる**。町に住む者が町の一員とされる | ケメヌに太陽の鳥の堂が完成する | |
| 前1800年頃 | ゲブツが大きな町になる | ワセトの岸に灯台が建つ。大競技場の工事が始まる | サマルカンドがタメン人を頼り、頼ってくる町が四つになる |
| 前1700年頃 | **ハウネ山が噴火し、アヘル河の二度目の大きな水害で多くの人が亡くなる**。兵に決まった訓練を課す | ティニスの近くの岩の神殿が完成する | |
| 前1700〜1600年頃 | | ケメヌの大鐘が鋳られる。ワセトに大競技場ができる | |
| 前1600年頃 | 町ごとに兵を出すことが定められる | | 弥生がゲブツを襲う |

## 疫病の時代

**前1550〜1000年頃**

遠い西で病がはやっているという話が伝わり、家の長たちの集まりは、病の兆しを見分ける者たちを町に置いた。後の世の人々は、この時から古代の終わりまでを疫病の時代と呼ぶ。疫病は周りの国々に広がったが、タメン人の町ではティニスの近くで一度起きただけで、大きくは広がらなかった。この間に、ワセトには大いなる家と学びの館ができ、知恵そのものを問う者たちが現れた。タメン人は鉄を作るようになり、メンネファーの星の広場で星を観た者たちは、大地は丸いと説いた。

|---|---|---|---|
| 前1550年頃 | **病の兆しを見分ける者たちが町に置かれる** | | **遠い西で病がはやっているという話が伝わる** |
| 前1550〜1500年頃 | ハウネ山が大きく噴火する | | |
| 前1500年頃 | **ワセトに、家の長たちの集まりの宮「大いなる家」が完成する** | 冥界ドゥアトの富が信じられ、墓や神殿に富が納められる。ゲブツに後の世の寺が完成する | スペインの都で疫病が確かめられる。西のソンガイが、タメン人の兵の様子をひそかに探り始める |
| 前1500〜1450年頃 | 五度目の大祭 | 読み書きが広まる | |

## マアトの時代

**前1000年頃〜150年頃**

古代の終わりに硬貨と市場で富んだ家々が、家の長たちの集まりの席を得て、富める家々の集まりができた。前750年頃、ワセトの神官たちの中からマアトの教えが生まれた。教えは書にまとめられ、天から告げられたものと説かれ、やがて改められて、ほかの神々も迎え入れた。職人たちは組合を作り、石の城が築かれ、人は生まれよりも富によって分けられるようになった。終わりのころには学舎が建ち、大きな船の造り方が整った。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 前1000〜950年頃 | **家の長たちの集まりの席が、富を納める家々に開かれる（富める家々の集まり）**。古い庭園や兵舎、祭壇が新しい造りに建て直される | 星の動きを数で表す学びと、富の動きを考える学びが生まれる | ずっと東の四つの国との同盟が続く |
| 前950年頃 | ワセトに屋根のある市、各地に石切りの作業場ができる。シナブン山が大きく火を噴く。最初の組合の祭り | 星の位置から地図を作るようになる。ワセトに星見の塔が建つ | |
| 前950〜900年頃 | | 古代の書き物が読み直され、写し直される（古い世の学びの見直し）。歯車と水の仕掛けが作られる | |
| 前900〜800年頃 | ワセトに石の埠頭ができる。富める家々が畑を耕す者に貸すようになる | 河の水車で麦をひき、木を挽くようになる | 旅する者たちが、はるか西の大陸の岸にたどり着く |

## 帆船の時代

**前150年頃〜200年頃**

大きな帆船が海に出て、タメン人の船は、どの国よりも早く世界をひと回りした。古代に説かれた丸い大地の考えは、船によって確かめられた。ペル・アトゥムのずっと東にはタ・ネチェルを望んだ。マアトの教えは、ノルマンのルーアンを初めに、ほかの国の町々から、アッバースの都バグダッド、ソンガイの都ガオにまで広まった。富める家々の集まりは在り方を根本の定めに記し、ワセトには閉ざされた宮が、各地には大工事が次々と完成した。

| 前100年頃 | 役人が集まりの務めを分けて担う | **タメン人の船の一団が、どの国よりも早く世界をひと回りし、大地が丸いことを確かめる** | 西の大陸でアメリカの人々に出会う |

## 神の地の時代

**200年頃〜500年頃**

海を越えたタ・ネチェルに、初めてのタメン人の町ジェデトが開かれた。ジェデトはホデノショニの人々にたびたび襲われながらも大きくなり、そこから宝の船団が仕立てられた。本国では、どの国よりも早く火の薬が作られ、物の動きの法則と、大地が太陽のまわりを回るという考えが示された。富める家々は富で町や兵を買いそろえ、町衆が力を強めた。集まりの座は神々が授けたものとされ、本国の町々では城壁が築かれ始めた。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 200年頃 | **海を越えてタ・ネチェルにジェデトが開かれる**。すぐにホデノショニに襲われるが、兵が撃ち退ける。ワセトに病人の家と両替の館ができる。タメン人の土地はどの国の命令にも従わないと定められる | どの国よりも早く八つの町にマアトの教えの神殿がそろう。絵や像が館に飾られて人々に見せられる | アルルと于山国がタメン人を頼り、頼ってくる町が九つになる |
| 250年頃 | 六度目の組合の祭り | ジャネトに金の塔が完成する | マアトの教えに改めた町が二十五を数える。戦国日本と再び同盟を結ぶ |
| 300年頃 | ジェデトが大きな町になり、ホデノショニの兵を退け続ける | | マアトの教えがスペインの町コルドバに広まる |
| 350年頃 | ホデノショニが再びジェデトを襲う | **どの国よりも早く火の薬を作る**。物の動きが力と重さで決まると示される。ティニスに白い塔が完成する | はるか西の海で、ングル・マプの舟と撃ち合う |
| 400年頃 | ジェデトで宝の船団が仕立てられる。町に住む富める人々（町衆）が力を強める。ワセトで石を放つ大筒が造られる | **大地が太陽のまわりを回ると説かれる**。限りなく小さく分けて量る数の術が編み出される。マアトの教えに従わない町が冷たく扱われる | はるか西の海で、ングル・マプの私掠の舟を沈める |
| 450年頃 | ワセト、ケメヌ、ゲブツで城壁が築かれ始める。**富める家々の集まりの座は、神々が授けたものと説かれる**。七度目の組合の祭り | | ングル・マプへ友好の使いを送る |

## 光の時代

**500年頃〜700年頃**

学びと富で栄える町の区画から、人の理の光で世を照らすべきだとする光の思想が起こった。タ・ネチェルの町は四つになり、宝の船団がたびたびペル・アトゥムに着いた。一方、フランス帝国の教えがマアトの教えの始まりの地ワセトに広まると、教えをめぐる争いが本国に及んだ。富める家々の集まりは町々の教えを改めさせる権を定め、本国の町々はいくつもの城壁で囲まれた。それでも、大きな国との戦は起きなかった。終わりのころには、タメン人の数は古代の終わりの倍を超えていた。

| 年代 | 国と町 | 信仰・学び・技 | 周りの国々 |
|---|---|---|---|
| 500年頃 | タ・ネチェルにベフデト、アジア側の東にイプが開かれる。宝の船団がペル・アトゥムに着く | **人の理の光で世を照らすべきだとする「光の思想」が起こる** | |
| 500〜550年頃 | | **フランス帝国の教えがワセトに広まる** | すべての国と交易の道を結ぶ |
| 550年頃 | 教えをめぐって本国の町々が乱れる。シナブン山が大きく火を噴く。**タ・ネチェルにネケブとクヒトが開かれ、タ・ネチェルの町が四つになる** | | 戦国日本、アッバースとの同盟が解かれ、ノルマンと再び同盟を結ぶ。エテルキョズがタメン人を頼る |
| 550〜600年頃 | **本国の町々が、いくつもの城壁で囲まれる（城の国）**。ジェデトで二つ目の宝の船団が仕立てられる。イプで金が掘られる | | |
| 600年頃 | 富める家々の集まりが、町々の教えを改めさせる権を定める。タ・ネチェルの町々で、自ら耕す者が増える。八度目の組合の祭り | 教えに引き戻された町で、ほかの教えの建物が壊される | |
