# 町々

[← アヘル文明](../アヘル.md) ｜ [暮らしの移り変わり](../社会と文化/暮らしの移り変わり.md)

タメン人の町々が、それぞれどんな町で、どんな役割を負い、人々がどう暮らしたかをまとめたもの。町に建てられた建物、町で採れた品、町に造られた大工事から推し量った。年代は、町が開かれた頃。

## 3. 町ごとの特徴と暮らし

### ワセト

**始まりの地。政と商いと学び、海の向こうへの出発地**

* **特徴**：アヘル河と塩の海の両方に面する、始まりの地。大工事はケメヌと並んで最も多い十一。古代の墓山、大石柱、万国の門、土の兵、イメルの大像、大競技場、大いなる家、学びの館、探検の時代の段の聖山と閉ざされた宮、近代のワセトの大学がある
* **新しいものが最初に来る町**：書の蔵、もてなしの館、灯台、市場、賢者の館、浴場、記念の碑、星見の塔、学舎、造船所、病人の家、両替の館、声の館、工場と、新しい建物の多くはまずワセトに建った。新しい暮らしは、いつもワセトから始まった
* **役割**：家の長たちの集まりの宮、のちに王ヒミコの座。遠い国々へ向かう商人の一行の多くはワセトで仕立てられ、海の向こうに町を開く家族たちの多くも、ワセトで集められて船出した
* **暮らし**：漁の舟が多く、塩の海では真珠が採られた。近くの採石場では石膏と石灰岩が切り出された。役人、学ぶ者、商人、船乗り、職人が集まる、いちばん人の多い町だった。人々は闘技の場や大競技場で楽しみ、浴場で体を洗った。近代には工場で働く者が増え、声の館から町じゅうに声が流れた
* **災い**：近くの河辺で、アヘル河の大水が古代から近代まで何度も起きた。近くにはハウネ山があった

### ケメヌ

**信仰と学びの町。のちに鉄の町**

* **特徴**：ワセトの家族たちが最初に開いた町。大工事は十一で、神託の祠、太陽の鳥の堂、太陽の基壇、大土壇、高塔の寺と、祈りの大工事が多い。書の大館もここにある
* **役割**：古代から、信仰と学びの町だった。書の大館には各地の書が集められた。古代に初めて弓の兵が置かれた町でもあり、探検の時代にも、いくさの長の率いる兵が集められた。近代には、ティニスとともに最初の鉄の炉が建ち、大筒を鋳る火を返す炉も造られた
* **暮らし**：神官、教えを修める者、学ぶ者が多く住んだ。河の畑では祀りに焚く香料の木が、のちにはブドウが育てられ、ワインが作られた。法の時代からは近くでスズが掘られ、青銅のスズを遠くから運ばなくてよくなった。段々の庭や大鐘は、ケメヌの人々の自慢だった
* **災い**：近代には、近くで竜巻が続けて起きた

### ティニス

**塩と墓と宮の町**

* **特徴**：ワセトの東の砂漠の岸に開かれた。開かれた時から塩が掘られた。大工事は六つで、岩の神殿、一枚岩の墓、泥の大墓と墓が多く、富める家々の集まりの宮と僧院、牢と蔵と武具の置き場を兼ねる白い塔、湯の館もある
* **役割**：塩を国じゅうへ送る町。富める家々の宮と僧院、白い塔があり、富める家々の集まりの時代には、政を支えるもう一つの中心だった。近代には大きな店と二つ目の工場が建った
* **暮らし**：塩を掘る者、ラクダを捕らえて飼う者、石膏を切り出す者、のちには銀を掘る者が住んだ。前の海では鯨が捕られた。古代の終わりには、近くで一度だけ疫病が出て、家族たちが東のメンネファーへ移り住んだ。近代の人々は、湯の館で体を休めた

### ゲブツ

**東の海辺の守りと祈りの町**

* **特徴**：ティニスより東の砂漠の海辺。大工事は五つで、後の世の寺、聖なる塚、堀の大神殿、マアトの大堂と祈りの大工事が多く、白鷺の城もある。鉱山が多く、ルビーが掘られた
* **役割**：古代から、海から来る人々（鮮卑、弥生、チャンパ）にたびたび襲われ、見張りの兵メジャイや弓の兵が置かれた、東の海辺の守りの町。同時に、遠くから人々が祈りに来る町でもあった。探検の時代には石の橋が架けられ、近代には学びの作業場が置かれた
* **暮らし**：古代には綿が育てられ、布が織られた。マンゴーやナツメヤシ、石灰岩、ルビーも採れた。海辺の家族は見張りを欠かさなかった。寺や大堂には、救いを願う人々が集まった
* **災い**：近代には、近くで竜巻や激しい雷雨が続き、学舎が傷んだ

### メンネファー

**星と絹と鉄の町**

* **特徴**：ゲブツより東の平原。採れる品の種類は町々の中でいちばん多く、絹、米、マンゴー、鉄、馬、象牙、香辛料、真珠が採れた。森も広く、木を伐る場が多い。大工事は、星の広場、骨の社、百八の塔の僧院
* **役割**：古代の星の広場で星が観られ、「大地は丸い」と説かれた、タメン人の学びの源の一つ。鉄の鉱石が見つかり、鉄の時代を開いた町でもある。探検の時代には、タメン人の町で最初にマアトの教えが広まった
* **暮らし**：野生の蚕から糸を取って絹を織る者、米を育てる者、木を伐る者、鉄を掘る者、星を観る者が住んだ。ティニスから移ってきた家族たちもいた。教えを修める者たちが、百八の塔の僧院に住んだ。近代には大きな店ができた

### ペル・アトゥム

**海の幸の港。タ・ネチェルへの門**

* **特徴**：ずっと東の熱帯の海辺。漁の舟は町々の中で最も多い。象牙、タカラガイ、ウミガメ、カニ、鯨、真珠と、海と熱帯の品が集まる。大工事はない。近くにシナブン山がある
* **役割**：タ・ネチェルへ渡る船の出る港であり、タ・ネチェルの宝の船団が着く港。本国と海の向こうをつなぐ門だった
* **暮らし**：漁師、真珠を採る潜り手、象牙を集める者、船乗りの町。シナブン山はたびたび火を噴き、神殿や鉱山が傷み、人が死んだが、人々は町を離れなかった。近代には、町に集まった働き手が住む何階もある長屋が初めて建ち、町の庭もつくられた

### イプ

**金とヒスイの鉱山の町**

* **特徴**：ゲブツより東の、アジア側の平原。鉱山の数は町々の中で最も多く、金とヒスイ、粘土が掘られた。大工事は芸術の宮
* **役割**：鉱山の富の町。近代には、近くのタシケントの人々の兵と戦い、国の東の守りも担った
* **暮らし**：金やヒスイを掘る者、粘土で焼き物を作る者が多く住んだ。近代には、町の庭がつくられ、芸術の宮で芝居や絵が楽しまれた。鉱山の町が、芸術の町にもなった

### ジャネト

**畑と守りと訳す学びの町**

* **特徴**：西の境。ソンガイの都に近い。漁の舟が一つもない、ただ一つの本国の町で、その代わりに畑は町々の中で最も多い。白い土（カオリン）とスズが採れた。大工事は、知恵の館、金の塔、花の城壁
* **役割**：開かれてすぐに城壁が築かれ、弓の兵が集められた、西の守りの町。探検の時代には、各地の書を訳す知恵の館が置かれ、近代には花の城壁が築かれた。近代のいくさでは、ソンガイの兵に攻められ続けたが、一度も落ちなかった
* **暮らし**：麦を育てる者、白い土で白い焼き物を作る者、兵が多く住んだ。知恵の館では、遠い国の言葉を学ぶ者たちが働いた。近代のいくさの間、人々は花の城壁の内で、外から撃ち込まれる大筒の音を聞きながら暮らした

### タ・ネチェルの町々

* **ジェデト**：海の向こうに開かれた最初の町。開かれたその年に、倉、船着き場、作業場、神殿が建てられ、のちには組合の館、両替の館、病人の家、市まで、富める家々が富で買いそろえた。砂糖きびが育てられ、宝の船団が二度ここから本国へ向かった。ホデノショニの人々にたびたび襲われ、町の外では兵が守った。近代には、タメン人の最初の鉄の道がここに敷かれ、鉄の塔が建った。砂糖きび畑で働く者、木を伐る者、兵、船乗りの町
* **ベフデト**：タ・ネチェルの砂漠。鉄とルビーが掘られ、海では鯨や真珠が採られた。三つ目の宝の船団がここで仕立てられた。近代には山の金の寺と、いくさの学び舎ができた。鉱山の働き手と漁師の町
* **ネケブ**：タ・ネチェルの平原。砂糖きび、石膏、スズ、馬。近くの大きな珊瑚の海へ出るための拠点が設けられた。新しい町を開く家族たちを、ここからさらに東へ送り出した（アケトアテン）。近代には白い霊廟が建った
* **クヒト**：タ・ネチェルの砂漠。ラクダを捕らえ、石灰岩を切り出した。近代には草葺きの大墓と、いくさの学び舎ができた
* **アケトアテン**：タ・ネチェルのいちばん東の熱帯の海辺。漁の舟でタカラガイや真珠を採った。近代に開かれた町で、西の大陸の町々と同じく、マアトの教えの神殿は建てられなかった

### アメンテトの町々

* **ネケン**：寒い野の海辺。地から湧く燃える水が、井戸でくみ上げられた。アメンテトで最初の町で、近代の終わりには、絵や像を集めて見せる宮の工事が始まった。寒い野にも、家の長の墓と死者の神殿が造られた
* **ザウ**：草原の海辺。金が掘られ、トリュフが採られた
* **ペル・ハトホル**：寒い野の海辺。堅い木が伐られ、燃える水もくみ上げられた。鉄の炉や食べ物の店も建った

### セケト・アアルの町々

* **スウェネト**：草原の海辺。セケト・アアルで最初の町。ブドウからワインが作られ、銀が掘られ、鯨が捕られた。近くにソンガイの町ゴビールがあり、近代のいくさでは、ソンガイの兵に攻められた。鉄の車が町を守った
* **アブ**：熱帯。砂糖きび、白い土、スズ。ソンガイの町々のすぐ近くに開かれ、いくさのきっかけの一つになったとされる。鉄の車が置かれた
* **ハットワレット**：熱帯の海辺。リャマが飼われた。近代のいくさの最中に開かれた、タメン人の最後の新しい町

### 奪った町

* **トレド、セビーリャ**：塩の海の向こうのスペインの古い町。鋼の戦船が守りを撃ち破り、タメン人の兵が入った。大理石、ワイン、魚が採れる。タメン人が自ら開かなかった、ただ二つの町である。セビーリャには、取り戻そうとするスペインの騎兵が攻めかかった

## 4. 町どうしのくらべ

### どの町にもあったもの

* **倉、レンガの作業場、木を挽く作業場**：疫病の時代に開かれたジャネトからは、新しい町には、開かれてすぐにこの三つが建てられた
* **家の長の墓と死者の神殿**：本国の町々だけでなく、タ・ネチェルやアメンテトの寒い野の町にまで造られた。タメン人は、どこへ移っても、家の長を同じ形で葬った
* **マアトの教えの神殿**：探検の時代までに開かれた町には、すべて建った。近代に開かれたアケトアテンと西の大陸の町々には、建てられなかった。近代の新しい町の暮らしは、教えよりも、畑や鉱山、燃える水の井戸を中心に始まった、とする
* **城壁**：探検の時代の終わりには、ワセト、ケメヌ、ティニス、ゲブツ、メンネファーが城壁で囲まれた。西の境のジャネトは、古代の疫病の時代から城壁を持ち、近代には花の城壁を築いた

### 町ごとに違ったもの

|---|---|
| 漁の舟が多い海の町 | ペル・アトゥム（いちばん多い）、ワセト、メンネファー、ベフデト、ケメヌ、ティニス |
| 畑の町 | ジャネト（漁の舟がなく、畑がいちばん多い）、ティニス |
| 鉱山の町 | イプ（いちばん多い）、ゲブツ、ベフデト、ネケブ |
| 森の町 | メンネファー、ジェデト、ジャネト |
| 大工事の町 | ワセト、ケメヌ（ともに十一）、ティニス（六） |
| 大工事のない町 | ペル・アトゥムと、近代に開かれた西の大陸の町々 |
| 守りの町 | ジャネト（西の境）、ゲブツ（東の海辺）、イプ（アジア側の東） |

### 町の役割の分かれ方

* **ワセト**は、新しい建物がまず建つ町であり、政、商い、学び、海の向こうへの出発地だった。他の町は、ワセトで始まったものを追いかけた
* **ケメヌ**は信仰と学び、**ティニス**は塩と墓と宮、**ゲブツ**は東の海辺の守りと祈り、**メンネファー**は星と絹と鉄、**ジャネト**は西の守りと畑と訳す学び、と、本国の町々はそれぞれに違う役を負った
* **ペル・アトゥム**は、大工事を一つも持たない代わりに、海の幸と、海の向こうへの港という役を負った
* **海の向こうの町々**は、砂糖、鉄、ルビー、金、燃える水と、本国にない品を送る町だった。どの町も、開かれた時に、倉や作業場を富める家々の富でいっぺんに買いそろえて始まった

### 暮らしぶりの違い

* **ワセトとケメヌ**の人々は、役人、学ぶ者、神官、商人として暮らし、大工事や学びの館に囲まれていた
* **ティニス、ゲブツ、イプ、ベフデト**の人々の多くは、塩や石、ルビー、金、鉄を掘って暮らした
* **ペル・アトゥム、アケトアテン**の人々は、漁師と潜り手と船乗りとして暮らした
* **ジャネト**の人々は、畑を耕し、兵として西の境を守った
* **メンネファー**の人々は、絹を織り、米を育て、木を伐り、星を観た
* **海の向こうの町々**の人々は、砂糖きびの畑や鉱山、燃える水の井戸で働き、本国へ富を送った。ジェデトやスウェネトの人々は、町を襲う兵におびえながら暮らした
* 近代には、ワセトとティニスに工場が、ペル・アトゥムに長屋が、ティニスとメンネファーに大きな店が建った。工場で働き、長屋に住み、店で品を買う暮らしは、本国の大きな町から始まった
