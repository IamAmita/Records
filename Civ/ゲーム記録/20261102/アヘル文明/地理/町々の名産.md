# 町々の名産

[← アヘル文明](../アヘル.md) ｜ [町々](町々.md) ｜ [暮らしの移り変わり](../社会と文化/暮らしの移り変わり.md)

タメン人の町々の名産をまとめたもの。町の近くで採られた品と、それから作られた品を書く。年代は、その町でその品が採られ始めた頃。

## 2. 町ごとの名産

### ワセト

* **魚**：村の時代から、葦の舟と網で河と塩の海の魚を捕った。漁の舟は、ペル・アトゥム、メンネファーと並んで多い
* **ナツメヤシ**：村の近くの砂地に生えていたナツメヤシを、子株から増やした。タメン人のいちばん古い名産
* **石膏と石灰岩**：近くの採石場で切り出された。石膏は家の壁を白く塗るのに使われ、ゲブツの白鷺の城の白い壁にもつながった。石灰岩は大工事の石になった
* **真珠**：ワセトの前の塩の海で採られた。法の時代から、家の長たちや神官の飾りになった
* **ラクダ**：近くの砂漠で捕らえ、飼われた

### ケメヌ

* **香料**：河の畑で、祀りに焚く香料の木が育てられた。神託の祠や太陽の鳥の堂を持つ信仰の町の香は、各地の祭壇で焚かれた
* **粘土**：焼き物とレンガの土。ケメヌの作業場で使われた
* **スズ**：法の時代から近くで掘られた。それまで遠くから運んでいたスズがケメヌで採れるようになり、青銅が手に入りやすくなった。ケメヌの大鐘も、この青銅で鋳られた、とする
* **ワイン**：遠い地でブドウ畑を勧めたのち、疫病の時代にケメヌでもブドウが育てられ、ワインが作られた

### ティニス

* **塩と塩漬けの魚**：ティニスは、開かれた時から塩を掘る町だった。ティニスの塩で魚を塩漬けにし、遠くまで運べるようになった。塩漬けの魚は、国じゅうに出回った
* **染めた布**：青銅の時代に、近くで染料が採られた。ゲブツの綿や各地の亜麻が、ティニスで染められた、とする。染めた布は、豊かな家の者が身につけた
* **石膏**：法の時代から、ティニスの採石場でも切り出された
* **ラクダとナツメヤシ**：砂漠の岸の町らしく、ラクダが捕らえられ、ナツメヤシが育てられた
* **銀**：古代の終わりに、近くで銀が掘られるようになった
* **鯨**：マアトの時代から、前の海で鯨が捕られた。鯨の肉と油が町を潤した

### ゲブツ

* **綿と綿の布**：青銅の時代に綿が育てられ、亜麻とは違う柔らかい布が作られた。ゲブツの綿の布は、タメン人の布の名産になった
* **マンゴーとナツメヤシ**：法の時代からマンゴー、疫病の時代にはナツメヤシの畑も開かれた
* **石灰岩**：採石場で切り出された
* **ルビー**：古代の終わりに鉱山で掘られた。ゲブツは鉱山の多い町で、ルビーは豊かな家の飾りになった
* **ラクダ**：砂漠の海辺で捕らえられた

### メンネファー

採れる品の種類は、町々の中でいちばん多い。

* **絹**：開かれてすぐ、野生の蚕から糸を取るようになった。絹の布は、家の長たちや神官の晴れ着になった
* **米とマンゴー**：法の時代に、東の平原で米とマンゴーが育てられた
* **鉄**：疫病の時代に鉄の鉱石が見つかり、タメン人の鉄の時代は、メンネファーの鉄から始まった
* **馬**：古代の終わりから牧草地で飼われた
* **象牙**：古代の終わりから集められた
* **香辛料、タカラガイ、真珠、魚**：マアトの時代から帆船の時代に、香辛料が採られ、海ではタカラガイ、真珠、魚が採られた

### ジャネト

* **麦**：漁の舟が一つもない代わりに、畑は町々の中で最も多い。ジャネトの麦は、西の境の兵と人々を養った
* **白い焼き物**：開かれた時から、白い土（カオリン）が採られた。白い土から、白く美しい焼き物が作られた、とする
* **スズ**：ケメヌに続く、スズの採れる町
* **香辛料と獣**：疫病の時代から獣が狩られ、マアトの時代には香辛料が採られた

### ペル・アトゥム

海と熱帯の品が集まる、名産の港。

* **魚、カニ、ウミガメ、鯨**：漁の舟は町々の中で最も多い
* **象牙**：開かれた時から集められ、象牙の細工が作られた、とする
* **タカラガイ**：探検の時代の初めから集められ、東の町々の市で小さな買い物に使われた
* **真珠**：光の時代に、近くの海で採られた

### ジェデト

* **砂糖**：タ・ネチェルに開かれたその年から、砂糖きびが育てられた。ジェデトの砂糖は宝の船団に積まれて本国へ運ばれ、本国の食卓に甘いものを届けた
* **木材**：近代には、木を伐る場が多く開かれた
* **魚、タカラガイ、鯨**：熱帯の海で採られた

### ベフデト

* **鉄とルビー**：タ・ネチェルの砂漠で、鉄とルビーが掘られた。ゲブツに続く、ルビーの採れる町
* **鯨、真珠、タカラガイ**：海の幸も豊かだった

### イプ

* **金**：光の時代に鉱山で掘られた。タメン人が自分の町で金を掘った初め。鉱山の数は、町々の中で最も多い
* **ヒスイ**：探検の時代の終わりに掘られた。古くは西の大陸の遺跡で富を出して掘らせたヒスイが、ここで採れるようになった
* **粘土**：開かれた時から採られた

### タ・ネチェルのほかの町々

* **ネケブ**：砂糖、石膏、スズ。近代には馬が飼われた
* **クヒト**：ラクダと石灰岩。タ・ネチェルの砂漠でも、本国の砂漠の町と同じようにラクダが捕らえられた
* **アケトアテン**：タカラガイと真珠。いちばん東の海辺の、漁の町

### アメンテトの町々

* **ネケン**：地から湧く燃える水。油の釜を動かすのに使われ、近代のタメン人の工業を支えた。魚と鯨も捕られた
* **ザウ**：金とトリュフ。トリュフは、本国にはない、土の中で育つ珍しい食べ物だった
* **ペル・ハトホル**：堅い木と燃える水

### セケト・アアルの町々

* **スウェネト**：ワイン、銀、鯨、カニ。ケメヌに次ぐ、ワインの採れる町になった
* **アブ**：砂糖、白い土、スズ。ジャネトと同じく白い土が採れた
* **ハットワレット**：リャマ。毛を刈り、荷を運ばせた、とする

### 奪った町

* **トレド、セビーリャ**：大理石、ワイン、魚。スペインの古い町の大理石は、タメン人の石膏や石灰岩にはない、美しい石だった

## 3. 品ごとに見る

| 品 | 採れた町 | 使われ方 |
|---|---|---|
| 塩 | ティニス | 魚を塩漬けにし、遠くへ運ぶ |
| 布（亜麻、綿、絹、染め） | 各地（亜麻）、ゲブツ（綿）、メンネファー（絹）、ティニス（染料） | 着るもの。絹と染めた布は身分を表した |
| 香料 | ケメヌ | 祀りに焚く |
| 香辛料 | ジャネト、メンネファー | 料理の味つけ |
| 実り | ワセト・ティニス・ゲブツ（ナツメヤシ）、ゲブツ・メンネファー（マンゴー）、メンネファー（米）、ケメヌ・スウェネト・トレド（ワイン）、ジェデト・ネケブ・アブ（砂糖） | 食べ物。砂糖は海の向こうから運ばれた |
| 海の幸 | ペル・アトゥム、ワセト、メンネファー、ベフデト、ジェデト、ティニス、スウェネト、ネケン、ザウ | 魚、カニ、ウミガメ、鯨 |
| 真珠とタカラガイ | ワセト、メンネファー、ペル・アトゥム、ベフデト、ジェデト、アケトアテン | 飾り、小さな買い物 |
| スズ | ケメヌ、ジャネト、ネケブ、アブ | 青銅 |
| 鉄 | メンネファー、ベフデト | 鉄の道具と武器、近代の鉄の炉 |
| 銀と金 | ティニス、スウェネト（銀）、イプ、ザウ（金） | 硬貨と飾り。近代には通貨の拠りどころ |
| 宝石 | ゲブツ、ベフデト（ルビー）、イプ（ヒスイ） | 豊かな家の飾り |
| 石 | ワセト、ティニス、ネケブ（石膏）、ワセト、ゲブツ、クヒト（石灰岩）、トレド、セビーリャ（大理石） | 白い壁、大工事の石 |
| 土 | ケメヌ、イプ（粘土）、ジャネト、アブ（白い土） | レンガ、焼き物、白い焼き物 |
| 獣 | ワセト・ティニス・ゲブツ・クヒト（ラクダ）、メンネファー・ネケブ（馬）、メンネファー・ペル・アトゥム（象牙）、ジャネト（獣）、ハットワレット（リャマ） | 荷を運ぶ、乗る、細工 |
| 燃える水と堅い木 | ネケン、ペル・ハトホル | 油の釜、近代の工業 |

* 塩（ティニス）、香料（ケメヌ）、綿（ゲブツ）、絹（メンネファー）、染料（ティニス）は、それぞれ一つの町だけで採れた。タメン人の町々は、互いの名産を運び合って暮らした
* スズ、鉄、ルビー、ラクダ、石膏、真珠のように、本国の町と海の向こうの町の両方で採れた品もある。砂糖は、海の向こうの町（ジェデト、ネケブ、アブ）だけで採れた。海の向こうに町を開くと、本国の名産と同じ品が、新しい土地でも採られるようになった

## 4. 名産の移り変わり

| 時代 | 新しく加わった名産 | 中心になった町 |
|---|---|---|
| 村の時代 | 魚、ナツメヤシ | ワセト |
| 墓山の時代 | 塩、ラクダ | ティニス |
| 青銅の時代 | 香料、染料、綿、石膏、粘土 | ケメヌ、ティニス、ゲブツ、ワセト |
| 法の時代 | 真珠、絹、米、マンゴー、スズ、石灰岩 | メンネファー、ワセト、ケメヌ、ゲブツ |
| 疫病の時代 | ワイン、白い土、鉄、馬、ルビー、象牙、獣、銀 | メンネファー、ジャネト、ゲブツ、ペル・アトゥム |
| マアトの時代 | タカラガイ、ウミガメ、香辛料、鯨、カニ | ペル・アトゥム、メンネファー、ジャネト、ティニス |
| 帆船の時代 | 真珠（メンネファー） | メンネファー |
| 神の地の時代 | 砂糖 | ジェデト |
| 光の時代 | 鉄とルビー（海の向こう）、金、ヒスイ、真珠（ペル・アトゥム） | ベフデト、イプ |
| 近代の時代 | 燃える水、トリュフ、堅い木、リャマ、大理石 | ネケン、ザウ、ペル・ハトホル、ハットワレット、トレド |

* 古代の名産は、**本国の河と砂漠と平原**の品だった。塩、布、石、スズ、鉄、絹
* 探検の時代には、**海の品**（鯨、真珠、タカラガイ）と、**海の向こうの品**（砂糖、鉄、ルビー、金）が加わった
* 近代には、**工業を動かす品**（燃える水、堅い木）が加わった。名産の中心は、ワセトの近くから、東の平原と海辺へ、さらに海の向こうの大陸へと移っていった
