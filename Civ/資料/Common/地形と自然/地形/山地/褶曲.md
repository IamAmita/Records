**褶曲（しゅうきょく、Fold）**とは、地層が強い圧力を受けて、**折れずに曲がる現象**のことだ。

地球内部ではプレートの運動によって地層に大きな圧縮力が加わることがある。この力が長い年月（数百万～数千万年）かけて働くと、地層は割れるのではなく、粘土のようにゆっくり変形して波打つような形になる。

### 褶曲のイメージ

もともと水平だった地層が、

```
──────────
──────────
──────────
```

圧縮されると、

```
   ／＼      ／＼
__/    \____/    \__
```

のように波状に曲がる。

### 主な種類

* **背斜（はいしゃ、Anticline）**

  * 上に盛り上がった部分。
  * 山のような形になる。
  * 古い地層が中心に現れやすい。

* **向斜（こうしゃ、Syncline）**

  * 下にへこんだ部分。
  * 谷のような形になる。
  * 新しい地層が中心に現れやすい。

### なぜ曲がるの？

岩石は普段は硬くて割れやすいが、地下深くでは

* 高温
* 高圧
* 非常に長い時間

という条件がそろうため、ゆっくりと塑性変形し、折れずに曲がることがある。

一方、浅い場所では岩石は割れやすく、褶曲ではなく**断層**ができることが多い。

### 褶曲山脈

褶曲によって形成された山脈を**褶曲山脈**という。

代表例は、

* ジュラ山脈
* ヒマラヤ山脈
* アルプス山脈

などである。

特にジュラ山脈は、規則正しい波状の褶曲が発達しているため、「ジュラ型褶曲」の名前の由来としても知られている。
