**製粉所（せいふんじょ）**とは、**小麦などの穀物を挽いて、粉に加工する施設**である。

特に歴史上の「製粉所（mill）」なら、**[水車](../../../Domain/建造物/水車小屋.md)や風車などの力で石臼を回し、小麦を小麦粉にする施設**を指すことが多い。簡単にいえば、**穀物 → 石臼で細かく砕く → 小麦粉などにする場所**である。

## 何を「製粉」するのか

代表的なのは**[小麦](../../資源/小麦.md)**である。収穫した小麦はそのままではパンにはできず、**小麦を収穫 → 脱穀して穀粒を取り出す → 製粉所へ運ぶ → 穀粒を挽く → 小麦粉になる → パンなどに加工**という工程が必要になる。小麦以外にも、ライ麦・トウモロコシ・ソバ・米などさまざまな穀物を粉にできる。

---

## 昔は石臼で挽いていた

製粉の基本的な道具が**石臼（millstone）**である。基本的には大きな円盤状の石を二枚重ね、下側の石を固定して上側の石を回転させる。その間に穀物を入れると、**上の石が回転 → 穀物が石の間で押し潰される → 細かな粉になる**という仕組みである。

かなり単純だが、人力で大量の穀物を挽くのは大変である。そこで重要になったのが**動力**だった。

### 水車を使った製粉所

特にヨーロッパなどで広く普及したのが**[水車小屋（watermill）](../../../Domain/建造物/水車小屋.md)**である。川の流れを利用して、**川の水 → 水車を回す → 回転を歯車や軸へ伝える → 石臼を回す → 穀物を挽く**という仕組みで、水の流れを機械の動力に変換している。人間が一日中石臼を回す必要がなくなるので、大量の穀物を効率よく製粉できる。

### 風車でも製粉できる

水の流れを利用しにくい地域では**風車（windmill）**も使われた。原理はほぼ同じで、**風 → 風車の羽根が回る → 歯車が回る → 石臼が回る → 穀物を粉にする**というものである。だから昔の風車は単なる景観用の建物ではなく、**風力を利用する産業機械**だった。製粉以外にも、排水や製材などさまざまな用途で風車は利用された。

---

## 中世ではかなり重要な施設

特に中世ヨーロッパでは製粉所は重要だった。理由は単純で、**パンが主食だったから**である。大量の人間が**穀物 → 小麦粉 → パン**を食べるため、毎日大量の穀物を製粉しなければならない。つまり製粉所は**社会の食料供給を支える基幹施設**であり、現代でいえば食品工場とインフラ設備を合わせたような重要性があった。

### 領主の収入源にもなった

中世ヨーロッパでは、製粉所を**領主が所有・管理する**ことも多かった。農民が収穫した穀物を製粉所へ持ってきて製粉してもらい、使用料を支払うという仕組みで、地域によっては農民が領主指定の製粉所を利用することを義務づけられる場合もあった。そのため製粉所は単なる機械設備ではなく、**領主が農村経済から収入を得るための重要な施設**でもあった。

---

## 現代の製粉所

現在も製粉所は存在するが、巨大な石臼と水車を使うのではなく、近代的な製粉工場では主に**ローラー式製粉機**などを使う。小麦を何段階にも分けて、**粉砕 → ふるい分け → さらに粉砕 → 胚乳・ふすまなどを分離**して、品質の揃った小麦粉を大量生産する。だから現代の「製粉所」は、実質的には**製粉工場**である。

## まとめ

**製粉所＝小麦などの穀物を挽いて粉にする施設**である。特に歴史上では、**穀物 → 水車・風車などで石臼を回す → 製粉 → 小麦粉 → パン**という流れを担った。

ゲームや中世史で「製粉所」が出てきたら、**「水車や風車を動力にして穀物を粉にし、パンなどの食料生産を支える重要な加工施設」**とイメージすると分かりやすい。同じく食料生産を支える加工施設としては[製塩](製塩.md)（塩づくり）、木材加工では[製材所](製材所.md)がある。
