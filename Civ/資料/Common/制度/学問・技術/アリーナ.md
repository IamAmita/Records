**アリーナ（Arena）**とは、**観客席に囲まれた競技や催し物のための中央空間**を指す言葉である。

現在ではスポーツ競技場やコンサート会場の意味で使われることが多いが、その語源は**古代ローマの円形闘技場**にある。

## 基本情報

* 語源：ラテン語 *harena*（砂）
* 本来の意味：円形闘技場の中央にある砂を敷いた競技場
* 現代の意味：屋内・屋外を問わない競技・イベント会場

「アリーナ」という名称は、競技場そのものではなく、もともとは**競技が行われる中央部分**を意味していた。

## 古代ローマのアリーナ

古代ローマでは、アリーナは円形闘技場（アンフィテアトルム）の中央に設けられた。

床には厚く砂が敷かれており、その理由は次のとおりである。

* 血液や雨水を吸収するため
* 足元を滑りにくくするため
* 清掃や砂の交換を容易にするため

ここでは、剣闘士（グラディエーター）の試合や猛獣との戦いなどが開催された。

## 地下施設

大規模な円形闘技場では、アリーナの床の下に広大な地下施設が設けられていた。

そこには、

* 剣闘士の待機室
* 動物の檻
* 舞台装置
* 昇降機

などがあり、人や猛獣を突然アリーナへ登場させる演出も行われていた。

代表例であるコロッセオでは、この地下施設（ヒュポゲウム）の一部が現在も見ることができる。

## 現代のアリーナ

現在では「アリーナ」は競技やイベントが行われる施設、あるいはその中央部分を意味する言葉として広く使われている。

例えば、

* バスケットボール
* バレーボール
* アイスホッケー
* コンサート
* 展示会
* eスポーツ大会

など、多目的なイベント会場を指すことが多い。

## スタジアムとの違い

| アリーナ                | スタジアム             |
| ------------------- | ----------------- |
| 主に屋内、または中央競技空間を指す   | 主に屋外の大規模競技場       |
| バスケットボールやコンサートなどに利用 | サッカーや陸上競技、野球などに利用 |
| 比較的観客との距離が近い        | 広いフィールドを囲む構造      |

なお、「アリーナ」は施設全体を指す場合もあれば、施設内の競技スペースのみを指す場合もある。

## 豆知識

「アリーナ」の語源であるラテン語 **harena** は「砂」を意味する。古代ローマでは、競技場の床一面に砂を敷いていたことから、その中央競技場そのものが「アリーナ」と呼ばれるようになり、その名称が現代まで受け継がれている。
