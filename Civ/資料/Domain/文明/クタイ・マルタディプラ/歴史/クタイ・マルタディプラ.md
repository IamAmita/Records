# クタイ・マルタディプラ

**クタイ・マルタディプラ（Kutai Martadipura）**とは、現在の**インドネシア・ボルネオ島東部（東カリマンタン）**に存在した、古代の王国である。

特に重要なのは、**インドネシアで確認されている最古級のヒンドゥー系王国**として知られていることである。4世紀ごろには存在していたことが碑文から確認できる。

## 概要

* **地域**：現在のインドネシア・東カリマンタン州、マハカム川流域
* **中心地**：現在のムアラ・カマン付近と考えられている
* **時期**：4世紀ごろ
* **性格**：インドネシア最古級のヒンドゥー系王国
* **主要史料**：ユパ（Yūpa）碑文

## どこにあったのか

場所は現在のインドネシア、**東カリマンタン州のマハカム川流域**である。中心地は現在の**ムアラ・カマン**付近だったと考えられている。

マハカム川はボルネオ島東部を流れる大河なので、

**内陸部 → マハカム川 → 海 → 東南アジア・インド方面**

という形で、人や物、文化が移動する経路になった。そのためこの地域には、海上交易などを通じて**インド文化やヒンドゥー教の影響**が入ってきたと考えられている。

## 「ユパ」という石碑

クタイ・マルタディプラについて分かっていることの多くは、**ユパ（Yūpa）碑文**という石柱から来ている。

ユパとは、本来ヒンドゥー教の祭祀で使われる**犠牲柱**のことである。クタイでは7本の石柱が発見されていて、そこには、

**サンスクリット語 ＋ パッラヴァ系文字**

で文章が刻まれている。これらは東南アジア島嶼部における非常に古いサンスクリット碑文でもある。

## ムーラヴァルマン王

碑文に登場する最も有名な王が**ムーラヴァルマン（Mulavarman / Mulawarman）**である。碑文から、

**クドゥンガ → アシュヴァヴァルマン → ムーラヴァルマン**

という王統が分かっている。

興味深いのは、祖父の**クドゥンガ**はインド系ではない現地由来とみられる名前なのに、その息子の**アシュヴァヴァルマン**や孫のムーラヴァルマンはサンスクリット系の名前になっていることである。

そのため、もともと存在した**ボルネオ島の現地首長層が、インド文化やヒンドゥー教を取り入れて王権を形成していった**過程を反映している可能性がある。ムーラヴァルマンについては、バラモンに大量の牛や金などを寄進したことが碑文に記録されている。

## なぜ歴史的に重要なのか

クタイ・マルタディプラが面白いのは、**インド文化が東南アジアへ広がっていった非常に早い段階を確認できる**ことである。

インドが軍事的にボルネオ島を征服して植民地化した、という話ではない。むしろ、

**インドとの海上交易 → サンスクリット語・宗教・思想などが伝わる → 現地の支配者がヒンドゥー的な王権文化を取り入れる → 東南アジア独自のヒンドゥー系国家が形成される**

という文化交流の一例として重要である。

このような流れは、その後の東南アジアでも非常に大きな影響を与える。後世にはジャワ島の**マタラム王国**、スマトラ島の**シュリーヴィジャヤ**、さらにカンボジアの**クメール帝国**など、インドの宗教・文字・政治思想から強い影響を受けた国家が各地に登場する。ジャワ島のシャイレーンドラ朝が8～9世紀に築いた巨大仏教遺跡[ボロブドゥール](../../../建造物/ボロブドゥール.md)も、こうした東南アジアのインド化がもたらした記念碑的な産物の一つである。

## 注意 ―― 「クタイ王国」の区別

「クタイ王国」という名前は後世の**クタイ・カルタヌガラ**など別の王国にも使われるので、厳密には区別が必要である。古代史で「クタイ・マルタディプラ」と言った場合は、基本的に**ユパ碑文とムーラヴァルマンで知られる古代のクタイ**を指している。

## まとめ

クタイ・マルタディプラは、

**「4世紀ごろのボルネオ島東部に存在し、インド文化・ヒンドゥー教を取り入れた、インドネシア最古級の王国」**

と覚えるとよい。
