# 張家界

**張家界（ちょうかかい／ジャンジャージエ、Zhangjiajie / 张家界）**とは、中国の**湖南省北西部にある都市・景勝地域**である。

特に有名なのが、無数の細長い岩峰が林立する独特な景観である。一般に「張家界」と言う場合、都市そのものよりも、**張家界国家森林公園や武陵源（ぶりょうげん）を中心とする景勝地**を指していることが多い。

## 概要

* **所在地**：中国・湖南省北西部
* **中心的景勝地**：武陵源（世界自然遺産）、張家界国家森林公園、天門山
* **地形**：石英砂岩の柱状・峰状地形
* **世界遺産**：武陵源が1992年にユネスコ世界自然遺産へ登録

## 何が特徴的なのか

張家界には、**細長い石柱のような岩山**が大量に立っている。武陵源には**3,000を超える珪岩砂岩の柱状・峰状地形**が存在し、その多くが高さ200mを超えるとされる。

その間に深い谷、渓流、滝、洞窟などが存在するため、**巨大な石柱の森**のような景観になっている。

## どうやってできたのか

基本的には**長期間の侵食と風化**によって形成された地形である。この地域には厚い**石英砂岩（quartz sandstone）**の地層が存在する。そこに地殻変動などによって亀裂が入り、

**岩盤に亀裂ができる → 雨水・河川などによる侵食 → 亀裂が拡大 → 岩盤が分断される → 周囲が削られる → 硬い部分が細長い岩柱として残る**

という過程が非常に長い時間をかけて進んだ。だから人工的な柱ではなく、**巨大な砂岩の山が細かく切り分けられて残ったもの**と考えると分かりやすい。

## カルスト地形とは少し違う

中国南部には桂林など、[石灰岩](../../../../Common/地形と自然/採掘/石灰岩.md)が水に溶かされて形成された**カルスト地形**が有名である。張家界も見た目が似ているので混同しやすい。でも張家界・武陵源を代表する岩峰は主に**石英砂岩**でできている。

* **桂林** → 石灰岩が溶食されたカルスト地形
* **張家界** → 主に石英砂岩が侵食・風化されて形成された岩峰群

という違いがある。

## 「武陵源」と「張家界」の違い

ここが名称として少しややこしい。

**張家界市**は中国湖南省にある行政上の都市である。その張家界市にある巨大な景勝地域が、**武陵源（Wulingyuan）**である。そして武陵源には、**張家界国家森林公園・索渓峪自然保護区・天子山自然保護区**などが含まれる。

つまり大雑把には、

**中国 → 湖南省 → 張家界市 → 武陵源景勝区 → 張家界国家森林公園など**

という関係である。「張家界の奇岩」として紹介される写真の多くは、この**武陵源地域**のものである。

## 世界遺産

武陵源は**1992年にユネスコ[世界自然遺産](../../../../Common/制度/学問・技術/自然遺産.md)**に登録された。登録名称は**Wulingyuan Scenic and Historic Interest Area（武陵源の自然景観と歴史地域）**となっている。特に評価されているのが、やはり圧倒的な数の砂岩峰である（3,000以上の石英砂岩の柱や峰が存在し、その多くが200m以上の高さを持つ）。

## 『アバター』との関係

張家界について非常によく出てくるのが、映画**『アバター』**との関係である。作中には、**ハレルヤ・マウンテン**という空中に浮かぶ巨大な岩山が登場する。

張家界の岩峰が『アバター』の景観に影響を与えた場所の一つとして宣伝されていて、2010年には張家界の**南天一柱（Southern Sky Column）**という岩峰が「アバター・ハレルヤ山」と改称されたと報道された。

ただし、「映画『アバター』の浮遊山は張家界だけをモデルにして作られた」と断定するのは正確ではない。中国側の観光宣伝によって「アバターのモデル」というイメージが非常に強くなった側面もある。

* **張家界の景観が『アバター』の世界観と強く結びつけられている** → ○
* **『アバター』の山＝張家界をそのままコピーした** → そこまで単純ではない

くらいに理解するとよい。

## 天門山

張家界には武陵源とは別に、**天門山（Tianmen Mountain）**という有名な山もある。巨大な天然の穴、**天門洞**があることで知られている。さらに、崖沿いの遊歩道、ガラス張りのスカイウォーク、非常に長いロープウェイなどでも有名である。

なので観光地としての「張家界」には、

* **武陵源・張家界国家森林公園** → 石柱のような岩峰群
* **天門山** → 巨大な天然洞門や断崖

という複数の有名スポットが存在する。

## 名前の由来

「張家界」という名前は漢字を見ると**張＋家＋界**となっている。「張」は中国で非常に一般的な姓である。そのため大まかには**「張氏一族の土地・領域」**という意味に由来する地名とされる。

現在の張家界市はもともと**大庸市**という名称だったが、観光地として有名になった「張家界」の知名度を利用して、**1994年に張家界市へ改称**された。つまり、

**有名な景勝地「張家界」 → 観光地として世界的に有名になる → 都市そのものが「張家界市」に改名**

という流れである。

## まとめ

**張家界＝中国湖南省北西部にある都市・景勝地域で、数千本もの巨大な石英砂岩の岩峰が林立することで世界的に有名な場所**である。

* **張家界市** → 行政上の都市
* **武陵源** → 世界遺産になっている巨大景勝地域
* **張家界国家森林公園** → 武陵源を代表する景勝地
* **天門山** → 張家界市にある別の有名景勝地

という区別をしておくと、「張家界」という言葉が何を指しているのか理解しやすい。

なお、同じく中国の砂岩が侵食・風化してできた景勝地としては[張掖丹霞](張掖丹霞.md)（赤い層状の丹霞地形）もある。
