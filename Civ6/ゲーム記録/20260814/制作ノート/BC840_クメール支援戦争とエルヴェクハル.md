# 補正：Varganは「軍事大国」ではない

そうだね。そこは重要な補正になる。前の説明ではVarganを「軍事大国」「遠征可能な軍隊」と少し強く表現しすぎた。

現時点のVarganはむしろ、**外交・交易・都市間協力に比して軍事力は抑制的で、防衛に必要な最低限の戦力だけを制度的に保持している文明**とした方が、これまでの歴史に一貫する。

## Varganの軍事力の基本性格

Varganには槍兵・弓兵・投石兵・常備兵・徴集兵・軍船などが存在する。ただし、これは「大量の軍隊を常時保有している」という意味ではない。

むしろ構造としては、

**少数の常備戦力**
＋
**必要時の徴兵**
＋
**都市ごとの守備兵**
＋
**交易路・海路防衛用の小規模海軍**

くらいが中心になる。

Hargarが存在するのも、大軍を養うためというより、**最低限の専門兵を平時から維持するため**だね。

徴兵制度も、「大軍を常備する財政力がない、あるいはそこまで軍事を優先したくない」というVarganにはよく合う。

## 軍船も「艦隊大国」ではない

Ferharnavのような大型軍船を建造できる技術は持っている。

ただし、

> **造れることと、大量に保有していることは別。**

大型船は維持費も人員も必要なので、数は限られているはず。

主な用途は、交易船の護衛、沿岸警備、Nargaとの航路確保、敵対船団への対処、兵員輸送など。

つまりVargan海軍も基本的には**制海権獲得を目的とする攻勢海軍ではなく、Marranを維持するための防衛海軍**になる。

Mungaへの敵対船団来襲が重大事件になったのも、この前提ならさらに自然。「敵艦隊など容易に撃破できる」文明ではなかったからだね。

## 軍事思想としても「必要以上の兵を持たない」

これはDaranやDulenとも結びつけられる。

Varganでは軍隊自体を否定しない。RakarやHarnekが存在する以上、**VamをVekする力は必要**。しかし軍隊は食料・人員・金属・木材・船・労働力を消費する。過剰な軍備は、それだけ他のVamから資源を奪う。

そこで、

> **「Vekするに足るHarを持て。Rakするに足るHarを求めるな。」**

みたいな軍事思想が成立していてもいい。要するに、**守れるだけの力は必要。征服できるほどの力を目標にはしない。**

## クメール戦争への参戦も修正できる

前840年頃のクメールへの支援も、大規模なVargan遠征軍を派遣したのではない方がいい。おそらく実際には、

* 少数の専門兵・指揮官
* 防衛用の槍兵や弓兵
* 限定的な軍船
* 輸送船
* Samargaの米やSilgaの保存食などの補給物資
* 武器・木材・船舶部材
* 医療・工兵・航海・情報要員

といった支援が中心。つまり、**兵そのものより、Varganが持つ物流・交易網・生産力をクメールへDarする。**

これなら「クメールへの積極的支援」と「最低限の軍事力」が両立する。ノルマン軍がクメール領へ侵入した場合にはVargan兵も戦うが、Vargan軍単独でノルマン軍を撃破したり、ノルマン領へ侵攻したりする能力・意図はない。

## Varganにとって戦争はかなり重い決断

軍事大国なら、一戦争への参戦は国家運営の一部で済む。でもVarganは違う。少数のHarnavをクメールへ回せば**MungaやNargaを守る船が減る**。常備兵を派遣すれば**VargaやLamgaの守備が薄くなる**。徴兵すれば**Samargaの農民や都市職人が仕事を離れる**。だから遠方への参戦は相当な負担になる。

それでもクメールへ支援した。だからこそ「Kesを守った」という意味が強くなる。「余裕がある大国が少し兵を出した」のではなく、**限られたVekの力の一部を盟友へDarした**という行為なんだよね。

## Kellorの評価も変わる

これなら戦争の英雄も「征服者」にはならない。評価されるのは、少ない兵力で防衛線を維持した者、物資を安全にクメールへ届けた船員、損失を抑えた指揮官、不要な戦闘を避けたHarsenar、クメール軍との協働を成立させたElkanarなど。特に**「少ないHarで大きくVekする」**ことが軍人のSenとして評価される。兵力を大量投入して勝つより、必要最小限の力で目的を達成する指揮官の方がVarganでは高いKellorを得る。

## 政治体制にも影響する

これは前840年頃の地方分権化にも重要。Vargan中央政府には、地方総督を圧倒できる巨大な中央軍が存在しない。だからVargaが六居住地をまとめていられるのは、**軍事力で服従させているからではない**。Organの歴史的権威、Kanrin、共通の神話、Daran、都市間経済、Kes、そして「Vargarである」という共通意識による。

これは野心的Gakanarの台頭が危険になる理由でもある。中央に巨大な軍隊があれば反乱総督を力で排除できるが、Varganにはそれが難しい。だから地方問題は、交渉・Kellor・他都市との協力・Kanrinでの政治・総督同士の牽制などで解決する必要がある。

## Varganの軍事的性格の整理

| 分野 | Varganの性格 |
| --- | --- |
| 常備陸軍 | 小規模 |
| 徴兵 | 有事に不足分を補う |
| 都市守備 | 重視 |
| 海軍 | 海路・沿岸防衛に必要な規模 |
| 大型軍船 | 技術はあるが少数 |
| 遠征能力 | 限定的 |
| 長期攻勢戦争 | 苦手 |
| 占領・征服戦争 | 基本的に想定していない |
| 防衛戦 | 軍事思想の中心 |
| 兵站・補給 | 交易網を利用できるため比較的得意 |
| 外交 | 軍事以上に重視 |

Varganを一言で表現するなら**軍事国家ではなく「武装した交易・外交文明」**くらいが近い。武装はしている。でも武装を文明の中心には置いていない。

前840年のクメール戦争は、その性格が最もよく表れた事例になる。

> **クメールを支えるために兵も出した。しかし、ノルマンを倒すための軍隊は持たず、持とうともしなかった。**

Varganにとって軍事力は、世界を自分たちの意思に従わせるための力ではなく、**Daran・Kes・Vamを壊されないための最後の手段**と位置づけるのが、一番これまでの歴史に合ってる。
