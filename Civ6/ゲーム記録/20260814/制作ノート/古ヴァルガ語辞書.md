# 古ヴァルガ語 辞書

ヴァルガ人の言語（古ヴァルガ語）の語彙をまとめた資料。各語の初出・詳細は、時代ごとの[考察ファイル](記録.md)を参照。文の作り方は[文法](古ヴァルガ語文法.md)を参照。

新語が生まれるたびに、この辞書へ追記していく。

## 造語法

古ヴァルガ語は、少数の**語根**を組み合わせて複合語を作ることを基本とする。

* 例：**Kal（硬い）＋Dor（木）＝ Kaldor（硬木）**
* 例：**Ur（石）＋Gar（道具）＝ Urgar（石器）**
* 例：**Mek（多い）＋Ragor（支配する）＝ Mekragor（大勢力）**

また、頻繁に使われる「名詞＋助詞 de（～の）＋名詞」は、やがて一語になる。

* 例：**Vam de ga（我々の土地）→ Vamga**

（助詞・語順の詳細は[文法](古ヴァルガ語文法.md)を参照）

### 造語の原則

古ヴァルガ語は「少数の語根を複合して語彙を増やす」ことが基本設計であり、語根レベルの衝突は複合語全体に波及する。したがって新語を作る際は次の優先順位に従う。

| 優先 | 原則 |
| --- | --- |
| 1 | 既存語根から複合語を作れないか考える |
| 2 | 既存語で表現できるなら、無理に一語化しない |
| 3 | 新語根が必要なら既存語との完全同音を避ける |
| 4 | 既存語根とのL/Rのみの違いも原則避ける |
| 5 | 母音違い（Sam／Som、Nakar／Nekar）は許容する |
| 6 | 古くから存在するL/R同音語（Kar/Kal 等）は歴史的特徴として維持し、遡って改名しない |
| 7 | 新しい短い語根は、基本的・日常的な概念に限定する |
| 8 | 高度な概念ほど、既存語根による複合語を優先する |

この結果、**「古い語彙には短くて紛らわしい語が多いが、文明の発達後に作られた言葉は複合語が多く意味も推測しやすい」**という言語史になる。実際、紀元前4000年頃はOr・Tal・Dorのような自然・生存に関する短い語根が中心で、時代が進むにつれてRagor・Elkanarのような複合的な政治語彙が増えている。

### 探検時代の造語方針（紀元前500年頃〜）

前500年頃、[Samarga遷都と多中心化](../ヴァルガ文明/歴史/多中心化するヴァルガン.md)を機にVarganが探検時代へ入ると、造語の優先順位に**三本目の柱**が加わる。

| 優先 | 方針 |
| --- | --- |
| ① | 既存語根で表現できるなら、複合語で対応する（従来通り） |
| ② | Vargarが古くから知りながら基本語根を持たなかった普遍的概念（例：島）は、新しい基本語根を導入してよい |
| ③ | 探検時代に初めて接触した外国由来の事物・概念（例：象、Ruvanの地名、茶）は、**借用語**として受け入れる |

判断基準は、**「Vargarがいつその概念を知ったか」**である。古くからある普遍的自然概念（島など）は本来語で、探検時代に初めて出会った外来の特産品・地名（象、茶、Ruvanなど）は借用語で、と語源の性質を意図的に使い分ける。実際に前500年頃、[第八居住地Ruvan](../ヴァルガ文明/地理/ルヴァン.md)の名は現地の西方系地名をそのまま音韻借用したもので、古ヴァルガ語内部に語源を持たない最初の地名となった。これにより、前500年頃を境に**借用語が目立ち始める**という言語史上の転換が生まれる。ただしこの方針は「何でも借用語にしてよい」という意味ではなく、新語根の乱造も引き続き避ける。既存語根の新しい組み合わせを基本としつつ、本当に新しく遭遇したものだけを借用語にするという抑制が、古ヴァルガ語を「単語を追加していった人工言語」ではなく「3000年以上使われて変化してきた言語」らしく保っている。

### 語族メモ：-kanar

**Kanar**（＜Kan「命じる・導く」）は「◯◯の意思・命令を受けて他者へ伝え、導く者」を表す語族を作る。通訳（Neklamar）は言語の仲介技術者であり、この語族には含めない。

* **Kanar** … 指揮官
* **Elkanar** … 使節（彼方へ意思を伝える者）
* **Sairkanar** … 神官（Sairの意思を伝える者）
* **Harkarkanar** … 軍団司令官（軍勢を率いる者）
* **Navkanar** … 船長、航海指揮者（船を導く者）
* **Vekkanar** … 防衛を指揮する者

### 語族メモ：Sair複合語（神話）

**Sair（神、神霊）**は、既存の自然語根と結びついて「◯◯を司る神」を表す説明的複合語を作る：**Narsair**（火の神）・**Falsair**（川の神）・**Marsair**（海の神）・**Gasair**（大地の神）・**Korsair**（山の神）。後世にはそれぞれ固有名を持つ可能性がある。詳細は[ヴァルガ神話](ヴァルガ神話.md)を参照。

### 語族メモ：美を表す語 ― Ser と Vel

紀元前2540年頃、**Vel（美しい、見て心が満たされる）**が新設された。既存の**Ser（美しい、心を惹く）**（前3600、セラン語からの借用）と意味が重なるため、用途で使い分ける。

* **Ser系**（Ser・Sergar・Serlor・Serpel・Sertek） … セラン起源の、**工芸品・装身具・衣服など「作られた物」が示す美**。威信（Lor）と結びつきやすい
* **Vel系**（Vel・Velan・Veltek） … ヴァルガ固有語根で、**庭園・空間・景観など「体験する場」が与える美**。Hakbelga（空中庭園）のような造園的達成から生まれた語

したがって「美しい装身具」はSer系、「美しい庭」はVel系で表現するのが自然。

### 特殊語：Organ

**Organ**はもと固有名詞（伝説的な初代指導者の名）であり、非常に古い語であるため、通常の派生規則に完全には従わない。*Organ＋-ar* のような派生語（Organar）は存在しない。後世のヴァルガ人も「なぜ指導者をOrganと呼ぶのか」と問われれば「最初のOrganがそう呼ばれていたからだ」と答えるのみである。

### 表記・発音の注記

ローマ字表記の r／l は区別されるが、カナ表記では同じになる同音語がある。文脈で判別する。

* **Var（白い）** と **Val（価値）** … ともに「ヴァル」
* **Kar（守る・戦士）** と **Kal（硬い）** … ともに「カル」
* **Har（戦う）** と **Hal（助ける）** … ともに「ハル」
* **Ur（石）** と **Ul（上げる、持ち上げる）** … ともに「ウル」
* **Ber（交換する）** と **Bel（育つ、芽吹く）** … ともに「ベル」
* **Ter（3）** と **Tel（段）** … ともに「テル」
* **Ser（美しい）** と **Sel（置く、手放す）** … ともに「セル」

なお **Sam（合わせる、一つにする）** と **Som（すべて、全部）**、**Nakar（死者）** と **Nekar（異邦人）** は母音違いで意味も近接するが、区別できる別語として確定している（維持）。

**方針：これらのL/R同音語は歴史的語彙として維持し、遡って改名しない。ただし今後新しい基本語根を作る場合、既存語根とL/Rのみが異なる語形は原則として避ける**（[造語の原則](#造語の原則)を参照）。

| **Mor**（＝鯨案） | **Wor** | 既存Mor（水、前4000）と衝突するため不採用。造語者自身が代替案Worを提示し、古ヴァルガ語で初めて語頭にWを持つ語根として区別した |
| **Yan**（＝生命・生きる、新語根案） | 不採用（既存Vem／Vemanを使用） | 既存Vem（生きる、前4000）・Veman（生、生命、前4000）とほぼ完全に意味が重複するため、造語の原則1（既存語根の活用）に従い新語根は不採用とした。王立動植物苑の名はSom＋Vem＋Ga（Somvemga）で組み立てた。なお「Liv」案は現実の英語liveに類似しすぎるとして造語者自身が先に却下している |
