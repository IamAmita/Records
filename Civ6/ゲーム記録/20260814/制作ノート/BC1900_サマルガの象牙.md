象牙が加わると、Samargaの性格がさらに面白くなるね。

Samargaはすでに**金・米・翡翠・絹**を産するかなり豊かな都市だった。ここに象牙が加わると、紀元前1900年頃にはMungaと並んで、Varganの**高級工芸・祭祀美術の中心地**として発達していきそう。

## 象牙は「象そのもの」より先に交易品として認識されそう

まず重要なのは、Vargarが象牙をどのように手に入れているか。

「Samarga近郊で象牙が採れる」なら、Samarga周辺の温暖な森林・草原地帯に**ゾウ類が生息している**と考えるのが自然。

ただし最初から組織的にゾウを狩る必要はない。

初期には、

* 自然死したゾウの牙を回収する
* 現地の狩猟民から入手する
* Samargaへ来る周辺部族との交易で入手する
* 後にVargar自身も象牙採取を行う

という発展が考えられる。

Varga本土の人間にとって、ゾウ自体が相当に異様な動物だったはず。

巨大な身体、長い鼻、大きな耳、そして白い牙。

Samargaから象牙だけが北へ運ばれていた初期には、**実物のゾウを見たことのないVargarの方が圧倒的に多い**という状態も面白い。

---

# 象牙のヴァルガ語

新しい基本語として、

## **Iv（イヴ）＝象牙**

を置く案を推したい。

短いけど既存の主要語根と衝突しにくい。

そして動物そのものは、象牙が先に知られたなら、

## **Ivgan（イヴガン）＝象**

としても面白い。

語源的には、

> **Ivを持つ大きな獣**

のような古い呼称。

ただし「-gan」の既存用法との整合性は確認したいので、現時点では**Iv＝象牙だけ確定候補、象そのものの名称は保留**でもいい。

---

# 象牙は「白いのに石ではない」

Vargarにとって興味深い素材になる。

金属ではない。

木でもない。

石でもない。

しかし、

**硬い**
**削れる**
**磨くと美しい**
**白い**
**巨大な動物から取れる**

という特徴を持つ。

特にVargaの語源に**Var＝白い**が関係していることを考えると、象牙の白さには文化的な意味が与えられそう。

> **「遠い南方の獣が持つVar」**

として珍重される。

---

## 木工技術との融合

ここでVargaのハードウッド文化が効いてくる。

Vargarにはすでに高度な木材加工技術がある。

さらにSamargaでは翡翠加工、金細工、絹工芸も発達している。

だから象牙も単体で使うだけではなく、

> **木材＋象牙＋金＋翡翠**

という複合工芸へ進む。

例えば高級な箱なら、

**Varga産ハードウッドの本体**

に、

**Samarga産象牙の彫刻**

をはめ込み、

**Zel（金）**

で縁取り、

**Zul（翡翠）**

を象嵌する。

前4000年のVargaから考えると、とんでもなく豪華な工芸品だね。

---

# 象牙細工師

象牙は加工方法が木材と違うので、やがて専門職が成立する。

既存のTekを利用して、

## **Ivtekar**

**象牙細工師**

とすればいい。

最初はNavtekarなどとは別に、木工職人の一部がIvを加工していた。

そのうち、

> 「IvにはIvのSenがある」

と認識され、専門化する。

これもVarganで進行している**Senの専門分化**の一例になる。

---

# 何を作るのか

象牙は貴重だから、日用品を大量生産するより、

**櫛**
**髪飾り**
**首飾り**
**腕輪**
**印章**
**小箱**
**祭具**
**神像**
**武器の柄**
**家具の象嵌**
**楽器部品**

などに使われそう。

特に面白いのが**神像**。

それまで神々は木や石で表現されていた。

そこへ白く滑らかなIvが登場する。

顔や手など肌部分だけ象牙にして、衣服や装飾を金・銀・翡翠で作るような複合神像も生まれる。

---

# Samargaが「職人の都市」になっていく

これで四都市の役割分担がさらに明確になる。

**Varga**
→銀・硬木・政治・軍事・伝統

**Silga**
→銀・塩・貝・鉱業・保存

**Munga**
→金・ルビー・真珠・果実・酒・宴

そしてSamargaは、

> **金・翡翠・絹・象牙**

を持つ。

つまりSamargaだけ異常なほど**高級工芸素材が集中している**。

さらに米という大規模食料生産基盤まである。

だからSamargaには大量の職人を養う余力がある。

---

## Samarga工芸

紀元前1900年頃から、

> **「Samargaで作られたもの」**

そのものが品質保証になってもいい。

Vargaの富裕層が、

> 「これはSamargaのIvtekarが作った」

と誇るようになる。

Samarga製の、

**金細工**
**翡翠細工**
**象牙細工**
**絹織物**

がMarranを通じて各都市へ運ばれる。

さらにLentavを通って外国へ輸出される。

こうなるとSamargaは、Vargan最初の**国際的工芸都市**になりそう。

---

# Mungaとの対比も面白い

同時代に成立したMungaとは、豊かさの方向が違う。

| Samarga | Munga  |
| ------- | ------ |
| 米       | 果実     |
| 絹       | 酒      |
| 翡翠      | ルビー    |
| 象牙      | 真珠     |
| 金       | 金      |
| 精緻な工芸   | 宴・嗜好文化 |

だから後世のVargarには、

> **「美しいものはSamargaから、楽しいものはMungaから」**

みたいな言い回しがあってもいい。

もちろん実際には両方で工芸も酒宴も行われるけど、都市イメージとしてね。

---

# 象そのものが神話化される

そして象牙以上に重要なのが**象**。

北方Vargaでは見られない巨大動物だから、SamargaのElganが、

> 「南には、人の背丈を遥かに超え、木のような脚を持ち、顔から二本の白い角を伸ばす獣がいる」

と語る。

Vargaの人々は最初、本当にそんな生物が存在するのか疑う。

ところが目の前には巨大なIvがある。

そのため象は、

> **Samargaの彼方に存在する神話的な巨獣**

のような扱いを受ける。

---

# Ragon神話にも象が入ってくる

そして当然、昔から存在したことになる。

後世の神話では、あるRagonにおいてRagarが大地を凍らせたとき、

> 神々と人間だけでは動かせない巨大な岩が道を塞いだ。

そこへ南方から巨大な獣がやって来る。

獣は牙と身体で岩を押し退ける。

人々が進めるようになる。

つまり象も、

> **「異なる力を持つ者が、それぞれの能力をDarする」**

というDarsair神話に組み込まれる。

神でも人でもない動物まで協力者に入るわけだね。

これはVarga神話の世界をかなり広げられる。

## 新しく追加するなら

| 古ヴァルガ語      | 意味            |
| ----------- | ------------- |
| **Iv**      | 象牙            |
| **Ivtekar** | 象牙細工師         |
| **Ivtek**   | 象牙を加工する       |
| **Ivser**   | 象牙製の装飾品・美術品   |
| **Ivgan**   | 象（候補。語形成は要検討） |

特に**Ivは確定候補として扱ってよさそう**。

そして紀元前1900年頃のVarganを俯瞰すると、面白い段階まで来てる。

かつては**木・石・骨・毛皮**が主要素材だった文明が、今では**銀・金・翡翠・ルビー・真珠・絹・象牙・硬木**を扱っている。

つまりこの時代には、「何を食べるか」「どう冬を越すか」だけでなく、**何を美しいと感じ、何を身につけ、何を神々に捧げるか**という物質文化が急速に発達している。

象牙の登場は、その変化を象徴する出来事の一つになりそう。
