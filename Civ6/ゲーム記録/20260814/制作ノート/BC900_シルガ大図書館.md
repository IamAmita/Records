紀元前900年頃に、Silgaで**史実のアレクサンドリア図書館に相当する大規模知識施設**が完成するのはかなり自然だと思う。

Silgaはすでに、銀・塩・タライガイを産する第二都市から、紀元前1300年頃の**Torsairzedga（大神託所）**完成によって宗教・知識の都市へ変化していた。現行語彙でも、Silgaには神託・賢人・教育に関する語彙が集積している。

だから前900年の大図書館は、Silgaが次に

> **「神の言葉を読む都市」から「人間の知識を集める都市」へ進んだ**

出来事として扱うとかなり綺麗。

# 歴史的背景

前1100年頃から、Varganは古代秩序の完成と形骸化が同時に進んでいた。

大臣は名目的存在になり、実務官僚が台頭する。

前1000年頃からは都市国家が乱立し、Mungaへ敵対艦隊が来襲。

前930年頃にはLamga方面まで領域が広がり、アッバース文明との国境交易も重要になってきた。

つまり世界が、

> **安定した既知世界**

から、

> **変化し続ける巨大な未知世界**

へ変わりつつある。

この状況では、知識そのものが国家資源になる。

どの都市国家がどこにあるか。

どの海路が安全か。

どの山道が通れるか。

アッバース側では何が起きているか。

どの土地で何が採れるか。

新しい船はどう造るか。

未知の植物は何に使えるか。

これらを記憶だけに頼るのは限界がある。

そこで、

> **「Senを集め、残し、次の世代へ渡す」**

という発想が生まれる。

# なぜSilgaなのか

これはVargaではなくSilgaなのが重要。

Vargaは政治・軍事・外交の中心。

でも政治中心地に巨大知識機関を置くと、知識がOrganやKanrinの都合に強く従属しやすい。

一方Silgaにはすでに大神託所があり、

**Sairzedar**
**Sairkanar**
**Senar**
**Lekar**

など、読む・解釈する・教える専門家が集まっていた。

だから大図書館は、

> **既存の宗教知識都市から自然に派生した施設**

になる。

しかも大神託所と図書館が同じ都市にあることで、

> **Sairから得る知識**
>
> と
>
> **Humが観察・記録して得る知識**

がSilgaに並存する。

これは探検時代への移行を象徴するうえでかなり強い。

# 神託から記録へ

古いSilgaでは、

> 「Sairは何を告げているか？」

が中心だった。

前900年頃には、

> 「過去に何が起きたか？」
>
> 「他のElganは何を見たか？」
>
> 「Gametarは何を測ったか？」
>
> 「Marvenarはどんな海流を記録したか？」

という問いが増える。

つまり、

**Zed――告げ**

だけでなく、

**Sen――理解**

が中心になっていく。

# 「図書館」の概念

ここは新しい語根を増やすより、既存のSenを中心に作りたい。

まず「記録」を表す基本語が必要。

候補として、

## **Teksen**

**知識を形にする、記録する**

Tek＝作る
Sen＝知識・理解

から、

> **「Senを形にして残す」**

という意味。

ただ、これは動詞として少し抽象的。

より専用語として、

## **SedSen**

**伝え残された知識**

Sed＝慣わし・継承されるもの
Sen＝知識

とする案もある。

でも「文書」「記録媒体」まで一語で表すなら、新しい短語根を置く価値がある。

### **Tal**

は既に糧なので不可。

そこで、

## **Tiksen**

はTik＝少ないと衝突。

なので、候補として

## **Kad（カド）＝記録、書き記されたもの**

を新語根にするのが扱いやすい。

すると、

**Kad**
＝記録、文書

**Kadtek**
＝記録する、書き記す

**Kadar**
＝書記、記録者

が作れる。

# 図書館

そこから、

## **Kadga**

**記録の場所、文書庫**

が一般的な小規模施設。

そしてSilgaの巨大施設は、

# **Torkadga**

**大記録所、大図書館**

とできる。

Tor＝大いなる、第一の。

かなり単純で使いやすい。

ただし、単なる書庫ではなく「知識機関」であることを強調するなら、

## **Senkadga**

**知識記録所**

という呼び方もいい。

個人的には、

* **Kadga**＝書庫・文書庫
* **Senkadga**＝図書館・知識庫
* **Torsenkadga**＝Silga大図書館

が一番きれい。

# 何が集められるのか

前900年頃のVarganなら、単なる文学作品だけじゃない。

むしろ最重要なのは実務資料。

**Gametan**
→測量記録

**Marran**
→航路

**Marvenar**
→航海記録

**Elgan**
→旅行記

**Elkanar**
→外国事情

**Berar**
→交易品・価格・市場

**Sairzedar**
→歴代神託

**Senar**
→政治・哲学・自然知識

**Harsenar**
→軍事記録

**Navtekar**
→造船技術

など。

現行語彙だけでも、測量・交易・航海・教育・神託の専門語彙がかなり整っているので、これらを記録する施設が必要になる段階には十分達している。

# 「世界の記録を集める」

ここでアレクサンドリア図書館らしさを出すなら、Silga側にかなり野心的な方針が生まれる。

> **「VarganのSenだけを集めるのでは足りない。」**

アッバース文明。

近隣都市国家。

遠方のNekga。

それぞれの知識も集める。

外国語文書が持ち込まれればNeklamarが翻訳する。

そのため、

> **Neklamarの社会的地位が急上昇する**

可能性が高い。

以前は外交補助職だった通訳が、

> **異文明のSenをVarganへ移す者**

になる。

# 翻訳文化の発達

この施設の完成によって初めて、本格的な翻訳活動が制度化されてもいい。

Vargan語の文書だけではなく、

> アッバース語 → Varga語

> 他都市国家語 → Varga語

と訳す。

その結果、Varga語自体にも大量の借用語が入る。

探検時代の古Varga語が、古代Varga語より語彙豊富になる理由にもできる。

# Elganと図書館

これは特に重要。

これから探検の時代が来る。

Elganが新しい土地へ行く。

帰ってくる。

以前なら、

> 「こんなものを見た」

と口頭で話すだけだった。

これからは、

> **Kadとして残す。**

どのVedへ何日進んだか。

どんなGaだったか。

どんなHumが住んでいたか。

何をBerできるか。

どんなSairを信じるか。

これを記録する。

すると、

> **一人のElganの経験が、次のElganの出発点になる。**

ここがものすごく大きい。

# 探検が「蓄積」できるようになる

一人目が100進む。

記録する。

二人目は100から始められる。

200まで進む。

また記録する。

これを繰り返せる。

つまり大図書館は、

> **探検を個人の冒険から文明的事業へ変える装置**

になる。

前900年という探検時代直前の施設として非常に象徴的。

# 地図の発達

Gametarの測量記録とElganの旅行記が集まれば、当然地図が作られる。

これまでの地図は、

> Varga周辺
>
> 主要交易路
>
> 既知の海岸線

くらい。

でもSilgaでは複数の記録を照合し、

> **「この川とこの山は同じものではないか？」**

と整理する。

ここから、

> **世界を一枚の形として描こうとする試み**

が始まる。

これは探検時代への超重要な準備になる。

# 神官との緊張

当然、大神託所との思想的な緊張も起きる。

Sairzedar：

> 「SairのZedこそ最も高い知識だ。」

新しいSenar：

> 「しかし、百人のMarvenarが同じ海流を記録している。」

という対立。

ただ、まだ宗教VS科学にはしない方がVarganらしい。

むしろ、

> **Sairの世界にも一定のTemがある**

と考える。

神々が作った世界に規則があるなら、その規則を理解することもSairへの理解だ、と。

この統合思想がVarganの自然哲学を生みそう。

# Kevrin制度にも影響する

知識施設が巨大化すると、

> **身分が低くても、優れたSenを持つ者が必要**

になる。

例えば低位Kevrin出身でも、

外国語に詳しい。

計算が得意。

航路に詳しい。

珍しい植物を識別できる。

なら図書館では価値が高い。

ここでも、

> **生まれより能力**

という探検時代の価値観が強まる。

# 大臣の形骸化との対照

前1100年頃から大臣はお飾りになりつつあった。

一方Silgaでは、

> **名前のないKadarやSenarが何百年分もの知識を管理する**

ようになる。

形式的権威より、実際に情報を持つ者が強くなる。

これも古代末期Varganの「名から実へ」という流れそのもの。

# Kellorにも新しい形が生まれる

前1040年頃から名誉が重視されている。

そこで、

> Harで勝つKellor

だけでなく、

> **Senによって得るKellor**

が強くなる。

優れた地図を作った者。

未知の言語を翻訳した者。

古い文書を整理した者。

新しい薬草を記録した者。

彼らもLorarになる。

つまり探検時代の英雄像が、

> 戦士だけでなく、Elgan・Senar・Kadar

へ広がる。

# Silgaの都市像が完成する

これでSilgaはかなり独特な都市になる。

## 地下

銀・塩。

## 山腹

Torsairzedga。

## 都市部

Torsenkadga。

つまりSilgaには、

> **Gaの中から取り出す富**

と

> **Sairから取り出すZed**

と

> **Humが蓄積するSen**

が全部集まる。

これはかなり美しい構造。

# 神託所と大図書館は対立ではなく双子

後世のVargarは、

> **大神託所は「まだ知らないもの」をSairへ問う。**
>
> **大図書館は「すでに知ったもの」をHumが忘れないよう残す。**

と説明するかもしれない。

この区別はすごくVarganらしい。

# 新しい語彙候補

| Varga語          | 意味        |
| --------------- | --------- |
| **Kad**         | 記録、文書     |
| **Kadtek**      | 記録する、書き記す |
| **Kadar**       | 書記、記録者    |
| **Kadga**       | 文書庫、書庫    |
| **Senkad**      | 知識記録、学術文書 |
| **Senkadga**    | 図書館、知識庫   |
| **Torsenkadga** | Silga大図書館 |
| **Nekkad**      | 外国文書      |
| **Elgankad**    | 旅行・探検記録   |
| **Marrankad**   | 航路記録      |
| **Gametkad**    | 測量記録      |
| **Sairzedkad**  | 神託記録      |

この辺はかなり複合語で処理できるから、新基本語根は**Kadだけ**で済む。

## 紀元前900年の歴史的位置

この建造物は、TorharinやTorOrgan像とは意味が違う。

TorOrgan像は、

> **過去の理想を記憶する建造物。**

Torharinは、

> **現在のVamを一つに見せる建造物。**

そしてTorsenkadgaは、

> **未来のVamへSenを渡す建造物。**

になる。

つまり古代Varganが崩れ始めている時代に、逆説的に、

> **古代が蓄積してきたものを次代へ受け渡す施設**

が完成した。

前900年頃のSilga大図書館は、**古代Vargan最後の巨大記念建築であると同時に、探検時代最初の巨大インフラ**と位置づけるとかなり綺麗だと思う。
