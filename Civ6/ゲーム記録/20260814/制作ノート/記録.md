* [第四都市ムンガ（紀元前1900年頃）](BC1900_第四都市.md) — 乾燥地・草原・森林・海が接する境界都市。果実（ムン）・酒（アジュ）・真珠（マウ）・ルビー（カズ）を産する嗜好品都市。正式名Munga（果実の土地）／通称Azhga（酒の土地）。「不足を補い合う」から「恵みを分かち合う」へのDaranの拡張、戦後の宴という新しい神話類型

* [TorOrgan巨像（紀元前1500年頃）](BC1500_TorOrgan巨像.md) — Vargaの2500年の歴史を集約した国家的記念物。武器を下ろし、もう一方の手を開いたTorOrgan（Tororganの語義拡張、「最初の」かつ「大いなる」オルガン）像が港に建つ。四都市の資材によるDaranの結晶、TorOrgan信仰の発生とOrgan論争、Dulenの神話への逆輸入
* [槍兵と弓兵の成立（紀元前1500年頃）](BC1500_槍兵と弓兵.md) — 投石兵に続き、槍兵（サッカル）・弓兵（ヤムカル）が専門兵種として編成される。「異なる兵種が互いを補う」という軍事的Daran思想、TorOrgan像の「力を持つが求めない」というメッセージを現実の軍制が裏付ける
* [大型軍船の登場（紀元前1500年頃）](BC1500_大型軍船.md) — Ralnavの発展形として、多数の漕ぎ手を組織的に運用する大型軍船（フェルハルナヴ）が登場。船上兵（ナヴカル）・艦隊司令官（ハルナヴカナル）の成立、Dulenを海上でも維持するための軍事力という思想
* [シルガ大神託所（紀元前1300年頃）](BC1300_シルガ大神託所.md) — 銀・塩・海産物の第二都市Silgaが「神意を問う都市」になる。神託（サイルゼド）の専門化・制度化、神託を受け解釈する者（サイルゼダル）の成立、「Sairは道を示す。歩くのはArである」という宗教と政治の分業思想
* [第五居住地ナルガ（紀元前1300年頃）](BC1300_第五居住地ナルガ.md) — Vargan史上初めて島（火山島）に築かれた恒久集落。大型軍船を含む航海技術が領域拡大へ結実。「Varganとは連続した土地ではなく、VamとKesによって結ばれた土地の集合である」という領域観の芽生え、海の道Marranの意味の拡張
* [全同盟の成立（紀元前1300年頃）](BC1300_全同盟の成立.md) — 前1800年のDulenが500年をかけて周辺文明に受け入れられ、既知の近隣文明すべてがVarganの同盟国となる。Vargaを結節点とする外交網（ネクケスラン）、「Vargaとの同盟はVargaの敵に対する同盟」という原則、KesとDulenの制度化、「Lenが去ってもLentavを閉じるな」という格言
* [大陸東端のヴァルガン（時代不定・地理的前提）](地理_大陸東端のヴァルガン.md) — Vargan文明圏は一つの巨大な大陸の東端に成立した、という地理的前提の確定。西に大陸、東に大海。「西へ開くLentav、東の海を見つめるTorOrgan」という都市構造の象徴的読み直し、海洋進出の必然性、Ragon神話の「これ以上退くGaはない」という解釈の追加
* [生活語彙（時代不定・最古層〜）](生活語彙.md) — 家・炉・家族・食事・保存・衣服・睡眠・労働・市場・客人といった日常語彙の体系化。Dom・Nardom・Sammak・Neklen・Lendarなど、Daranの起源が政治思想ではなくごく普通の暮らしにあったことを示す語彙群
* [食文化（時代不定・最古層〜前1300年頃）](食文化.md) — 肉・魚・貝・米・酒を軸に、煮る（カス）・焼く（ヌル）・干す（デス）・味（メス）といった調理・味覚語彙を体系化。北方の保存食文化（サヴサル）と南方の農耕料理（カスファルベル）が融合し、鍋料理カスタルがVargan「国民食」として位置づけられる
* [人間語彙（時代不定・最古層〜）](人間語彙.md) — 人間一般（フム）・男女（タン／ミア）・身体各部（ハム・トク・フェズ・ヴィズ・モク・ベス・ポド）・心（エシュ）・名前（ネム）・生死（ヴェム／ナク）を体系化。「孤立した個人」より「誰とどういう関係にあり、共同体で何をする人か」を表す語彙が豊富、というVargan言語の特徴を裏付ける
* [身分秩序ケヴリンの成立（紀元前1200年頃）](BC1200_身分秩序ケヴリン.md) — 高度に分業化した社会が、Daran思想を用いて職能を「ケヴ（役割）」として制度化。神聖・指導・生産・交易などのケヴリンが成立し、当初は流動的だったが後世に世襲化・清浄観念と結合していく萌芽。「違っていてもよい」から「違っていなければならない」への転換、Senkanan・Vamanとの将来的な緊張
* [儀礼と作法（紀元前1200年頃）](BC1200_儀礼と作法.md) — RitanとSedanが社会秩序を可視化する装置へ拡張。作法（セドラン）・良き作法（ケルセド）・秩序を壊す振る舞い（ラクセド）が成立し、身分（ケヴリン）ごとの服装・席順・挨拶の差が制度として整う。外交儀礼の高度化、TorOrgan神話への「争いを防ぐ技術」としての作法の投影
* [制度の形骸化と探検時代の予兆（紀元前1100年頃）](BC1100_制度の形骸化と探検時代の予兆.md) — 完成した制度が完成したがゆえに形骸化し始める時代。大臣が儀礼的存在（ネムケヴ）になり実務官が政策を動かす、Senarの世襲化、Organの権威と実権の分離。一方でNargaや航海では身分より実務知識（ケヴセン）が優先され始め、Elganの精神が探検者として再評価される予兆
* [大競技場トルハリン（紀元前1060年頃）](BC1060_大競技場トルハリン.md) — Varga大競技場「大いなる戦いの輪」が完成。TorOrgan像が「Vargarとは何者か」を示す記念碑なら、Torharinは巨大化した社会が儀礼・娯楽・神話再演を共有する装置。Kevrinを可視化する観客席配置、殺し合いを前提としない競技（ハルサム）、政治の形骸化と壮麗な建築が同時進行するという「古代末期」の象徴、探検時代には「世界を見る場所」への転換の萌芽
* [同盟休止とDulenの定着（紀元前1040年頃）](BC1040_同盟休止とDulenの定着.md) — 同盟国同士の戦争に対し、確立済みのDulen原則を迷わず再適用。「同盟をやめる」ことと「友でなくなる」ことを区別する軍事同盟の一時休止（ダルハルリス）が成立し、Dulenが国内理念から他文明にも理解される外交慣行へ定着する。前1800年の「Dulenの発見」に対する「Dulenの定着」、TorOrgan像・Torharinとの象徴的呼応
* [名誉文化ケロル（紀元前1040年頃）](BC1040_名誉文化ケロル.md) — LorとKellorが社会秩序の中心的価値へ上昇。「名誉は自分で宣言するものではなく他人が与えるもの」という思想、Kevrinごとの職業倫理化、名家（ロルダム）と本人の功績の緊張、悪名（ラクロル）・不名誉（ノルロル）という対概念の成立。「家柄の名誉」対「自ら得た名誉」という探検時代への対立の萌芽
* [ムンガ襲来と古代秩序の終焉（紀元前1000年頃）](BC1000_ムンガ襲来と古代秩序の終焉.md) — Mungaへの敵対艦隊来襲（ラクハル）を機に、Dulenが前提としてきた「安定した複数のLen」という秩序そのものが崩れ始める。都市国家（ガダラゴル）の乱立、LensamarよりElkanarが重要になる時代、実戦のKellorが家柄の名誉を凌駕する契機。「秩序を維持する時代」から「世界を読み直し続ける時代」への転換点
* [第六都市ナムガと総督（紀元前930年頃）](BC930_第六都市ナムガと総督.md) — 巨大な湖畔に築かれた第六居住地ナムガ。翡翠・金・真珠・象牙・綿・亜麻を産し、西方アッバース文明圏との国境都市となる。野心的な総督（ガカナル、自称トルガカナル）の台頭は、中央のKevrinとRitanでは対応しきれない戦乱の時代の産物。「与えられた場所で役割を果たす」古代的人間像から外れた、自らKellorを獲得する個人の登場

| 前500年頃 | アシュガより西北、クメールとの境界に第八居住地Ruvan（ルヴァン）を建設する。要塞ではなく交流都市として発達し、ルビー・茶・ラクダを産する。ラクダ隊による砂漠交易網とオアシス集落、「茶を共に飲む」という新しい作法、Vargar/クメール人/遊牧民が混住する国境地帯が成立する。都市名は現地地名の借用で、古ヴァルガ語内部に語源を持たない初の地名となる |
| 西暦435年頃 | 国境都市Ruvanで、DaranとDarsair信仰を普遍的倫理へ再解釈する組織宗教が創始される。中心教義は「この世界に糧を」。民族・身分・国境を越えて糧(食・知・信頼)を分け与えることを使命とし、隊商文化から生まれた使徒が教えと救援を各地へ運ぶ。前4000年頃の建国から続くDaranが、初めてVamという境界を越えて世界そのものを対象とする普遍宗教へ変貌する。さらに、教えの根拠を「天の啓示」に求める啓示宗教としての性格も確立し、既存のSairzed(神託)とは区別される独自の宇宙観を持つに至る |
| 西暦465年頃 | SamargaのOrganが地方を巡行して実情を確認する「行郊」が君主の徳目として重視され始める。「Organは座す者ではなく巡る者」という神話的Organ像の再解釈で、地方統治への監査機能と施食・寄進を伴う双方向的な巡行が定着する。435年のRuvan宗教で使徒が糧を運んだことの30年後という連関があり、多中心的Varganが制度として完成する契機となる |
| 西暦500年頃 | 「同盟国を助けること」と「同盟国の戦争に参加すること」を切り離す「非参戦原則」が確立する。前1800年のDulen発見以来積み重ねられた参戦と防衛の区別の到達点で、Darharan(軍事同盟)が形骸化し、参戦しない代わりに食料・医療・仲介で同盟国を支える外交へ移行する |
| 西暦560年頃 | 三河川の河口都市Samargaを複合水害(河川氾濫・高潮・土砂災害)が襲い、政治首都機能が一時的に麻痺する。465年からの行郊による多中心統治のおかげで国家そのものは崩壊せず、435年成立の新宗教の使徒が最初の大規模救援を行い、教義「この世界に糧を」を実地で証明する。旧来のDaranと新宗教の違いが社会に可視化され、治水・都市防災技術と災害時のOrganの義務が発展する契機となる |
| 西暦560年頃 | サマルガ大水害での救援活動を機に、ルヴァン宗教の布教・救済活動を国家・社会が積極的に保護する「福音主義」的方針が確立する。国教化ではなく法的保護という形をとり、Ruvanが聖地として台頭し、軍事力ではなく救済・知識によって形成される対外ネットワークが広がり始める |
| 西暦600年頃 | Mungaに聖なる祖廟(Nakarsaiga)の最大級施設「トルナカルガ(Tornakarga)」が完成する。歴代のOrganや共同体に大きくDarした死者を祀るVargan的祖先祭祀で、Ruvan宗教の拡大と並行して古来のSair信仰も自らの伝統を再構築する宗教的多元化が進む |
| 西暦620年頃 | 土地・貨幣・生産手段を集積し大規模な生産・交易を可能にする経済政策「原始的蓄積」が確立する。サマルガ大水害からの復興需要と非参戦外交による「平和の配当」が背景にあり、国家・Galorar・Berarが同時に蓄積を進める。土地を持たずKevを対価に生活する人々の増加を受け、給金(Kevdan)と税(Vamdar)が正式な経済用語として確定する |
| 西暦680年頃 | 古都Vargaに世界各地の動植物を集めた王立庭園(王立動植物苑)が成立する。Organの庭園として始まり、外国からの珍獣贈答という外交儀礼、SilgaのSenarによる自然研究施設への発展を経て、Vargaが「Varganが知った世界を集める都市」としての性格を帯びる |
| 西暦685年頃 | Namgaに、新宗教を強く保護した有力者を葬る巨大墓廟複合施設が完成する。600年のMunga聖廟とは異なりRuvan発祥の新宗教と政治権威が結びついた象徴で、財産を基金化し死後も収益でDarし続ける宗教財団の原型が生まれる |
| 西暦710年頃 | 前500年からの探検時代が成熟し、古典の再発見(ルネサンス)と世界の再発見(大航海時代)が同時に起こる。大型外洋帆船(キャラック相当)が複数建造され沿岸航海から真の外洋航海へ転換、原始的蓄積の資本が造船・航海への出資という形で「投資」概念を完成させる。古ヴァルガ語が研究対象の古典語となり、「古典だから正しいとは限らない」という実証的態度が育ち、探検時代が終わって「世界そのものを理解し直す時代」が始まる |
| 西暦715年頃 | 別文明の領域を挟んだ北方に、Vargan初の飛び地となる第九居住地ナイラン(Nairan)が成立する。大河川を下って海へ出る物流経路によって本土と結ばれ、絹・茶・ルビー・馬・ラクダ・鯨など内陸/河川/海洋三交易圏へアクセスする。通行権など高度な外交制度と遠隔地ゆえの特別自治権が生まれ、「Vargarとは何か」という問いが再燃する |
| 西暦715年頃 | 435年創始のルヴァン発新宗教がVargan本土の多数派宗教となり、大航海時代の到来と同時に組織的な国外布教が始まる。使徒が外交官・民族誌学者・慈善活動家を兼ねる形で制度化され、外国人も使徒になれるとする普遍主義と、信仰の有無にかかわらず糧を与えるという結論へ向かう |
| 西暦750年頃 | 東方の海を越え、既知文明圏と系統の異なるメキシコ文明とVargan史上初めて接触する(東海遭遇)。「発見」でなく「未知だった文明をSenに加えた遭遇」という捉え方、慎重な初期接触、言葉の通じない相手との外交から専門通訳が生まれる。「この世界に糧を」がメキシコのHumにも及ぶかという神学的衝撃と宗派対立、投資の投機化、海外代表権の制度化、「東の果て」という地理観の崩壊 |
| 西暦755年頃 | Mungaに新宗教のノートルダム相当の巨大聖堂が完成する。600年の祖廟トルナカルガと同じ都市に並び立つ宗教的多元性、信徒・Berar・Galorar・宗教財団・都市政府による共同建設、「天を描写せず、ただ天へ向かう」建築思想、礼拝と慈善を一体化した複合施設、Ruvan(起源)とMunga(大聖堂・使徒派遣拠点)という宗教地理の分化 |
| 西暦755年頃 | 恒常風を記録・共有・航路設計に利用する貿易風の体系的利用が普及する。往路と復路で異なる風を使う環状航路の確立、Silgaが航海記録を集約する組織的経験科学の萌芽、航海の再現可能性が生む商業革命、「世界は観察すれば規則を見つけられる」という自然観の芽生え |
| 西暦770年頃 | Namgaに、地上からToraruへ登る過程を歩いて体験する巨大巡礼壇Taldarugaが完成する。三段階構成(Mel/Dar/Toraruの世界)、天を像にしない宗教美術思想、宗教史を刻んだ回廊、Ruvan/Munga/Namgaという宗教地理の三分化 |
| 西暦790年頃 | 古都Vargaに、Darsairを中心とする古代Sair信仰のルネサンス大神殿Tordarsairgaが完成する。旧宗教への回帰ではなくVargan古典文化としての再評価、古ヴァルガ語碑文とSilga古典学者による監修、Munga・Namga・Vargaの三大宗教建築の象徴分化 |
| 西暦820年頃 | Mungaに、初期Taldarたちの遺品・記録を納める聖遺物塔Tortaldarkadが完成する。聖性は物を通じたDarの記憶に宿るという神学、建設費に応じた慈善拠出「同量施食」の原則、Taldaran自身が自らの古代を自覚する記憶の時代への移行 |
| 西暦825年頃 | Varganの古典復興が「古代を発見する段階」から「体系化し現代へ組み込む段階」へ移行する。Silgaでの文献批判による古典学の学問的独立、標準化された「古典ヴァルガ語」の成立、Vargaの文化首都化、Taldaran自身の聖典校訂運動の始まり |
| 西暦850年頃 | Namgaに、修道・神学校・図書館・写本工房・宗教会議所・翻訳院を統合した大複合施設Torsendargaが完成する。世俗知のSilgaと宗教知のNamgaという二大知識拠点の分化、異教文献も保存する翻訳院、「SenをDarする」ことも善行であるという思想の拡張、政教関係の理論化の始まり |
| 西暦870年頃 | Nairanよりさらに西、丘陵に囲まれた金鉱地帯にVargan文明初の西方海洋圏への恒久的出口Veyran(第十居住地)が成立する。東西二つのMarを持つ文明への転換、Nairanが飛び地から西方圏への中継拠点へ変化、Nairan生まれのVargarが主体の最初の都市、地下資源権を巡る法学論争の芽 |
| 西暦905年頃 | 政治首都ではないSilgaに、Organの居所・中央官庁・文書庫・外交施設を統合した紫禁城相当の巨大宮城Torkevgaが完成する。「Kadを通してSenする政治」への移行、Kevによって分化した中央官僚制の本格化、SamargaとSilgaの二重首都化、地方は封建的・中央は官僚的という二重構造、官吏登用試験の萌芽 |
| 西暦920年頃 | 政治首都Samargaに、各地の知識を集約し翻訳・比較・実用化する国家的研究機関Torsengaが完成する。保存のSilga・信仰のNamgaとは異なる「研究と応用」という性格、国家的翻訳事業、外国人Senarの受け入れ、古典復興の普遍史観への発展、政策研究機関としての性格 |
| 西暦935年頃 | 560年から375年ぶりにSamargaを豪雨が襲い、Torsengaが初めて大規模な実践課題に取り組む。災害の反復傾向の発見、都市化が被害を拡大させたという指摘、行郊と官僚制の接続、慈善から国家責任への救済観の転換、気象観測の制度化 |
| 西暦950年頃 | 東海の彼方にある大島Elkenの西岸に、Vargan初の本格的な海外居住地(第十一居住地)が成立する。Marを越えなければ到達できない初の海外領域、漁業・水産加工中心の経済、通信不能時の非常権限、「本土を見たことがないVargar」の出現 |
| 西暦950年頃 | Vamdarの徴収基準として「収穫・収益の十分の一」が標準化される。935年豪雨後の財政需要が後押し、TaldaranのDarと国家のVamdarの分離、十分の一が徴収の上限にもなる納税者保護、Kad官僚制の一般生活への浸透 |

### 用語メモ

* **Urgar（ウルガル）** … 石器・石製道具
* **Vakur（ヴァクル）** … 投石用の石弾
* **Urtal（ウルタル）** … 投石弾（Vakur）の備蓄

造語の接尾辞（古ヴァルガ語）：

* **-an** … 個別の行為 → 集団的・継続的な活動（Har→Haran〔戦争〕、Ber→Beran〔交易〕）
* **-ar** … 行為者（Berar〔交易者〕、Melar〔所有者〕、Lorar〔有力者〕、Nekar〔異邦人〕）
