# 未確定事項

古ヴァルガ語の語彙・文法のうち、まだ結論が出ていない未確定事項・保留中の語彙候補・矛盾点をここにまとめる。すでに別語へ確定した衝突事例（改訂履歴）は[古ヴァルガ語辞書](../../制作ノート/古ヴァルガ語辞書.md)の「不採用・整理された語」「改訂履歴」を参照。

## 造語方針（探検時代）

前500年頃、Samarga遷都と多中心化を機に探検時代へ入ったVarganの造語は、三本柱で運用する（詳細は[古ヴァルガ語辞書の「探検時代の造語方針」](../../制作ノート/古ヴァルガ語辞書.md)を参照）。

1. 既存語根で表現できるなら複合語で対応する
2. Vargarが古くから知る普遍的概念で基本語根を欠くもの（例：島）は新しい基本語根を導入してよい
3. 探検時代に初めて接触した外国由来の事物・地名（象、茶、Ruvanの地名など）は借用語とする

判断基準は「Vargarがいつその概念を知ったか」。何でも借用語にするのではなく、この基準で語源の性質を使い分ける。**「島」はこの方針に基づき新語根Kep（Kep／Kepmar／Kepnav）としてすでに確定済み**であり、辞書・語彙集に反映されている（候補ではない）。同様に**[第八居住地の名Ruvan（ルヴァン）](../地理/ルヴァン.md)も、現地の西方系地名をそのまま音韻借用した確定済みの固有名詞**であり、古ヴァルガ語内部に語源を持たない最初の地名として辞書の固有名詞表に反映済みである。**「茶」を表すSey（セイ）も同じ方針の借用語として確定済み**（[古ヴァルガ語辞書](../../制作ノート/古ヴァルガ語辞書.md)を参照）。

435〜755年の未確定語彙は、[中期ヴァルガ語の造語規則](言語史.md)を固定したうえで一括確定した（詳細は[語彙一括確定・中期ヴァルガ語](../../制作ノート/語彙一括確定_中期ヴァルガ語.md)を参照）。さらにその後、風を表す新古語根**Vez**（当初提案のZurは既存Zul「翡翠」とカナ表記が完全一致するL/R衝突のため、事後点検でVezへ差し替えた）、帆船**Veznav**、統治者の裁量権を体系的に指す**Elkev**、飛び地**Elvamga**、ラクダを表す借用語**Nosh**を追加で確定した。以下は、それでもなお性質上まだ保留すべきものだけを残している。

## ①語形成のみ整理すればよいもの

いずれも「新語根が必要」という誤解から保留になっていたが、既存語で十分表現できることが分かっているため、辞書側にはすでに不採用として記録し、このページからは除外した。

* **Ashmel**（砂漠文学案）→ 不採用。Zom／Zomkad（前760、確定済み）を使い、必要ならAshzom／Ashzomkadという透明な複合語で当てる
* **Sar**（太陽案）→ 不採用。太陽はAgar（前840、確定済み）ですでに表現できる

**Nargaran**（火山島への航路など）も同種の扱いとする。既存Marran（海路）で当面代用でき、専用の見出し語として辞書化する必要はない。「Narga（de）Marran」のような句が繰り返し使われるようになった段階で、初めて一語への縮約を検討する（＝辞書化を急がない、使用頻度待ちの語）。

## ②まとめて体系化すべき新語彙群（優先順位つき）

一語ずつ場当たり的に作るより、分野ごとに既存語根との接続を検討してから体系的に作る。「未知」（Elsen）・「発見」（Sendar）・「地図・海図・航路図」（Gametkad／Margamkad／Marrangamkad）・「外洋」（Elmar）・「投資」「利益」（Meldar／Valvun）・封建君主制語彙（Sulkes／Vekkes）は確定済みのため、以下からは除外した。優先順位は次の通り。

1. **探検語彙の残り**（[西暦710年頃のルネサンスと大航海時代](../歴史/ルネサンスと大航海時代.md)により緊急度が最大になった）― [キャラック相当の大型外洋帆船](../歴史/ルネサンスと大航海時代.md)そのものを指す語は**Veznav（vez＋nav）に確定済み**。海岸・海峡・半島・星・天測などの残りの地理・航海語彙は未整備。季節風・恒常風・向かい風・追い風・無風・海流といった航海気象語彙は、新古語根**Vez（風）が確定済み**のため、Vezmar（海風）・Vezran（風路）・Vezved（風向）のようなVez複合語として整備できる見込みだが、恒常風候補の**Setvez**（set＋vez）だけは、Set（留まる・定住する、前3400）との衝突がないことは確認済みであるものの、他の航海気象語彙とまとめて確定する方針を維持し、あえて単独では確定していない
   * **船団内の役職名**は、新語根を増やさず既存語根を再利用できる見込み ― 航海長はMarven＋Kan系、記録官はKad＋-ar系、交易責任者はBer＋Kan系、通訳は既存Neklam系、外交担当はElkanar系、医療担当は治療に相当する語根が確定すればそこから派生させる
2. **国境交流語彙** ― [第八居住地ルヴァン](../地理/ルヴァン.md)の成立に伴う。隊商・オアシス・遊牧・草原／ステップ・関税・通行証など（ラクダは借用語**Nosh**として確定済み）。[715年頃のナイラン成立](../地理/ナイラン.md)によって、「国境で外国と接触する語彙」から「**外国領を越えた先に自国民が住む**ための語彙」へと一段階変わっている――通過・保護・外国領内の自国民・現地法・二重権限は未整備だが、遠隔自治と本国の対概念にあたる**遠隔地の裁量権はElkev（el＋kev）**、**飛び地はElvamga（el＋vamga）**にそれぞれ確定した
3. **貨幣制度語彙** ― Vikberの大衆化に伴う残りの語（税Vamdar・給金Kevdanは確定済み）
4. **文学・学問語彙**（優先度は低め）― Zom／Kad／Sen系の基礎はすでにあるため急がない。著者・書物・写本・読む・書く・翻訳・歴史・学派など

**馬（Rov）・ウミガメ（Kum）・鯨（Wor）**は、[中期ヴァルガ語の一括確定](../../制作ノート/語彙一括確定_中期ヴァルガ語.md)により古語根として確定済み（島＝Kepと同種の扱い）。ただし**捕鯨・鯨油**は生物名とは別に、既存の狩猟に相当する語根が確定してから複合語として作る方針で、まだ保留のままである。

**Damdar**（家・名家による奉納）は、辞書の見出し語として固定せず、必要な場面でdam＋darの透明な複合語としてその都度使う方針になったため、上記いずれのリストにも含めていない。

## ③中期ヴァルガ語の語形確定待ちのもの

[西暦435年頃](../社会と文化/新宗教の成立.md)以降、[前500年頃に確立した古ヴァルガ語の語彙体系](古ヴァルガ語.md)からおよそ900年以上が経過し、宗教・政治・経済の各分野で古ヴァルガ語確立期には存在しなかった概念が大量に発生していた。この「そのまま古語根を複合し続けてよいか」という根本的な問いは、**[言語史](言語史.md)にて「古ヴァルガ語 → 中期ヴァルガ語」という言語段階の移行を正式に導入する形で解決**し、さらに[語彙一括確定・中期ヴァルガ語](../../制作ノート/語彙一括確定_中期ヴァルガ語.md)によって宗教語彙一式・行郊・王立動植物苑・ナムガの大墓廟・宗教財団・政策名・ムンガの大聖堂・宗教財産権が一括で確定した。残っているのは以下のものだけである。

| 案 | 理由・確定条件 |
| --- | --- |
| **ルネサンス／大航海時代を指す時代区分語彙** | [西暦710年頃の転換](../歴史/ルネサンスと大航海時代.md)を、Vargan自身が後の歴史記述でどう呼ぶか。「古典の再発見」「世界の再発見」に相当する語も、古典学（校訂・古語辞典・碑文解読・現代語訳）に関わる語彙群も未整備 |
| **宗派・立場を指す語** | [新宗教の内部で生まれつつある対立軸](../社会と文化/世界宗教への転換.md)――天の正体を巡る穏健派／厳格派、財の使途を巡る即時分配派／生産拡大派、国家との関係を巡る協調派／独立派、[750年の東海遭遇](../歴史/東海遭遇.md)以降の早期布教派／理解優先派――は、いずれも便宜的な日本語の呼び名しか持たない |
| **メキシコ文明・東海遭遇そのものを指す語** | [西暦750年頃に接触した、既知文明圏の外にある文明](../歴史/東海遭遇.md)。「メキシコ文明」「東海遭遇」はいずれも便宜的な日本語ラベルで、Vargan語での固有名・出来事名を持たない。相手文明側の自称を借用するか、Vargan側で命名するかも未定 |
| **海外代表権を指す語** | [750年の東海遭遇](../歴史/東海遭遇.md)以降、誰がどこまでのKesを外国と締結できるかという権限（Elkanarの拡張された権限）を指す専用語がない。既存Elkanar（使節）の権限規定を言葉で拡張するか、新しい役職語を作るかも未定 |
| **ナムガの大墓廟の「壁の塗り直し」共同作業を指す語** | [西暦685年頃のナムガの大墓廟](../地理/ナムガ.md)で、信徒が定期的に外壁を塗り直す共同作業そのものが宗教行事になっている。この祭礼・作業を指す固有の語がまだない。あわせて、Ruvan式・Namga式・Samarga式というように分かれ始めている地方ごとの宗教建築様式の呼び名も未整備 |
| **官僚・官吏登用試験に関わる語彙** | [西暦905年頃のシルガの宮城トルケヴガ](../政治と軍事/シルガの宮城トルケヴガ.md)を機に、家柄によらずKevを担う「官僚」、その登用試験を指す語がまだない。既存Kev（役割）・Sen（知る）を核にした複合が想定されるが、制度自体がまだ萌芽段階のため語形成を急がない |
| **エルケンの居住地そのものの固有名** | [西暦950年頃の第十一居住地](../地理/エルケン.md)は、島名Elkenとは別に居住地自体の固有名がまだない。周辺の地形・現地勢力の有無が判明してから命名する方針 |
| **十分の一税の固有名** | [西暦950年頃に標準化された徴収基準](../政治と軍事/十分の一税.md)は、現時点では「十分の一を表す数詞＋Vamdar」という句のままで、一語への縮約はまだ確定していない。中期ヴァルガ語の数詞体系を整理する際に確定する方針 |

## 語彙以外で未確定の事柄（世界観レベル）

辞書の語形ではなく、世界観そのもののレベルでまだ形を与えていない事柄。単なる抜け漏れではなく、いずれも「今すぐ決めるべきではない」という判断のもとで意図的に保留されているもの。

| 事柄 | 状況 |
| --- | --- |
| **「天」の正体** | [西暦435年のRuvan新宗教](../社会と文化/新宗教の成立.md)における最大の神学的論点。語自体は**Toraru**として確定済みだが、その内実（意味論）は宗派ごとに異なる解釈を持たせる方針は維持する――①天そのものが最高神、②天は非人格的な秩序・真理の源でSairもその下にある、③天が何であるかを人間は完全には知り得ないとして定義自体を避ける、の三方向を意図的に未決着のまま残し、同じ語を人格神・非人格的秩序・不可知の超越者としてそれぞれ別の宗派が解釈している、という状態を最終形とする |
| **「Vargarとは誰か」の最終的な定義基準** | [アシュガ](../地理/アシュガ.md)（Varga語を母語としないVargarの出現）、[Ruvan](../地理/ルヴァン.md)（多言語家庭の一般化）、[ナイラン](../地理/ナイラン.md)（Samargaに行ったことのないVargarの出現）と、居住地が広がるたびに繰り返し提起されながら結論が出されていない。715年以降は血統論（Damを重視）・文化論（Varga語・Sedan・Daranを重視）・法論（VarganのKesと法に属する者をVargarとする）の三説が並立する方向性が有力。**Taldaranの信徒であることはVargarの条件ではない**という点だけは、宗教の世界宗教化に伴い明確になりつつある。今後の居住地拡大・布教拡大のたびに再浮上する、Vargan史全体を貫く未決着の問い |
| **地下資源権を土地所有権から区別する語** | [870年のヴェイラン](../地理/ヴェイラン.md)の金鉱を機に、「GaをMelしていることと、その地下の金をMelしていることは同じか」という法学論争が生まれた。Mel（所有する）を核にした複合が想定されるが未確定。この論争の帰趨そのものも意図的に未決着のまま残す |
| **東西の海は同じ世界海洋につながっているか** | [870年のヴェイラン成立](../地理/ヴェイラン.md)により、Varganは初めて東（[メキシコ文明](../歴史/東海遭遇.md)方面）と西（ヴェイラン方面）の両方に海を持つ。二つのMarが同一の海洋につながっているのか、Gaを囲んで一周しているのかは、後世の世界周航につながりうる地理的な問いとして意図的に未決着のまま残す |
| **SamargaとSilga、どちらが真の首都か** | [西暦905年頃のシルガの宮城トルケヴガ](../政治と軍事/シルガの宮城トルケヴガ.md)成立以降、法的・儀礼的首都Samargaと、Organが実際に大半の時間を過ごす行政首都Silgaが並立する。伝統主義者は「OrganのGaはSamargaである」と主張し続けるが、この曖昧さは意図的に解消せず、後の中央集権化の議論の火種として残す |
| **エルケンに先住民がいたか** | [西暦950年頃の第十一居住地](../地理/エルケン.md)が築かれた大島に、Vargar以前から住民がいたのかどうかは意図的に未決着のまま残す。先住民がいれば「Vargan史上初の本格的な海外入植と異民族統治」、無人島であれば「海を越えて社会そのものを移植した最初の例」となり、どちらに転んでも大きな歴史的意味を持つため、周辺情報が判明してから確定する |
