# ヴァルガン文学の成立（紀元前760年頃）

紀元前900年頃の[Silga大図書館（トルセンカドガ）](../技術と知識/シルガ大図書館.md)が「知識を書き残し、集め、読む」文化を育ててから約140年、紀元前760年頃になると、記録は実用目的を超えて**物語そのものを残すため**にも使われ始める。TorOrganの物語、Darsairをはじめとする神々の物語、冬を越えた祖先の物語、戦争や航海の英雄譚――これらはそれ以前から存在したが、長らく**口承文化**にとどまっていた。物語がなかったのではなく、**物語が文学という独立した文化領域になっていなかった**のである。

## 実用記録から物語へ

Torsenkadga完成当初、最も重要だったのは測量記録・航海記録・外交記録・神託・歴史・交易情報・技術記録という実用的な**Kad**だった。しかし記録技術が普及すると、「役に立つ情報だけを残す必要があるのか」という発想が自然に生まれる。TorOrganの物語を、古いRagar神話を、祖父から聞いた昔話を書き残す者が現れ、その文章を読む者が現れる。ここに**物語を書く者と、それを読む者**が生まれる。

## 口承神話の文学化

それまでTorOrgan神話には地域差があった。Vargaでは「Vamを一つにした者」、Silgaでは「SairのZedを正しく理解した賢王」、Samargaでは「Ragarと戦った偉大な戦士」、Nargaでは「Marを越えて人々を導いた者」――微妙に異なるこれらの伝承を、Kadar・Senarが収集し、**「TorOrganの物語」**として一本の長大な物語に編むようになる。ただし一つの正典に統一されることはなく、Silga版・Varga版・Samarga版・民間伝承版・Sairkanarの祭祀版がそれぞれ残り、Senarが「古いSilgaのKadではDarsairがこう語っている」と比較・議論する、豊かな神話研究文化が育っていく。多神教のVarganらしい、正史化しきらない神話のあり方である。

## 語 ― Zom と Yal

「語る・物語る」を表す語として、当初Melが検討されたが、既存の**Mel（持つ、所有する。前3600、Melar・Melga・Melgar等で多用）**と衝突するため不採用となり、代わって新語根**Zom（ゾム）＝語る、物語る**が置かれた。

* **Zoman（ゾマン）＝物語る行為、物語**（zom＋-an）
* **Zomar（ゾマル）＝語り手**（zom＋-ar）
* **Zomkad（ゾムカド）＝書かれた物語、文学作品**（zom＋kad）
* **Torzom（トルゾム）＝大いなる物語、叙事詩**（tor＋zom）

詩歌には別の語根**Yal（ヤル）＝歌う、韻律をつけて唱える**が置かれる。

* **Yalar（ヤラル）＝歌い手、詩人**（yal＋-ar）
* **Yalkad（ヤルカド）＝書かれた詩**（yal＋kad）

## 最初の叙事詩 ― Ragonの物語

Vargan最古の文学ジャンルとして最も自然なのは叙事詩であり、Rakonを扱う大叙事詩（Torzom）が最重要作品になる。Rakarによって長いOrがもたらされ、一柱の神では対抗できず、Darsairの諸神がそれぞれ戦い、Humも戦う――ある者はNarを守り、ある者はTalをDarし、ある者はHarし、ある者は傷ついた者を救う。最後にDarsairの血を引くTorOrganがRakarを倒すが、支配者になるのではなく、再びRakonが起こらないよう人々をSamする。これまで蓄積されてきた[ヴァルガ神話](ヴァルガ神話.md)そのものが、文学として編纂される。

重要なのは、TorOrganだけではRakarに勝てなかったという構造が保たれている点である。古典Vargan文学の英雄像は**「最も強い者」ではなく「皆の力をSamできる者」**であり、これは[Daran思想](互恵思想ダラン.md)と完全に結びついている。

## 戦争文学とノルマンという主題

[前1000年以降の戦争経験](../歴史/ムンガ襲来と古代秩序の終焉.md)、とりわけ[前840年頃のクメール支援戦争](../政治と軍事/クメール支援戦争エルヴェクハル.md)は、新しい文学的主題を生む。Varganらしく「敵を大量に殺した」英雄譚にはならず、故郷を離れた兵士、遠方のクメールで冬を迎えたVargar、戦友の死、故郷へ帰る船、敵だった者との対話が題材になる。かつてLenだったノルマンと戦わなければならないという葛藤は、単純な善悪の物語にならない――神話のRakarは明確な悪だが、現実のノルマン人にもVam・家族・Kellorがある。ここから「Harnekとは何か」「正しいHarとは何か」「KesとLenのどちらを重んじるべきか」という文学的テーマが生まれ、Vargan文学は神話から人間ドラマへと一歩を進める。

## 恋愛文学・旅行文学・寓話

文学は政治・宗教にとどまらない。異なるKevrinの男女、VargaとSamargaの男女、VargarとNekar、Elganと故郷で待つ恋人、戦争によって引き裂かれたVargarとノルマン人――[Kevrin制度が固定化した時代](../政治と軍事/身分秩序ケヴリン.md)だからこそ、「愛する相手」と「Sedanによって求められる相手」の落差が強い題材になる。

旅行文学は、探検時代への直接的な伏線になる。当初はElgankad（探検記録）という実務記録に過ぎなかったが、これを読む者に「彼方にはどんな世界があるのだろう」という想像力を刺激し、実際のElganの記録に基づく旅行文学・冒険譚が生まれ、さらには実在しない土地への旅までもが書かれる――ここでフィクションが本格的に成立する。**物語が次の探検者を作る**、という循環が生まれる。

政治批判も避けられない。露骨な名指しはせずとも、「欲深い架空のGakanarがVamを破滅させる物語」は読者に誰を指すか伝わる。[前930年頃からの野心的総督の台頭](../地理/ナムガ.md)、[前840年頃の分権化する寡頭制](../政治と軍事/分権化する寡頭制.md)を背景に、文学は新しい政治思想を広める媒体にもなっていく。

## 文学によるKellor

最初の文学者は専業作家ではなく、Kadar・Senar・Sairkanar・Elgan・元Elkanar・退役軍人など、何かを経験した人間、あるいは記録を職業とする人間が物語も書いた。やがて読者が増えるにつれ、**ZomだけでKellorを得る人間**が現れる――何も征服せず、巨大建築も作らず、言葉だけでVam全体に知られる、新しいLorarの誕生である。この存在は、[古いKevrin秩序](../政治と軍事/身分秩序ケヴリン.md)からすればかなり異質なものである。

一方で文学は、[前720年頃に台頭する独立貴族（Galorar）](../政治と軍事/独立貴族ガロラル.md)にとっては別の使い方をされる。祖先の物語をKadとして書かせ、数世代後にはそれを家の権威として扱う――**言葉によって自らを高める者**と**言葉によって家柄を飾る者**が、同じ文学文化から同時に生まれてくる。

## 都市ごとの文学文化

[大図書館を持つSilga](../技術と知識/シルガ大図書館.md)は収集・研究・批評の中心になり、金・翡翠・絹・象牙・米と工芸文化に富む[Samarga](../地理/サマルガ.md)は創作・詩・演芸の中心になりうる。Vargaでは政治的・歴史的文学、Mungaでは酒宴と歌謡、Nargaでは航海譚、Namgaではアッバース文化との交流から翻訳文学が育つ、というように、都市ごとに異なる文学文化が並び立つ。

| ジャンル | 内容 |

| 神話文学 | Darsair、Rakar、Rakon、TorOrgan |
| 叙事詩 | 神々・英雄・Vamの歴史 |
| 歴史文学 | 古いVargan史、都市成立譚 |
| 戦争文学 | Munga防衛、クメール支援戦争など |
| 詩歌 | 冬、太陽、海、故郷、愛、死 |

## 位置づけ

前900年頃のTorsenkadgaは「知っていることをKadにして残す」文化を作った。前760年頃、それは「考えたこと、感じたこと、想像したこともKadにしてよい」へと拡張される。ここに文学誕生の本質がある。

> 神話を口で受け継ぐ文明 → 知識を記録する文明 → 物語を書く文明 → 書かれた物語を読んで、まだ見ぬ世界を想像する文明

探検時代を目前にして、Vargarは実際に世界を広げるよりも一足先に、**物語の中で世界を広げ始めた**。軍事や政治ほど目立たない紀元前760年頃の文学発展は、後のVargan社会を静かに、しかし大きく変えていく転換点である。
