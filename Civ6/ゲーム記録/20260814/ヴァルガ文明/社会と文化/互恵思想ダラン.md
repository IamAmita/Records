# 互恵思想ダラン

**ダラン（Daran）**は、ヴァルガ文明の根本的な価値観であり、**相互扶助・助け合い**を意味する。ツンドラという環境から生まれた生存倫理が、交易・王権・信仰・外交にまで拡張されたものである。

## 起源

ツンドラでは、一つの家族や一人では対処できない危機（狩猟の失敗、病人・負傷者、吹雪、備蓄の喪失、不猟の年）が頻繁に起こる。そこで古くから、

> **「今日、余裕のある者が不足する者を助ける。明日には立場が逆になるかもしれない」**

という考え方が形成された。これは慈善ではなく、**相互扶助によって共同体全体の生存可能性を高める仕組み**である。

* **Dar（分ける、分け与える）** … 中核となる動詞語根
* **Daran（dar＋-an）** … 継続的・集団的に分け与えること＝相互扶助
* **Hal（助ける）／Halar（助ける者）** … 個別に助ける行為
* **Del（受けた恩、返すべき助け）** … 数量化されない社会的債務。同じ物で返す必要はない

繰り返される助け合いから、社会に巨大な**恩義のネットワーク**が形成された。

## 出発点は日常の暮らしだった

Daranは哲学者が考案した思想ではなく、その出発点は[家（Dom）と炉（Nardom）を中心とするごく普通の生活](暮らしと家族.md)にある。隣人（Ganar）のNardomから火を分けてもらう、Orket（冬支度）が足りない家にMakan（食べ物）を分ける、吹雪の夜にNekar（異邦人）をDomへ入れる――こうした行為の一つひとつが、生き残るための当たり前の判断だった。

* **Orket（or＋zon）＝冬に備えて蓄える、冬支度をする** … 食料の保存だけでなく、薪集め・家の補修・衣服の準備・家畜の移動までを含む、一年で最も重要な共同作業
* **Sammak（sam＋mak）＝共に食べる、会食する** … 同じものを食べることによって仲間になるという発想。外国使節との宴席にも用いられ、Kesを結ぶ前にSammakする習慣へつながる
* **Neklen（nek＋len）＝客、家へ迎え入れた異邦人** … 「異邦人でも、迎え入れれば友になれる」という思想を体現する語
* **Lendar（len＋dar）＝もてなす、歓待する** … 「自分のDomに入った者をOrから守る」という古い慣習から発達した、Darの日常的な実践

政治・外交で幾度も登場するDaranは、もともとVargarの**日常生活の倫理**だった、という位置づけがここにある。

## 交易・外交への拡張

ヴァルガ人が交易に開放的で、取引を基本的に拒まないのは、ダランの延長として説明できる。

* **Darber／Darberan** … 互恵的な交換・互恵関係。単なる交易（Beran）と違い「双方が相手の不足を満たす」価値観を含む
* 交易を受け入れる＝相手を**Daranの輪に入れる**。逆に「何も分けない」という拒絶は、外交的敵対宣言になり得る
* **Nekar（異邦人）**であっても、Darを返す者ならDaranの相手になれる

この思想はやがて信頼（Ithan）・約束（Kesan）を経て、[軍事同盟ダルハラン](../政治と軍事/軍事と同盟.md)（「戦争においてもDaranを行う関係」）へと発展した。

## 王権・政治との関係

ダランは[王権](../歴史/オルガン王.md)と[寡頭制](../政治と軍事/寡頭制カンリン.md)を貫く原理でもある。

> **最も多く受け取る者は、最も多く共同体へ返さなければならない。**

権力は「所有物」ではなくダランの一部であり、王も評議員（Rinar）も共同体を支える義務から自由ではない。

## 信仰との関係

自然もまた与える存在である――海は魚を、森は木を、山は銀を、獣は肉・皮・骨を。ゆえに人間も一方的に受け取るだけではいけない。狩猟後の儀礼（Ritan）、獲物を無駄にしないこと、聖地（Saiga）を荒らさないことも広義のダランとされ、[信仰](信仰と神官.md)には**「世界は互いに与えることで成り立っている」**という世界観が形成された。

## 「違っていてもよい」から「違っていなければならない」へ

紀元前1200年頃、[身分秩序ケヴリン](../政治と軍事/身分秩序ケヴリン.md)が成立すると、Daranの解釈にも重大な転換が生じる。「すべての者が同じものをDarする必要はない。それぞれが自らの役割（Kev）を守ることこそ最大のDaranである」という論理が、皮肉にもDaran思想そのものによって身分秩序を正当化する。

それまでのDaranが「異なる者が違うものを提供し合う」という開放的な思想だったのに対し、ここに「異なる者には、それぞれ決められた役割がある」という解釈が加わる。似ているようでいて、**「違っていてもよい」から「違っていなければならない」へ**――Varganの相互扶助思想が、初めて社会的拘束へと転化し始める瞬間である。

## 後世への遺産

> **「交易を拒まない。恩を忘れない。約束を軽んじない。そして、長く助け合った者を見捨てない。」**

これがダランを外交へ拡張したヴァルガの原則として定着していく。国家が巨大化しても、ダランは「冬を越える」思想と並ぶヴァルガ文化の中核に残る。

### Vamを越えるダラン

[西暦435年頃、国境都市Ruvanで創始された組織宗教](新宗教の成立.md)は、このダランをさらに一歩進める。「我々が共に生き延びる」という共同体倫理だったダランから、**我々であるかどうかを問わず世界へ与えよ**という普遍的使命への飛躍である。前4000年頃、冬を生き延びるための実践から始まった思想が、4000年以上の時を経てVamという境界そのものを越える。
