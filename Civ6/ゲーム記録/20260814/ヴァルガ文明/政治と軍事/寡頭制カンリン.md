# 寡頭制カンリン

ヴァルガの政治体制は、王を戴きつつも一人に全権を集中させない**寡頭制**へと発達した。後世に**Kanrin制（評議会による統治）**と呼ばれうる。

## 起源

[オルガン王](../歴史/オルガン王.md)以来、ヴァルガの「王」は後世の専制君主とは違い、**「人々を冬（Or）から生き延びさせる指導者」**であった。生存に関わる判断には狩人・老人・旅人・各氏族有力者の知識が必要だったため、王が重要な者を集めて相談する慣習が早くから存在した。これが寡頭制の原型である。

## 中心概念

* **Rin（リン）** … 輪、円、囲んで集まること。火（Sai Nar）を囲む会合が、やがて「重要な者が集まり物事を決める場」という政治的意味を持った
* **Kanrin（カンリン）** … 評議会。「導く者たちの輪」（kan＋rin）
* **Rinar（リナル）** … 評議員。「輪に加わる者」（rin＋-ar）
* **Rinkan（リンカン）** … 評議会の議事進行役（rin＋kan）。実務的な役職であり、最高指導者ではない

政治的最高職は、既存の称号**[Organ](../歴史/オルガン王.md)**（評議会を代表し導く者）に統一されている。Rinkanという語も一時は「評議会首席」として検討されたが、Organと役割が重複するため議事進行役へ役割を譲った。

## なぜ王だけでは統治できなくなったのか

交易の発達、軍事の専門化、[シルガ](../地理/シルガ.md)への入植、神官サイルカナルの成立、遠方勢力との外交、軍団司令官Harkarkanarの成立――こうして王が一人で軍事・交易・宗教・鉱山・各集落・外交・備蓄すべての最高判断を下すことは不可能になった。そこで専門的権威を持つ者が政治に参加する。

## 誰が評議員になるのか

全成人が参加するわけでも、単純な世襲貴族制でもない。各有力氏族の代表、Varga・Silgaなど主要集落の代表、神官の代表、軍団司令官、交易・資源管理で力を持つ者などが評議員となる。すなわち**社会の主要な力を握る少数者が共同で統治する**ヴァルガ型寡頭制である。

## 権力の抑制

* **[ダラン](../社会と文化/互恵思想ダラン.md)** … 権力は「所有物」ではなく共同体から預かったもの。王も評議員も共同体を支える義務を負う
* **Sam（合わせる）／Saman（合意）** … 多数決より合意形成を重視。「主要な評議員が反対しない状態」を目指す
* **Res（拒む、反対する）／Resar（反対者）／Resan（異議）** … 重要な評議員の反対を王は無視できない
* **Sed（慣わし）／Sedan（慣習、掟）** … 成文法はまだ無く、祖先から受け継いだ慣習に反する決定は避けられた

## 王の位置づけ

称号**[Organ](../歴史/オルガン王.md)**（オルガン以来）は残るが、Organは**絶対君主ではなくKanrinを代表する最高指導者**である。OrganはKanrinの招集、議論の取りまとめ、外交上の代表、緊急時の暫定命令、軍団司令官の任命などの特権を持つ一方、戦争開始・大規模入植・重要な交易協定・備蓄の大規模放出などにはKanrinの承認を要した。

## 三本柱

* **ダラン（Daran）** … 社会原理
* **合意（Saman）** … 政治原理
* **評議会（Kanrin）** … 政治機関

その原型は「一人の知恵では冬を越せない」という経験にある。
