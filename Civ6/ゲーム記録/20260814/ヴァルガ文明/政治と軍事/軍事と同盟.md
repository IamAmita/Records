# 軍事と同盟

ヴァルガの軍事は、共同体を守る戦士から、専門化した兵科・指揮・そして他民族との同盟へと発展した。

## 起源 ― 守る者カル

最初期の戦士は **Kar（カル）**と呼ばれた。原義は**「守る」**であり、外敵や大型獣から共同体を守る者だった。常備軍はなく、平時は狩猟・漁労に参加した。

## 前3700年頃 ― 戦争と兵科の分化

人口増加と資源利用圏の固定化で集団間の戦闘が増え、**Har（戦う）／Haran（戦争）**という「守る」とは異なる概念が定着する。

* **投石器ヴァカル（Vakar）と投石兵ウルヴァク（Urvak）** … 貴重なカルドルを消費せず多数を武装できる兵器。ヴァルガ史初期の専門兵科
* **カルガラン（Kargaran）** … 戦列・陣形。距離による役割分担が生まれる
* **カナル（Kanar）** … 指揮官。個の強さと「軍を率いる能力」が分離し始める
* **ウルタル（Urtal）** … 投石弾（Vakur）の備蓄＝軍需備蓄

## 前3100年頃 ― 指揮の専門化

VargaやSilgaなど各地の戦力を一つの戦場へ集めるようになり、指揮そのものが専門化する。

| 階層 | 語 |
| --- | --- |
| 個々の戦士 | Kar／Urvak |
| 部隊 | **Harket**（har＋ket） |
| 部隊長 | **Ketkanar** |
| 軍勢 | **Harkar** |
| 軍団司令官 | **Harkarkanar**（軍勢を率いる者） |

命令（**Kanta**）は伝令（**Kanlamar**）を通じ *Harkarkanar → Kanlamar → Kanar → Kar* と伝わる。司令官は部隊を配置（陣＝**Harrag**、布陣＝Harragtek）し、作戦（**Harmen**）を立てる。ここでヴァルガ人は**「戦士として強い者」と「軍を率いるのが上手い者」は必ずしも同じではない**と認識するに至る。

## 前3000年頃 ― 同盟ダルハラン

ヴァルガにとって同盟は単なる軍事協定ではなく、[ダラン](../社会と文化/互恵思想ダラン.md)を戦争にまで拡張した関係である。長年の交易（Beran）と互恵（Darberan）を通じて、

**交易 → 互恵 → 信頼（Ithan）→ 約束（Kesan）→ 同盟（Darharan）**

という発展をたどった。

* **Ith（信じる）／Ithan（信頼）** … 「必要なとき、この者はDarを返すだろう」という過去の行動に基づく信用
* **Kes（約束する）／Kesan（約束、誓約）** … 共同体間で交わす誓い
* **Darhar（共に戦う）／Darharan（軍事同盟）** … 「戦いにおける相互扶助」（dar＋haran）
* **Darharar（盟友）** … Lennek（友好的な異民族）より強い関係
* **Harnek（敵）／Vamharnek（共通の敵）** … 同盟の成立により「敵」も政治概念となる

同盟は共同体全体を戦争へ巻き込みうるため、[評議会カンリン](寡頭制カンリン.md)で審議され、合意（Saman）を経て締結された。締結は神官サイルカナルによる儀礼（Ritan）を伴い、両者は「お前の冬（Or）には我らが分け与え（Dar）、我らの戦（Haran）にはお前が戦う（Har）」という趣旨の誓いを立てた。

## 外交関係の深さ

**Nekar（異邦人）→ Berar（交易相手）→ Lennek（友好的な異民族）→ Darharar（共に戦う盟友）**

ヴァルガ人は関係の深さを語彙で区別した。血縁や民族ではなく、繰り返しDaranを実践し信頼を築いたかで「仲間」を判断した点が特徴である。

軍制はその後も発展を続ける。[大いなる駆逐](大いなる駆逐.md)を経て地域覇権を確立した後、紀元前2400年頃には[常設の兵舎ハルガルと常備戦士セトカル](常備軍と兵舎.md)が現れ、軍事力は「必要なときだけの活動」から「恒常的な制度」へと移行する。
