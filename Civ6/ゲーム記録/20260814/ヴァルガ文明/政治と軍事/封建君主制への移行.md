# 封建君主制への移行（紀元前500年頃）

[前500年頃のSamarga遷都](../歴史/多中心化するヴァルガン.md)は、単なる政庁の移転ではなく、Varganの統治体制そのものを再編する契機になる。**封建君主制・金権政治・神権政治**という三つの方向性のうち、これまでのVargan史を踏まえると、**「封建君主制へ移行しつつ、実態としては強い金権政治的性格を伴う」**という体制が最も自然な帰結である。

## なぜ封建君主制なのか

前500年に突然封建化するのではなく、少なくとも前1000〜700年頃から前提条件が積み重なっている。

> 中央の大臣が形骸化する
> → 地方Gakanarが力を持つ
> → [前720年頃、Galorar（独立貴族）が成立する](独立貴族ガロラル.md)
> → Ga・Dam・Kellorが世襲的な権力基盤になる
> → Vargaだけでは七つのGaを統治できなくなる

これは典型的な**中央集権的寡頭制から分権的君主制への移行**であり、Samarga遷都はその決定打となる。古都Vargaには、Organの伝統・古いLordam・Galorar・Kanrin・古い祭祀・TorOrganの記憶が集中しているが、政治機能をSamargaへ移すということは、Organそのものを廃止するのではなく、**古いVarga寡頭政治から距離を置き、Organを頂点としながら各Gaの有力者がそれぞれの地域を統治する体制へ移る**ことを意味する。

## Vargan型封建君主制の性格

史実の中世西欧型（王→大諸侯→騎士→農奴）をそのまま移植する必要はない。Varganの場合は、**Organを頂点とする、都市・Ga・Damの連合的な封建君主制**になる。Organは（新たな政治実務の中心である）Samargaにおり、各都市にはGakanarが、地方にはGalorarやLordamがいる。Kanrinには彼らの代表が集まる。各勢力が一定の自治権を持ちながら、共通貨幣・共通外交・共通法・共同防衛・Daran・Varganという民族意識によってまとまる、**封建的な連邦君主制**に近い形である。

### Organの性格の変化

古代のOrganは「Vargaを中心としてVamを導く者」だったが、この時代のOrganは**「複数のGaとDamの間をSamする者」**へと変わっていく。これは、Ragarを倒した後も自分一人ですべてを支配せず、再び争いが起こらないようHumを導いた[神話上の初代Organ](../社会と文化/ヴァルガ神話.md)の姿にむしろ近い。強いOrganとは、すべてを直接統治する者ではなく、**多くのGa・Dam・KevをSamできる者**を意味するようになる。

## 新しい統治構造

| 主体 | 役割 |
| --- | --- |
| **Organ** | Vargan全体の君主。各Gaを直接統治せず、外交・共同防衛・Vargan全体のKes・貨幣規格・大規模公共事業などを担う |
| **Kanrin** | 存続するが、古いVarga有力者だけの寡頭会議から、各Ga・主要Dam・主要Kevを代表する会議へ再編される |
| **Gakanar** | 各都市・地方の統治者。Organへの忠誠を認めつつ、広い自治権を持つ。この忠誠は単なる服従ではなく、**Sulkes（封臣が主君に負う契約、sul＋kes）**と**Vekkes（主君が封臣に負う保護契約、vek＋kes）**という双務契約として語彙化されている（両者をまとめた封建契約はSulvekkes、封臣はSulkesar、封主はVekkesar） |
| **Galorar** | Damgaを世襲。地方行政・経済・治水などを担う代わりに、その土地に対する一定の権利を認められる |
| **Berar** | 正式な封建身分ではないが、Samargaを中心として政治への影響力を急速に強める |
| **Sairkanar** | [Sairsamga](../社会と文化/サイルサムガ.md)など宗教施設を管理し、新体制に宗教的正統性を与える。統治者にはならない |

[同時期に築かれる第八居住地ルヴァン](../地理/ルヴァン.md)のGakanarは、この裁量の大きさを最もよく体現する例になる。中央から遠く、クメールと国境を接し、交易量も多いこの都市では、クメール地方官との交渉から国境紛争の仲裁、オアシス管理まで、Gakanarに広い権限が委ねられる。

## なぜ金権政治ではないのか

[前600年頃の硬貨の普及](貨幣の大衆化.md)、Samargaの莫大な富、政治実務のSamarga移転を考えれば、Berarの政治力が急上昇する条件は揃っている。しかし、Varganの政治的正統性は長い歴史を通してSen・Kellor・Dam・Ga・Kes・Daran・Sair・Organによって構成されており、「富を持つ者が統治してよい」という思想には至っていない。Samargaで最も裕福なBerarよりも、1000年以上の歴史を持つVargaのLordamの方が社会的Kellorが高い可能性がある。**貨幣は権力を獲得する手段にはなっているが、まだ権力そのものを正当化する原理ではない。**

### それでも急速に金権化する

制度上は封建君主制でありながら、実態は異なる。Samarga遷都によってOrganの周囲にはGalorar以外にも、Berar・工房経営者・外国商人・両替商・船主・富裕な土地所有者が集まる。Organも彼らの財力なしには公共事業・船舶建造・外交・祭典・探検を進められない。**制度上は封建君主制、実態としては金を持つ者の発言力が猛烈に強い体制**――これが将来の金権政治への移行伏線になる。

[前720年頃のGalorar](独立貴族ガロラル.md)はGa＋Dam＋Kellorを権力の源としていたが、前500年頃には**Ga＋Dam＋Kellor＋貨幣**へと変わる。港湾へ投資し、Berarに資金を出し、船を所有し、香料交易に参加し、鉱山へ投資する――**地主貴族が商業貴族へ変わっていく**。逆に大富豪BerarがGalorarのDamと婚姻することもあり、「貴族」と「富豪」の境界は最初から曖昧になっていく。Varganの封建君主制は、成立の当初から**商業的封建制**としての性格を色濃く帯びている。

## なぜ神権政治ではないのか

Sair信仰は極めて重要であり、大神託所・Sairkanar・Tortekkor・Sairsamgaという蓄積があるうえ、前530年の巨大宗教施設完成の直後に遷都が起きていることから、表面的には神権政治も候補になりうる。しかしVarganは多神教であり、神話そのものが「一柱の神がすべてを支配する」のではなく「異なるSairとHumがSamしてRagarへ立ち向かう」という構造を持つ――**宗教思想そのものが権力集中型ではない**。

Sairkanarは重要な権威だが、Senar・Kanar・Gakanar・Berar・Galorar・Organといった別々の権威と長く共存しており、歴史的に政治権力を独占してきたわけではない。[Sairsamga](../社会と文化/サイルサムガ.md)自体も一柱の最高神の寺院ではなく、Sairkanar・Senar・Galorar・Berar・職人・複数都市・クメールが関わって完成した、**「宗教もまたSamされるものの一つ」**であることを体現する建築である。「Sairkanarが政治を支配する」という体制へ至るには、これまでのVargan史にない宗教革命が別途必要であり、現時点ではその契機がない。

## 三体制の比較

| 体制 | 適合度 | 理由 |
| --- | --- | --- |
| **封建君主制** | ★★★★★ | Galorar、Gakanar、地方分権、Organ、Dam、Gaの世襲化がすでに進行している |
| **金権政治** | ★★★★☆ | 硬貨・交易・Samarga・Berarの台頭により急速に強まっている |
| **神権政治** | ★★☆☆☆ | 宗教権威は非常に強いが、Sairkanarによる政治権力独占には至っていない |

## 古代を否定しない新体制

この新体制は古代を否定しない。Organは「我々はTorOrgan以来のVamを、新しい時代に合わせてSamし直した」と説明する。Vargaは廃都にならず、Varganの古都・Organの起源・祖先のGaとして特別な地位を保つ。新Organは政治をSamargaで行っていても、**即位だけはVargaで行う**。政治権力はSamarga、王権の歴史的正統性はVarga、宗教的大祭はSamargaのSairsamga、知識的権威はSilga――この**権威の分散**こそがVarganらしさである。

## 政治体制の変遷

```
古代前期 ― 寡頭制（Senar・有力者・Organによる合議）
   ↓
古代末期 ― 寡頭制の形骸化（Gakanar・Galorarが台頭）
   ↓
前500年頃 ― 封建君主制（Organを頂点として各Ga・Damの自治権を制度化）
   ↓
探検時代 ― 交易・航海・硬貨経済が爆発的に拡大。BerarとGalorarの商業化が進む
   ↓
将来 ― 金権政治化？（「Gaを持つ者」より「船・硬貨・交易網を持つ者」が力を持つ）
```

## 位置づけ

前500年の選択は、**封建君主制が過去の積み重ねから最も自然に導かれ、金権政治が未来へ向けて最も強く伸び始めている**という二重の性格を持つ。神権政治だけは、Sairkanarによる権力掌握や「神託なくしてOrganは統治できない」といった別個の宗教的事件が起こらない限り、選ばれにくい。

Samarga遷都は、「Vargaの権威を捨てた」出来事ではなく、**「VargaだけでVarganを統治する時代を終わらせた」**出来事である。前500年は、古代Vargan寡頭制が、Organ・地方貴族・都市・商人・神官という複数の権力を包み込んだ**Vargan型封建君主制**へ再編された年として位置づけられる。

この体制はおよそ1000年を経て、[西暦465年頃の「行郊」](行郊.md)という形でさらに一段階進む。Organが実際に各Gaを巡行し、中央と地方の関係を定期的に再確認する制度が生まれることで、前500年に始まった多中心的な統治構造が実質的に完成していく。
