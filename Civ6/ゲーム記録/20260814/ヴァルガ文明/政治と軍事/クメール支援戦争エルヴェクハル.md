# クメール支援戦争とエルヴェクハル（紀元前840年頃）

紀元前840年頃、Varganは同盟国クメールへの支援要請を受け、かつて同盟関係にあったが現在は[Darharris（同盟休止）](中立外交ドゥレン.md)状態にあるノルマンとの戦争に加わる。これは[前1040年頃のDulen](中立外交ドゥレン.md)からさらに一歩進み、**「同盟を尊重するために、直接的な利害が薄くても戦争へ参加する」**という新しい段階を示す出来事である。

## DulenよりDarharkesを優先する

これまでのVarganは、友好国同士が戦えば双方との同盟を休止し中立を保つ（Dulen）という原則を選んできた。しかし今回、クメールとのDarharan（軍事同盟）は現に有効であり、ノルマンとのそれはすでに休止している。有効な同盟義務はクメール側にのみ存在する――ゆえにVarganは**Darharkes（ダルハルケス）＝軍事同盟上の参戦義務**（darhar＋kes）を優先し、クメールを支援する。これはDulenの放棄ではなく、**中立を守るべき戦争と、盟約を履行すべき戦争を区別し始めた**という発展である。

* **Kesdar（ケスダル）＝約束・盟約を履行する**（kes＋dar）。今回の参戦はまさにKesdarとして説明される

Kanrin内部では当然議論になった。「かつてのLenに剣を向けるべきではない」という保守的Dulen派と、「現在のKesを破れば、今後誰がVargaの盟約を信じるのか」というDarharan重視派の対立の末、後者が優先された。Varganは初めて、**過去の友好より現在有効な盟約を優先する**という、より制度的・法的な外交判断を下したことになる。

## 戦争目的を「援助」に限定する

重要なのは、Varganがクメール側に立ったこと自体ではなく、**「クメールを助ける。しかしノルマンを打倒するためには戦わない」**という線引きを明確にしたことである。Vargan側の戦争目的は、クメール領の防衛、クメール船団の護衛、兵糧・装備・船舶の供給、ノルマン軍侵入時の迎撃、交易路の防衛に限定され、ノルマン本土への侵攻・領土占領・都市攻略・略奪は行わない。

* **Elvekhar（エルヴェクハル）＝盟友を守るための遠方防衛戦**（el「彼方」＋vek「守る」＋har「戦う」）。奪取目的の[Rakhar](../社会と文化/ヴァルガ神話.md)や、一般的な外征を指す**Elhar（エルハル）**（el＋har）・**Elharan（エルハラン、外征）**・**Elharkar（エルハルカル、遠征兵）**とは明確に区別される

これまでのVekharが「自分たちのVamを守る戦争」だったのに対し、Elvekharは**LenのVamを守るためにもVekharを行える**という解釈の拡張である。Daranの対象がVargarだけに限定されないのと同様、Vekする対象もVarganだけに限らない。

## Harnekではなく Harkesar

ノルマンは、Varganにとって恒久的な敵Harnekではない。現在Kes上の事情によって戦っている**Harkesar（ハルケサル）＝現在の交戦相手**（har＋kes＋-ar）として扱われ、戦争終結後の友好再建が最初から想定される。ノルマン軍をクメール領から排除するところまでは追うが、ノルマン領へ逃げ込んだ後は原則追撃しない――**Harpekはする。Rakharはしない。**捕虜は「Rakarの者」ではなく「Harが終わるまで武器を持たせないHarkesar」として扱われ、戦闘終了後に返還や捕虜交換が行われる。ノルマンの農村を焼く、食料を奪う、財宝を略奪するといった行為はRakと理解され、[Vekhar中にRakを行えばその者自身がRakar的行為をしたことになる](../社会と文化/ヴァルガ神話.md)という、重い軍規違反として扱われる。

## 「武装した交易・外交文明」

この戦争を理解するうえで重要な補正がある。Varganは**軍事大国でも遠征可能な巨大な軍隊を持つ文明でもない**。むしろ、外交・交易・都市間協力に比して軍事力は抑制的で、**防衛に必要な最低限の戦力だけを制度的に保持している文明**である。

| 分野 | Varganの性格 |
| --- | --- |
| 常備陸軍 | 小規模 |
| 徴兵 | 有事に不足分を補う |
| 都市守備 | 重視 |
| 海軍 | 海路・沿岸防衛に必要な規模 |
| 大型軍船（Ferharnav） | 技術はあるが少数 |
| 遠征能力 | 限定的 |
| 長期攻勢戦争 | 苦手 |
| 占領・征服戦争 | 基本的に想定していない |
| 防衛戦 | 軍事思想の中心 |
| 兵站・補給 | 交易網を利用できるため比較的得意 |
| 外交 | 軍事以上に重視 |

[Munga敵対船団来襲が重大事件になったのも](../歴史/ムンガ襲来と古代秩序の終焉.md)、「敵艦隊を容易に撃破できる」文明ではなかったからこそである。Hargarが維持するのも大軍ではなく最低限の専門兵であり、Ferharnavも交易船の護衛・沿岸警備・Narga航路確保のための少数の防衛戦力にとどまる。

> **「Vekするに足るHarを持て。Rakするに足るHarを求めるな。」**

過剰な軍備は他のVamから資源を奪う――この軍事思想は、[Daran](../社会と文化/互恵思想ダラン.md)や[Dulen](中立外交ドゥレン.md)と地続きである。

## クメールへの支援の実態

前840年のクメール支援も、大規模な遠征軍の派遣ではない。実際には、少数の専門兵・指揮官、防衛用の槍兵・弓兵、限定的な軍船と輸送船、[Samargaの米やSilgaの保存食](../地理/サマルガ.md)などの補給物資、武器・木材・船舶部材、医療・工兵・航海・情報要員による支援が中心となる。**兵そのものより、Varganが持つ物流・交易網・生産力をクメールへDarする**ことに主眼がある。

遠方への参戦はVarganにとって軽い決断ではない。少数のHarnavをクメールへ回せばMungaやNargaを守る船が減り、常備兵を派遣すればVargaやNamgaの守備が薄くなり、徴兵すればSamargaの農民や都市職人が仕事を離れる。それでも支援した――だからこそ「Kesを守った」という意味が重くなる。**「余裕がある大国が少し兵を出した」のではなく、限られたVekの力の一部を盟友へDarした**という行為である。

## Kellorの新しい基準

この戦争で評価される軍人像は「征服者」ではない。少ない兵力で防衛線を維持した者、物資を安全にクメールへ届けた船員、損失を抑えた指揮官、不要な戦闘を避けたHarsenar、クメール軍との協働を成立させたElkanarが高いKellorを得る。**「少ないHarで大きくVekする」**ことが軍人のSenとして評価され、[前1500年頃に確立した兵種](兵種の確立.md)の中でも、勇猛さより節制を含む判断力が重視されるようになる。これは[TorOrgan像](../技術と知識/TorOrgan像.md)が体現する「下ろされた武器」という理想とも一致する。

## 「同盟国を守る」と「敵を征服する」の分離

この戦争の思想的成果は、参戦が敵を倒しきることを意味しないと理解された点にある。今回の目的は**Lenを守ること**であり、目的を達成する以上のHarは不要である。Kanrinが参戦を承認した際の宣言は、次の四点に整理できる。

1. クメールとのKesを守る
2. ノルマンのGaを求めない
3. ノルマンのVamをRakしない
4. クメールへのHarが止まれば、Varganのharも止まる

ゆえにVargan側の終戦条件は、**ノルマンによるクメールへの軍事行動が停止すること**であり、ノルマンがVarganに降伏する必要すらない。

## 中央政治への影響

Vargan中央政府には、[台頭する地方総督（Gakanar）](../地理/ナムガ.md)を軍事力で圧倒できるほどの巨大な中央軍が存在しない。ゆえにVarganが六居住地をまとめていられるのは軍事力による服従ではなく、Organの歴史的権威、Kanrin、共通の神話、Daran、都市間経済、Kes、「Vargarである」という共通意識による。[分権化する寡頭制](分権化する寡頭制.md)の中で、遠征を率いたGakanarやHarnavkanarが得る高いLorは、中央にとって危険にも映る――大臣より人気のある地方軍人が、政治家として台頭していく可能性を孕んでいる。

## 位置づけ

Vargan外交の歴史を並べると、その成熟がよくわかる。

```
前1800年頃 ― 友同士が戦ったら中立を選ぶ（Dulenの発見）
   ↓
前1040年頃 ― 同盟を休止して友好を維持する（Dulenの定着）
   ↓
前840年頃 ― 有効な同盟から要請を受ければ、目的を限定して参戦する（エルヴェクハルの成立）
   ↓
前600年頃 ― 要請を待たず、こちらから共同事業をSamしようと提案する（クメールとの共同事業）
   ↓
西暦500年頃 ― 同盟国を助けることと戦争に参加することを切り離す（非参戦原則の確立）
```

DulenだけをよりどころとしてきたVargan外交は、DulenとDarharkesを状況に応じて使い分ける外交へと成熟した。**クメールには積極的にDarする。ノルマンのHarには積極的にVekする。しかしノルマンそのものをRakしない。**Varganにとって軍事力は、世界を自らの意思に従わせる力ではなく、**Daran・Kes・Vamを壊されないための最後の手段**であり続ける。この240年後、[クメールとの共同事業](クメールとの共同事業.md)によって、Varganの外交はさらに「受動的協調主義」から「能動的協調主義」へと歩を進めることになる。
