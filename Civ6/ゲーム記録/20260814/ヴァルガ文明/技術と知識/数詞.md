# 数詞

[測量](測量.md)が発達する紀元前3000年頃、ヴァルガ語の数詞は「数える言葉」から**計算・測定に使える体系**へと発達する。数そのものは紀元前3000年に突然生まれたのではなく、狩猟・人口・備蓄・交易の時点ですでに存在していたと考えられる。

## 五進的な語源を持つ十進法

ヴァルガ人は身体（片手の指＝5、両手＝10）を基礎に数を数えた。1〜5が最古の独立数詞で、6〜10は「5＋◯」から発達する。ただし後の数学的な扱いやすさを考え、体系そのものは**五進的な語源を持つ十進法**とする。

| 数 | 語 | 成り立ち |
| --- | --- | --- |
| 1 | **Ek** | 語根 |
| 2 | **Du** | 語根 |
| 3 | **Ter** | 語根 |
| 4 | **Fer** | 語根 |
| 5 | **Pan** | 語根（「一つの手にある数」の意とも） |
| 6 | **Parek** | par〔5を超えて〕＋ek |
| 7 | **Pardu** | par＋du |
| 8 | **Parter** | par＋ter |
| 9 | **Parfer** | par＋fer |
| 10 | **Von** | 語根 |
| 11〜15 | Vonek・Vondu・Vonter・Vonfer・Vonpan | von＋一の位 |
| 20 | **Duvon** | du＋von |
| 30 | **Tervon** | ter＋von |
| 40 | **Fervon** | fer＋von |
| 50 | **Panvon** | pan＋von |
| 100 | **Sat** | 語根。備蓄・交易が発達するまで一般人にはほぼ不要だった語 |
| 1000 | **Mil** | 語根。紀元前3000年頃はまだ「非常に大きな数」という語感が強く、行政・軍事・大規模交易の専門語 |

### 数え方の例

* 23 → Duvon-ter → **Duvonter**
* 47 → Fervon-pardu → **Fervonpardu**
* 125 → Sat-duvon-pan → **Satduvonpan**

## 0はまだ存在しない

歴史的な面白さとして、紀元前3000年時点では**独立した0を持たせない**。ヴァルガ人には「何もない」という概念（**Nol＝ない、無い**）はあるが、それを数そのものとして数列に含める発想はまだない。後世、数学が高度化したとき、Nolが数体系に組み込まれ0となる、という言語史・数学史をたどる。

## 序数・回数

* **-ir（～番目）** … Ekir（第一）、Duir（第二）。軍団・測量・行政で便利（例：*Duir Harket*＝第二部隊）
* **-do（～回）** … Ekdo（一回）、Terdo（三回）。測量では「同じ場所を複数回測って一致するか確認する」習慣が生まれうる

## 数量を表す文法

古ヴァルガ語では**数詞＋名詞**が基本で、名詞を複数形にする必要がない（数詞があれば複数と分かるため）。

* **Ter Kar** … 三人の戦士
* **Pardu Urvak** … 七人の投石兵
* **Duvon Elsetar** … 二十人の開拓者
* **Sat Vakar** … 百個の投石器

正確な数を示さない場合は量の形容語を使う。

* **Mek（多い）／Tik（少ない）** … Mek Kar（多くの戦士）、Tik Sil（少量の銀）
* **Som（すべて）／Pir（一部）** … Som Kar（すべての戦士）、Pir Rinar（一部の評議員）

## 数詞と測量 ― 抽象的な量へ

以前の数詞は「毛皮三枚（Ter Pel）」のような**具体物の数量**しか表さなかった。しかし[測量（Gametan）](測量.md)が発達すると、**Ter Mettem（三単位）**のように、数詞が**物ではなく抽象的な量**を表現するようになる。測量士（Gametar）が測り縄（Metfen）を伸ばし「Panvondu Mettem（52単位）」と記録する――これは数学史上の大きな転換である。

## 記録の萌芽

数詞を話すだけでなく、**数の記号**も生まれ始める。単純な刻み目（｜＝1）から、5でまとめる別記号、10・100の専用記号へ発展しうる。これは交易品の数量・備蓄（Tal）・銀（Sil）の産出量・軍勢の人数・測量（Gametan）の結果を記録するためであり、**ヴァルガの文字文化は「文章を書くため」ではなく「数を忘れないため」に始まった**、という筋道が描ける。

## 歴史的な流れ

```
前4000年頃：指を中心とした小さな数。獲物・人数・備蓄を数える
   ↓
前3600年頃：交易の発達によって数量比較が重要になる
   ↓
前3340年頃：シルガ成立。銀などの資源量を数える必要が増える
   ↓
前3100年頃：軍団組織の成立によって数十〜数百人規模の数量管理が必要になる
   ↓
前3000年頃：測量（Gametan）の発達。数詞が「物がいくつあるか」から
           「世界の大きさを数字で表現する言葉」へ変わり始める
```

この変化は、後の幾何学・暦・建築・地図・会計の発展へとつながる、ヴァルガ数学の始まりとして位置づけられる。
