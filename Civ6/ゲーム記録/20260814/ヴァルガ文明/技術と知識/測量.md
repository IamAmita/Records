# 測量

紀元前3000年頃、ヴァルガ社会に**測量（Gametan）**の技術が発達する。突然「発明」されたのではなく、[入植](../地理/シルガ.md)・銀採掘・交易・軍事・領域統治が積み重なった結果、距離や土地を正確に測る必要が生じた結果である。

## 測量以前

紀元前4000年頃のヴァルガ人は、「歩いて半日ほど」「大きな岩から海まで」「三人が横になれる長さ」のような**身体・時間・地形を基準とした相対的な測定**で生活していた。一つの集落周辺で暮らす限り、これで問題はなかった。

## 発達を促した四つの要因

* **入植（Elsetan）と新しい土地** … [シルガ](../地理/シルガ.md)のような遠方の集落が生まれると、「どこまでが新しい集落の土地か」を決める必要が生じ、既存の境界概念**Gor**が「二点を結んだ線」として記録されるようになった
* **シルガの銀** … 銀鉱床（Silganur）の位置・採掘の深さと方向を把握する必要から、**鉱山測量**が発達した
* **交易路（Elberan）** … Vargaとシルガの間の道程を比較する必要から、**道（Ran）を測る**発想が生まれた
* **軍事（[Harkarkanar](../政治と軍事/軍事と同盟.md)）** … 敵までの距離、投石兵の射程、丘の高さ、軍団の移動距離など、軍事上の距離把握が測量を後押しした

## 中心語彙

* **Met（測る）／Metan（測定）** … 既知の大きさを基準に、未知のものの大きさを知る行為
* **Gamet（土地を測る、測量する）／Gametan（測量）／Gametar（測量士）** … 「土地を測る者」。最初のGametarはElgan・鉱山管理者・建設担当者・評議会に仕える役人の中から専門化した
* **Nel（長さ、距離）／Rannel（道程）**
* **Hak（高さ）／Gul（深さ）** … 山・丘・鉱山の多いシルガで特に発達
* **Ved（向き、方角）** … 助詞 *ra*（～の方向へ）と違い、地理的な方角そのもの。当初は「日の出側」「海側」のようなランドマーク基準で、後世の固定方位へ変化していく
* **Fen（縄、紐）／Metfen（測り縄）** … 一定間隔に印をつけた縄。二人で張って数え、個人差のある歩幅の問題を解消した
* **Tem（基準、尺度）／Mettem（測定基準、単位）** … 「誰が測っても同じ結果になる」という発想
* **Vun（広がる）／Vunan（広がり）／Gavun（面積）** … まだ「測り縄何本×何本」という実務的な面積概念で、数学的な平方単位ではない

## 記録の萌芽

測量士個人の記憶に頼っていては情報が失われるため、木片・骨・石板に「SilgaからVargaまでMetfenが◯◯本」のような**数詞＋地形記号＋距離**を刻む原始的な記録体系が生まれ得る。すなわち**交易の会計と測量記録が、文字の発達を促した**という筋が描ける。

## 位置づけ

測量は、「あの丘までは遠い」という感覚的な把握から、「あの丘まではMetfenで何単位ある」という**客観的な測定**への移行である。後の地図・建築・鉱山技術・幾何学・度量衡・行政・徴税・土地所有・天文観測へ枝分かれしていく技術革命として位置づけられる。
