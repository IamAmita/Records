# ヴァルガ年表

紀元前4000年〜3000年のヴァルガ文明の主な出来事。

| 年代 | 出来事 |
| --- | --- |
| 前4000年頃 | ヴァルガ人がツンドラの地「ヴァルガ（白き大地）」に居住。狩猟・漁労・採集の半定住生活 |
| 前4000年頃 | [オルガン王](オルガン王.md)が複数のヴァルガ氏族を初めて統合 |
| 前4000年頃 | 〔文化基層〕互恵思想「[ダラン](../社会と文化/互恵思想ダラン.md)」が形成される |
| 前3700年頃 | 人口増加・集落の大型化。氏族間の衝突が増加 |
| 前3700年頃 | 戦争概念「ハラン」が定着。投石器「ヴァカル」と投石兵「ウルヴァク」が登場し兵科が分化 |
| 前3700年頃 | 陣形「カルガラン」・指揮官「カナル」・軍需備蓄「ウルタル」が成立 |
| 前3700年頃 | 加工技術「テク」と職人「ガルテク」が発達。石器・骨角器・複合道具が普及し技術が専門分化 |
| 前3600年頃 | セラン人と交易開始。交易「ベラン」・価値「ヴァル」・所有「メルガル」の概念、威信財「シルセル」 |
| 前3600年頃 | ドルガ人とカルドル産地を巡り対立。境界意識「ゴル」が成立 |
| 前3600年頃 | 「我々＝ヴァルガ人（ヴァム）」という民族意識が芽生える |
| 前3500年頃 | 遠方の広域勢力「アシュラ」と初接触＝「世界の発見」 |
| 前3500年頃 | 支配「ラゴル」・大勢力「メクラゴル」など政治概念が流入 |
| 前3500年頃 | アシュラと友好関係「レナン」を結び贈答外交を開始。使節「エルカナル」・長距離交易「エルベラン」 |
| 前3400年頃 | 最初の開拓者「エルセタル」が登場。「我らの土地（ヴァムガ）」思想と計画的移住が始まる |
| 前3340年頃 | 第二の土地「[シルガ](../地理/シルガ.md)（銀の地）」を建設。銀採掘「シルダク」が始まる |
| 前3340年頃 | 専門的な神官「サイルカナル」が登場。信仰が「[宗教制度](../社会と文化/信仰と神官.md)」へ向かう |
| 前3100年頃 | 軍団司令官「ハルカルカナル」が登場。指揮の専門化 |
| 前3100年頃 | 評議会「カンリン」による[寡頭制](../政治と軍事/寡頭制カンリン.md)が完成 |
| 前3000年頃 | 遠方の軍事共同体と初の[軍事同盟「ダルハラン」](../政治と軍事/軍事と同盟.md)を締結 |
| 前3000年頃 | 入植・銀採掘・交易・軍事・領域統治の蓄積から[測量](../技術と知識/測量.md)「ガメタン」が発達。客観的な測定と記録・文字の萌芽が生まれる |
| 前3000年頃 | 五進的な語源を持つ十進の[数詞](../技術と知識/数詞.md)体系が確立。数が「物の量」から「抽象的な量」へ変わり始める |
| 前2540年頃 | 川沿いの丘に[空中庭園ハクベルガ](../技術と知識/空中庭園.md)が完成。揚水・造園技術と、専門家の協働（センサム）による建設 |
| 前2500年頃 | 「Senを持つ者が統治すべき」という[賢人統治](../政治と軍事/賢人統治.md)の思想が成立。賢人（セナル）が政治に加わり始める |
| 前2500年頃 | 前3600年頃から続く近隣勢力との抗争に決着（[大いなる駆逐](../政治と軍事/大いなる駆逐.md)）。民族名「ヴァルガル」・連帯「ヴァマン」の意識が強まる |
| 前2500年頃 | 大型櫂走船[ラルナヴ](../技術と知識/航海とガレー船.md)が登場。海路が開け、Ralnavが軍船（ハルナヴ）にも転用される |
| 前2500年頃 | 戦争経験が[ヴァルガ神話](../社会と文化/ヴァルガ神話.md)を書き換える。戦神ハルサイルの確立、「敵とは行為の名」という教義、Organが「戦いを終わらせる者」として再解釈される |
| 前2500年頃 | 遠方の友好部族から[移住者](../社会と文化/移住者とヴァルガ人.md)（ダルガナル）を受け入れる。「Vargarとは血かVamanか」という論争が始まり、異邦の神々もサイルリンへ組み込まれていく |
| 前2400年頃 | ヴァルガ初の[兵舎ハルガル](../政治と軍事/常備軍と兵舎.md)が建設される。常備戦士（セトカル）が生まれ、軍事力が恒常的な制度へ移行。「軍はVamのもの」という軍政原則が確立 |
| 前2200年頃 | 三河川の河口に第三都市[サマルガ](../地理/サマルガ.md)を建設。金（ゼル）・翡翠（ズル）・稲作（ファルベル）の産地となり、Varga／Vargan／Vargarの三層構造が生まれる |
| 前2200年頃 | [三都市の産物が結びついた生活文化](../社会と文化/三都市の暮らし.md)が花開く。ダランが理念から経済構造そのものへ発展し、「一つのGaだけではVamは栄えない」という思想が定着する |
| 前2000年頃 | Varga中心部に外交儀礼の国家的建造物[万国の門（ソムネクタヴ）](../技術と知識/万国の門.md)が建てられる。三都市の産物を集めて建造され、「Lenには開き、Harnekには閉ざす」という外交思想を可視化する |
| 前1900年頃 | 乾燥地・草原・森林・海が接する境界に第四都市[ムンガ（通称アジュガ）](../地理/ムンガ.md)を建設。果実・酒・真珠・ルビー・金を産し、「生存する共同体」から「豊かさを共有する文明」への転換を象徴する |
| 前1900年頃 | [サマルガ](../地理/サマルガ.md)近郊で象牙（イヴ）の交易・加工が発達。象牙細工師（イヴテカル）が成立し、金・翡翠・絹と並ぶ高級工芸素材として、サマルガが職人の都市としての性格を強める |
| 前1800年頃 | 友好国同士の戦争を機に、[積極的中立「ドゥレン」](../政治と軍事/中立外交ドゥレン.md)の外交原則が成立。Lentavは双方の使節に開かれたまま維持され、調停者（レンサマル）が生まれる |
| 前1500年頃 | Varga港湾部に国家的記念物[「TorOrgan」の巨像](../技術と知識/TorOrgan像.md)が建立。四都市の資材で造られ、武器を下ろした姿でDaranとDulenの思想を象徴する |
| 前1500年頃 | [槍兵（サッカル）・弓兵（ヤムカル）](../政治と軍事/兵種の確立.md)が専門兵種として成立し、Vargan軍が複合兵種軍へ発展する |
| 前1500年頃 | 多数の漕ぎ手を組織的に運用する[大型軍船「フェルハルナヴ」](../技術と知識/航海とガレー船.md)が登場。Marranの軍事的維持が可能になり、Dulenを海上でも支える力となる |
| 前1300年頃 | [シルガに大神託所（トルサイルゼドガ）](../社会と文化/大神託所.md)が完成。神託の専門化・制度化が進み、Silgaが宗教的権威の都市としての性格を強める |
| 前1300年頃 | Varga北方の火山島に第五居住地[「ナルガ」](../地理/ナルガ.md)を建設。Vargan史上初めて海で隔てられた土地への恒久入植が実現する |
| 前1300年頃 | [前1800年のDulenが500年をかけて受け入れられ、既知の近隣文明すべてがVarganの同盟国となる（全同盟の成立）](../政治と軍事/中立外交ドゥレン.md) |
| 前1200年頃 | [高度に分業化した社会が職能を「ケヴ（役割）」として制度化し、身分秩序ケヴリンが成立する](../政治と軍事/身分秩序ケヴリン.md)。RitanとSedanが社会秩序を可視化する作法（セドラン）へ拡張する |
| 前1100年頃 | [完成した政治制度が形骸化し始める](制度の形骸化と探検時代の予兆.md)。大臣は名目的な存在（ネムケヴ）となり、実務官が事実上の政策決定者となる。Nargaや航海の現場で実務知識（ケヴセン）が重視され、探検時代の予兆が現れる |
| 前1060年頃 | [Varga大競技場「トルハリン」](../技術と知識/大競技場トルハリン.md)が完成。軍事競技・宗教祭典・公開儀礼を通じ、巨大化したVargan社会そのものを演出する装置となる |
| 前1040年頃 | [同盟国同士の戦争に対し、確立済みのDulen原則が迷わず再適用される](../政治と軍事/中立外交ドゥレン.md)（Dulenの定着）。軍事同盟の一時休止（ダルハルリス）という区別が定着する |
| 前1040年頃 | [LorとKellor（名誉）が社会秩序の中心的価値へ上昇する](../政治と軍事/身分秩序ケヴリン.md)。Kevrinごとの職業倫理として機能する一方、「家柄の名誉」と「本人の功績」との緊張が芽生える |
| 前1000年頃 | [Mungaへ敵対艦隊が来襲（ラクハル）](ムンガ襲来と古代秩序の終焉.md)。Dulenが前提としてきた安定した同盟網が崩れ始め、都市国家（ガダラゴル）が乱立する時代に入る。古代Vargan国際秩序の終わりとされる |
| 前930年頃 | [巨大な湖畔に第六居住地「ナムガ」を建設](../地理/ナムガ.md)。翡翠・金・真珠・象牙・綿・亜麻を産し、西方アッバース文明圏との国境都市となる。野心的な総督（ガカナル）の台頭が中央のKevrin秩序を揺るがし始める |
| 前900年頃 | [Silgaに大図書館「トルセンカドガ」](../技術と知識/シルガ大図書館.md)が完成。測量・航海・交易・神託の記録が集積され、探検を個人の冒険から文明的事業へ変える装置となる |
| 前900年頃 | [Samargaに巨大陪葬軍団「トリドハルカル」](../地理/サマルガ.md)が完成。死後も続く「変化しないVam」を地下に固定しようとする、地方総督の権威を象徴する事業 |
| 前900年頃 | [ナムガにVargan文明初の本格的な防壁「ゴルヴェク」](../地理/ナムガ.md)が築かれる。「外交の時代」から「境界の時代」への転換を象徴する |
| 前840年頃 | [Vargaに巨大祭祀ピラミッド「トルテクコル」](../技術と知識/太陽の人工山トルテクコル.md)が完成。「六つのGaは一つのVam」という宗教的統合を、弱まる中央求心力に対して示す |
| 前840年頃 | [中央のOrgan・Kanrinと地方総督ガカナルの間に多層的な統治構造が生まれる](../政治と軍事/分権化する寡頭制.md)。「分権化する寡頭制」への移行が始まる |
| 前840年頃 | [同盟国クメールをノルマンから守る限定戦争「エルヴェクハル」](../政治と軍事/クメール支援戦争エルヴェクハル.md)に参戦。「Lenを守る」目的に限定し、敵を求めない参戦というVargan独自の戦争思想が確立する |
| 前760年頃 | [シルガ大図書館の記録文化から「ヴァルガン文学」が成立する](../社会と文化/ヴァルガン文学の成立.md)。口承神話が文学として編纂され、Rakonを扱う大叙事詩トルゾムが生まれる |
| 前720年頃 | [Vargaで独立貴族「ガロラル」が出現する](../政治と軍事/独立貴族ガロラル.md)。官職ではなく土地・財産・家の名誉(Kellor)を基盤に政治的に自立する存在で、名家(ロルダム)の世襲的権威化と文学による正統性の物語化が背景にある |
| 前600年頃 | [文明圏西北端に第七居住地「アシュガ」が建設される](../地理/アシュガ.md)。山・砂漠・河川・海が接する土地に金・果樹酒・亜麻・香料を産し、西北海域交易の拠点となる。「寒冷地文明Vargan」という自己認識が覆り、複数の気候帯を包含する広域文明圏への転換点となる |
| 前600年頃 | [硬貨(ヴィクベル)がBerarや政府に限られた道具から庶民の日常取引まで浸透する](../政治と軍事/貨幣の大衆化.md)。給金による都市労働者の成立、地代・税の貨幣化、土地基盤のGalorarと貨幣基盤のBerarの序列問題が生まれる |
| 前600年頃 | [Vargan自身がクメールへ共同研究・共同祭典を持ちかける「働きかける外交」へ転換する](../政治と軍事/クメールとの共同事業.md)。前840年のクメール支援戦争で築かれた信頼を土台に、「求められるのを待たずこちらからSamを提案する」という外交思想が成立する |
| 前530年頃 | [Samargaに巨大寺院複合体「サイルサムガ」が完成する](../社会と文化/サイルサムガ.md)。一柱の神ではなくDarsair全体を祀り、Ragonを描く回廊浮彫を持つ、多神教的宇宙観とDaran思想を石造建築で表現した大神殿 |
| 前500年頃 | [Samarga遷都論が提起されるがVargaの正統性から完全遷都はされず、政治機能が分散する「多中心化」で決着する](多中心化するヴァルガン.md)。Varga(古都・王権)・Silga(知識・宗教)・Samarga(経済・文化)という三大中心が形成され、古代制度を残したまま探検時代へ移行する |
| 前500年頃 | [政治実務がSamargaへ移り、即位儀礼と王権の正統性のみVargaに残る「Vargan型封建君主制」が成立する](../政治と軍事/封建君主制への移行.md)。Organ・Kanrin・Gakanar・Galorar・Berar・Sairkanarそれぞれが役割を持つ体制で、実態としては強い金権政治的性格を伴う |
| 前500年頃 | [アシュガより西北、クメールとの境界の丘陵に第八居住地「ルヴァン」を建設する](../地理/ルヴァン.md)。要塞ではなく交流都市として発達し、ルビー・茶・ラクダを産する。ラクダによる砂漠交易とオアシス網、「茶を共に飲む」という新しい作法が生まれる |
| 西暦435年頃 | [国境都市Ruvanで組織宗教が創始される](../社会と文化/新宗教の成立.md)。中心教義は「この世界に糧を」。DaranとDarsair信仰を普遍的倫理へ再解釈し、隊商文化から生まれた使徒が民族・身分・国境を越えて糧を届ける、Vargan史上初の普遍宗教が成立する |
| 西暦465年頃 | [OrganがSamargaに留まらず地方を巡行する「行郊」が君主の徳目として重視され始める](../政治と軍事/行郊.md)。「Organは座す者ではなく巡る者」という神話的Organ像の再解釈で、地方監査機能と施食・寄進を伴う双方向的な巡行が定着し、多中心的Varganが制度として完成する |
| 西暦500年頃 | [「同盟国を助けること」と「同盟国の戦争に参加すること」を切り離す「非参戦原則」が確立する](../政治と軍事/非参戦原則.md)。Darharan(軍事同盟)が形骸化し、参戦しない代わりに食料・医療・仲介で同盟国を支える外交へ移行する |
| 西暦560年頃 | [三河川の河口都市Samargaを複合水害が襲い、政治首都機能が一時麻痺する](サマルガ大水害.md)。行郊による多中心統治が国家崩壊を防ぎ、新宗教の使徒による大規模救援が教義「この世界に糧を」を実地で証明する |
| 西暦560年頃 | [サマルガ大水害での救援活動を機に、布教・救済活動を国家・社会が積極的に保護する「福音主義」的方針が確立する](../政治と軍事/福音主義.md)。Ruvanが聖地として台頭し、軍事力でなく救済・知識によって形成される対外ネットワークが広がり始める |
| 西暦600年頃 | [Mungaに聖なる祖廟の最大級施設「トルナカルガ」が完成する](../地理/ムンガ.md)。「多くをDarした者」を祀るVargan的祖先祭祀で、Ruvan宗教の拡大と並行して古来の信仰も自らの伝統を再構築する宗教的多元化が進む |
| 西暦620年頃 | [土地・貨幣・生産手段を集積する経済政策「原始的蓄積」が確立する](../政治と軍事/原始的蓄積.md)。サマルガ大水害の復興需要と非参戦外交の「平和の配当」が背景にあり、給金(Kevdan)・税(Vamdar)が正式な経済用語として確定する |
| 西暦680年頃 | [古都Vargaに世界各地の動植物を集めた王立庭園が成立する](../技術と知識/王立動植物苑.md)。外国からの珍獣贈答という外交儀礼、SilgaのSenarによる自然研究施設への発展を経て、Vargaが「Varganが知った世界を集める都市」としての性格を帯びる |
| 西暦685年頃 | [Namgaに新宗教を保護した有力者を葬る巨大墓廟複合施設が完成する](../地理/ナムガ.md)。600年のMunga聖廟とは異なり、財産を基金化し死後も収益でDarし続ける宗教財団の原型が生まれる |
| 西暦710年頃 | [探検時代が成熟し、古典の再発見(ルネサンス)と世界の再発見(大航海時代)が同時に起こる](ルネサンスと大航海時代.md)。大型外洋帆船(キャラック相当)が複数建造されて真の外洋航海が現実化し、原始的蓄積の資本が造船・航海事業への出資という形で「投資」概念を完成させる |
| 西暦715年頃 | [別文明の領域を挟んだ北方に、Vargan初の飛び地「ナイラン」が成立する](../地理/ナイラン.md)。大河川を下って海へ出る物流経路によって本土と結ばれ、内陸/河川/海洋三交易圏へアクセスする最初の遠隔居住地となる |
