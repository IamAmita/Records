# ヴァルガ人

**ヴァルガ人**は、北方のツンドラの地**[ヴァルガ（白き大地）](../地理/ヴァルガ本土.md)**に暮らす人々。狩猟・漁労・採集を営む半定住社会から、交易・外交・専門化した軍事・宗教・寡頭制の政治を備えた文明へと発展した。

## 通史の流れ

ヴァルガ人の歴史は、**「一人ではOr（冬）を越えられない」**という原体験から一貫した発展として理解できる。

| 時期 | 段階 |
| --- | --- |
| 前4000年頃 | [オルガン王](オルガン王.md)による氏族統合。生存共同体の形成 |
| 前3700年頃 | 技術・軍事の専門化（投石兵ウルヴァク、職人ガルテク） |
| 前3600年頃 | ドルガ・セランとの接触。交易・所有・威信・境界・民族意識の形成 |
| 前3500年頃 | 遠方勢力アシュラとの接触＝「世界の発見」。政治・外交の語彙が成立 |
| 前3400年頃 | 開拓者エルセタルの登場。「我らの土地（Vamga）」という領土観 |
| 前3340年頃 | 第二の地[シルガ](../地理/シルガ.md)建設。神官サイルカナルの登場 |
| 前3100年頃 | 軍団司令官の成立。[寡頭制カンリン](../政治と軍事/寡頭制カンリン.md)の完成 |
| 前3000年頃 | 遠方勢力との初の[軍事同盟ダルハラン](../政治と軍事/軍事と同盟.md) |

詳細な出来事は[年表](年表.md)を参照。

## 社会の輪の広がり

ヴァルガ人にとって「仲間」の範囲は、歴史とともに広がった。

**家族 → 氏族 → 集落（Gadar）→ ヴァルガ人（Vam）→ 信頼できる異民族**

血縁や民族だけでなく、**互いに助け合えるか（[ダラン](../社会と文化/互恵思想ダラン.md)）**が仲間の判断基準になった点が、ヴァルガ人の民族観の大きな特徴である。
