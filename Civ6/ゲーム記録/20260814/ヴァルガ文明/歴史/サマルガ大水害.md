# サマルガ大水害（西暦560年頃）

西暦560年頃、政治首都[Samarga](../地理/サマルガ.md)一帯を、数日から数週間にわたる異常降雨と巨大な嵐が襲う。三つの河川が同時に増水し、河口低地を中心に広範囲が水没した――**河川氾濫・高潮・土砂災害を伴う複合水害**であり、Vargan史上それまで経験のない規模の都市災害となる。河川によって発展してきたSamargaにとって、その河川そのものが最大の脅威に転じた出来事である。

## 被害の様相

河口・低地の住宅地の浸水、水田・農地の冠水、河川港と船着場の破壊、橋梁の流失、倉庫に蓄えられた食料・商品の水没、絹などの商品作物への被害、家畜の大量死、上流からの流木・土砂の流入、飲料水の汚染、そして災害後の深刻な食料不足――Samargaが完全に壊滅したわけではないが、文明が経験したことのない規模の都市災害として記憶される。

## 首都機能の麻痺

[前500年頃から政治首都であるSamarga](../歴史/多中心化するヴァルガン.md)には、行政機関、Organの宮廷、文書、財政機構、中央市場が集積していた。そのためこの災害は「一都市の水害」では済まず、**Vargan全土の政治機能が一時的に麻痺する**事態となる。ここで、約1000年前のSamarga遷都が抱えていた弱点――多中心的な文明でありながら政治機能だけはSamargaに集中しすぎていたのではないか――が、初めて大々的に露呈することになる。

## 行郊が国家を救う

歴史のつながりとして重要なのは、[西暦465年頃から発達していた「行郊」](../政治と軍事/行郊.md)が、この時点ですでに100年近く実践されていたことである。「政治はSamargaの宮廷でのみ行われる」という発想は、行郊の定着によってすでに崩れ始めていた。Organが地方で政務を行った前例があり、地方統治者との連絡網も機能していたため、Samargaが機能不全に陥っても、Varga・Silga・Ruvanなどへ政治機能を一時的に移すことができる。

結果として、**Samargaは大きな被害を受けたが、Vargan国家そのものは崩壊しなかった**。後世には、「行郊の制度がVarganを救った」と評価されることになる。

## 新宗教が試される ― 最初の大規模救援

[西暦435年頃にRuvanで成立した新宗教](../社会と文化/新宗教の成立.md)にとって、この災害はおよそ125年目にして初めての巨大な実践機会になる。中心教義「この世界に糧を」を体現する使徒たちが各地から集まり、食料を運び、水を配り、避難民を収容し、遺体を葬り、孤児を保護し、病人を看護し、破壊された家屋の再建を手伝う。彼らは説教より先に**糧を運ぶ**。

災害以前、この宗教は「Ruvanで生まれた新しい信仰」程度の認識だったかもしれない。しかしSamargaが壊滅的被害を受けたとき、宗教共同体が民族・身分を問わず救援する姿を、首都の住民が初めて目の当たりにする。抽象的だった教義が実地で証明されたことで、560年代以降、信徒が急増していく。

### 神学的な問い ― なぜ天は嵐を起こしたのか

天の啓示を信仰するこの宗教にとって、「なぜ天はSamargaにこれほどの災害をもたらしたのか」という問いは避けられない。「人々が堕落したから天罰が下った」という単純な解釈は、「この世界に糧を」という教義とは相容れない。むしろこの宗教が採る立場は、

> 天の意図を人は完全には知り得ない。しかし、苦しむ者が存在するとき、人が何をすべきかは啓示によってすでに示されている。

というものである。**なぜ災害が起きたかは分からない。しかし災害が起きたとき何をすべきかは分かっている――糧を与えよ。**という姿勢が、この宗教の性格をいっそう鮮明にする。

### 旧来のSair信仰の解釈

一方、従来のSair信仰では、河川・雨・嵐を司るSairとの関係から災害が説明される。神官は祭祀に問題がなかったかを問い、あるいは自然のSairが人間へ警告を与えたと解釈する。旧来の祭祀が「なぜ災害が起きたのか」を神々との関係から理解しようとするのに対し、新宗教は「災害を受けた人間に何をすべきか」を啓示から導く――両者は必ずしも敵対せず、神官が祭祀を行い、使徒が救援活動を行う光景が同時に存在してもよい。

## DaranとVamを越えた慈愛の違い

[Daran（相互扶助）](../社会と文化/互恵思想ダラン.md)もまた、この災害で改めて機能する。Vargaから銀や木材、Silgaから塩、他都市から食料、アシュガやRuvanから隊商物資が届けられる――文明圏全体からの支援である。ここで、古来のDaranと新宗教の違いが可視化される。

* **Daran** … Samargaは我々の都市だから助ける
* **使徒** … 誰であろうと苦しんでいるなら助ける

この災害を経験したことで、一般のVargarにも新宗教の普遍性が初めて実感を伴って理解され始める。

## 復興と治水思想の発展

560年代から数十年にわたるSamarga再建を通じ、堤防・放水路・排水路・貯水池・河川改修・高床倉庫・避難場所・洪水時用備蓄といった大規模治水・防災インフラが整備されていく。三河川の河口都市では「水を防ぐ」だけでは不十分であり、「どこへ水を逃がすか」という治水思想が発達する。これはVarganのSen・測量・建築技術を一気に進歩させる契機にもなる。

この巨大な復興需要は、[西暦620年頃に確立する経済政策「原始的蓄積」](../政治と軍事/原始的蓄積.md)の直接の背景にもなる。個々のDomや小規模共同体が資材を分散して持つだけでは大規模な治水事業は実現できず、「余剰を一度集め、大規模事業へ投じる」という発想がここから育っていく。

## 「備えあれば憂いなし」の再解釈

[前500年の探検時代開始時にVarganが選び直した価値観](../歴史/多中心化するヴァルガン.md)である「備えあれば憂いなし」は、1000年以上を経たこの社会に「我々は本当に備えていたのか」という強烈な問いを突きつける。古代Vargaでは冬に備えてOrtalを蓄えたが、巨大都市Samargaでは、洪水への備蓄・都市排水・避難経路・食料の分散備蓄・政治機能の分散までもが必要になる。古代の「冬への備え」が、ここで**国家的な防災思想**へと発展する。

## Organの新しい義務

行郊を重視する時代のOrganにとって、災害後に現地へ赴くことはほぼ政治的義務になる。宮殿の安全な場所に留まって指示するだけでは「Humを見ないOrgan」と批判される。Organが被災地区を自ら巡り、被災者と会い、備蓄を放出し、地方からの支援を指揮し、使徒やSairkanarとも会い、復興計画を承認する――ここに「災害時にOrganが何をすべきか」という君主の新しい義務が成立する。

## 後世から見た560年

この出来事は「Samarga大嵐」という単純な災害史にとどまらず、複数の歴史的意味を持つ。

| 分野 | 意味 |
| --- | --- |
| 政治史 | 行郊・多中心統治の有効性が証明された事件 |
| 宗教史 | Ruvan発祥の新宗教が大規模救援を通じてVargan中枢へ浸透した事件 |
| 思想史 | Daranと「この世界に糧を」の違いが社会に認識された事件 |
| 技術史 | 大規模治水・都市防災の発展を促した事件 |
| 都市史 | Samargaの都市構造そのものを作り変えた事件 |

## 位置づけ

435年に「この世界に糧を」と説かれ、465年には為政者が人々のもとへ自ら赴くようになり、560年には**その思想が巨大災害という現実によって試された**。「なぜ天は嵐を起こしたのか」ではなく「嵐の中で人は何をするのか」を問うこの宗教のあり方が、災害を通じてVargan社会全体に鮮明に刻まれた出来事として位置づけられる。この経験は、同時期に国家・社会が布教と救済活動を積極的に保護する[「福音主義」](../政治と軍事/福音主義.md)へと直接つながっていく。

375年後の[西暦935年頃、Samargaは再び同規模の豪雨に見舞われる](サマルガの治水事業.md)。560年当時「経験」でしかなかったこの災害は、935年には**比較対象となる過去のKad**として扱われ、宗教的・倫理的解釈が中心だった560年の災害理解は、「なぜ豪雨が起きたのか」をSenしようとする935年の実証的な災害理解へと変わっていく。
