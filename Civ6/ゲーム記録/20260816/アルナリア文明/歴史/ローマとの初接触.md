# ローマとの初接触

**紀元前510年頃**、[サラシュ石林の発見](../地理/サラシュ石林.md)の直後、エジプト系居住地をさらに越えた北方で、後に世界最大級の国家の一つとなる**ローマ**と接触した。史実の年代に合わせるなら、伝承上ローマが王政から共和政へ移行したとされる紀元前509年の直前・直後にあたり、アルナリアが出会ったのは「ローマ帝国」ではなく**政治変動の真っただ中にある若いローマ**である。

## エジプトとは異なる印象

[エジプトとの初接触](エジプトとの初接触.md)がもたらしたのは、何千年もの歴史・文字・官僚・神殿を備えた圧倒的な文明格差の実感だった。一方ローマは、アルナリアから見ても「強そうではあるが、エジプトほど圧倒的ではない」と感じられる相手であり、定住開始（前1200年頃）から700年近くを経て評議会・戦士団・神官制度・海上交易を備えるに至ったアルナリアにとって、初めて**「我々と同じ時代を生きている文明」**という感覚を抱かせる存在になった。

## 政治制度の類似という驚き

アルナリアの[寡頭制](../政治と軍事/寡頭制とナムリア盟約.md)（五家・アル・ラーナ・評議会による合議）と、ちょうどこの頃に元老院・貴族層・複数の政務担当者による合議へ移行しつつあるローマの共和政は、制度の細部は異なっても「王一人がすべてを決めるわけではない」という点で相互に理解可能なものだった。ラーナ人は「王を追放した」というローマの政治変動に驚く一方、アルナリアでアル・ラーナという地位そのものを廃止する発想はまだ生まれていない。

後世から見れば、両文明がほぼ同時期に**血縁共同体から公的社会への移行**を独自に経験していたことは、象徴的な符合として語られる。

## ローマ側からの認識とルビー交易

ラーナ人は熱帯特有の服装・装飾・米食文化・独自の陶器・遠洋航海を持つ存在として珍しがられ、当初は国家としてのアルナリアよりも**珍しい南方交易品を持ってくる商人**として認識される可能性が高い。良質なルビーは金や鉄と違って珍重され、「ラーナの赤石」のような呼び名でローマ上流層に知られるようになる。**ナムリア → エジプト圏 → ローマ圏**という長距離交易路の萌芽がここに生まれる。

## 外交構造の全体像

| 勢力 | 関係 |
| --- | --- |
| シー・テープ | 友好 |
| エジプト | 友好・文化交流 |
| ローマ | 友好 |
| セレウキア | 敵対的 |
| アクモニア | 敵対・襲撃経験あり |
| チャン・チャン | 敵対的 |

近隣の小勢力とは領土・交易圏を巡る摩擦があり、遠方の主要文明とは友好関係にあるという構図は、**近隣国とは利害が衝突するが、遠方の大文明とは交易利益の方が大きい**という国際政治の力学として一貫している。

## 世界観のさらなる拡大

シー・テープで東方世界を、エジプトで北方世界を知ったアルナリアは、ローマとの遭遇によって「エジプトの向こうにも世界が続いている」ことを知る。ナムリアと周辺の森・海に限られていた世界観は、この時点でさらに一段広がっている。

## 習合思想の加速

ローマの天空神・戦神・炉の神・農耕神・海神は、[太陽神アーラ](../社会と文化/太陽神アーラとパンテオン.md)を中心とするアルナリアのパンテオンと類似の役割を持つ。エジプト・シー・テープ・ローマといった系統の異なる文明がいずれも似た神格を持つという発見は、神官たちの間に**「神々は同じで、人間が異なる名前で呼んでいるだけではないか」**という発想を強め、今後の焦点である**習合**の土壌をさらに厚くしている。

## 位置づけ

エジプトとの初接触が「若い文明が古い文明と出会った日」であるのに対し、ローマとの初接触は**「後に大国となる二つの若い文明が初めて互いを認識した日」**として対比される。誰もまだ、自分たちがどのような存在になるかを知らない時点での出会いとして、後世のアルナリア史で象徴的に語られる。→ [年表](年表.md)
