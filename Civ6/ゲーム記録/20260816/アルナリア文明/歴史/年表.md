# アルナリア年表

紀元前1600年頃〜前475年頃のアルナリア文明の主な出来事。

| 年代 | 出来事 |
| --- | --- |
| 前1600年頃 | 沿岸漁撈民の集団が、[ナムリア](../地理/ナムリア.md)となる河口を季節的に利用し始める |
| 前1500年頃 | 毎年利用される野営地として定着。舟の引き上げ場、魚の加工場所などが決まってくる |
| 前1400年頃 | 貝塚・墓地・半恒久的な小屋が成立。「帰ってくる場所」としての記憶が土地に蓄積し始める |
| 前1300年頃 | 外部の農耕民との接触を経て、初歩的な稲作が始まる |
| **前1200年頃** | **年間を通じて居住する家族が多数派になる。[ラーナ人](ラーナ人.md)の恒常的定住集落として、ナムリアが成立** |
| 前1100年頃 | 水田・穀物倉・共同墓地が成立 |
| 前1050〜950年頃 | 家族・氏族単位の合議から、富を再分配できる個人へ権力が集中し始める（首長制の萌芽） |
| 前1020年頃 | ナムリアに最初の首長制が成立（ゲーム上の政策採用年としての便宜的な年代） → [寡頭制とナムリア盟約](../政治と軍事/寡頭制とナムリア盟約.md) |
| 前1000年頃 | 「我々は何者か」という問いから、建国神話「アルナリアの起源」が口承として形成される（氏族ごとに細部の異なる複数の伝承として） → [ラーナ人](ラーナ人.md) |
| 前900年頃 | 上流（カルダ山地）との交易網が成立 |
| **前850年頃** | **ナムリア盟約成立。有力氏族「ナムリア五家」による寡頭制へ移行** → [寡頭制とナムリア盟約](../政治と軍事/寡頭制とナムリア盟約.md) |
| 前820年頃 | 「アルの宴」に代表される名望政治が発達 → [名望政治とアルの宴](../社会と文化/名望政治とアルの宴.md) |
| 前800年頃 | 専門職人が増加し、職人街「カルム」が形成される → [専門職人とカルム](../社会と文化/専門職人とカルム.md) |
| 前780年頃 | ナムリア独自の工芸様式（波文・稲穂文・赤石文・三重螺旋）が成立 |
| **前770年頃** | **アル・ラーナ直属の戦士団（約48人）が成立** → [戦士団の成立](../政治と軍事/戦士団の成立.md) |
| **前750年頃** | **ナムリア窯業成立。専門陶工が窯を用いた高品質な陶器を量産するようになる** → [窯業と帆走術](../技術と知識/窯業と帆走術.md) |
| 前730年頃 | [アマルの塚](../社会と文化/アマルの塚.md)発見。冬至の日に光が差し込む由来不明の遺構が、アルナリア宗教に「天の秩序」の観念をもたらす |
| **前720年頃** | **ナムリア大穀倉建設。ナムリア五家の共同管理による再分配の中心地が生まれる** → [ナムリア大穀倉](../技術と知識/ナムリア大穀倉.md) |
| **前700年頃** | **帆走技術が確立。帆を備えた舟が交通・漁業・交易の実用手段として定着する** → [窯業と帆走術](../技術と知識/窯業と帆走術.md) |
| **前680年頃** | **「アルナリアの起源」確立。氏族ごとに異なっていた祖先伝承が、司祭・語り部によって一つの起源神話へ統合される。アマルの塚の存在も「ラーナ以前の古き者（アマル）」として物語に組み込まれる** → [アルナリアの起源](../社会と文化/アルナリアの起源.md) |
| **前660年頃** | **デバゴシュタ成立。共同労役が制度化され、大規模公共事業「ナムリア第一堤」が築かれる** → [デバゴシュタと公共事業](../政治と軍事/デバゴシュタと公共事業.md) |
| **前640年頃** | **東方の大湖畔の政治勢力[シー・テープ](シー・テープとの遭遇.md)と初接触。ラーナ人が初めて「もう一つの文明」を認識する** |
| **前630年頃** | **シー・テープから大規模建設技術が伝来。「作らせる専門家」ゴシャルが生まれる** → [ゴシャルと建設術の伝来](../技術と知識/ゴシャルと建設術の伝来.md) |
| 前620年頃 | 貴族の狩猟をめぐり、放棄物の所有権慣習と「富める者は余剰を還元すべき」という倫理観が強まる → [放棄物の慣習と再分配倫理](../社会と文化/放棄物の慣習と再分配倫理.md) |
| **前610年頃** | **北西でセレウキア系の恒久的居住地を発見。初めて「我々の土地」という領域意識が芽生える** → [北西セレウキア居住地の発見](../政治と軍事/北西セレウキア居住地の発見.md) |
| 前600年頃 | アクモニアへ向かう牧畜商人と遭遇。牛を奪わず、「旅する商人を害さない」慣習が強まる。大型家畜（牛）への関心が高まり、畜産研究の優先度が上昇。「アクモニア」という新たな交易先の存在を伝聞で知る → [牛飼いとアクモニア遭遇戦](牛飼いとアクモニア遭遇戦.md) |
| 前595年頃 | アクモニア遭遇戦。探索中の一団がアクモニアの武装集団に襲撃される、対アクモニア初の武力接触。交易者と政治勢力を区別する外交感覚が形成される一方、「規律」（軍紀）の必要性が決定的に高まる → [牛飼いとアクモニア遭遇戦](牛飼いとアクモニア遭遇戦.md) |
| **前590年頃** | **北方で「エジプト」と初接触。数千年の歴史を持つ国家文明との遭遇により、文字・記録という概念に強い衝撃を受け、「世界は我々が知るよりずっと広い」と知る** → [エジプトとの初接触](エジプトとの初接触.md) |
| **前580年頃** | **南東の政治勢力チャン・チャンと敵対的に遭遇。セレウキア・アクモニア・チャン・チャンとの緊張が同時進行する「三方緊張期」が始まる** → [チャン・チャンとの遭遇と三方緊張期](チャン・チャンとの遭遇と三方緊張期.md) |
| **前570年頃** | **第一回大評議宴。拡大した評議会が対外方針の合意を祝う祝宴を開き、評議会が公的機関へ変わったことを示す。祭日「ラーナシュ」の起源** → [大評議宴とラーナシュ](../政治と軍事/大評議宴とラーナシュ.md) |
| **前560年頃** | **神秘主義が確立。アマルの塚の観測170年を経て、天界・地上界・水界からなる三界の宇宙観が成立。「神々は空から都市を見守る」という教義と、聖地アラシュ山が生まれる** → [神秘主義と天界思想](../社会と文化/神秘主義と天界思想.md) |
| **前550年頃** | **エジプトとの文化交流が開始。継続的な人の往来（ナムリアのエジプト人街）が生まれ、文字・測量・宝飾・宗教習合への刺激が流入する「第一次開化期」が始まる** → [エジプトとの文化交流開始](エジプトとの文化交流開始.md) |
| **前540年頃** | **太陽神アーラが汎アルナリア的な最高神格として成立。天界思想の到達点であり、エジプトの太陽神ラーとの同一視が語られ始める** → [太陽神アーラとパンテオン](../社会と文化/太陽神アーラとパンテオン.md) |
| **前530年頃** | **神官制度が成立（アーラ神官改革）。地域的な司祭が公的祭祀専門職へ再編され、教育・暦管理・司法的先例の記憶という役割を担う「第三の権威」が生まれる** → [神官制度の成立](../社会と文化/神官制度の成立.md) |
| **前520年頃** | **東方でサラシュ石林を発見。熱帯カルスト地形を「人間より古い世界」の象徴として聖地化し、人工物を加えない聖域保護制度が生まれる。「山は山でしかない」という自然観の芽も現れる** → [サラシュ石林](../地理/サラシュ石林.md) |
| **前510年頃** | **ローマと初接触。共和政成立直前・直後の若きローマと出会い、似た政治制度・似た神々に驚く** → [ローマとの初接触](ローマとの初接触.md) |
| **前500年頃** | **アルナリア文字が成立。エジプトに刺激を受けつつ既存の記号体系から独自発達し、先史時代から歴史時代への移行点となる** → [アルナリア文字の成立](../技術と知識/アルナリア文字の成立.md) |
| **前500年頃** | **ローマとの文化交流が開始。「公職」概念や隊列戦術など、エジプトとは異なる刺激をもたらす「北方交流時代」の一角となる** → [ローマとの文化交流開始](ローマとの文化交流開始.md) |
| **前495年頃** | **異神巡礼の遭遇。敵対的な大船渡近郊で異民族の巡礼を見て、課税ではなく「ともに喜ぶ」を選ぶ。十分の一税は評議会と分離した神官団の財源として応用され、巡礼文化の萌芽と「神々は国境に従わない」という習合への思想的土台が生まれる** → [異神巡礼の遭遇](../社会と文化/異神巡礼の遭遇.md) |
| **前490年頃** | **セレウキア融和が始まる。最も古い敵対国との緊張緩和に着手し、国境市の不可侵や文字による条約外交という「近隣との和解」戦略の第一歩となる** → [セレウキア融和と条約外交の始まり](../政治と軍事/セレウキア融和と条約外交の始まり.md) |
| **前490年頃** | **ナムリア避難港が完成。デバゴシュタではなく金銭で専門労働を購入した初の大型公共事業で、外国船にも開放され港湾不可侵の起源となる** → [ナムリア避難港](../技術と知識/ナムリア避難港.md) |
| **前485年頃** | **サラシュ石林の東でケルマと初接触。石林を挟んだ友好関係が「サラシュ街道」という新たな交易軸を生み、東西のバランスが取れた外交網が整い始める** → [ケルマとの初接触](ケルマとの初接触.md) |
| **前480年頃** | **ケルマとの相互贈答。青銅鏡への返礼に太陽円盤を贈り、国家間の贈答外交と外交用の「贈答庫」が制度化される** → [ケルマとの相互贈答](../政治と軍事/ケルマとの相互贈答.md) |
| **前475年頃** | **ラーナ使節、ローマ市へ到達。フォルムに象徴される「公的生活」を目撃し、共和政の混乱から「アル・ラーナを残しつつ制度化する」という教訓を得る** → [ローマ市への到達](ローマ市への到達.md) |

## 今後の展望（研究中）

### 技術：通貨、そして筆記Ⅱ

前500年頃、**筆記**が完成した（→ [アルナリア文字の成立](../技術と知識/アルナリア文字の成立.md)）。ナムリアの市場・専門職人・外国商人（シー・テープ、エジプト、ローマ）・金の産出という条件が揃った今、物々交換の限界を解決する**通貨**が次の焦点となる見込み。まず重量を規格化した金属（金片・銀片）が交換尺度として使われ、偽物対策として評議会や神官の印による重量保証（秤量貨幣）が刻まれ、最終的に鋳造貨幣へ発達すると想定している。

その後、通貨経済の発達によって契約・帳簿の需要が高まり、文字を書記官・公文書・契約書・土地台帳といった社会制度として運用する**筆記Ⅱ**が続く見込み。**筆記 → 通貨 → 筆記Ⅱ**という順で、「価値を記録する」「価値を交換する」「交換・所有・契約を国家が管理する」という三段階の発展を想定している。畜産（大型家畜の体系的管理）はさらにその後になる見込み。

### 社会制度：規律、そして公的生活・習合

前560年頃に**神秘主義**、前540年頃に**太陽神アーラ**、前530年頃に**神官制度**が成立し、宗教面の体系化が一区切りついた。→ [神秘主義と天界思想](../社会と文化/神秘主義と天界思想.md)、[太陽神アーラとパンテオン](../社会と文化/太陽神アーラとパンテオン.md)、[神官制度の成立](../社会と文化/神官制度の成立.md)

次の焦点は、前610年頃の北西セレウキア居住地の発見、前595年頃のアクモニア遭遇戦、前580年頃のチャン・チャンとの敵対的接触という三方緊張期を受けて優先度が明確に上がっている**規律**（軍紀・公的秩序）。

続いて、評議会・戦士団・神官団という三権的な分業が整いつつあることから**公的生活**（社会制度の共有意識、旧称アルナリアの基盤）、また太陽神アーラとエジプトの太陽神ラーの同一視が語られ始めていることから**習合**（海上交易による異文化の神々の統合）が焦点になる見込み。
