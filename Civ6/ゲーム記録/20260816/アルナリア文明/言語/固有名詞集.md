# 固有名詞集

民族・地理・氏族・制度・伝承の固有名詞と、古ラーナ語由来の語を分野別に整理する。何でも固有名詞化するのではなく、**後世の歴史家が名前を付けるような対象だけ**を命名する方針を取っている。

## 民族・文明

| 語 | 位置づけ |
| --- | --- |
| **ラーナ人（ラーナ）** | ナムリアを中心に形成された民族。古語で「河の民」「水辺に生きる者」 |
| **アルナリア文明** | ラーナ人を中心とする文明圏。「アルの地」を意味するとの説があるが未確定 |
| **アルナリアの起源** | 海から来た祖先とナムリア定住を語る建国神話・歴史観の総称 |
| **アーラ（Āra）** | 太陽神。「天を巡る者」。前540年頃、汎アルナリア的な最高神格として成立。エジプトの太陽神ラーとの同一視が語られる |

## 地理

| 語 | 位置づけ |
| --- | --- |
| **ナムリア** | アルナリア発祥の地。語源は後世不明（「豊かな河口」説は民間語源） |
| **ラウ川** | ナムリアを流れて海へ注ぐ聖河。古語で「流れるもの・水」 |
| **カルダ山地** | 金・鉄・ルビーの産地。ラウ川上流 |
| **サーリア海** | ラーナ人が最初に認識した海域 |
| **アマルの塚** | 由来不明の古代遺構。「アマル」は「最も遠いもの・天の果て・古き光」 |
| **サラシュ（サル・アラシュ）** | 東方の熱帯カルスト石林。「天へ触れる石々」。前520年頃発見、「人間より古い世界」の象徴として聖地化 |
| **シー・テープ** | 東方の大湖畔に成立した有力首長国。前640年頃初接触 |

## 周辺の人々

| 語 | 位置づけ |
| --- | --- |
| **サルカ人** | 十字路（サルカ市）で定期市を営んでいた内陸の交易民。ラーナ人に「特定の日時・場所で継続的に交換する市場」という制度をもたらした |
| **ハルガ族** | 卓越した弓術を持つ流浪の狩猟民・傭兵集団。アルナリア弓術に影響を与えたとされる |
| **セレウキア** | 近隣の勢力。アルナリアが最初に外交関係を築いた隣人。北西で境界問題が発生 |
| **アクモニア** | 内陸の交易先。牧畜民の目的地として先に名が知られ、後にその武装集団との武力衝突が発生 |
| **シー・テープ** | 東方の大湖畔の政治勢力。前640年頃初接触、友好的。建設技術の伝来元 |
| **エジプト** | 北方で接触した、桁違いに古い国家文明。友好的。前550年頃から継続的な文化交流が始まり、文字・測量・宝飾・宗教習合の刺激をもたらした |
| **ローマ** | 前510年頃接触。友好的。共和政成立期の若い都市国家。前500年頃から文化交流が始まり、「公職」概念や隊列戦術の刺激をもたらす |
| **北方交流時代** | 前550〜450年頃の呼称。エジプト・ローマとの文化交流が連続し、文字・政治・軍事・通貨・宗教が急速に変化した時期 |
| **アラシュ山** | 神秘主義の聖地。「上界に触れるところ」。天界と地上界が最も近づく場所とされる |
| **チャン・チャン** | 南東の政治勢力。海上交易圏で競合し、敵対的 |
| **大船渡** | エジプト北西の遠方勢力。敵対的だが実害は小さい。近郊での異民族巡礼との遭遇が習合思想を深めた |
| **ケルマ** | サラシュ石林東方の友好的な都市国家。牧畜・農耕・金属加工・交易に強い。「サラシュ街道」で結ばれる |
| **バビロン** | 遥か西方の古い都市文明。前470年頃初接触。レンガ都市・文字記録・契約・天文観測でアルナリアに衝撃を与える |
| **マウリヤ** | 東方の第三の大文明。前435年頃初接触。史実的にはマガダ系諸勢力に近いが、後世の呼称で記録される。象・米・沙門思想でアルナリアに親近感と衝撃の両方を与える。首都パータリプトラはツンドラに位置し、寒冷地を中心に温暖な北西方面まで広がる交易圏を持つ文明として再定義された |
| **パータリプトラ** | マウリヤの首都。前415年頃発見。ナムリアから遥か南東のツンドラに位置する。史実の温暖な同名都市とは異なる独自設定 |
| **サマパ** | マウリヤの第二都市。前410年頃発見。パータリプトラとは異なる役割（交易・生産・地方統治）を持つとみられる |

## 政治用語

| 語 | 位置づけ |
| --- | --- |
| **アル（Al）** | 首長。原義は「前に立つ者・先頭の者・導く者」。後世「王（アルナ）」へ意味が広がる可能性が語られている（未確定） |
| **アル・ラーナ** | ラーナ人全体を代表する大首長。「ラーナの第一人者」 |
| **ラーナ評議会** | 有力氏族の合議機関 |
| **地方評議会** | 前470年頃、第二都市建設に伴い生まれた地方行政機関。日常行政を担い、税・外交は中央（ラーナ評議会）が管轄する |
| **市警隊** | 前450年頃成立の治安専門組織。市場監視・夜警・門番・港湾警備・火災監視などを担当 |
| **アンノナ** | 前450年頃制度化された公共食糧管理。穀倉運用・備蓄・凶作時の放出・新都市への供給を担う |
| **メルナ** | 前430年頃建設のアルナリア第二都市。「二つの水の間」。二大河川に挟まれた計画都市。塩・鹿から始まり綿織物・ルビーで成長 |
| **ナムリア盟約** | 前850年頃成立の氏族間盟約。寡頭制成立の象徴 |
| **諸氏族時代** | 寡頭制期を指す、後世の歴史学上の時代区分 |
| **ナムリア五家** | 寡頭制を支える有力氏族。ナム家（祭祀・伝統）、カルダ家（上流・鉱物交易）、サーラ家（海運・漁業）、リュナ家（稲作・水利）、アルガ家（戦士・狩猟） |
| **デバゴシュタ** | 共同労役の制度。デバ（共同体・皆）＋ゴシュタ（働く・手を貸す）＝「皆のために働くこと」 |
| **ゴシャル** | 建設現場で人と道具を組織し指揮する専門家。デバゴシュタと同系語で「仕事を導く者」 |
| **神官（区別：司祭）** | 司祭＝地域・氏族の宗教専門家、神官＝前530年頃に成立した公的祭祀専門職。アーラ神官・海神神官・収穫神官・祖霊神官・山岳神官などに専門分化 |
| **アーラ輪** | 神官の紋章。円の中から八本の光が伸びる意匠 |
| **アルナリア紋章文化** | 前460年頃の北方織技伝来に由来する視覚言語。円＝アーラ、波＝海、三角＝山、菱形連続＝家系など、文字と並存する象徴体系 |

## 施設・地区

| 語 | 位置づけ |
| --- | --- |
| **カルム** | ナムリアの職人街。古語で「作る場所・手仕事の場所」から「工房」の意へ |
| **ナムリア大穀倉** | 前720年頃建設の共同管理穀倉 |
| **アルナ祭宴** | 収穫後の大宴会。アルの権威を可視化する政治的行事 |
| **太陽円盤** | 前480年頃、ケルマの青銅鏡への返礼として贈られた金・ルビー製の外交贈答品。アーラを象徴するが信仰の押し付けではない |
| **ラーナ広場（構想）** | ローマのフォルムに触発された、評議場・市場・神殿・告知場を一ヶ所に集めた公共地区の構想。前475年頃以降の都市改造の焦点 |
| **ラーナシュ** | 「民の食卓」。前570年頃の大評議宴に由来する祭日。ラーナ（民・我々）＋シュ（食卓・分かち合う） |

## 語源についての方針

「ナムリア」「アル」「アマル」など、古い語ほど確定した語源を与えず、**「〜という説があるが確定していない」という余地を残す**方針を取っている。ラーナ人自身の民間語源（後付けの尤もらしい説明）と、現代の言語学者が推定する語源が食い違っていてもよく、そのずれ自体が歴史の厚みを表す要素として機能する。
