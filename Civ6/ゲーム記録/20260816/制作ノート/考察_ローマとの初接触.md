# アルナリア・ローマ初接触 ― 紀元前510年頃

[サラシュ石林の発見 → 考察_サラシュ石林の発見.md](考察_サラシュ石林の発見.md)

これはエジプトとの遭遇とはまた違った意味で、アルナリア史の大事件になる。年代はサラシュ石林発見(前520年頃)の直後、**紀元前510年頃**くらいがいい。ただし「史実のローマ」として扱うなら、この時代のローマは後世の大帝国とはまったく違う。むしろそこが面白い。

---

## 紀元前510年頃――アルナリア・ローマ初接触

探索者たちはナムリアから北方へ進み、すでに交流のあるエジプト系居住地を越え、さらに北へ進んだ先で新しい勢力に遭遇する。後世、世界最大級の国家の一つを築くことになる**ローマ**。しかし当然、この時代のラーナ人にそんな未来は分からない。

年代が絶妙で、史実ではまさにAncient Romeが**王政から共和政へ移行する直前・直後**に相当する。伝承上、最後の王タルクィニウス・スペルブスが追放され共和政が始まったのが紀元前509年。つまりアルナリア人が出会ったのは「ローマ帝国」ではなく、**激しい政治変動の真っただ中にいる、まだ若いローマ**である。

## エジプトとの遭遇とは印象が違う

エジプトを見たラーナ人は、何千年もの歴史・文字・神殿・官僚・高度な宗教という圧倒的な歴史の厚みに驚いた。しかしローマは違う。前510年頃なら、アルナリアから見ても「強そうではあるが、エジプトほど圧倒的ではない」と感じる可能性が高い。

アルナリアも前1200年頃の定住開始から700年近くが経ち、評議会・戦士団・神官制度・公共事業・海上交易を備え、シー・テープやエジプトから技術を吸収している。だからローマに対しては初めて、**「我々と同じ時代を生きている文明」**という感覚を持てるかもしれない。

## 政治制度が妙に似ている

アルナリアはゲーム上**寡頭制**を選び、五家・アル・ラーナ・評議会という有力者による合議から、主要集落や神官、戦士も取り込んだ公的評議会へ発展している。一方のローマもちょうどこの頃、元老院・貴族層・複数の政務担当者による合議へ移行する。制度は違うが、ラーナ人からすれば「王一人ですべてを決めないのか」というところで話が通じる。

想定される対話：

> ローマ人「誰がお前たちの王だ？」
> ラーナ人「アル・ラーナだ。」
> ローマ人「ならばアルが決めるのか？」
> ラーナ人「いや、評議会で決める。」
> ローマ人「では王ではないではないか。」
> ラーナ人「何を言っている。アルはアルだ。」

逆にラーナ人も「王を追放した」というローマの政治変動に驚く。アルナリアではアル・ラーナそのものを廃止しようという発想はまだない。

## 後世からの象徴性

何百年後かにアルナリアとローマが両方とも大国になったら、「両文明が初めて出会ったのはローマ共和政成立とほぼ同時期だった」というのは非常に象徴的な歴史になる。しかもアルナリア側も同じ頃、血縁共同体から公的社会へ移行している。両文明とも、それぞれ独自に**「個人ではなく制度によって政治を行う」**方向へ進み始めていた。

## ローマ側から見たアルナリア

ラーナ人は熱帯から来て、肌や服装、装飾文化も違い、米を主食にし、ルビーを持ち、独特の陶器、珍しい木材、遠方航海をする——ローマ側からすれば、最初は「アルナリア」という国家そのものより**珍しい南方交易品を持ってくるラーナ商人**として知られる可能性が高い。

## ルビーが外交カードになる

金や鉄はローマも知っているが、良質なルビーは珍しい。アルナリア産の赤い宝石が**「ラーナの赤石」**のような名でローマ上流層に知られるようになる。まだ直接交易量は少ないが、**ナムリア → エジプト圏 → ローマ圏**という長距離交易路が形成され始める。

## 外交構造の整理

| 勢力 | 関係 |
| --- | --- |
| シー・テープ | 友好 |
| エジプト | 友好・文化交流 |
| ローマ | 友好 |
| セレウキア | 敵対的 |
| アクモニア | 敵対・襲撃経験あり |
| チャン・チャン | 敵対的 |

近隣の小国とは領土・交易圏を巡って摩擦があり、少し離れた主要文明とは友好的——**近隣国とは利害が衝突するが、遠方の大文明とは交易利益の方が大きい**という国際政治として説明できる、かなり自然な構造。

## 「北方世界」の広がり

シー・テープで東方世界を、エジプトで北方世界を知ったラーナ人は、ローマとの遭遇で「エジプトの向こうにも世界が続いている」ことを知る。ナムリア＋周辺森林＋海だった世界観が、ここで一気に広がる。

## 神官の関心と習合の加速

ローマにも天空神・戦神・炉の神・農耕神・海神がおり、アルナリアのパンテオンと似た役割の神が見つかる。エジプトとも違う体系でありながら似ている——神官たちは「なぜ遠く離れた民が、似た神々を祀るのか」と考え始める。エジプトだけなら偶然かもしれないが、シー・テープもローマも似た神を持つとなると、**「神々は同じで、人間が異なる名前で呼んでいるだけなのではないか」**という思想がさらに強まる。[太陽神アーラ](考察_太陽神アーラとパンテオン.md)の項で触れた習合への流れが加速する。

## 「公的生活」研究の意味がさらに強まる

次の研究は引き続き**公的生活**を推したい。エジプトからは官僚・記録・測量・神殿行政を、ローマからは評議・公職・公共空間・市民共同体という発想の刺激を受け、それをそのまま輸入せず既存のアルナリア評議会と融合させる——これは「公的生活」研究完了の背景として説得力がある。

## 結論

**紀元前510年頃――アルナリア・ローマ初接触。**

この時点では誰も知らない。ローマ人も自分たちが後に地中海世界を覆う大帝国になるとは知らず、ラーナ人もアルナリアが後世「主要文明」と呼ばれる存在になるとは知らない。北方のある居住地で、二つの若い文明の使者が、ただ友好的に挨拶を交わした。

エジプトとの初接触が**「若い文明が古い文明と出会った日」**なら、ローマとの初接触は**「後に大国となる二つの若い文明が初めて互いを認識した日」**として対比できる、かなり美しい歴史になる。
