## 1. T2 に起きたこと

* 技術「農業」が完了（古代の技術、Depth=1）
* 平安京で斥候が完成（World Count=1、Player Count=1）
* 斥候は平安京のマス (67,22) から動かず、「捜索」を使った（UnitOperations.log の UNITOPERATION_SEARCH。移動の記録にも、T2 には行き先がない）
* ゲーム内の年：前3975年（T1 から25年）

### 農業

* 古代の時代の最初の技術で、研究に必要な量は1（progression-trees-tech.xml の Cost="1"）。そのため、10の文明すべてが T2 に完了している
* できるようになるもの：建造物の穀物庫と釣り埠頭。陶磁器・畜産・帆走術を研究するための前提にもなる
* 施設の農場は、技術がなくても作れる（人口が増えたときに、平地のマスに置く。districts.xml）
* 平安京で最初の農場ができるのは T76 の (68,20)。自国で最初の農場は、T30 の武蔵 (71,17)
* 平安京の穀物庫は T23 の (67,23)、釣り埠頭は T62 の (68,22)
* T1〜T10 に平安京が建てた施設は、伐採場（T3）と漁船（T7）だけ

### 最初の斥候

* 斥候は視界2、移動力2（units.xml）。ゲームの説明は「タイルの様子を明らかにし、新たな場所を発見することを得意とする陸上支援ユニット。樹草地形によって移動が終了しない」
* 捜索の説明は「1ターンの間、視界+1。この2倍の範囲に存在する『発見』がすべて明らかになる」。斥候の視界は2なので、捜索で視界が3になり、6マス以内の発見の場所が分かる
* 平安京から6マス以内にある発見の場所は、次の3つ。T2 の捜索で、この3つが分かったとみられる（推定）
  * (68,27) テント・キャンプ（緯度の低い側へ5マス）
  * (61,22) キャンプファイヤー（西へ6マス）
  * (71,25) キャンプファイヤー（緯度の低い側へ6マス、東寄り）
* World Count は、世界で何番目の斥候かを表す。ただ、ほかの9つの文明も同じ T2 に斥候を作っていて、平安京が1番なのは記録の並び順によるとみられる（推定）

### このあとの斥候の動き

移動の記録（AStar_APP.csv、AStar_GC.csv）から分かる、T3〜T5 の動き。斥候は、捜索で分かった3つの場所に順に向かっている。

| ターン | 斥候 | 動き |
|---|---|---|
| T3 | 1つ目 | (68,27) に向けて出発し、(67,24)、(67,25) へ進む |
| T4 | 1つ目 | (67,26) を通って (68,27) に着く。同じターンに発見イベント「労働者たちのストライキ」。エイヴォン川 (66,28) とユーフラテス川 (69,27) を見つける |
| T4 | 2つ目（T4 に完成） | (61,22) に向けて出発し、(65,22)、(64,22) へ進む。エブロ川 (62,21) を見つける |
| T5 | 1つ目 | (68,27) から (71,25) に向かう |
| T5 | 2つ目 | (64,22) から (63,22) を通って (61,23) へ進む |

* 2つ目の斥候は、T6 に (61,22) の発見イベント「詩人の舌禍」に行き当たる
* (71,25) で発見イベント「農地を牧草地に」が起きるのは T12

### T3 のはじめの数字

T2 の終わりの姿として、Player_Stats.csv の T3 のはじめの数字を書いておく。

| 項目 | 値 |
|---|---|
| 居住地 | 1（都市1、町0） |
| 人口 | 2（都市部1、農村部1。人口が2になったことは、T3 の出来事として記録されている） |
| 持っているマス | 7 |
| ゴールドの蓄え | 10 |
| 1ターンの産出 | T2 と同じ（食料5、生産力5、科学力10、文化力10、ゴールド5、幸福度5、影響力10） |

* 生産（CityBuildQueue.csv）：T2 に生産力5が入って斥候が完成し、余りの4が繰り越された。T3 から2つ目の斥候（必要な生産力30）を作り始め、T4 に完成する
* 研究は、農業のあとに畜産（T8 に完了）を選んだとみられる（推定。選んだことはログに出ず、完了した順から推し量った）。社会制度は首長制を続けている（T6 に完了）

## 2. 同じターンの世界

* 10の文明すべてが、T2 に農業を完了し、首都で斥候を作った
* 漢が長江 (20,13) を見つける（最初の発見者）。この世界で、最初に見つかった川
* 30の独立勢力が地図に置かれた（Independents.csv の CREATE TRIBE）。どれも、戦士と斥候を1つずつ持って現れた
* 独立勢力の民の名（Game_Gossip.csv の「村」の行）：チムー、オルメカ、ベルガエ、カルタゴニアン、タルマヌガラ、ティワナク、トロイア、シャルダナ、トルテカ、スキタイ、シンタシュタ、セレウコス、エラム、カナン、オポーネアン、クシュ（2つ）、ホホカム、ゴート、フナン、羯、マンナエ、百済、リュキア、ヒッタイト、鮮卑、匈奴、高句麗、カバラン、モチェ
* 7つの独立勢力（ティワナク、スーサ、国内城、モチェなど）について、10の文明すべてに「Total Influence=3」の記録が出る。何を表すかは、ログからは分からない
