Civ7 の Logs フォルダから取り出した、ゲーム上の出来事の記録。解釈は入れず、ログにあることだけを書く。

* プレイヤー0：近代日本／卑弥呼（倭の女王）
* ゲーム：2026-11-03 04:04 ごろに始めたゲームの続き（前の時代は [02_探検の時代_T001-T120.md](02_探検の時代_T001-T120.md)）
* 範囲：近代の時代 T1〜T165。2026-11-03 17:02 ごろ始まった（GameCore.log）。T60 で勝利したあとも、プロイセンとの戦争が終わるまで続けて遊んだ
* 勝利：T60 に軍事による勝利（GameCore.log「Team 0 has won 1 place in a 'VICTORY_MILITARY_MODERN' victory!」18:24:31）。ターンは Telemetry.log で確かめた（T59 のターンの終わりが 18:24:27、時代の終わり「AgeEnd」が 18:24:32 の T60）
* 戦争の終わり：T163 にプロイセンが滅び（GameCore.log「Player 3 has been defeated」20:56:44）、プロイセンとの戦争が終わった。T164・T165 は戦争のあとのターン
* 文明：近代の時代は近代日本（CIVILIZATION_MEIJI）。ほかの国も文明が変わる（探検の時代→近代）。マキャヴェッリは高麗→フランス帝国、イサベルはスペイン→メキシコ、フリードリヒ2世はノルマン→プロイセン、ベンジャミン・フランクリンはチョーラ→アメリカ、孔子は明→清、ハリエット・タブマンはソンガイ→ブガンダ、アショーカはハワイ→シャム、徴側はマジャパヒト→ムガル、ホセ・リサールはインカ→ロシア
* ゲーム内の年：1750〜1924年（標準速度。最初の10ターンは1ターン2年、その後は1年。T1を1750年とした計算で、ゲーム画面とはまだ照らし合わせていない）。勝利の T60 は 1819年
* 同じ名前の都市：鎌倉と堺は2つずつある。この記録では、建てた大陸の名前を付けて書き分けた（鎌倉（コンゴ・クラトン）と鎌倉（シベリア）、堺（コンゴ・クラトン）と堺（オセアニア））
* 「焼き払わずに残す」は Gossip の OCCUPY_CITY。奪った都市を焼き払わずに残したときに出る（他国が奪った都市にも出る）
* ログの取得：2026-11-03 20:59 ごろ（ゲームは起動したまま）。作成には [age_record.py](../../../ゲームログ解析/スクリプト/age_record.py) を使った
* 発見イベントの本文と選択肢、独立勢力の名前は、ゲーム本体の日本語テキスト（ja_JP_Text.xml）から引いた。〈首都〉〈独立勢力〉〈報酬〉は、ゲーム画面では具体的な名前や量に置き換わる部分
