# 日ノ本古代年表

[行動記録](../ゲームログ/01_古代の時代_T001-T140.md)の「2. ターンごとの出来事」を、和風の名前で歴史として読み替えた年表。並びは行動記録のターンのまま。作者の依頼（2026-11-03）を受けて、名前と読み替えは Claude が決めた。

* 年は、ゲーム内の年をそのまま使った（計算のしかたは [ゲームログ/01_古代の時代_西暦年表.md](../ゲームログ/01_古代の時代_西暦年表.md)）。そのまま読むと不自然になるところは、年を動かさずに出来事の読み方を調整した。くわしくは2章の「年代と読み方の調整」にある
* ターンの列は、行動記録と照らし合わせるために残した
* 太字は、国の行く末にかかわる出来事
* 名前の対応は1章にまとめた

### 年代と読み方の調整

年はゲーム内の年をそのまま使った。ゲーム内の年は、1ターンごとに一定の年数（最初の80ターンは25年、その後は20年）で進む。そのまま読むと不自然になるところは、年は動かさず、出来事の読み方を次のように調整した。

* **卑弥呼は代々の名**：古代は約3200年続くので、卑弥呼は代々の女王が継ぐ名とした
* **加留多胡との戦いは三度**：最初の戦闘（前2300年）から最後の戦闘（前1640年）までは660年ある。戦闘のあったターンは、前2300〜前2175年、前1940〜前1900年、前1680〜前1640年の三つにまとまっているので、三度の戦いとして書いた
* **大工事は代々の工事**：大工事は、着工から完成まで80〜415年かかっている。数代の女王にわたって受け継がれた工事として読む
* **鉄の石と鉄器**：大宰府で鉄を掘るのは前2850年だが、鉄器を作り始めるのは前960年。それまでに掘った鉄の石は、赤い顔料などに使ったとした
* **貨幣**：貨幣（前2900年）は、直前に武蔵で掘り始めた銀を量って使う貨幣とした。硬貨の政策（前1260年）は、金属の小片を銭として使うこととした
* **盗みは伝わり**：布哇が技術を盗むのに500年（前3350〜前2850年）、高麗が政府の機密を盗むのに380年（前1280〜前900年）かかっている。何百年もかけて、日ノ本の技や政の仕組みが伝わったと読む
* **古代の終わり**：古代は前820年に終わるが、次の探検の時代は400年に始まる（あいだの約1200年は、ゲーム上の空白）。この年表では「古代の記録が終わる」と書くだけにし、あいだの扱いは探検の時代を記録するときに決める

史実の世界と比べると、日ノ本の歩みは次のようになる。文字や鉄器は世界の早い文明とほぼ同じころで、哲学や数学はそれより早い。史実の日本列島では、この年代は縄文時代にあたる。

| 年表の出来事 | 年 | 史実の世界で近いもの |
|---|---|---|
| 帆船を使い始める（T10） | 前3775年 | エジプトの帆船（前3500年頃〜） |
| 文字を使い始める（T33） | 前3200年 | メソポタミアの文字（前3200年頃） |
| 銀を量る貨幣（T45） | 前2900年 | メソポタミアの銀の秤量貨幣（前3000年紀）。硬貨は前7世紀から |
| 青銅器を作り始める（T64） | 前2425年 | 西アジアの青銅器時代（前3300年頃〜）、中国の青銅器（前2000年頃〜） |
| 条坊制（T79） | 前2050年 | インダス文明の碁盤目の町（前2600年頃〜） |
| 九つの政策（T98、レガシー「ハンムラビ法典」） | 前1660年 | ハンムラビ法典（前1750年頃） |
| 数学（T120）・哲学（T125） | 前1220・前1120年 | ギリシアの哲学、中国の諸子百家（前6〜前3世紀）より500年ほど早い |
| 鉄器を作り始める（T133） | 前960年 | 西アジアの鉄器時代（前1200年頃〜） |

## 3. 年表

### 第一章「平安京の建国」（前4000〜前3700年）

前4000年、初代の卑弥呼が葦原中国の平原に平安京を建て、日ノ本が始まった。まもなく、政は氏族の長たちの合議で決めるようになる。

| 年 | ターン | 出来事 |
|---|---|---|
| 前4000年 | T1 | **初代の卑弥呼、葦原中国の平原に平安京を建てる。日ノ本の始まり。** すぐ東に、もう一つの大陸・秋津島を見つける |
| 前3975年 | T2 | 農耕を始める。都から最初の斥候を送り出す |
| 前3950年 | T3 | 都の近くの、川辺のギョリュウの茂みに伐採場をつくる |

| 前3900年 | T5 | 川を一つ見つける（最初の発見） |
| 前3875年 | T6 | 氏上の制が整う。**政体を共和制とし、氏族の長たちの合議で政を決めることになる。** 道具作りを重んじる政策をとる。舌禍で隠れ住んでいた詩人をとりなし、町に迎え入れさせる |
| 前3850年 | T7 | 火山ランギトトと川を一つ見つける（いずれも最初の発見）。都のそばの湖で漁が始まる |
| 前3825年 | T8 | 牧畜を始める |
| 前3800年 | T9 | 冬至の日が奥まで差し込むように造られた古い塚を見つけ、天体の観測に使うことにする |
| 前3775年 | T10 | 帆船を使い始める。東の地で川を二つ見つける（いずれも最初の発見） |
| 前3750年 | T11 | 目立った出来事なし |
| 前3725年 | T12 | **海の向こうの布哇と初めて出会う。** 作物の育たない岩だらけの土地を、馬の放牧地に変える |
