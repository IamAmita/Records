近代の時代（T1〜T60）を5ターンずつ歴史にする（作者の依頼「自由に解釈してよいので、ログを歴史化してください」、2026-11-03）。その前に、時代全体にかかわる年代と名前を決めておく。名前・年代・読み替えは、作者の委任を受けて Claude が決めた（2026-11-03）。

* 近代の時代も、ターンが1から数え直しになる。ノートはこのフォルダに置く
* ノートの形はこれまでと同じ。「ゲームで起きたこと／年代／名前／読み替え／歴史／年表」
* 文明はログの上ではエジプトのまま。このゲームは近代の時代の T60 に、経済による勝利で終わった（作者による。ログには勝利のターンが出ない）（[行動記録](../../ゲームログ/03_近代の時代_T001-T060.md)の見出しを参照）
* 近代の時代には、発見イベントがない

## 1. 年代

探検の時代の終わりを700年頃とした。近代の時代のタメン人は、蒸気機関から電気、内燃機関、無線、大量生産、航空、計算機へと進む。史実ではおよそ1770年から1945年までの175年ほどに当たる。タメン人はゲームの上でもどの国よりずっと研究が早い（T59 の技術は18で、2位のアッバースの7の倍以上）。そこで、史実と同じくらいの速さで進んだとみて、近代の時代を700年頃〜850年頃とする。

## 2. 時代全体の名前

| 名前 | 中身 | 由来 |
|---|---|---|
| 大いなる家（の主） | 官僚主義的君主制の君主 | 古代からの集まりの宮の名を、そこに座る一人の呼び名にした。史実のエジプトで「ペル・アア（大いなる家）」が王を指す言葉になったのにならう |
| ヒミコ | 大いなる家の座に就く者が名乗る名 | ゲームの指導者の名（卑弥呼）を、ほかの文明の指導者の名と同じく、代々名乗る名とする。作中の言葉で「日に仕える者」の意味とし、太陽の神アメン・ラーに結びつける |
| 民の集まり | イデオロギー「民主主義」のもとでの議会 | 町の一員たちが選んだ者たちの集まり。ヒミコのもとに置かれる |
| アメンテト | 北アメリカ大陸 | エジプトの言葉で「西の地」。ネケン、ザウ、ペル・ハトホルがある |
| セケト・アアル | 南アメリカ大陸 | エジプトの言葉で「葦の野」。史実のエジプトで、西の果てにあるとされた死者の楽土。スウェネト、アブ、ハットワレットがある |
| 鉄の道 | 鉄道 | |
| 火の車 | 蒸気機関で動く車 | |

* 探検の時代には二つの大陸をまとめて「西の大陸」と呼んだ。近代の時代に両方に町を開いたので、分けて呼ぶ
* ヒミコの名は Claude の決めごと。名前を出したくなければ「大いなる家」とだけ書けばよい
* 遺産と新しい町の作中の呼び名は、ノートごとに決める

## 3. 時代を通した筋

* **王の立つ国**：T2 に官僚主義的君主制。光の思想（探検の時代の啓蒙思想）から「理を持つ一人が治めるべきだ」という考えが生まれ、富める家々の集まりが一人を大いなる家の座に据えた。後の世の評価に置いた「大いなる家に王の芽を見る説」は、ここで当たったことになる
* **王と民の集まり**：T20 に民主主義（イデオロギー）、T25 に自由主義、T54 に進歩主義。古代からの「町の一員」が、選ぶ者になる
* **火と鉄**：蒸気機関（T4）、製鉄所（T8〜）、工業化（T12）、電気（T17）、鉄道駅（T28〜）、工場（T51・T60）。最後は工場の品を鉄の道で運んで、経済による勝利
* **海の向こうの町**：タ・ネチェルにアケトアテン（T15）。アメンテトとセケト・アアルに6つの町（T32〜T53）
* **五つの同盟**：ノルマン（T1）、アッバース（T7）、漢（T8）、フランス帝国（T11）、戦国日本（T12）。世界の指導者の半数と同盟する（T12 国際連盟）
* **初めてのいくさ**：T45 にソンガイと都市国家エチオピア、T46 にスペインが宣戦。同盟国もソンガイとスペインに宣戦する。ソンガイはジャネトを T50〜T59 に攻め続け、セケト・アアルのスウェネトも攻めた。タメン人は T57・T58 にスペインのトレドとセビーリャを占領した。タメン人が他の国の町を奪ったのは、これが初めて。講和の記録はなく、いくさの中で時代が終わる
* **かつての敵が頼る**：斥候を襲ったブハラ（T43）、マンダレー（T48）、インデイスラン・ナカー（T53）が、のちにタメン人を頼る町になる。T53 に都市国家7つの宗主（パペットマスター）
* **災い**：竜巻（T15〜T17、T38〜T39）、激しい雷雨（T22〜T23）、ワセトの近くの大きな水害（T34）、シナブン山の噴火
* **探られる国**：フランス帝国、アッバース、ブガンダが技や秘密を探り続ける。ソンガイ、スペインは富を損なおうとする
