# 大工事の一覧と史実

作者の依頼「大工事の一覧と、経緯や役割などについてまとめてください。史実情報との比較も記載してください」（2026-11-03）を受けて、タメン人の大工事（ゲーム上の遺産）44をまとめたもの。

* 作中の名前・経緯・役割は、各時代の制作ノートで決めた読み替えによる（作者の委任を受けて Claude が決めた）。着工・完成・建設競争のターンは、[古代](../ゲームログ/01_古代の時代_T001-T134.md)・[探検の時代](../ゲームログ/02_探検の時代_T001-T102.md)・[近代の時代](../ゲームログ/03_近代の時代_T001-T060.md)の行動記録から取った
* 「史実」は、ゲームの遺産のもとになった実在の建物の情報。年代や中身はおおよそのもの
* タメン人は、建設競争に一度も負けていない

## 2. 古代の大工事（22）

### 墓山（ピラミッド）

* 経緯：ワセト。T21 着工、T32 完成。タメン人の最初の大工事。畑が水に沈む増水の季節に、多くの男たちが工事に出て、集まりの倉から麦を受け取った
* 役割：家の長たちを葬る、石を積んだ大きな墓。のちに土の兵が周りに並べられた
* 史実：ギザのピラミッド（前26世紀、古王国第4王朝）。クフ王など、神とされた王の墓
* 比べて：形はそのままだが、作中では**王ではなく家の長たちの墓**。王のいない国の象徴になった。年代は史実より700年ほど早い

### 大石柱（大ステッレ）

* 経緯：ワセト。T37 着工、T46 完成。文字が使われ始めてすぐに建てられた
* 役割：文字を刻んだ石の柱。集まりの取り決め、増水の高さ、古い先例を刻んだ
* 史実：アクスム王国の石碑群（3〜4世紀頃）。王の墓所を示す花崗岩の高い柱
* 比べて：史実は墓の目印だが、作中では**法と記録の柱**にした。役割は、法を刻んだハンムラビ法典の石碑（前18世紀）に近い

### 万国の門

* 経緯：ワセト。T49 着工、T57 完成。遠い国々と次々に出会った時期に造られた
* 役割：多くの国の使いを迎える門。ゲーム上の名前をそのまま作中の名前にした
* 史実：ペルセポリスの「万国の門」（前5世紀、アケメネス朝クセルクセス1世）。属国の使節が王に貢ぎ物を捧げるために通った
* 比べて：史実は大帝国の王に従う国々の門だが、作中では**同盟や頼ってくる町の使いを迎える門**

### 土の兵（兵馬俑）

* 経緯：ワセト。T57 着工、T65 完成。弓の兵が投石兵に代わった時期
* 役割：墓山のまわりに並べた焼き物の兵の像。墓に眠る家の長たちを守る
* 史実：秦の始皇帝陵の兵馬俑（前3世紀末）。約8000体の陶製の兵
* 比べて：皇帝一人の墓を守る兵が、作中では**家の長たちの墓を守る兵**になった

### 段々の庭（空中庭園）

* 経緯：ワセトで T57 に着工したが、T59 にケメヌへ移し、T68 に完成。スペインのマドリードとの建設競争に勝った（相手の進み具合12%）。古代の T27 に、遠い地で焼けた庭園の再建を手伝ったときに覚えた庭造りが生きた、とした
* 役割：河から水を引き上げて潤す、段々に造った庭
* 史実：バビロンの空中庭園（伝承では前6世紀、ネブカドネザル2世）。実在は確かめられていない
* 比べて：史実では王が妃のために造ったと伝わる。作中では、**遠い地の人々を助けて得た技**の実りとした

### イメルの大像（コロッサス）

* 経緯：ワセト。T65 に着工し、T67 に再び着工して、T73 に完成
* 役割：船着き場に立つ、水の神イメルの大きな像。塩の海から来る舟が、まずこの像を目にした
* 史実：ロドス島の巨像（前280年頃）。港に立つ太陽神ヘリオスの青銅像で、前226年の地震で倒れた
* 比べて：港の巨像という形は同じ。神は**太陽の神から水の神に**変えた。ワセトが海に面していることの手がかりにもなった

### 城壁の町（ドゥル・シャルキン）

* 経緯：ワセトで T57 に着工したが、T68 にケメヌへ移し、T74 に完成。スペインのマドリード（52%）、フランス帝国のパリ（35%）との建設競争に勝った。これでタメン人の大工事は七つになった（レガシー「古代世界の遺産」）
* 役割：ケメヌに、城壁で囲んで新しく造った町並みと大広間
* 史実：アッシリアのサルゴン2世が築いた新しい都（前717〜前706年）。王の死後まもなく捨てられた
* 比べて：王の都が、作中では**町の新しい区画**になった

### 神託の祠（神託所）

* 経緯：ケメヌ。T74 着工、T82 完成
* 役割：神のお告げを聞く所。ケメヌが信仰と学びの町になる始まり
* 史実：デルフォイのアポロン神殿の神託（前8世紀頃から）。巫女ピュティアがお告げを伝えた
* 比べて：中身はほぼ同じ。のちのマアトの教えの「天のお告げ」につながる

### 太陽の鳥の堂（平等院鳳凰堂）

* 経緯：ケメヌ。T82 着工、T89 完成。人は生まれた家の務めを継ぐと定められた年に仕上がった
* 役割：池に臨む堂。屋根に、太陽の神アメン・ラーの使いとする太陽の鳥の像をのせる
* 史実：宇治の平等院鳳凰堂（1053年、藤原頼通）。屋根に鳳凰の像、阿弥陀如来を祀り、極楽浄土を表す
* 比べて：鳳凰を**太陽の鳥**に読み替えた。史実より約2900年早い

### 岩の神殿（ペトラ）

* 経緯：ティニス。T84 着工、T94 完成。アッバースのバグダッドとの建設競争に勝った（68%）
* 役割：ティニスの近くの岩山に彫り込んだ神殿と墓
* 史実：ナバテア王国の都ペトラ（前1〜1世紀頃が盛期）。岩を彫った「エル・カズネ」は王の墓とされる
* 比べて：岩を彫る形は同じ。作中では、ティニスの岩山を祀る所とした

### 大鐘（エミレの鐘）

* 経緯：ケメヌ。T89 着工、T95 完成
* 役割：ケメヌで鋳た、青銅の大きな鐘
* 史実：統一新羅の聖徳大王神鐘（771年）。韓国に残る最大の青銅の鐘
* 比べて：形はそのまま。古代の青銅の技の頂点とした

### 大競技場（コロッセオ）

* 経緯：ワセト。T90 着工、T96 完成。人々が競技や芝居を楽しむようになった時期
* 役割：競技や見世物のための大きな囲い。疫病の時代にも人々を満ち足らせた
* 史実：ローマのコロッセウム（80年完成）。剣闘士の試合や見世物が行われた
* 比べて：役割はほぼ同じ。史実より約1700年早い

### 後の世の寺（彌勒寺）

* 経緯：ゲブツ。T91 着工、T100 完成。疫病の時代の始まりと重なる
* 役割：いつか来る救い手を待つ寺。高い石の塔を持つ。人々の祈りが集まった
* 史実：百済の彌勒寺（7世紀前半、武王）。未来仏である弥勒を祀り、残る石塔は韓国で最も古い石塔とされる
* 比べて：「未来の救い手を待つ」という中身を、そのまま作中に移した

### 大いなる家（未央宮）

* 経緯：ワセト。T96 着工、T101 完成。フランス帝国のパリとの建設競争に勝った（37%）
* 役割：家の長たちの集まりのための大きな宮。家々の上に立つ「大いなる家」と呼ばれた。近代の時代には、この宮の名が、そこに座る王（ヒミコ）の呼び名になった
* 史実：前漢の長安の未央宮（前200年）。皇帝が政を行った宮殿
* 比べて：皇帝の宮殿が、作中では**王のいない集まりの宮**になり、二千年以上たって王の呼び名になった。史実のエジプトの「ペル・アア（大いなる家）」が王を指す言葉になったのにならった

### 一枚岩の墓（テオドリック廟）

* 経緯：ティニス。T97 着工、T105 完成
* 役割：一枚岩の屋根をのせた墓
* 史実：ラヴェンナの東ゴート王テオドリックの廟（520年頃）。重さ200トンを超える一枚岩の屋根
* 比べて：形はそのまま。王の墓が、作中では家の長の墓になった

### 学びの館（ナーランダ）

* 経緯：ワセト。T102 着工、T106 完成。読み書きが家の長や商人、神官にも広まった時期
* 役割：読み書きと知恵を学ぶ館。ここで学んだ者の中から「知を愛する者」たちが現れた
* 史実：インドのナーランダ僧院（5世紀、グプタ朝）。仏教の大学で、各地から学ぶ者が集まった
* 比べて：学び舎という役割は同じ。史実より約1900年早い

### 太陽の基壇（太陽のピラミッド）

* 経緯：ケメヌ。T107 着工、T113 完成。フランス帝国のパリとの建設競争に勝った（70%）
* 役割：太陽の神アメン・ラーを祀る大きな基壇
* 史実：テオティワカンの太陽のピラミッド（200年頃）。神殿をのせた大きな基壇
* 比べて：太陽の神を祀る形は同じ。墓山（墓）とは別の、祀りのための基壇とした

### 聖なる塚（サーンチー）

* 経緯：ゲブツ。T107 着工、T114 完成
* 役割：それまでに得た聖なる品（遺物）を納めた、丸い塚
* 史実：サーンチーの大ストゥーパ（前3世紀、アショーカ王）。仏舎利を納めた半球形の塚
* 比べて：聖なる品を納める丸い塚という中身は同じ

### 書の大館（アレキサンドリア図書館）

* 経緯：ケメヌ。T113 着工、T116 完成
* 役割：各地の書を集めた大きな館。ケメヌは、神託の祠と書の大館を持つ信仰と学びの町になった
* 史実：アレクサンドリア図書館（前3世紀、プトレマイオス朝）。地中海世界の書を集めた
* 比べて：役割は同じ。史実では失われたが、作中では探検の時代の知恵の館へ、学びが受け継がれた

### 堀の大神殿（アンコールワット）

* 経緯：ゲブツ。T114 着工、T120 完成。弥生の人々がゲブツを襲った時期と重なる
* 役割：堀に囲まれた大きな神殿
* 史実：アンコール・ワット（12世紀前半、クメール王朝スーリヤヴァルマン2世）。環濠に囲まれたヒンドゥー教の寺院で、のちに仏教寺院となった
* 比べて：形はそのまま。史実より約2300年早い

### 大土壇（モンクス・マウンド）

* 経緯：ケメヌ。T118 着工、T122 完成
* 役割：土を盛り上げた大きな壇
* 史実：カホキアのモンクス・マウンド（900〜1200年頃、ミシシッピ文化）。北アメリカ最大の土の基壇
* 比べて：形はそのまま。石の墓山に対して、土の壇とした

### 星の広場（ムンド・ペルディド）

* 経緯：メンネファー。T114 着工、T123 完成。古代の T17 に遠い流域の人々から学んだ星の観測が、ここで大きな形になった

* 史実：ティカルの「失われた世界」（前700年頃から）。太陽の動きを観る建物群をもつマヤの祭祀の場
* 比べて：天体を観る場という役割は同じ。作中では、**タメン人の学びの源**として、最も大きな役割を負わせた

## 3. 探検の時代の大工事（12）

探検の時代には、マアトの教えの信条「天のお告げ」（ゲーム上の「天の啓示」：遺産を建設すると伝道師2人を得る）によって、大工事が仕上がるたびに、教えを説く者たちが出た、とした。大工事が、教えを広める元にもなった。

### 泥の大墓（アスキアの墓）

* 経緯：ティニス。T18 着工、T25 完成。探検の時代の最初の大工事
* 役割：泥を固めて段に積んだ、富める家々の長たちの大きな墓
* 史実：ガオのアスキアの墓（1495年、ソンガイ帝国のアスキア・ムハンマド1世）。泥れんがのピラミッド形の墓
* 比べて：史実ではソンガイの王の墓。作中では、隣国ソンガイより先に、**タメン人の富める家々の墓**として造られた

### 白鷺の城（姫路城）

* 経緯：ゲブツ。T21 着工、T28 完成。石の城が築かれるようになった時期
* 役割：白い石膏で壁を塗り上げた城。海から見ると白鷺が羽を広げたように見える
* 史実：姫路城（今の天守は1609年）。白漆喰の壁から「白鷺城」と呼ばれる
* 比べて：史実の呼び名をそのまま作中の名前にした。白い壁は、古代に石膏で家を塗ったタメン人の習わしにつなげた

### 骨の社（ハレ・オ・ケアウェ）

* 経緯：メンネファー。T30 着工、T37 完成
* 役割：町を開いた長たちの骨を納め、町を守る社
* 史実：ハワイ島プウホヌア・オ・ホナウナウのハレ・オ・ケアウェ（17世紀頃）。首長たちの骨を納め、その力で聖域を守るとされた
* 比べて：中身はほぼ同じ。王の骨ではなく町の長の骨とした

### 百八の塔の僧院（エルデネ・ゾー）

* 経緯：メンネファー。T37 着工、T43 完成。ほかの神々をマアトの教えに迎え入れた時期
* 役割：百八の小さな塔を連ねた壁で囲んだ、マアトの教えを修める者たちの僧院
* 史実：モンゴルのエルデネ・ゾー（1585年）。108の仏塔を連ねた壁で囲まれた仏教寺院
* 比べて：形はそのまま。仏教の寺を、マアトの教えの僧院に読み替えた

### マアトの大堂（ノートルダム）

* 経緯：ゲブツ。T40 着工、T47 完成。大きな帆船が海に出た時期
* 役割：高い天井と色ガラスの窓を持つ、大きな祈りの堂
* 史実：パリのノートルダム大聖堂（1163〜1345年頃）。ゴシック様式の大聖堂で、色ガラスのバラ窓で知られる
* 比べて：キリスト教の大聖堂を、マアトの教えの大堂に読み替えた。史実より約1300年早い

### 段の聖山（ボロブドゥール）

* 経緯：ワセト。T55 着工、T59 完成
* 役割：石を段に積んだ山のような聖堂。壁にマアトの教えの物語が刻まれる
* 史実：ジャワ島のボロブドゥール（9世紀、シャイレーンドラ朝）。仏教の教えを浮き彫りで表した段の聖堂
* 比べて：浮き彫りで教えを伝える役割は同じ

### 高塔の寺（ブリハディーシュヴァラ寺院）

* 経緯：ケメヌ。T55 着工、T59 完成。段の聖山と同じ年に仕上がった。これで探検の時代の大工事は六つになった（レガシー「ルネサンス世界の遺産」）
* 役割：石を高く積み上げた塔を持つ寺
* 史実：タンジャーヴールのブリハディーシュヴァラ寺院（1010年、チョーラ朝ラージャラージャ1世）。高さ約66メートルの塔を持つヒンドゥー教の寺院
* 比べて：形はそのまま

### 宮と僧院（エル・エスコリアル修道院）

* 経緯：ティニス。T56 着工、T60 完成
* 役割：富める家々の集まりのための宮と、教えを修める者たちの僧院を一つにした建物
* 史実：エル・エスコリアル（1563〜1584年、スペイン王フェリペ2世）。王宮、修道院、王家の霊廟を一つにした建物
* 比べて：王宮を、王のいない**集まりの宮**に読み替えた。史実ではスペイン王の建物で、作中のスペインは近代にタメン人と戦う国になる

### 閉ざされた宮（紫禁城）

* 経緯：ワセト。T59 着工、T64 完成。海の向こうの町々を本国から治める仕組みが考えられた時期
* 役割：高い壁で囲んだ、富める家々の集まりの新しい宮。集まりに席を持つ家の者と役人しか入れなかった
* 史実：北京の紫禁城（1420年、明の永楽帝）。皇帝の宮殿で、庶民は入れなかった
* 比べて：「限られた者しか入れない宮」という性格は同じ。皇帝ではなく富める家々の宮とした

### 知恵の館

* 経緯：ジャネト。T59 着工、T66 完成
* 役割：各地の書を集め、遠い国の言葉からタメン人の言葉に移す館。古代の書の大館の後を継ぐ
* 史実：バグダードの「知恵の館」（9世紀、アッバース朝マアムーン）。ギリシャ語などの書をアラビア語に訳した
* 比べて：役割はほぼ同じ。史実ではアッバース朝の館で、作中のアッバースはタメン人の古くからの同盟国

### 金の塔（シェダゴン・パゴダ）

* 経緯：ジャネト。T66 着工、T74 完成。マアトの教えに改めた町が二十五を数えた年
* 役割：金で覆った高い塔
* 史実：ヤンゴンのシュエダゴン・パゴダ（伝承では古く、今の姿は15世紀以降）。金箔で覆われた仏塔
* 比べて：形はそのまま

### 白い塔（ホワイト・タワー）

* 経緯：ティニス。T74 着工、T79 完成。火の薬が作られた時期
* 役割：白い石の高い塔。牢と蔵と武具の置き場を兼ねる
* 史実：ロンドン塔のホワイト・タワー（1078年頃着工、ノルマン朝のウィリアム1世）。王の城であり、牢や武器庫にも使われた
* 比べて：牢と武器庫という役割は同じ。史実ではノルマン人の王が築いた塔で、作中のノルマンはタメン人の同盟国

## 4. 近代の時代の大工事（10）

### ワセトの大学（オックスフォード大学）

* 経緯：ワセト。T4 着工、T17 完成。ソンガイのガオとの建設競争に勝った（15%）
* 役割：学舎をいくつも集めた大きな学び舎。古代の学びの館、探検の時代の学舎の後を継ぐ
* 史実：オックスフォード大学（1096年頃から教え始める）。英語圏で最も古い大学。いくつもの学寮（カレッジ）から成る
* 比べて：「学舎の集まり」という形は同じ

### 赤い砦（赤い城）

* 経緯：ケメヌ。T8 着工、T21 完成
* 役割：赤い石の城壁を持つ砦
* 史実：デリーのラール・キラー（1639〜1648年、ムガル帝国シャー・ジャハーン）。赤砂岩の城壁に囲まれた皇帝の居城
* 比べて：皇帝の居城を、ケメヌの砦とした

### 湯の館（道後温泉）

* 経緯：ティニス。T8 着工、T21 完成
* 役割：湧き湯を引いた大きな湯殿。古代から「体を洗うことは病を遠ざける」とされてきたタメン人の習わしを受け継ぐ
* 史実：松山の道後温泉本館（1894年）。温泉そのものは、日本で最も古い温泉の一つとされる
* 比べて：形はそのまま。古代のワセトの浴場（1100年頃）とつなげた

### 花の城壁（華城）

* 経緯：ジャネト。T11 着工、T23 完成。フランス帝国のパリ（23%）、ブガンダのカンパラ（10%）との建設競争に勝った
* 役割：西の境のジャネトを守る、花のように美しい石の城壁。ソンガイとのいくさ（T47〜T59）で、ソンガイの兵の攻めを防ぎ続け、ジャネトは一度も落ちなかった
* 史実：水原華城（1796年、朝鮮王朝の正祖）。城壁と砲台を備えた城郭都市
* 比べて：守りの城壁という役割は同じ。作中では、**近代のいくさで実際に町を守った大工事**として、最も大きな役割を負わせた

### 草葺きの大墓（ムジブ・アザーラ・ムパンガ）

* 経緯：クヒト。T13 着工、T39 完成。ブガンダのカンパラとの建設競争に、相手の進み具合74%で勝った。ブガンダの人々は、自分たちの墓の形をまねられたと怒った、とした
* 役割：草で葺いた大きな屋根の墓
* 史実：カンパラのカスビの王墓の中心の建物（1882年）。ブガンダ王国の歴代の王（カバカ）の墓で、草葺きの大屋根を持つ。2010年に焼け、建て直された
* 比べて：史実ではブガンダの王の墓。作中では、ブガンダより先にタメン人が造り、**ブガンダとの間のわだかまり**の一つにした（近代の T57 のブガンダの非難声明にもつながる）

### 山の金の寺（ドイ・ステープ）

* 経緯：ベフデト。T12 着工、T40 完成。これで近代の時代の大工事は六つになった（レガシー「近代世界の遺産」）
* 役割：山の上の金の塔を持つ寺
* 史実：チェンマイのワット・プラタート・ドイ・ステープ（1383年）。山の上に金色の仏塔が立つ
* 比べて：形はそのまま。タ・ネチェルに造られた

### 鉄の塔（エッフェル塔）

* 経緯：ジェデト。T35 着工、T53 完成。ソンガイ、スペインとのいくさの最中に仕上がった
* 役割：鉄の骨組みの高い塔。鉄の炉と工場の国の力を示す
* 史実：パリのエッフェル塔（1889年、パリ万国博覧会）。錬鉄の骨組みの塔
* 比べて：工業の力を示すという役割は同じ。本国ではなく、海の向こうのタ・ネチェルに建てた

### 火を返す炉（韮山反射炉）

* 経緯：ケメヌ。T46 着工、T56 完成。いくさの最中に造られた
* 役割：炉の天井で火の熱を返して鉄を溶かし、大筒を鋳る大きな炉
* 史実：伊豆の韮山反射炉（1857年、江川英龍・英敏）。鉄の大砲を鋳るために造られた
* 比べて：大筒を鋳るという役割は同じ。作中では、いくさのための大工事とした

### 白い霊廟（タージ・マハル）

* 経緯：ネケブ。T31 着工、T58 完成
* 役割：白い石の大きな墓廟
* 史実：アグラのタージ・マハル（1632〜1653年頃、ムガル帝国シャー・ジャハーンが妃ムムターズ・マハルのために）。白大理石の霊廟
* 比べて：形はそのまま。誰の墓かは決めていない

### 芸術の宮（ベジャス・アルテス宮殿）

* 経緯：イプ。T42 着工、T59 完成。近代の時代の最後の大工事
* 役割：芝居や絵のための大きな宮
* 史実：メキシコシティのベジャス・アルテス宮殿（1934年）。劇場と美術館を兼ねる
* 比べて：役割は同じ

### 絵の宮（エルミタージュ美術館、未完成）

* 経緯：ネケン。T51 に着工したが、時代の終わりまでに完成しなかった
* 史実：サンクトペテルブルクのエルミタージュ美術館（1764年、エカチェリーナ2世の収集に始まる）

| ワセト | 8 | 2 | 1 | 11 |
| ケメヌ | 8 | 1 | 2 | 11 |
| ティニス | 2 | 3 | 1 | 6 |

| メンネファー | 1 | 2 | 0 | 3 |

古代はワセトとケメヌに集まり（22のうち16）、時代が下るほど、東の町々、西の境のジャネト、海の向こうのタ・ネチェルへ広がった。国の広がりと大工事の広がりが重なっている。

### 5.2 役割の移り変わり

| 役割 | 古代 | 探検の時代 | 近代の時代 |
|---|---|---|---|
| 墓 | 墓山、土の兵、一枚岩の墓 | 泥の大墓、骨の社 | 草葺きの大墓、白い霊廟 |
| 神々と教え | 神託の祠、太陽の鳥の堂、岩の神殿、後の世の寺、太陽の基壇、聖なる塚、堀の大神殿、大土壇 | 百八の塔の僧院、マアトの大堂、段の聖山、高塔の寺、金の塔 | 山の金の寺 |
| 学び | 学びの館、書の大館、星の広場 | 知恵の館 | ワセトの大学 |
| 政と宮 | 大いなる家 | 宮と僧院、閉ざされた宮 | |
| 守り | 城壁の町 | 白鷺の城、白い塔 | 赤い砦、花の城壁 |
| 楽しみと芸術 | 段々の庭、大競技場 | | 湯の館、芸術の宮 |
| 記録と技 | 大石柱、万国の門、イメルの大像、大鐘 | | 鉄の塔、火を返す炉 |

古代は**墓と神々**、探検の時代は**教えと宮と城**、近代は**学びと守りと工業**が中心になった。国の歩み（大河の国 → 商人と教えの国 → 工業の国）が、大工事の役割にそのまま映っている。

### 5.3 史実との年代のずれ

44の大工事は、どれも**史実より早く**仕上がっている。差は次のとおり。

* 古代：墓山（史実より約700年早い）や大石柱（法の柱として見れば、ハンムラビ法典より約1200年早い）のように数百年早いものから、堀の大神殿（約2300年早い）、太陽の鳥の堂（約2900年早い）のように二千年以上早いものまである
* 探検の時代：泥の大墓（約2100年早い）、白鷺の城（約2200年早い）、マアトの大堂（約1300年早い）など、千年から二千年早い
* 近代の時代：ワセトの大学（約350年早い）から、鉄の塔（約1050年早い）、芸術の宮（約1100年早い）まで

ゲームでは遺産が時代ごとにまとめられているので、史実では二千年以上離れた建物（ピラミッドと平等院鳳凰堂など）が、作中では同じ古代に並ぶ。作中では、タメン人が学びでどの国よりも先に進んでいたこと（[通史と史実の比較](考察_通史と史実の比較.md)の4.3）とあわせて、「タメン人は、史実の人々が長い時をかけて造ったものを、早く、続けて造った」と読める。

### 5.4 ほかの国のゆかりの遺産

史実で、作中に登場する国（ゲーム上の文明）にゆかりのある遺産を、タメン人が先に造った例がある。

| 遺産 | 史実のゆかり | 作中のその国 |
|---|---|---|
| アスキアの墓 | ソンガイ帝国の王の墓 | 西の隣国。近代にタメン人といくさをする |
| ムジブ・アザーラ・ムパンガ | ブガンダ王国の王の墓 | 建設競争で負け、怒った。近代にタメン人を非難する |
| 知恵の館 | アッバース朝の翻訳の館 | 古代からの同盟国 |
| ホワイト・タワー | ノルマン朝の王の塔 | 同盟国 |
| エル・エスコリアル修道院 | スペイン王の宮と修道院 | 近代にタメン人といくさをし、町を奪われる |
| ノートルダム、エッフェル塔 | フランスの大聖堂と塔 | 同盟国。探検の時代にワセトを改宗させる |
| 未央宮 | 漢の皇帝の宮殿 | 古代からの同盟国 |
| 姫路城、平等院鳳凰堂、道後温泉、韮山反射炉 | 日本の城・寺・湯・炉 | 戦国日本。同盟国 |

作中では、どれもタメン人が自ら考えて造ったものとして書いている。ただ、ブガンダの草葺きの大墓のように、その国の人々とのわだかまりの種として使った例もある。

### 5.5 建設競争

タメン人は、8つの大工事で、遠い国々ののべ10の町と競い、すべてに勝った。

| 大工事 | 競った相手（相手の進み具合） |
|---|---|
| 段々の庭 | スペインのマドリード（12%） |
| 城壁の町 | スペインのマドリード（52%）、フランス帝国のパリ（35%） |
| 岩の神殿 | アッバースのバグダッド（68%） |
| 大いなる家 | フランス帝国のパリ（37%） |
| 太陽の基壇 | フランス帝国のパリ（70%） |
| ワセトの大学 | ソンガイのガオ（15%） |
| 花の城壁 | フランス帝国のパリ（23%）、ブガンダのカンパラ（10%） |
| 草葺きの大墓 | ブガンダのカンパラ（74%） |

いちばん競り合ったのは、草葺きの大墓（74%）と太陽の基壇（70%）。フランス帝国は4回競り、4回とも後れを取った。
