# 食生活

[← アヘル文明](../アヘル.md) ｜ [暮らしの移り変わり](暮らしの移り変わり.md) ｜ [町々](../地理/町々.md) ｜ [町々の名産](../地理/町々の名産.md)

タメン人が何を食べ、どう手に入れ、どう保ち、誰とどこで食べたかを、町々の名産と、倉や粉ひき場、船着き場、食べ物の店などの施設から推し量ったもの。

---

## 1. 食卓の土台

どの時代、どの町にも共通した食べ物。

* **麦のパンと麦の酒**：村の時代には、泥にまいた麦をすり石でひいて焼いた。墓山の時代からはパンと麦の酒が作られ、探検の時代には河の水車でひいた粉のパンが毎日の食べ物になった。麦の酒は、古代から人々のふだんの飲み物だった
* **ナツメヤシ**：タメン人のいちばん古い名産。干して蓄え、甘みとして食べた。砂糖が届くまで、ナツメヤシはタメン人の甘いものの中心だった
* **魚**：アヘル河と塩の海の魚。焼き、干し、ティニスの塩で塩漬けにした。漁の舟は、ほとんどの町にあった
* **乳と肉**：羊、山羊、牛の乳と肉。乳からはチーズが作られた（墓山の時代から）。肉はふだんの食べ物というより、祭りや豊かな家の食卓のものだった

---

## 2. 食べ物を支える仕組み

| 仕組み | 町 | 役割 |
|---|---|---|
| 倉 | すべての町 | 穀物を蓄え、不作や水害の年に配る（古代の法の時代から） |
| 粉ひき場 | ワセト、ケメヌ、ゲブツ（探検の時代）、イプ、ネケン、ハットワレット（近代） | 河の水車で麦をひく |
| 船着き場 | ジャネト、ネケブ、アブを除く町 | 漁の舟を出し、魚を揚げる |
| 庭園 | ケメヌ、ワセト、ティニス、ゲブツ（古代） | 果樹や香りのよい木を育て、楽しむ |
| もてなしの館 | ワセト、ケメヌ、ゲブツ、メンネファー、ジャネト | 遠くからの客を、もてなしの食事で迎える |
| 旅の宿 | ワセト、ケメヌ、ティニス、ゲブツ、ジャネト、メンネファー、ペル・アトゥム、ジェデト | 旅する商人や使いに食事を出す |
| 食べ物の店 | 本国の町々と、タ・ネチェルの町々の多く、ペル・ハトホル（近代） | 遠くから運ばれた食べ物を売る |
| 大きな店 | ティニス、メンネファー（近代） | 工場の品や遠い国の食べ物を並べる |

* **倉から配る**：古代の法の時代に始まった、余った穀物を倉から配る仕組みは、探検の時代、近代の時代にも行われた。大水や噴火、竜巻のあと、人々は倉の穀物で食いつないだ。タメン人の町で大きな飢えが記録されていないのは、この倉のためとみられる
* **作る・受け取る・買う**：食べ物の手に入れ方は、村の時代には自分で作るもの、墓山の時代からは集まりの倉から受け取るもの、疫病の時代からは市場で買うもの、近代には店で買うものへと移った
* **保つ**：干す、塩漬けにする（ティニスの塩）、倉に蓄える。近代には、鉄の道と火の釜の船で、傷む前に遠くへ運べるようになった

## 3. 地方ごとの食卓

### アヘル河の町（ワセト、ケメヌ）

**麦と魚とナツメヤシの、いちばんタメン人らしい食卓**

* ワセトは、粉ひき場が最初に建った町。河の水車でひいた白い粉のパンと、河と塩の海の魚、ナツメヤシが毎日の食卓にのぼった
* ワセトは商人の町でもあり、遠い国々の品がまず集まった。屋根のある市、旅の宿、もてなしの館、近代には食べ物の店と、食べ物を買い、外で食べる場がどの町よりも早くそろった
* ケメヌでは、疫病の時代からブドウが育てられ、ワインが作られた。ワインは、神官や豊かな家の食卓と、祭りの席で飲まれた
* ケメヌの香料は、食べ物ではなく、祀りに焚く香だった。神殿に捧げた麦やパン、魚、肉は、祀りのあとに人々に分けられた、とする

### 東の砂漠と海辺（ティニス、ゲブツ）

**塩とナツメヤシと海の幸**

* ティニスは、開かれた時から塩を掘る町だった。ティニスの人々は、塩漬けの魚を作り、国じゅうへ送った。マアトの時代からは前の海で鯨が捕られ、鯨の肉と脂が食卓を潤した
* 砂漠の岸の町らしく、ナツメヤシとラクダ。ラクダの乳は、砂漠の町の人々の飲み物にもなった、とする
* ゲブツでは、法の時代にマンゴーが、疫病の時代にナツメヤシが育てられた。ゲブツにも粉ひき場があり、麦のパンを食べた
* 二つの町には古代の庭園があり、果樹の実を楽しむ家もあった

### 東の平原（メンネファー）

**米と香辛料の食卓**

* メンネファーは、タメン人の町でただ一つ、米が育てられた町だった（法の時代から）。メンネファーの人々は、麦のパンだけでなく、炊いた米を食べた
* マンゴー、香辛料、海の魚。海ではタカラガイや真珠も採れた。香辛料で味をつけた米と魚の料理は、ほかの町にはないメンネファーの味だった、とする
* 平原の牧草地では馬が飼われたが、馬は乗り、引かせるためのもので、食べ物ではなかった

### 東の港（ペル・アトゥム）

**海の幸だけの食卓、麦は運ばれてくるもの**

* 漁の舟は町々の中で最も多く、魚、カニ、ウミガメ、鯨が採れた。ペル・アトゥムの食卓の中心は、いつも海の幸だった
* その一方で、畑はほとんど開かれなかった。麦は倉に運ばれてくるもので、ペル・アトゥムの人々は、魚や海の品と引き換えに麦を手に入れた
* 熱帯の海辺で、タカラガイが小さな買い物に使われた。魚とタカラガイで麦を買う暮らしだった、とする
* 近代には、町に集まった働き手が長屋に住んだ。長屋の小さな部屋では煮炊きが難しく、働き手たちは店や屋台で食べ物を買った、とする

### 西の境（ジャネト）

**畑の麦と、獣の肉と香辛料**

* ジャネトは、漁の舟が一つもない、ただ一つの本国の町だった。その代わり、畑は町々の中で最も多い。ジャネトの食卓は、魚ではなく、麦と獣の肉だった
* 疫病の時代から獣が狩られ、マアトの時代には香辛料が採られた。香辛料で味をつけた肉は、ジャネトの名物だった、とする
* ジャネトの麦は、西の境に集められた兵を養った
* 近代のいくさで、ジャネトはソンガイの兵に攻められ続けた。城壁の内の人々は、倉の麦と畑の実りで食いつなぎ、町は落ちなかった

### 鉱山の町（イプ）

**買って食べる鉱山の町**

* イプは鉱山の多い町で、畑や漁の舟はわずかだった。金やヒスイを掘る者たちは、運ばれてきた麦や食べ物を買って食べた
* 近代には粉ひき場、食べ物の店、町の庭ができ、食卓は豊かになった

### タ・ネチェルの町々

**砂糖と海の幸の、新しい土地の食卓**

* **ジェデト**：砂糖きびと海の幸。砂糖は宝の船団に積まれて本国へ送られたが、ジェデトの人々は、搾った砂糖きびの甘い汁を日々口にした、とする。旅の宿や食べ物の店もでき、本国の町と変わらない食卓になった
* **ネケブ**：砂糖きびと馬
* **ベフデト、クヒト、アケトアテン**：漁の舟が多く、魚と鯨の海の幸が中心。クヒトでは、本国の砂漠の町と同じくラクダが飼われた
* アケトアテンには食べ物の店がなく、人々は海と畑の実りで暮らした

### アメンテトの町々

**寒い野の魚と鯨**

* **ネケン、ペル・ハトホル**：寒い野の海辺の町。麦が育ちにくく、魚と鯨が食卓の中心だった。ネケンには粉ひき場ができ、運ばれた麦をひいた。ペル・ハトホルには食べ物の店ができた
* **ザウ**：草原の町。トリュフが採られた。土の中で育つ珍しいトリュフは、本国の豊かな家に送られた、とする。海ではカニが捕られた

### セケト・アアルの町々

**ワインと砂糖とリャマ**

* **スウェネト**：ワインと鯨、カニ。ケメヌに次ぐワインの町
* **アブ**：砂糖きび
* **ハットワレット**：リャマを飼う町。リャマの肉と乳を食べ、粉ひき場で麦もひいた
* 近代のいくさでは、スウェネトやアブの人々は、ソンガイの兵におびえながら暮らした

### 奪った町（トレド、セビーリャ）

* スペインの古い町で、ワインと魚が採れた。奪ったあとは、トレドのワインもタメン人の食卓に届いた

## 4. 身分と食卓

| 人々 | 古代 | 探検の時代 | 近代の時代 |
|---|---|---|---|
| 家の長たち、富める家々、王の宮 | 肉、ワイン、チーズ、祭りのごちそう | ワイン、香辛料、鯨、ウミガメ、砂糖。もてなしの館での宴 | 遠い国の食べ物、トリュフ、トレドやスウェネトのワイン |
| 職人、商人、町衆 | パン、麦の酒、魚、ナツメヤシ | 粉ひき場のパン、塩漬けの魚、旅の宿の食事 | 食べ物の店で買う食べ物 |
| 畑を耕す者、漁師 | 自分で作ったものと、倉からの配りもの | 富める家々に借り賃を納めたあとの残り | 店で買い足す |
| 大工事や工場の働き手 | 倉から受け取る麦 | | 長屋に住み、店や屋台で食べる |
| 兵 | 町ごとに出され、倉の麦で養われる | 雇われる兵 | いくさの学び舎、前線の兵。ジャネトの麦やタ・ネチェルの砂糖で養われる |

* 古代には、肉とワインは家の長たちのものだった。探検の時代には、富があれば誰でも、遠い国の品や砂糖を口にできるようになった
* 近代には、店で食べ物を買う暮らしが広まり、身分よりも、どこで働き、どれだけ稼ぐかで、食卓が分かれるようになった

---

## 5. 祈り、祭り、病と食べ物

* **供え物**：古代には、イメルの祠に魚や麦が供えられ、集まりの手で人々に配られた。死者には品を添え、のちには死者の神殿に供え物が運ばれた
* **祭り**：大祭や組合の祭り、大いなる家の祭りでは、肉やワインのごちそうがふるまわれた
* **体を洗い、体を養う**：疫病の時代には浴場で体を洗うことが病を遠ざけるとされた。光の時代には、腹の病に効く薬が作られた。近代には湯の館で体を休めた
* **災いのあと**：大水や噴火、竜巻のあとは、倉の穀物が配られた

## 6. まとめ

| 地方 | 主食 | おかず | 甘みと飲み物 | 手に入れ方 |
|---|---|---|---|---|
| アヘル河の町 | 粉ひき場の麦のパン | 河と海の魚 | ナツメヤシ、麦の酒、ワイン（ケメヌ） | 作る、市で買う、店で買う |
| 東の砂漠と海辺 | 麦のパン | 塩漬けの魚、鯨 | ナツメヤシ、ラクダの乳、マンゴー | 作る、塩と引き換える |
| 東の平原 | 米と麦 | 魚、香辛料 | マンゴー | 作る |
| 東の港 | 運ばれてくる麦 | 魚、カニ、ウミガメ、鯨 | | 海の幸と引き換える |
| 西の境 | 畑の麦 | 獣の肉、香辛料 | | 作る |
| 鉱山の町 | 運ばれてくる麦 | | | 買う |
| タ・ネチェル | 麦 | 海の幸 | 砂糖きび | 作る、運ばれてくる |
| アメンテト | 運ばれてくる麦 | 魚、鯨、トリュフ | | 捕る、運ばれてくる |
| セケト・アアル | 麦 | 鯨、カニ、リャマ | ワイン、砂糖きび | 作る |

タメン人の食卓は、どの時代にも**麦と魚とナツメヤシ**を土台にしていた。その上に、町ごとの名産が、その町らしい味を加えた。ティニスの塩、ケメヌのワイン、メンネファーの米と香辛料、ペル・アトゥムの海の幸、ジャネトの麦と獣の肉、タ・ネチェルの砂糖である。そして、すべての町にあった倉が、災いの年にも人々の食卓を支え続けた。
