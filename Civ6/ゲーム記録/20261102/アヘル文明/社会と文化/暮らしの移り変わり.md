# 暮らしの移り変わり

[← アヘル文明](../アヘル.md) ｜ [歴史年表](../歴史/歴史年表.md) ｜ [年表](../歴史/年表.md)

タメン人の暮らしが、ワセトの村の始まり（前4400年頃）から近代の時代の終わり（850年頃）まで、どう変わったかを推し量ったもの。家の跡、墓に納められた品、書き残されたもの、町の記録から考えられる姿を書く。

時代の分け方は次のとおり。古代と探検の時代は[歴史年表](../歴史/歴史年表.md)と同じ。近代の時代は、暮らしの変わり方から三つに分けた。

| 時代 | 年代 | 暮らしのあらまし |
|---|---|---|
| **古代** | | |
| 村の時代 | 前4400〜3500年頃 | 皆が顔を知る河岸の村。畑と漁と家畜をかけもちする |
| 墓山の時代 | 前3500〜2900年頃 | 倉と墓山のまわりで働く。文字と秤が暮らしに入る |
| 青銅の時代 | 前2900〜2300年頃 | 大水のあとの町。青銅、綿、染めた布、香料と、品が増える |
| 法の時代 | 前2300〜1550年頃 | 書かれた法と、生まれた家の務めを継ぐ定めのもとで暮らす |
| 疫病の時代 | 前1550〜1000年頃 | 市場と学び。病への恐れと備え |
| **探検の時代** | | |
| マアトの時代 | 前1000年頃〜150年頃 | 富める家々と組合の町。マアトの教えが暮らしに入る |
| 帆船の時代 | 前150年頃〜200年頃 | 港町に船乗りが増え、遠い国の品と話が都に集まる |
| 神の地の時代 | 200年頃〜500年頃 | 海の向こうの町が生まれ、富で買いそろえる暮らしになる |
| 光の時代 | 500年頃〜700年頃 | 理の光と、教えをめぐる争い。城壁の内の暮らし |
| **近代の時代** | | |
| 火の釜の時代 | 700年頃〜760年頃 | 王の国の町。湯気で動く機械と鉄の炉。店で食べ物を買う |
| 鉄の道の時代 | 760年頃〜830年頃 | 鉄の道と港で国じゅうが結ばれ、声が遠くまで届く |
| いくさの時代 | 830年頃〜850年頃 | 工場と長屋の町。初めての大きないくさの中の暮らし |

## 通して変わらなかったこと

* **増水の一年**：暮らしの拍子は、古代から近代まで、アヘル河の増水が決めた。増水の季節アケトの祭りと河の仕事は、探検の時代にも、近代の時代にも続いた
* **家**：人は家に生まれ、家の品と家の技を受け継いだ。「品物も技もその家のもの」という考えは、富める家々の集まりを生み、最後には家の長の一人が王になるところまで続いた
* **麦とナツメヤシと魚**：どの時代にも、食卓の中心は麦、ナツメヤシ、アヘル河と塩の海の魚だった。その上に、時代ごとに新しい食べ物が加わっていった
* **倉から配る**：不作や水害の年に、倉の穀物を人々に配る仕組みは、古代の法の時代に生まれ、探検の時代、近代の時代にも形を変えて行われた
* **体を洗う**：体を洗うことは病を遠ざける、という考えは、古代の浴場から近代の湯の館まで受け継がれた

## 古代

### 村の時代（前4400〜3500年頃）

**皆が顔を知る、河岸の村**

ワセトは、増水の届かない高い所に家々が寄り集まった村だった。村の者はみな、互いの顔と家を知っていた。

* **住まい**：泥を塗り固めた壁に、葦やナツメヤシの葉で屋根をふいた小さな家。家のそばに、穀物を蓄える穴や壺を置いた
* **食べ物**：泥にまいた麦をすり石でひき、焼いて食べた。ナツメヤシの実は干して蓄えた。網で捕った魚は焼くか干した。羊や山羊、牛の乳と肉もあった
* **着るもの**：獣の皮と、亜麻とみられる植物の繊維で織った布。織り方は家ごとに伝えられた。西の地の織物の秘伝を断ったのも、自分たちの織り方を重んじたからとされる
* **仕事**：ほとんどの者が、畑と漁と家畜の世話をかけもちした。石を打ち欠いて刃物を作る家、網のおもりや釣り針を作る家のように、道具作りを専らにする家も出てきた。終わりのころには、遠い流域から来た職人たちが石の器や石臼を作った
* **家と人々**：物事は家の長たちの集まりで決めた。死んだ者の品は、その家に返すのが決まりだった。若者たちは投石器を持って、家畜と畑を守った
* **祈り**：舟で漁をする者たちは、深い水の神イメルに祈った。供え物は祠に集まり、集まりの手で配られた。夜には星を見て、増水の近づくのを知ろうとした

### 墓山の時代（前3500〜2900年頃）

**倉と墓山のまわりで働く人々**

ケメヌとティニスが開かれ、タメン人は三つの町に分かれて住むようになった。家の長たちの集まりは大きな倉に穀物を集め、ワセトの外れで墓山を築いた。「集まりのために働き、集まりの倉から受け取る」ことが、暮らしの一部になった。

* **住まい**：ワセトでは、日干しレンガの家が増えた。木を挽く作業場もでき、戸や柱に板が使われた。ティニスでは、砂漠の岸で塩を掘る家族が多かった
* **食べ物**：土手で囲った畑に増水の水を長くとどめられるようになり、麦の取れ高が増えた。麦からはパンと麦の酒が作られた。ティニスの塩で魚を塩漬けにし、遠くまで運べるようになった。遠い地で学んだチーズも作られた
* **仕事**：畑が水に沈む増水の季節には、多くの男たちが墓山の工事に出て、集まりの倉から麦を受け取った。文字を書ける者が現れ、壺や倉の品に持ち主の家のしるしを書いた。銅や穀物は秤で量り、その重さで品物の値を決めた
* **家と人々**：家の長たちの集まりは、争いのときに兵を率いる、いくさの長を選ぶようになった。倉と墓山を仕切る者や書く者が、家の長たちのそばで力を持ち始めた
* **祈りと楽しみ**：一年は三つの季節に分けられ、最初の季節は増水の季節アケトと呼ばれた。人々は増水の神ハピに豊かな水を願った。死者の心はアヌビスの秤にかけられると信じられ、死者は品を添えて葬られた。国が豊かなときには、家の長たちの集まりが大祭を開いた

### 青銅の時代（前2900〜2300年頃）

**大水のあとの町と、増えていく品々**

大水は、ワセトの近くの畑と家々を沈めた。人々は家を建て直し、倉には見張りの兵メジャイが立った。その後、青銅、荷車、染めた布、綿、香料が現れ、暮らしに使われる品の種類が一気に増えた。

* **住まい**：建て直したワセトの家の壁は、白い石膏で塗られるようになった。町には、人々が集まって取り決めを聞く広場ができた。ケメヌには、城壁で囲んだ新しい町並みが造られた
* **食べ物**：東の砂漠の海辺のゲブツでは、魚が多く捕られた。麦や塩は、荷車で町から町へ運ばれた
* **着るもの**：ゲブツで綿が育てられ、亜麻とは違う柔らかい布ができた。染めた布は、豊かな家の者が身につけた。ガラスのお守りを下げる者もいた
* **道具**：青銅の刃物や道具は、まず職人や兵、豊かな家に広まった。スズを遠くから運ぶため、青銅は高価だった。畑を耕す者の多くは、なお石や銅の道具を使った
* **仕事**：大工事が続き、石を切る者、像を焼く者、庭を造る者など、大工事の仕事で暮らす者が増えた。植物の繊維で作った軽い書き物が使われるようになり、書く者の仕事も増えた。舟は沖へ出て、遠い国の品を運んだ
* **家と人々**：自分たちの土地をケメット（黒い土地）と呼ぶようになり、「ケメットの者」という思いが生まれた。ゲブツの海辺の家族は、鮮卑の人々や海から来る舟に脅かされ、見張りを欠かさなかった
* **祈り**：太陽の神アメン・ラーが祀られ、船着き場にはイメルの大像が立った。人々は朝には日の出を拝み、舟を出す前にはイメルに祈った。ケメヌでは、祀りに焚く香料の木が育てられた

### 法の時代（前2300〜1550年頃）

**書かれた法と定めのもとで**

書かれた法ができ、暮らしは、口伝えの先例から書かれた決まりに従うものに変わった。生まれた家の務めを継ぐ定め、町の一員の定め、祭りと祀りの作法が整い、タメン人は、どの国よりも決まりごとの多い国に暮らした。

* **住まい**：町は大きくなり、ワセトの岸には灯台が立ち、遠くからの客をもてなす館もできた。家の長たちは、墓山とは別に、家ごとの長の墓を造った
* **食べ物**：不作や水害の年には、余った穀物が倉から人々に配られた。新しく開かれたメンネファーでは、米とマンゴーが育てられた
* **着るもの**：メンネファーの野生の蚕から取った糸で、絹の布が作られた。絹は家の長たちや神官の晴れ着になった。ワセトの前の海で採れた真珠も、飾りに使われた
* **仕事**：人は生まれた家の務めを継いだ。漁師の子は漁師に、書く者の子は書く者になった。町ごとに兵を出す定めができ、若者たちは決まった訓練を受けた。ケメヌの近くでスズが掘られるようになり、青銅が手に入りやすくなった。交易の道は、はるか西のスペインまで延びた
* **家と人々**：争いは、書かれた法で裁かれた。町に住む者はその町の一員とされ、町の記録に名が載った。使いの者には、言葉の巧みさが求められた
* **祈りと楽しみ**：死者に供え物をする神殿が建ち、家々は祖先に供え物を運んだ。祭りと祀りの作法は細かく定められた。人々は競技や芝居を楽しみ、ワセトの大競技場には多くの人が集まった
* **災い**：ハウネ山の噴火と二度目の大きな水害で、多くの人が亡くなった。倉の穀物が配られ、人々は家を建て直した

### 疫病の時代（前1550〜1000年頃）

**市場と学び、そして病への恐れ**

町はさらに大きくなり、ワセトには遠くの国々の商人が行き交った。読み書きが広まり、知恵そのものを問う者たちが現れた。その一方で、遠い国々に広がる疫病の話が、いつも人々の心にあった。

* **住まい**：町には市場、闘技の場、庭園、大きな浴場ができた。各地に兵舎が建ち、兵が町に常に置かれた。遠い地の大昔の水路の跡から学んだ造り方で、町に水路が引かれた
* **食べ物**：ケメヌでブドウが育てられ、ワインが飲まれるようになった。町の市場には、遠い国々の品が並んだ
* **着るもの**：豊かな家は、象牙やルビー、銀の飾りを身につけた。西の境のジャネトで取れる白い土からは、白い焼き物が作られた
* **道具**：鉄が作られるようになり、鉄の鍬や鎌が、畑を耕す者の手にも届き始めた。メンネファーでは馬が飼われた
* **仕事**：硬貨が使われ、市場で品物を買う暮らしが広まった。ブガンダ、アッバース、ノルマン、ソンガイの商人がタメン人の町へ来た。務めごとに専門の者が育ち、数を扱う者、書く者、病の手当てをする者が町に住んだ
* **家と人々**：読み書きは、書く者だけでなく、家の長や商人、神官にも広まった。ワセトの学びの館や賢者の館では、若者たちが学び、論じ合った。書かれた物語や歌が好まれた
* **祈りと楽しみ**：冥界ドゥアトの富が信じられ、豊かな家は墓に多くの富を納めた。大祭や闘技の場の見世物は、疫病の時代にあっても人々を満ち足らせた
* **病への備え**：町には、病の兆しを見分ける者たちが置かれた。病は、神々から離れた者への罰とも、悪い気から起こるものとも考えられた。人々は祭壇での祀りを欠かさず、浴場で体を洗い、病の出た所からは家族ごと移り住んだ

## 探検の時代

### マアトの時代（前1000年頃〜150年頃）

**富める家々と組合の町、新しい教え**

家の長たちの集まりの席が富める家々に開かれ、町の暮らしの中心は、商いと作業場になった。水車が麦をひき、木を挽き、職人たちは組合を作った。人々の祈りは、古い神々に加えて、マアトの教えへ向かった。

* **住まい**：日干しレンガと石の家に、石切りの作業場で整えた石が使われた。町の中心には屋根のある市、星見の塔、組合の館、旅の宿が並んだ。富める家々の館の門には、家のしるしが掲げられた。城や館の下には牢が設けられ、やがて石の城も築かれた
* **食べ物**：河の水車でひいた粉のパンが、毎日の食べ物になった。ナツメヤシと魚に加えて、ティニスの前の海で捕れる鯨、ジャネトとメンネファーの香辛料、ペル・アトゥムのウミガメやカニが食卓にのぼった
* **着るもの**：亜麻と綿と絹。富める家々の者は、家のしるしを染め抜いた布をまとい、ペル・アトゥムのタカラガイや象牙の飾りを下げた
* **仕事**：組合に入った職人（石工、焼き物師、木挽き、鍛冶）、遠い国々へ向かう商人の一行、旅の宿の主、富める家々から畑を借りて耕す者、金で雇われる兵、役人、星見の塔で星を観る者。教えを説く者や僧院で教えを修める者、学舎で学ぶ者も現れた
* **家と人々**：人は家の生まれよりも、持つ富によって分けられるようになった。富める家々、組合の職人、畑を借りて耕す者、雇われる者の別ができた。富める家々の集まりに逆らう者は、牢に入れられた
* **祈りと教え**：町ごとにマアトの教えの神殿が建ち、人々は正しい行いで損なわれた世を繕うよう説かれた。教えの改めのあとは、神殿に富を納めるより一人ひとりの行いが重んじられ、教えの書は誰もが読むべきものとされた。読み書きをする者は、いっそう増えた。黄金のホルスの像も祀られた
* **楽しみ**：富める家々と職人たちの組合の祭りが、たびたび開かれた。旅の宿は、遠くの町の話を聞く場でもあった
* **学び**：星の位置から地図が作られた。学びの段階と、それを修めたしるしが定められ、学舎が建った
* **災い**：ペル・アトゥムの近くのシナブン山がたびたび火を噴いた。ワセトの近くでは、アヘル河があふれた

### 帆船の時代（前150年頃〜200年頃）

**海へ出る人々**

大きな帆船が造られ、港町では船乗りと船大工が増えた。タメン人の船は世界をひと回りし、遠い国の品と話が都に集まった。ワセトには閉ざされた宮、珍獣の園、見晴らしの館ができ、都の暮らしは華やいだ。その一方で、海の向こうへ渡る家族たちが集められ始めた。

* **住まい**：港町には造船所と埠頭が並んだ。ワセトには、集まりに席を持つ家の者と役人しか入れない閉ざされた宮ができた
* **食べ物**：長い航海に出る船乗りは、干したパンと酸い果物を積んだ。遠い国々の品が、交易の道と船で運ばれた
* **着るもの**：メンネファーの海の真珠が飾りに使われた。法で裁く者は、目を助けるガラスを掛けるようになった
* **仕事**：船乗り、船大工、武具の職人、書く者や数を扱う役人、遠い国の都に常に置かれる使い。教えを説く者たちは海を渡り、ほかの国の都にまで教えを広めた。知恵の館では、遠い国の言葉の書を訳す者たちが働いた
* **家と人々**：富める家々の集まりの在り方と、専門の務めを持つ者の扱いが、根本の定めに書かれた。海の向こうに町を開く家族たちが、ワセトとペル・アトゥムに集められた
* **祈り**：ゲブツのマアトの大堂、ワセトの段の聖山、メンネファーの僧院に人々が集まった。段の聖山の壁に刻まれた教えの物語は、字を読めない者にも教えを伝えた
* **楽しみ**：珍獣の園で遠い国の獣を見て、見晴らしの館で歌や芝居、絵を楽しんだ

### 神の地の時代（200年頃〜500年頃）

**海の向こうの町と、富で買う暮らし**

タ・ネチェルにジェデトが開かれ、本国から渡った家族たちが、熱帯の海辺で砂糖きびを育てた。本国では、病人の家と両替の館ができ、町衆が力を強めた。火の薬の筒を持つ兵が町を守り、終わりのころには、本国の町々で城壁が築かれ始めた。

* **住まい**：ジェデトでは、開かれたその年に、倉、船着き場、作業場、神殿が建てられた。のちには組合の館、両替の館、病人の家、市、武具の工房まで、富める家々が富で買いそろえた。本国では、ワセト、ケメヌ、ゲブツで城壁の工事が始まり、ゲブツには石の橋が架けられた
* **食べ物**：ジェデトの砂糖は宝の船団に積まれ、やがて本国の食卓にも届いた
* **仕事**：ジェデトの砂糖きび畑で働く者、宝の船団の船乗り、両替の館で富を預かり貸す者、病人の家で手当てをする者、火の薬の筒を持つ兵。遠い地の名高い彫り手に弟子入りする若者もいた
* **家と人々**：町に住む商人や職人など、富を持つ人々が町衆と呼ばれ、力を強めた。富によって分けられた身分は、町の記録に書き分けられた。富める家々の集まりの座は、神々が授けたものとされた
* **祈り**：マアトの教えに従わない町は冷たく扱われ、教えを説く者たちがいっそう多く遣わされた
* **楽しみ**：館に飾られた絵や像が、人々に見せられた
* **学び**：火の薬、物の動きの法則、大地が太陽のまわりを回るという考え、限りなく小さく分けて量る数の術が生まれた
* **海の向こうの暮らし**：ジェデトの人々は、ホデノショニの兵にたびたび襲われた。町の外では、弩や火の薬の筒を持つ兵が守った

### 光の時代（500年頃〜700年頃）

**理の光と、乱れる町**

学びと富で栄える区画では、人の理で世を照らすべきだという光の思想が語られた。夜空をのぞく観測所は、誰にでも開かれた。一方、フランス帝国の教えがワセトに広まると、教えをめぐる争いで町々が乱れ、引き戻された町ではほかの教えの建物が壊された。本国の町々はいくつもの城壁で囲まれ、畑は三つに分けて耕された。

* **住まい**：本国の町々は、区画ごとに城壁で囲まれた。タ・ネチェルにはベフデト、ネケブ、クヒトが、アジア側の東にはイプが開かれた
* **食べ物**：畑を三つに分け、順に休ませながら耕すやり方が広まり、食べ物が増えた。ネケブの砂糖きび、鯨、真珠が運ばれた
* **仕事**：タ・ネチェルでは、自分の畑を持って耕す者が町を支えた。ベフデトでは鉄とルビー、イプでは金とヒスイが掘られた。宝の船団はたびたびペル・アトゥムに着いた。西の大陸では、腹の病に効く薬を作る学者に、薬をもっと作らせた
* **家と人々**：教えをめぐって、町の中の家々や近所の人々が分かれ、争った。引き戻された町では、従わない者たちが家族ごと町を去った。はるか西の海では、教えを自由に信じられる地を求めて船出した巡礼者たちを救い、仕事を世話した
* **学び**：天のお告げではなく、人の理で世を照らすべきだと説かれた
* **災い**：シナブン山が大きく火を噴き、ペル・アトゥムの近くで人が死んだ

## 近代の時代

### 火の釜の時代（700年頃〜760年頃）

**王の国の町、湯気と鉄**

タメン人に初めて王が立ち、国の務めは王ヒミコのもとで役人たちが担った。火で湯を沸かして動かす釜が機械を回し、鉄の炉が煙を上げた。畑を離れて町に住む人々が増え、遠くの食べ物を店で買う暮らしが広まった。終わりのころには、町の一員たちが、民の集まりに出る者を選ぶようになった。

* **住まい**：町は大きく広がり、人々が混み合って住むようになった。鉄の炉の煙が町の空にかかった。メンネファーやペル・アトゥムには、火の釜の船のための港ができた
* **食べ物**：各地に、遠くから運ばれた食べ物を売る店ができた。人々は畑で作るより、店で食べ物を買うようになった
* **着るもの**：火の釜で動く織機で、布が大量に作られるようになった。布は前より安く手に入るようになった
* **仕事**：鉄の炉や、機械を据えた作業場で働く者が増えた。王のもとの役人、学ぶ者や専門の務めを持つ者が重んじられた。いくさの学び舎で学ぶ者と、溝を刻んだ筒の兵も現れた
* **家と人々**：家の長の一人が大いなる家の座に就き、富める家々は集まりの席を失った。混み合う町の暮らしの苦しみが論じられ、人々の暮らしの豊かさが測られて、町ごとに記録された。終わりのころには、町の一員たちが民の集まりに出る者を選び、誰でも思うことを書き、語ってよいと定められた
* **祈り**：王ヒミコは、太陽の神アメン・ラーの名のもとに国を治めるとされた
* **楽しみ**：大いなる家の祭りが開かれた
* **学び**：ワセトに、学舎をいくつも集めた大きな学び舎ができた。生き物や石を集めて分け、名をつける学びが盛んになった
* **災い**：ケメヌとジャネトの近くで竜巻が続けて起き、人が死んだ

### 鉄の道の時代（760年頃〜830年頃）

**鉄の道と、声の届く国**

本国の町々が鉄の道で結ばれ、港には火の釜の船が着いた。西の大陸のアメンテトとセケト・アアルにもタメン人の町が開かれ、地から湧く燃える水がくみ上げられた。線なしで声を送る術が生まれ、ワセトでは声の館が町じゅうに声を送った。

* **住まい**：町々に鉄の道の駅と港ができた。イプには町の庭がつくられた。西の大陸の寒い野のネケンでは、燃える水の井戸のまわりに家が建った
* **食べ物**：鉄の道と港で、遠くの町の食べ物が早く届くようになった。セケト・アアルのスウェネトのワイン、アブの砂糖、各地の鯨やカニが運ばれた
* **仕事**：鉄の道の駅や車で働く者、港の者、燃える水をくむ者、油の釜を作る者が増えた。西の大陸へ渡り、金を掘る者（ザウ）や砂糖きびを育てる者（アブ）もいた
* **家と人々**：一人ひとりの自由と、自由な商いが重んじられた。国の務めは文書で動くようになり、通貨は蔵に納めた金を拠りどころとするようになった
* **楽しみ**：ティニスに湧き湯を引いた大きな湯殿ができ、人々が体を休めた。線なしで送られる声が、遠くの町の出来事を伝え、ワセトには、声を町じゅうに送る声の館ができた
* **学び**：世界の国々が商いと声で一つに結ばれ始めた
* **災い**：ワセトの近くでアヘル河が大きくあふれ、ゲブツの近くでは竜巻と激しい雷雨が続いた

### いくさの時代（830年頃〜850年頃）

**工場と長屋の町、いくさの中の暮らし**

ソンガイとスペインがいくさを挑み、タメン人は初めて大きないくさの中で暮らすことになった。西の境のジャネトは大筒に攻められ続けた。本国では工場が建ち、町に集まった働き手は何階もある長屋に住み、大きな店で品物を買った。

* **住まい**：ペル・アトゥムには、町に集まった人々が住む何階もある長屋が建った。ティニスとメンネファーには、いくつもの売り場を一つにまとめた大きな店ができた。ジャネトの人々は、花の城壁の内で、外から撃ち込まれる大筒の音を聞きながら暮らした
* **食べ物**：工場の品や遠い国の食べ物が、大きな店に並んだ。奪ったトレドとセビーリャからは、ワインや魚が届いた
* **着るもの**：工場で同じ形の服が大量に作られ、大きな店で売られた
* **仕事**：ワセトとティニスの工場で働く者、学びの作業場で試みを重ねる者、鉄の車や鋼の戦船の兵、大筒を鋳る炉で働く者。国が富を出して大工事を進め、働き口が作られた。古代の遺跡を掘り、古い品から自分たちの昔を調べる者も現れた
* **家と人々**：いくさの中で、人々は自分たちをケメットの民として強く思うようになった。世の仕組みを改め、暮らしをよくしていこうとする考えが広まった
* **楽しみ**：イプの芸術の宮では芝居や絵が見られ、各地の声の館は、いくさの報せと歌を町じゅうに送った
* **学び**：空を飛ぶ機械と、数を速く計算する機械が作られた
* **いくさ**：セケト・アアルのスウェネトはソンガイの兵に攻められ、町を開きに向かう家族たちも襲われた。ジャネトは最後まで落ちなかった

## 通史で見る移り変わり

### 人の数と町

* ワセトの一つの村から、古代の終わりには七つの町、探検の時代の終わりには十二の町、近代の終わりには二十一の町になった
* タメン人の数は、町の記録で見ると、探検の時代のうちに古代の終わりの倍に、近代の終わりには古代の終わりの三倍ほどになった
* 古代の人々は、皆が顔を知る村に住んだ。近代の人々は、何階もある長屋に、見知らぬ者どうしで住んだ

### 住まい

| 時代 | 住まいのようす |
|---|---|
| 村の時代 | 泥と葦の小さな家 |
| 墓山〜青銅の時代 | 日干しレンガの家。石膏で白く塗る |
| 法〜疫病の時代 | 町に灯台、もてなしの館、市場、浴場、水路 |
| マアトの時代 | 石の館に家のしるし。屋根のある市、旅の宿、組合の館。城と牢 |
| 帆船の時代 | 港町の造船所と埠頭。閉ざされた宮 |
| 神の地〜光の時代 | 城壁で囲まれた町。海の向こうの町 |
| 近代の時代 | 鉄の道の駅、港、長屋、大きな店、町の庭 |

住まいは、**家族の家 → 町の中の家 → 城壁の内の家 → 長屋の一間**と移り、時代が下るほど、人は大きな町の中で混み合って住むようになった。

### 食べ物

* 麦、ナツメヤシ、魚は、どの時代にも変わらなかった
* 加わった食べ物：パンと麦の酒、塩漬けの魚、チーズ（墓山の時代）→ 米、マンゴー（法の時代）→ ワイン（疫病の時代）→ 鯨、香辛料、ウミガメ（マアトの時代）→ 砂糖（神の地の時代）→ 遠くの町の食べ物を店で買う（近代の時代）
* 食べ物の手に入れ方は、**自分で作る → 集まりの倉から受け取る → 市場で買う → 店で買う**と移った
* 不作や水害のときに倉から配る仕組みは、古代から近代まで続いた

### 着るもの

* 獣の皮と亜麻（村の時代）→ 綿と染めた布（青銅の時代）→ 絹と真珠（法の時代）→ 象牙、ルビー、銀の飾り（疫病の時代）→ 家のしるしを染め抜いた布（マアトの時代）→ 機械で織った安い布（火の釜の時代）→ 工場で作った同じ形の服（いくさの時代）
* 古代から探検の時代までは、着るものが**家と身分を表す**ものだった。近代には、工場の服が広まり、着るもので身分を見分けにくくなった、とする

### 仕事

| 時代 | 新しく増えた仕事 |
|---|---|
| 村の時代 | 畑・漁・家畜のかけもち、道具作りの家 |
| 墓山〜青銅の時代 | 大工事の働き手、書く者、倉を仕切る者、職人 |
| 法の時代 | 生まれた家の務めを継ぐ。町ごとに兵を出す |
| 疫病の時代 | 商人、数を扱う者、病の手当てをする者 |
| マアトの時代 | 組合の職人、旅の宿の主、雇われる兵、教えを説く者 |
| 帆船の時代 | 船乗り、船大工、役人、遠い都に置かれる使い、訳す者 |
| 神の地〜光の時代 | 海の向こうの畑で働く者、宝の船団の船乗り、両替の館の者、自ら耕す者 |
| 近代の時代 | 鉄の炉と工場の働き手、鉄の道の者、燃える水をくむ者、学びの作業場の者、兵 |

古代の法の時代には、人は生まれた家の務めを継いだ。探検の時代には、富によって、近代の時代には、どこで働くかによって、暮らしが分かれるようになった。

### 家と身分と政

* **古代**：家の長たちの集まりが治め、人は家に属した。法の時代に、生まれた家の務めを継ぐ定めと、町の一員の定めができた
* **探検の時代**：生まれよりも富で人が分けられ、その身分は町の記録に書き分けられた。富める家々と町衆が力を持った
* **近代の時代**：家の長の一人が王になり、富める家々は集まりの席を失った。町の一員は、民の集まりに出る者を選ぶようになり、誰でも思うことを書き、語ってよいとされた

古代の法の時代に「町の一員」と定められた人々は、二千五百年あまりたって、国の政に加わる者を選ぶ人々になった。

### お金と商い

* 品物と品物の交換（村の時代）→ 秤で量る（墓山の時代）→ 硬貨と市場（疫病の時代）→ 屋根のある市、組合、重商主義（マアトの時代）→ 両替の館（神の地の時代）→ 金を拠りどころとする通貨、大きな店（近代の時代）
* 富める家々は、探検の時代から近代の時代まで、富で町々の建物を買いそろえる力を持ち続けた

### 学びと読み書き

* 星を見て増水を知る（村の時代）→ 文字は書く者のもの（墓山の時代）→ 読み書きが家の長や商人、神官に広まる（疫病の時代）→ 誰もが教えの書を読むべき（マアトの時代）→ 町の一員が政に加わる者を選ぶ（近代の時代）
* 学びの場は、書の蔵、学びの館、書の大館、学舎、知恵の館、ワセトの大学、学びの作業場と、途切れずに続いた
* 人々が受け取る知らせは、口伝え → 書き物 → 線なしで送られる声と移った

### 祈りと教え

* **古代**：イメル、ハピ、アヌビス、アメン・ラーなどの神々。死者は品を添えて葬られ、冥界ドゥアトの富が信じられた
* **探検の時代**：マアトの教えが生まれ、正しい行いで世を繕うことが説かれた。教えの改めのあと、神殿に富を納めるより一人ひとりの行いが重んじられた。光の時代には、教えをめぐって家々が分かれ、争った
* **近代の時代**：王が太陽の神の名のもとに国を治める一方で、暮らしの多くは、工場と鉄の道と学びによって動くようになった

### 病と命

* 疫病の時代に、病の兆しを見分ける者と浴場が置かれた
* 神の地の時代に病人の家ができ、光の時代には腹の病に効く薬が作られた
* 近代の時代には、湯の館と町の庭が生まれ、暮らしの豊かさが測られ、暮らしをよくしていこうとする考えが広まった

### 楽しみ

* 大祭（墓山の時代〜）、競技と芝居（法の時代〜）、書かれた物語と歌（疫病の時代〜）、組合の祭り（マアトの時代〜）、珍獣の園と見晴らしの館（帆船の時代〜）、館に飾られた絵や像（神の地の時代〜）、湯の館と声の館（鉄の道の時代〜）、芸術の宮（いくさの時代）
* 古代の楽しみは、集まりや富める家々が開く**祭り**が中心だった。近代には、町の人々がそれぞれに楽しむ**館や声**が加わった

### 旅と運ぶこと

* 歩いて草場を移る、葦の舟（村の時代）→ むしろの帆、荷車、沖へ出る舟（墓山〜青銅の時代）→ 大きな帆船、世界をめぐる船（帆船の時代）→ 宝の船団（神の地の時代）→ 鉄の道、火の釜の船（近代の時代）→ 空を飛ぶ機械（いくさの時代）
* 古代の人々にとって、遠い流域は何年もかけて旅する所だった。近代の人々にとって、海の向こうの大陸は、家族で渡って住む所になった

### 災いと暮らし

* アヘル河の大水は、ワセトの近くで、古代に二度、探検の時代に一度、近代の時代にも一度起きた。そのたびに、倉の穀物と富める家々の富で、舟や家が直された
* ハウネ山とシナブン山は、古代から近代まで火を噴き続けた。ペル・アトゥムの人々は、シナブン山の近くを離れなかった
* 疫病は、古代の終わりに遠い国々で広がったが、タメン人の町では大きく広がらなかった
* 近代の時代には、竜巻や激しい雷雨という新しい災いが記録された

### いくさと暮らし

* 古代から探検の時代の終わりまで、五千年あまり、大きな国とのいくさはなかった。いくさは、海辺の町や海の向こうの町を襲う人々との小さな戦いだけだった
* それでも、兵は常に置かれ、探検の時代の終わりには、本国の町々は城壁で囲まれた
* 近代の終わりに、初めて大きないくさが暮らしに入り込んだ。ジャネトの人々は大筒の音の中で暮らし、セケト・アアルの町は攻められ、工場は大筒や戦船を作った

## ワセトの一つの家でたどると

最後に、ワセトの漁師の家が、時代ごとにどう暮らしたかを、推し量ってたどる。

* **前4000年頃（村の時代）**：家族は葦の舟で網を打ち、増水が引くと泥に麦をまき、家畜を草場へ連れていった。捕った魚の一部は、イメルの祠に供えた
* **前1600年頃（法の時代）**：家は「漁師の家」と町の記録に載り、子は漁師の務めを継いだ。不作の年には、倉の穀物を受け取った。祖先に供え物を運び、大競技場の見世物を見に行った
* **前200年頃（マアトの時代）**：家の者の一人は船大工の組合に入った。家族はマアトの教えの神殿に通い、教えの書を読めるようになった。富める家々から借りた舟で漁をし、借り賃を納めた
* **100年頃（帆船の時代）**：家の若者は大きな帆船の船乗りになり、遠い国々の話を持ち帰った。家族の一部は、海の向こうに町を開く一行に加わった
* **840年頃（いくさの時代）**：家の者は工場に勤め、長屋に住み、大きな店で服を買った。民の集まりに出る者を選び、声の館から流れるいくさの報せを聞いた。それでも、増水の季節アケトには、家族でアヘル河の祭りに出かけた
