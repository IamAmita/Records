**トンレ・サン川（トンレサップ川、Tonlé Sap River）**は、**カンボジア**にある全長約147kmの川で、トンレサップ湖とメコン川を結んでいる。世界でも珍しい**季節によって流れる向きが逆転する川**として知られている。

### 基本情報

* **所在地**：カンボジア
* **全長**：約147km
* **上流**：トンレサップ湖
* **下流**：メコン川（首都プノンペン付近で合流）

### 最大の特徴：流れが逆転する

トンレ・サン川最大の特徴は、**年に2回、流れる方向が変わる**ことだ。

#### 乾季（11～5月ごろ）

```
トンレサップ湖
        ↓
  トンレ・サン川
        ↓
     メコン川
```

湖の水がメコン川へ流れ出す。

#### 雨季（5～10月ごろ）

```
メコン川
    ↑
トンレ・サン川
    ↑
トンレサップ湖
```

モンスーンで増水したメコン川の水位が湖より高くなるため、水が逆流して湖へ流れ込む。

### トンレサップ湖への影響

雨季に逆流した水によって、トンレサップ湖は劇的に拡大する。

* 面積：約2,700km² → 最大約16,000km²
* 水深：約1m → 約10m

この大規模な氾濫が魚の産卵・成長に最適な環境をつくり、トンレサップ湖は**世界有数の豊かな内水面漁業**を支えている。

### 人々の暮らし

トンレ・サン川とトンレサップ湖の周辺では、水位の大きな変化に合わせて、

* 水上集落
* 高床式住宅
* 漁業
* 水運

が発達している。人々の生活は、この川の「逆流するリズム」に合わせて営まれている。

### 地理で重要なポイント

* カンボジアにある川。
* **トンレサップ湖とメコン川を結ぶ。**
* **雨季に流れが逆転する世界的にも珍しい河川。**
* 逆流によってトンレサップ湖が大きく広がり、豊かな漁場を形成する。
