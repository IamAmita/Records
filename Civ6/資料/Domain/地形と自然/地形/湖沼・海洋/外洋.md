**外洋（がいよう）**とは、**大陸や島から離れた、広く開けた海域**のことをいう。

英語では **Open Ocean** や **High Seas**（文脈による）と表現される。

---

## 外洋の特徴

外洋には次のような特徴がある。

* 陸地がほとんど見えない。
* 水深が非常に深い（数千メートルになることも多い）。
* 波やうねりが大きい。
* 潮流や海流の影響を強く受ける。
* 天候が急変しやすい。

沿岸とは環境が大きく異なるため、航海には高度な技術が必要となる。

---

## 沿岸との違い

| 外洋        | 沿岸          |
| --------- | ----------- |
| 陸から遠い     | 陸に近い        |
| 水深が深い     | 比較的浅い       |
| 波が大きい     | 波が穏やかなことが多い |
| 海流の影響が大きい | 地形の影響を受けやすい |
| 長距離航海が中心  | 漁業や港湾利用が中心  |

---

## 外洋航海

大航海時代（15～17世紀）には、ヨーロッパの航海者たちが外洋を横断する技術を発展させた。

例えば、

* クリストファー・コロンブスは大西洋を横断した。
* ヴァスコ・ダ・ガマはアフリカ南端を回ってインドへ到達した。
* フェルディナンド・マゼランの艦隊は世界一周を達成した。

外洋では陸地を目印にできないため、

* 太陽や星の位置
* 羅針盤
* 海図
* 海流や風向き

などを利用して航海した。

---

## 外洋に生息する生物

外洋には、

* マグロ
* カツオ
* サメ
* クジラ
* イルカ
* マンボウ

などが生息している。

また、表層だけでなく数千メートルの深海にも、多様な生物が暮らしている。

---

## 現代の外洋

現在では、

* 大型コンテナ船
* タンカー
* 客船
* 調査船
* 海洋観測ブイ

などが外洋を航行・利用している。

GPSや人工衛星による航法、気象予報の発達により航海の安全性は大きく向上したが、台風やハリケーン、高波などの自然条件には依然として注意が必要である。

---

## 外洋と公海の違い

「外洋」と「公海」は混同されることがあるが、意味は異なる。

| 外洋         | 公海                          |
| ---------- | --------------------------- |
| 地理的な概念     | 法律上の概念                      |
| 陸から離れた広い海域 | どの国の領海・排他的経済水域（EEZ）にも属さない海域 |
| EEZ内の外洋も含む | 必ずしも「外洋」と一致しない              |

つまり、**外洋は海の地理的な呼び方**、**公海は国際法上の区分**であり、両者は重なる部分もあるが同じ意味ではない。
