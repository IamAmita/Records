# イーリアス

『**イーリアス（Iliad / Ἰλιάς）**』は、**古代ギリシアを代表する叙事詩**。伝統的には紀元前8世紀ごろの詩人Homer（ホメロス）の作品とされている。

### 何を描いた作品なのか

舞台は、有名な**トロイア戦争**。

ギリシア諸勢力が海を渡って小アジアの都市**トロイア（イーリオス）**を攻めたという伝説を背景にしている。

ただし、『イーリアス』は**トロイア戦争の最初から最後までを描いた物語ではない**。10年に及ぶとされる戦争の最終盤、そのうち**ごく短い期間**に焦点を当てている。

物語の中心にいるのが、ギリシア側最強の英雄**アキレウス**。

ギリシア軍の総大将アガメムノンとアキレウスが対立し、怒ったアキレウスが戦闘を拒否する。彼が抜けたことでギリシア軍は苦戦し、やがて親友パトロクロスがトロイアの英雄**ヘクトル**に殺される。

ここからアキレウスは復讐のため戦場へ戻り、ヘクトルと対決する。

つまり作品を貫いている最大のテーマは、冒頭から示される**「アキレウスの怒り」**なんだ。

### 「トロイの木馬」は出てこない

意外と重要なのがこれ。

トロイア戦争といえば、

**巨大な木馬にギリシア兵が隠れる
→ トロイア人が城内へ運び込む
→ 夜中に兵士が出てきて城門を開く
→ トロイア陥落**

という「トロイの木馬」が有名だけど、**『イーリアス』本編にはこの場面はない**。

『イーリアス』はヘクトルの死後、その葬儀までで終わる。トロイアそのものはまだ陥落していない。

木馬については、同じくホメロス作とされる『**オデュッセイア**』など、別の古代文献で言及されている。

### 神々も普通に戦争へ介入する

『イーリアス』の世界では、人間だけで戦争をしているわけじゃない。

ゼウス、アテナ、アポロン、アフロディテ、ヘラ、ポセイドンなどの**オリュンポスの神々が、それぞれギリシア側・トロイア側に肩入れする**。

神が兵士を助けたり、攻撃を妨害したり、別の神と争ったりする。

だから『イーリアス』は、単なる歴史的な戦争物語というより、

**英雄の名誉・怒り・死・運命 ＋ 神々の意志**

によって展開する神話的な英雄叙事詩になっている。

### 名前の意味

「イーリアス（Ἰλιάς）」は、トロイアの別名である**イーリオス（Ἴλιος / Ilios）**に由来する。

大まかには、

**「イーリオスについての物語」
＝「トロイアの物語」**

という意味。

そして『イーリアス』と『オデュッセイア』は、後世のヨーロッパ文学にとてつもなく大きな影響を与えた。英雄叙事詩というジャンルを考えるうえで、ほぼ原点級の作品だよ。
