**ティワナク（Tiwanaku／Tiahuanaco）**とは、**現在のボリビア西部、チチカカ湖の南東に存在した古代都市、およびその都市を中心に発展したアンデス文明**のことである。

インカ帝国より数百年以上前に繁栄した文明で、最盛期には現在の**ボリビア・ペルー・チリなど南部アンデス一帯に大きな影響力を持っていた**。現在残るティワナク遺跡は、2000年に「ティワナク：ティワナク文化の宗教的・政治的中心地」として世界遺産になっている。

## どんな文明だったのか

まず時代関係をざっくり並べると、

**ティワナク → その後のアンデス諸勢力 → インカ帝国 → スペイン征服**

という位置になる。

ティワナク遺跡の年代については研究史上かなり変遷がある。古い資料では紀元前1500年ごろまで遡るという説もあったが、現在ではその年代測定の信頼性に疑問が呈されている。近年の放射性炭素年代の再検討では、ティワナクの都市的集落の成立を**紀元1世紀～2世紀ごろ**とする推定も出ている。

一方、UNESCOでは、小規模な集落から発展して**西暦400～900年ごろに計画都市として繁栄し、特に500～900年ごろが最盛期**だったとしている。

つまり、細かい成立年代には議論があるものの、

**「紀元1千年紀の前半から急速に成長し、500～900年ごろ南部アンデスを代表する大都市・政治勢力になった」**

というところは押さえておけばよい。

## 場所がかなり特殊

ティワナクがあるのは、現在のボリビアのラパス県。

チチカカ湖の南岸付近に位置していて、標高はなんと**約3,850m**。富士山山頂より高い場所に大規模な都市文明が成立していたことになる。

しかも、この地域は寒冷で農業条件が決して良くない。

そこでティワナクでは、土地を盛り上げ、その周囲に水路を設ける**盛畑（raised fields、現地ではスカ・コリュ／suka kolluなど）**を大規模に利用した。

水路は灌漑だけでなく、昼間に太陽熱を蓄えて夜間の冷え込みを緩和するなど、高地農業に適した環境を作る役割もあったと考えられている。

UNESCOによれば、ティワナク周辺には非常に広範囲にこうした農耕地の痕跡が存在する。こうした農業技術が、大都市人口を支える経済基盤の一つになった。

## 「帝国」だったのか？

ここはティワナクを理解するときに面白いところである。

昔は、

**「ティワナク帝国が軍事力で周辺地域を征服した」**

というイメージで説明されることも多かった。

実際、UNESCOも便宜上「empire（帝国）」という言葉を使用していて、南部アンデスの広大な地域に影響を及ぼした強力な政治勢力だったとしている。

ただし、古代ローマや後のインカ帝国のような**中央集権的な領土国家だったのかについては議論がある**。

考古学的にはティワナク式の

* 土器
* 宗教的図像
* 建築
* 儀礼
* 農業技術

などが広大な範囲に広がっている。

一方で、それがすべて「ティワナク軍が征服した領土」を意味するわけではない。

植民拠点を作ったり、交易ネットワークを構築したり、宗教的権威を利用したり、現地社会と政治的関係を結んだりすることで影響力を拡大した可能性もある。

ティワナク国家を**中央官僚制による国家と考えるべきなのか、ある程度自治的な共同体の連合として考えるべきなのか議論が続いている**。

だから「ティワナク帝国」という名前だけから、インカ帝国のような国家を想像しない方がよい。

## ティワナクの巨大建築

ティワナクが特に有名なのが石造建築である。

代表的なのが、

**アカパナ（Akapana）**
巨大な階段状の基壇。宗教的・儀礼的な中心施設だったと考えられている。

**カラササヤ（Kalasasaya）**
巨大な石を使った方形の儀礼施設。

**半地下神殿（Semi-subterranean Temple）**
地面より低い位置に作られた神殿。壁面には多数の人間の頭部を表現した石彫が埋め込まれている。

**プマ・プンク（Pumapunku）**
非常に精密に加工された巨大石材で有名な建築複合体。

そして一番有名なのが、

**「太陽の門（Gateway of the Sun）」**である。

一枚の巨大な安山岩から作られた石門で、上部中央には杖のようなものを両手に持った神格が彫刻されている。その周囲には翼を持った人物などが並ぶ。

この中央神は一般に**「杖を持つ神（Staff God）」**などと呼ばれる。

UNESCOでは、このレリーフについて農業暦を表現したものという解釈も紹介している。

この図像はティワナクだけにとどまらず、アンデス世界の宗教美術を考えるうえでかなり重要になる。

## プマ・プンクの「謎」

ティワナクを調べると、たぶんかなり高確率でプマ・プンクについて、

「現代技術でも困難な精度」

「レーザー加工されたような石」

「古代人には加工不可能」

「宇宙人が建設した」

みたいな話に遭遇する。

ただ、これは考古学的な説明とはかなり違う。

ティワナク人が**非常に高度な石材加工技術を持っていたこと自体は事実**である。UNESCOも、異なる種類の石を正確に切削・研磨する技術を特筆している。

でも、「当時の人間には加工できなかった」という証拠があるわけではない。

むしろ石工たちが研磨、打撃、測定などを組み合わせて高精度な部材を製作したと考えるのが考古学的な立場になる。

## ワリとの関係

同じころ、現在のペルーでは**ワリ（Wari／Huari）文化**が発展していた。

だいたい西暦600～1000年ごろなので、ティワナクとかなり時期が重なる。

両者は似た宗教的図像を持っていて、特に「杖を持つ神」のモチーフなどに共通性がある。

ただし、

**「ワリ＝ティワナク帝国の一部」**

という単純な関係ではない。

基本的には、

> ティワナク
> → チチカカ湖周辺～南部アンデスを中心とする勢力
>
> ワリ
> → 現在のペルー中部を中心とする勢力

という、**同時代に存在した二つの大きなアンデス文明圏**として考える方がよい。

## そして衰退する

ティワナクの政治的影響力はおおむね**11世紀ごろから衰退**し、UNESCOでは12世紀前半までに政治体制が崩壊したとしている。

原因は完全には確定していない。

有力な要素の一つが**乾燥化・干ばつ**である。

ティワナクは高地農業を支える高度な農業システムを構築していた反面、水環境の変化には影響を受ける。気候が乾燥化すると農業生産が低下し、それによって都市人口や政治体制を維持できなくなった可能性がある。崩壊期の乾燥化を示す研究も紹介されている。

ただし「大干ばつ一発で文明が滅亡した」というほど単純ではなく、政治構造・社会変動などを含めて現在も研究されている。

## インカとの関係が面白い

ティワナクが衰退してから数百年後、15世紀になると**インカ帝国**がこの地域を支配する。

その頃にはティワナクを建設した政治体制そのものはすでに存在していなかった。

つまり、**インカ人にとってもティワナクは「昔の人が作った謎の巨大遺跡」だった**。

そしてインカはティワナクを非常に重要な聖地として扱った。

これはティワナクの歴史でかなり面白いところで、

**ティワナク文明 → 崩壊 → 数百年経過 → インカが遺跡を発見・聖地化**

という時間関係になる。

なので、よくある「インカ文明のティワナク遺跡」という表現は正確ではない。ティワナクは**インカ以前（Pre-Inca）の文明**である。

## 時系列

| 時期             | ティワナク               |
| -------------- | ------------------- |
| 紀元1～2世紀ごろ      | 現在の研究では初期集落成立の有力年代  |
| 4～5世紀ごろ        | 都市として大きく発展          |
| **500～900年ごろ** | **最盛期**             |
| 600～1000年ごろ    | 南部アンデス各地へ強い文化・政治的影響 |
| 11世紀ごろ         | 政治的影響力が衰退           |
| 12世紀前半まで       | ティワナク政治体制が崩壊        |
| 15世紀           | インカ帝国がこの地域を支配       |
| 16世紀           | スペイン人が遺跡を記録         |
| 2000年          | 世界遺産登録              |

なお、年代について古い資料と現在の研究でかなり数字が違うのは、**ティワナク研究では年代測定が大きく更新されてきた**ためである。古い文献にある「紀元前1500年ごろ成立」をそのまま確定事項として扱うのは注意が必要。

## まとめ

ティワナクを一言で位置づけるなら、**「インカよりはるか以前、チチカカ湖周辺を中心として南部アンデスに広大な文化的・政治的影響を与えた、高地都市文明」**になる。
