# ハワイ

**ハワイ（Hawaiʻi）**とは、太平洋のほぼ中央に位置する**ハワイ諸島と、そこにあるアメリカ合衆国のハワイ州**を指す言葉である。

## 概要

* **位置**：太平洋のほぼ中央
* **主要な島**：ハワイ島、マウイ島、オアフ島、カウアイ島、モロカイ島など
* **州都**：ホノルル（オアフ島）
* **先住文化**：ポリネシア文化圏
* **成り立ち**：火山（ホットスポット）によって形成された島々

ハワイ諸島には多数の島があるが、主要な島としてハワイ島、マウイ島、オアフ島、カウアイ島、モロカイ島などがある。州都ホノルルがあるのはオアフ島である。

## どうやってできたのか

ハワイ諸島は基本的に**火山によってできた島々**である。

太平洋プレートの下には「**ホットスポット**」と呼ばれる、マグマが上昇してくる場所がある。プレートがその上を移動していくことで、長い時間をかけて次々と火山島が形成された。

**火山ができる → プレートが移動する → 古い火山がホットスポットから離れる → 別の場所に新しい火山ができる**

という過程で、島が列をなしている。現在でもハワイ島には**キラウエア**や**マウナ・ロア**といった非常に大きな活火山がある。

## 人間はどこから来たのか

もともとのハワイ人は**ポリネシア人**である。

ハワイは大陸から数千kmも離れているが、ポリネシア人は高度な航海技術を持っていて、星・太陽・波・風・鳥などを手掛かりにカヌーで太平洋を航海した。おおむね西暦1000年前後までにはポリネシア人がハワイに定住していたと考えられている。

だからハワイの先住文化は、タヒチ、サモア、トンガなどと同じ**ポリネシア文化圏**に属する。ポリネシア神話の英雄[マウイ](../../../偉人/マウイ.md)などの伝承も、この文化圏で広く共有されている。

## ハワイ王国

長い間、島ごとに複数の首長勢力が存在していたが、18世紀末になると**カメハメハ1世**が台頭する。

カメハメハ1世は戦争と外交によってハワイ諸島の大部分を統一し、**1810年までにハワイ王国を成立させた**。その後、ハワイ王国は欧米諸国と外交・交易を行う近代国家になっていく。初期にはマウイ島の[ラハイナ](ラハイナ.md)が事実上の首都となり、1845年に首都機能がオアフ島のホノルルへ移された。

ところが19世紀になると、特にアメリカ系の入植者・実業家の影響力が強くなる。砂糖産業などを背景として政治への介入も進み、**1893年にリリウオカラニ女王が廃位され、ハワイ王国は崩壊**した。

その後は、

**ハワイ王国 → ハワイ共和国 → アメリカによる併合（1898年） → ハワイ準州 → 1959年にアメリカ50番目の州**

という経緯をたどって現在に至る。

## ハワイの重要な特徴

ハワイを理解するときに面白いのが、その**地理的な孤立性**である。

ハワイは北米大陸からもアジアからも非常に離れている。そのため独特な生態系やポリネシア文化が発達した一方で、太平洋のほぼ中央という位置から、近代以降は**太平洋航路・軍事上の重要拠点**にもなった。特にオアフ島の**真珠湾（パールハーバー）**はアメリカ海軍の重要拠点として知られている。

## まとめ

歴史・文明として見るなら、

**「ポリネシア人が太平洋航海によって築いた島嶼社会 → カメハメハによる統一王国 → 欧米との交易とアメリカ勢力の拡大 → アメリカ合衆国の州」**

という流れを押さえると、ハワイがどういう地域なのかかなり理解しやすい。
