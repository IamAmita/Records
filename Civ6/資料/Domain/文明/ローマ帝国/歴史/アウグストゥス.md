# アウグストゥス

**アウグストゥス（Augustus、紀元前63年9月23日～紀元14年8月19日）**は、一般に**[ローマ帝国](ローマ帝国.md)の初代皇帝**とされる人物である。本名はもともと**ガイウス・オクタウィウス**。カエサルの養子・後継者となったことで権力闘争に入り、最終的にローマ世界の単独支配者となった。

アウグストゥスの重要性は単に「初代皇帝だった」というより、**共和政を表向き維持したまま、実質的な皇帝政治を成立させたこと**にある。

## 概要

* **生没年**：紀元前63年～紀元14年
* **本名**：ガイウス・オクタウィウス（後にオクタウィアヌスと呼ばれる）
* **在位**：紀元前27年1月16日～紀元14年8月19日
* **確立した政治体制**：プリンキパトゥス（元首政）
* **称号**：Augustus（尊厳ある者）、princeps（第一人者）

## 何をした人物なのか

一言でいうなら、

> **内戦でバラバラになったローマを統一し、共和政の制度を残しながら、自分に権力を集中させてローマ帝国の政治体制を作った人物**

である。

アウグストゥス以前のローマは「ローマ共和国（[共和政](../../../../Common/制度/統治・行政/共和制.md)ローマ）」だった。ところが紀元前1世紀になると、マリウスとスッラ、ポンペイウスとカエサル、そしてカエサル暗殺後の内戦と、巨大な軍事力を持った有力者同士の争いが続く。その最終的な勝者になったのがアウグストゥスだった。

## カエサルとの関係

アウグストゥスは最初から「アウグストゥス」という名前だったわけではない。生まれたときは**ガイウス・オクタウィウス（Gaius Octavius）**という名前だった。

母方の大叔父が、あの**ガイウス・ユリウス・カエサル**（著作に[『ガリア戦記』](ガリア戦記.md)がある）である。カエサルが紀元前44年に暗殺されたあと、遺言が開封されると、当時18歳だったオクタウィウスが**カエサルの養子・相続人**に指定されていた。

そのためオクタウィウスはカエサルの名を継承する。後世では、カエサル本人との混同を避けるため、この時期の彼を普通、**オクタウィアヌス（Octavian）**と呼ぶ。ただし「Octavian」は後世の歴史学で使われる便宜的な呼称に近い。

## カエサル暗殺後の内戦

カエサルが暗殺されたからといって共和政が平和に復活したわけではない。むしろ、

**「カエサル亡き後、誰がローマを支配するのか」**

という巨大な権力闘争が始まった。そこで中心人物になったのが、

* オクタウィアヌス
* マルクス・アントニウス
* マルクス・アエミリウス・レピドゥス

の3人である。彼らは**第二回三頭政治**を成立させる。最初は協力してカエサル暗殺派を倒したものの、その後は仲間割れする。レピドゥスは失脚。最後に残ったのが、**オクタウィアヌス vs アントニウス**だった。

## アクティウムの海戦

決定的だったのが**紀元前31年のアクティウムの海戦**である。

アントニウスはエジプト女王**クレオパトラ7世**と同盟関係にあり、オクタウィアヌス陣営と戦った。結果はオクタウィアヌスの勝利。翌紀元前30年にはアントニウスとクレオパトラが自殺し、エジプトもオクタウィアヌスの支配下に入る。これによってオクタウィアヌスに対抗できる勢力はほぼ消滅し、事実上の単独支配者になった。

## なぜ「皇帝」になったのか

ここがアウグストゥスを理解するうえで一番面白いところである。

実は、**「共和政を廃止して、今日から皇帝だ」**とはやっていない。むしろ逆で、アウグストゥスは**「共和政を復興しました」**という建前を非常に重視した。なぜなら、養父カエサルが独裁的な権力を持った結果、暗殺されているからである。ローマ人には「王」に対する強烈な拒否感もあった。

だからアウグストゥスは王になるのではなく、**共和政の制度の中に自分の権力を埋め込んだ**。

### 紀元前27年――「アウグストゥス」になる

紀元前27年、オクタウィアヌスは元老院から**Augustus（アウグストゥス）**という尊称を与えられる。意味としては「尊厳ある者」「尊崇すべき者」といったニュアンスである。

これが伝統的に、**ローマ帝国の成立**、そして**アウグストゥスの初代皇帝即位**とされるポイントである。在位は通常、紀元前27年1月16日～紀元14年8月19日とされる。

## 「皇帝」という役職ができたわけではない

アウグストゥスは「皇帝」という新しい公職を作って就任したわけではない。むしろ、**共和政時代から存在していた複数の権限を一人で握った**。

たとえば、軍隊を指揮する権限、属州を統治する権限、護民官的な権限、元老院における特別な地位、宗教上の最高権威など。こうした権限を組み合わせることで、**法律上は共和政なのに、実際にはアウグストゥスが国家の頂点**という状態を作った。

だから彼は自分を露骨に「王」とは呼ばず、**princeps（プリンケプス）＝「第一人者」「第一市民」**という立場を強調した。

## プリンキパトゥス

このアウグストゥスが作った政治体制を、**プリンキパトゥス（Principate／元首政）**という。つまり、

* **表向き** → 共和政。元老院も執政官も存在する。
* **実態** → アウグストゥスが軍事・政治・宗教などの巨大な権力を握っている。

という二重構造である。だから「アウグストゥス＝絶対君主」と考えると少し違う。**「共和政の第一人者」という形式を利用して実質的な君主になった**というのがポイントである。

## なぜ回りくどいことをしたのか

最大の理由は**カエサルの失敗を見ていたから**と考えると分かりやすい。

カエサルは「終身独裁官」となり、権力を露骨に集中させた。その結果、「王になるつもりでは？」という疑念を持たれ、紀元前44年に暗殺された。

アウグストゥスは同じ轍を踏まなかった。「王ではない」「独裁官ではない」「共和政は存続している」「私はその中で最も権威ある市民にすぎない」という形を取った。でも実際には軍事力を背景として国家の頂点にいる。この**「共和政を壊すのではなく、共和政の制度を利用して帝政へ移行する」**というやり方が非常に重要である。

## アウグストゥスの統治

アウグストゥスは単に内戦に勝っただけではなく、**約40年間にわたってこの新体制を安定させた**。ここがカエサルとの大きな違いである。

その間に行政制度、属州統治、軍事制度、税制などを整備し、内戦後のローマ世界を安定させていった。その結果、後に**Pax Romana（パクス・ロマーナ／ローマの平和）**と呼ばれる長期的な安定の基礎が作られた。

## 名前から皇帝称号へ

もともと「Augustus」はオクタウィアヌス個人に与えられた尊称だった。ところが彼があまりにも「皇帝」という地位そのものを確立したため、後の皇帝たちも**Augustus**を名乗るようになる。

同じように、**Caesar（カエサル）**も個人名・家名から皇帝の称号へ変化していく。なので後世の「カイザー（Kaiser）」や「ツァーリ（Tsar）」もCaesarに由来する。

## 『神君アウグストゥス業績録』

アウグストゥスの自己イメージを知るうえで重要な史料が、**『神君アウグストゥス業績録（Res Gestae Divi Augusti）』**である。

アウグストゥス自身が自分の政治的経歴や功績をまとめさせたもので、死後、霊廟入口の青銅板に刻むことを望んでいた。ローマにあった原版は失われたが、小アジアで碑文の写しが発見されているため、現在でもかなり内容が分かっている。

ここでも彼の自己イメージは、「共和政を破壊して皇帝になった人物」ではなく、**「内乱を終わらせ、国家を共和政に返還し、ローマから最高の栄誉を受けた人物」**というものである。

## カエサルとアウグストゥスの違い

| | カエサル | アウグストゥス |
| --- | --- | --- |
| 時代 | 共和政末期 | 共和政末期～帝政初期 |
| 権力 | 独裁官 | プリンケプス |
| 王になったか | ならなかった | ならなかった |
| 皇帝扱い | 通常は皇帝に数えない | **初代皇帝** |
| 権力集中 | 非常に露骨 | 共和政制度の中に組み込む |
| 最期 | 暗殺 | 自然死とされる |
| 最大の歴史的役割 | 共和政崩壊を決定的に進める | **帝政を安定した制度として確立** |

だから、**「カエサルが共和政を壊し、アウグストゥスが帝政を作った」**くらいに覚えておくと、最初はかなり理解しやすい。

ただ厳密にはアウグストゥス自身も「共和政を廃止して帝政を創設した」と宣言したわけではない。この曖昧さこそ、初期ローマ帝政の特徴である。そしてこの**「共和政なのに実質的には皇帝が支配している」プリンキパトゥスという仕組み**が、その後約300年にわたるローマ帝国前期の政治体制につながっていく。
