# アジャンクール

**アジャンクール（Azincourt / Agincourt）**は、フランス北部にある小さな村である。

歴史上ものすごく有名なのは、**1415年10月25日の「アジャンクールの戦い」**が行われた場所だからである。百年戦争を代表する戦いの一つで、**イングランド軍が数で優勢なフランス軍を破った**ことで知られている。

## 概要

* **所在地**：フランス北部
* **出来事**：アジャンクールの戦い（1415年10月25日）
* **戦った勢力**：イングランド王ヘンリー5世 vs. フランス王国の諸侯軍
* **背景**：百年戦争
* **結果**：イングランド軍の大勝

## アジャンクールの戦いとは

戦ったのは、

**イングランド王ヘンリー5世**
vs.
**フランス王国の諸侯軍**

だった。

ヘンリー5世率いるイングランド軍は、フランス遠征中に消耗していた。兵士は疲れており、病人も出ていて、しかもフランス軍の方が数的に優勢だったと考えられている。

普通に考えれば、

> 「フランス側が勝つだろう」

という状況だった。ところが結果は**イングランド軍の大勝**になった。

### なぜイングランド軍が勝ったのか

有名なのが**ロングボウ（長弓）兵**である。イングランド軍には大量の長弓兵がいた。一方、フランス側の主力には重装備の騎士・兵士がいた。

ただ、

> 「ロングボウがフランス騎士の鎧を簡単に貫通したから勝った」

と単純化するのは注意が必要である。アジャンクールでは**地形と泥濘**が極めて重要だった。

戦場は狭く、前後の雨で地面がぬかるんでいた。そこへ重い鎧を装備したフランス兵が大量に前進する。すると、

**狭い戦場＋泥＋密集した兵士＋イングランド長弓兵からの射撃**

という最悪の組み合わせになった。フランス軍は前へ進むだけでも消耗し、さらに後方から味方が押してくる。結果として陣形が崩壊した。

## ロングボウ兵は近接戦闘もした

「弓兵だから遠くから撃って終わり」ではない。フランス軍が接近して乱戦になると、イングランドの弓兵も剣や斧などを持って戦った。

重装備で泥の中を進んできたフランス兵に対して、比較的軽装のイングランド兵は動きやすかった。だから、

> **ロングボウによる射撃＋地形＋泥濘＋フランス軍の密集＋接近戦**

が組み合わさって、フランス側に壊滅的な損害が出た。

## フランス軍はなぜそんな戦い方をしたのか

当時のフランス貴族社会も関係している。戦争において、**騎士として直接戦うこと**には大きな名誉があった。

さらに多数の有力貴族が参加していたので、指揮系統も複雑だった。「誰が先陣を切るのか」「誰がどこで戦うのか」といった問題に、軍事合理性だけでなく**身分・名誉・政治的競争**まで絡んでくる。結果として、大量の兵士が狭い場所に集中してしまった。

これは中世戦争を見るうえで重要で、軍隊は現代のような完全に統一された国家組織ではない。**王＋大貴族＋その家臣＋各地から集められた兵士**という性格が強かった。

## ヘンリー5世

アジャンクールの勝利によって、ヘンリー5世はイングランド史上の英雄的な王の一人になった。

その後もフランスへの攻勢を続け、1420年には**トロワ条約**を結ぶ。これによってヘンリー5世はフランス王シャルル6世の娘カトリーヌと結婚し、

**ヘンリー5世とその子孫がフランス王位を継承する**

というところまで到達した。つまり一時期、

> **イングランド王家がフランス王位を獲得する寸前**

までいったのである。

ところがヘンリー5世は1422年に若くして死亡。その後、幼い**ヘンリー6世**が王になる。そしてフランス側には、後にあの**ジャンヌ・ダルク**が登場する。

## 百年戦争全体の流れ

| 年 | 出来事 |
| --- | --- |
| 1415年 | アジャンクールの戦い → ヘンリー5世大勝 |
| 1420年 | トロワ条約 → イングランド王家によるフランス王位継承が現実味を帯びる |
| 1422年 | ヘンリー5世死去 → 幼いヘンリー6世が継承 |
| 1429年 | ジャンヌ・ダルク登場 → フランス側が反撃 |
| 1453年ごろ | 百年戦争終結 → イングランドはフランス領のほとんどを失う |

## シェイクスピアでも有名

アジャンクールが現在まで有名なのは、軍事史だけが理由ではない。シェイクスピアの戯曲**『ヘンリー五世』**で劇的に描かれた。

特にアジャンクールの戦いの直前にヘンリー5世が兵士を鼓舞する**「聖クリスピンの日の演説」**が有名である。そのためイギリス文化ではアジャンクールは、

> **圧倒的不利な状況で少数の仲間が団結し、強大な敵を打ち破る**

という英雄物語の象徴にもなっている。ただし、史実とシェイクスピアによる英雄化は分けて考える必要がある。

## まとめ

世界史として押さえるなら、**アジャンクール＝百年戦争中の1415年、ヘンリー5世率いるイングランド軍がフランス軍に大勝した場所**で十分である。

そのうえで「ロングボウだけで勝ったのではなく、泥濘・狭い地形・フランス軍の密集と指揮上の問題が重なった」と理解すると、かなり実態に近くなる。
