# 国際河川

**国際河川**とは、**2か国以上の国に関係する河川**のことだ。

大きく分けると、次の2種類がある。

1. **複数の国を流れる河川**

   * 川が国境を越えて流れる。
   * 例：ライン川、ドナウ川、メコン川

2. **国境を形成する河川**

   * 川そのものが国境の一部になっている。
   * 例：リオ・グランデ川、アムール川

中には両方の性質を持つ河川もある。

### なぜ重要なのか

国際河川は、流域の国々が同じ水資源を利用するため、さまざまな問題や協力が生じる。

* **水資源の利用**

  * 飲料水
  * 農業用水
  * 工業用水

* **発電**

  * ダムや水力発電所の建設

* **航行**

  * 船舶による物流
  * 国際貿易

* **環境保全**

  * 水質汚染対策
  * 洪水対策
  * 生態系の保護

そのため、多くの国際河川では条約や国際委員会によって共同管理が行われている。

### 主な国際河川

| 河川    | 関係する国                      | 特徴             |
| ----- | -------------------------- | -------------- |
| ナイル川  | ウガンダ、南スーダン、スーダン、エジプトなど     | 水利用をめぐる国際問題が多い |
| ドナウ川  | ドイツ、オーストリア、ハンガリーなど10か国以上   | ヨーロッパ最大級の国際河川  |
| ライン川  | スイス、ドイツ、フランス、オランダなど        | ヨーロッパ有数の物流ルート  |
| メコン川  | 中国、ミャンマー、ラオス、タイ、カンボジア、ベトナム | 農業・漁業の生命線      |
| スヘルデ川 | フランス、ベルギー、オランダ             | 北海へ注ぐ重要な航路     |

### 「国際河川」と「越境河川」の違い

現在では、「**越境河川（transboundary river）**」という表現もよく使われる。意味はほぼ同じだが、国際機関や学術分野では、国境をまたぐ河川や流域全体を指す「越境河川」のほうが一般的になりつつある。一方、「国際河川」は地理教育や一般的な説明で広く用いられる言葉だ。
