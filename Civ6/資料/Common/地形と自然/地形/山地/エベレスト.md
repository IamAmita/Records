# エベレスト

**エベレスト（Mount Everest）**とは、ヒマラヤ山脈にある、**海抜高度が世界で最も高い山**である。ネパールと中国（チベット自治区）の国境上に位置している。

公式に認められている標高は**8,848.86 m**。2020年に中国とネパールが共同で発表した測量結果である。

## 概要

* **所在地**：ヒマラヤ山脈、ネパールと中国・チベット自治区の国境
* **標高**：8,848.86 m（世界最高峰）
* **成り立ち**：インドプレートとユーラシアプレートの衝突による隆起
* **各言語の名称**：Everest（英語）／チョモランマ（チベット語）／サガルマータ（ネパール語）
* **初登頂**：1953年5月29日

## どこにあるか

エベレストはアジア南部の巨大山脈である**ヒマラヤ山脈**の一部である。北側が中国・チベット自治区、南側がネパールで、エベレストの山頂そのものが**中国とネパールの国境**になっている。

## 世界で一番「高い」山

エベレストの最大の特徴はもちろん、**標高8,848.86 m**という高さである。これは**平均海面から山頂までの高さ**なので、「標高という基準では世界最高峰」という意味である。

ただ、「世界一高い山」という表現には少し面白い問題がある。

* **海底の基部から測った高さ** → ハワイの**マウナ・ケア**（大部分が海中にある）
* **地球の中心から最も遠い場所** → 南米エクアドルの**チンボラソ山**（地球は赤道付近が膨らんでいるため）

まとめると、

* **海抜高度世界一** → エベレスト
* **海底の基部から測った高さ** → マウナ・ケア
* **地球中心からの距離** → チンボラソ

という違いがある。普通に「世界最高峰」と言った場合はエベレストでよい。

## どうしてこんな巨大な山ができたのか

エベレストの成り立ちは**プレートテクトニクス**と深く関係している。ものすごく大まかにいうと、**インドプレート**がユーラシア大陸へ衝突している。

インド亜大陸はもともと現在よりかなり南にあった。それが北上してユーラシア大陸と衝突した。

**インドプレートが北上 → ユーラシアプレートと衝突 → 地殻が圧縮される（[褶曲](褶曲.md)）→ 岩石が押し上げられる → ヒマラヤ山脈形成**

という流れである。そして、このヒマラヤ山脈の一つがエベレストである。現在でもインドプレートはユーラシアプレートに対して動いているので、ヒマラヤ周辺は現在進行形で地殻変動が活発な地域である。

## 「エベレスト」という名前

実は「Everest」は現地の名前ではない。イギリスの測量・地理学者、**ジョージ・エベレスト（George Everest）**に由来する。

19世紀、イギリス領インドで大規模な測量が行われていた。当初この山は**Peak XV（第15峰）**という事務的な名称で呼ばれていた。その後、測量によって世界最高峰であることが判明する。そこで1865年、英国王立地理学会が、インド測量局長官を務めたジョージ・エベレストにちなんで**Mount Everest**という名称を正式に採用した。

面白いことに、**ジョージ・エベレスト本人はこの命名に反対していた**とされる。

### 現地の名前

チベット語では**チョモランマ（Qomolangma）**と呼ばれる。「世界の母なる女神」などと訳される名前である。一方、ネパールでは**サガルマータ（Sagarmāthā）**という名称が使われる。

* **英語・国際的名称** → Everest
* **チベット語** → チョモランマ
* **ネパール語** → サガルマータ

## 初登頂

エベレスト登山史で最も有名なのが、**1953年5月29日**の初登頂である。登頂したのは、**エドモンド・ヒラリー**（ニュージーランド出身）と**テンジン・ノルゲイ**（シェルパの登山家）の2人で、イギリス隊による遠征の一員として登頂に成功した。

なお、それ以前にも登頂への挑戦は行われている。特に有名なのが1924年の**ジョージ・マロリーとアンドリュー・アーヴィン**である。2人は山頂付近で行方不明になった。そのため「実は1953年より前に山頂へ到達していたのでは？」という謎が残っている。ただし登頂を証明する証拠は発見されていないので、公式には**ヒラリーとテンジンが人類初の登頂者**とされている。

## なぜ登るのが危険なのか

単純に「山が高い」だけではない。最大の問題の一つが**酸素不足**である。標高が上がるほど大気圧が低下する。エベレスト山頂では大気圧が海面付近の**約3分の1程度**しかない。つまり呼吸しても体内に取り込める酸素が非常に少ない。

特に標高約8,000m以上は、**デスゾーン（Death Zone）**と呼ばれる。人間が長期間正常に生存できる環境ではない。

## シェルパとは

エベレストの話では「シェルパ」という言葉がよく出てくる。本来、**シェルパ（Sherpa）は職業名ではなく民族名**である。ネパールなどヒマラヤ地域に暮らす民族で、高地環境への適応でも知られている。

ヒマラヤ登山でシェルパ民族の人々が登山隊の案内・荷物運搬・ルート整備などで非常に重要な役割を担ってきたため、「シェルパ＝登山ガイド」のように使われることもある。でも本来は**民族の名称**である。初登頂者テンジン・ノルゲイもシェルパだった。

## 海の生物の痕跡

エベレストの地質で面白いのがここである。山頂付近には**[石灰岩](../../採掘/石灰岩.md)などの堆積岩**が存在する。これらはもともと、古代の海に堆積した物質から形成されたものである。つまり、

**かつて海底だった場所 → インドプレートがユーラシアプレートへ衝突 → 地層が圧縮・隆起 → 現在は標高8,000mを超えるヒマラヤ山脈**

となった。そのためエベレスト周辺の岩石から**海洋生物由来の化石**も見つかる。「世界最高峰の岩石が、もともとは海底にあった」という、プレートテクトニクスを実感しやすい例である。

## まとめ

**エベレスト＝ネパールと中国・チベット自治区の国境にある、標高8,848.86mの世界最高峰**である。そして、**インドプレートとユーラシアプレートの衝突によって形成されたヒマラヤ山脈の一部**というのが地理・地学的には一番重要である。

[グランド・キャニオン](../河川/グランド・キャニオン.md)が**「侵食によって大地が削られてできた巨大地形」**なら、エベレストを含むヒマラヤは**「プレート同士の衝突によって大地が押し上げられてできた巨大地形」**と対比すると覚えやすい。
