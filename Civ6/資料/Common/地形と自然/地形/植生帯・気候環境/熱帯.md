# 熱帯

**熱帯（ねったい）**とは、簡単にいうと**一年を通して気温が高い地域**のことである。

地理的には、赤道を中心として**北回帰線（北緯約23.4度）と南回帰線（南緯約23.4度）の間**を「熱帯」と呼ぶことが多い。

## 緯度による定義と気候による定義

「熱帯」という言葉には**緯度による定義**と**気候による定義**がある。

気候学、とくにケッペンの気候区分では、熱帯（A気候）は**一年で最も寒い月でも月平均気温が18℃以上**の地域とされる。つまり「冬になってもかなり暖かい」のが特徴である。

## 熱帯＝熱帯雨林ではない

**熱帯＝[熱帯雨林](熱帯雨林.md)**ではない。気温は高くても、雨の降り方によって景観はかなり違う。

* **熱帯雨林気候** … 一年中雨が多い。アマゾンや東南アジアなど
* **熱帯モンスーン気候** … 雨季に非常に多く雨が降る
* **サバナ気候** … 雨季と乾季がはっきりしている

つまり、

* **熱帯** → 暑い地域全体
* **[熱帯雨林](熱帯雨林.md)** → 熱帯の中でも特に一年中雨が多い地域

という関係である。なお、サバナ気候に対応する植生は[草原](草原.md)（サバンナ）である。

## なぜ赤道付近は暑いのか

赤道付近が暑いのは、**太陽光が一年を通して地面に比較的垂直に近い角度で当たり、単位面積あたりに受け取る太陽エネルギーが大きいから**である。そのため季節による気温差も比較的小さい地域が多い。
