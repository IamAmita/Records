# 農業

**農業**とは、簡単に言えば、

> **土地や生物を人間が管理し、食料やその他の有用なものを継続的に生産する営み**

のことである。

代表的なのは米・小麦・野菜などを育てる**農耕**だが、広い意味では[畜産](畜産.md)なども農業に含まれる。

たとえば野生の小麦を見つけて採って食べるだけなら**採集**である。一方で、

**種をまく → 育てる → 収穫する → 一部を次の種として残す → また育てる**

というように、人間が生産過程に継続的に介入するようになると農業になる。

## 農業には何が含まれるか

中心になるのは大きく**耕種農業と[畜産](畜産.md)**である。

耕種農業なら、

* 稲作
* 小麦・大麦などの穀物栽培
* 野菜栽培
* 果樹栽培
* 豆類・芋類の栽培
* 綿花・茶・コーヒーなどの商品作物

など。

畜産なら、牛・豚・羊・鶏などを飼育して、肉・乳・卵・毛などを生産する。

一方、**漁業や林業は通常、農業とは別の産業として分類される**。まとめて「農林水産業」と呼ばれることはある。

## 人類史での重要性

農業は単なる「食べ物の作り方」以上の意味を持っている。

人類はもともと、狩猟や採集を中心に生活していた。ところが約1万年前から世界各地で農耕・牧畜が発達していく。

農業が成立すると、同じ土地から比較的継続して食料を生産できるようになる。すると、

**農業 → 食料を計画的に生産できる → 定住する人が増える → 村落が大きくなる → 人口が増える → 食料の余剰が生まれる → 農業以外を専門にする人を養える → 職人・商人・兵士・官僚・宗教者などが増える → 都市や国家が成立する**

という巨大な変化が起こった。

もちろん実際の歴史はこんな一直線ではないが、**農業による余剰生産は複雑な社会が成立するための重要な基盤**になった。

## 「余剰」が特に重要

仮に100人の共同体で、100人全員が自分の食料を探し続けなければ生きられないとする。この社会では、食料生産以外の仕事を専門にするのが難しい。

でも農業生産力が上がって、

**70人の農民が100人分の食料を生産できる**

ようになれば、残り30人は別の仕事ができる。例えば、

* **鍛冶屋** → 農具や武器を作る
* **兵士** → 集団を防衛する
* **官僚** → 税や土地を管理する
* **商人** → 物資を交換する
* **建築家・職人** → 建物や道具を作る

といった**分業**が可能になる。

さらに国家が農民から穀物を税として徴収すれば、それを使って兵士や官僚を養える。だから古代国家を理解するとき、

> **農業生産 → 余剰 → 税 → 国家**

という関係は非常に重要である。

例えば古代エジプトがナイル川と深く結びついていたのも、ナイル流域の農業生産が国家の経済的基盤だったからである。

## 「農業＝畑を耕すこと」だけではない

農業をもう少し本質的に見ると、

> **太陽エネルギー、水、土壌、生物の成長を、人間が管理して有用な生産物へ変換するシステム**

とも言える。そして歴史的には、その生産物が**人間社会を支えるエネルギー源**だった。

現代なら石油、電気、工業、金融、ITなど様々なものが経済を動かしているが、人間は食べなければ生きられない。だからどれだけ高度な文明になっても、農業は社会の最も基礎的な生産活動の一つであり続けている。

## まとめ

世界史を勉強する場合は、単に「食料を作る産業」と覚えるより、

**「食料を生産し、余剰を生み、その余剰が人口増加・分業・都市・国家を支えた」**

と理解しておくと、その後の文明史がかなりつながりやすくなる。

なお、農業を支える技術・施設としては[灌漑](灌漑.md)や[農場](農場.md)などがある。
