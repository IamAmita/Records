# マディーナ

**マディーナ（Medina / المدينة）**とは、現在の**サウジアラビア西部、ヒジャーズ地方にある都市**である。イスラム教では**メッカに次ぐ第2の[聖地](../制度/宗教・思想/聖地.md)**として極めて重要な都市である。

特に重要なのは、**ムハンマドがメッカから移住し、最初のイスラム共同体を築いた都市**だということである。

## 概要

* **所在地**：サウジアラビア西部、ヒジャーズ地方
* **旧名**：ヤスリブ（Yathrib）
* **イスラムでの位置づけ**：メッカに次ぐ第2の聖地
* **主要施設**：預言者のモスク（ムハンマドの墓がある）
* **歴史的意味**：ヒジュラ（622年）の移住先、イスラム共同体（ウンマ）の成立地

## なぜマディーナが重要なのか

イスラム教が誕生したのはメッカだが、初期のムハンマドと信者たちはメッカで迫害を受けていた。そこで**622年**、ムハンマドたちはメッカから約400km北にある都市へ移住する。これが有名な**ヒジュラ（聖遷）**である。この移住先が現在のマディーナである。

そして622年は非常に重要なので、**イスラム暦（ヒジュラ暦）の紀元**になっている。つまり、

* **西暦** → イエス・キリストの誕生を基準とする伝統から成立
* **イスラム暦** → ムハンマドのマディーナへの移住を基準とする

という違いがある。

## 元々は「ヤスリブ」という都市だった

マディーナはムハンマド以前から存在していた。当時は一般に**ヤスリブ（Yathrib / يثرب）**と呼ばれていた。オアシス都市で、複数のアラブ系部族やユダヤ系部族などが暮らしていた。

ムハンマドの移住後、**al-Madīna al-Munawwara（アル＝マディーナ・アル＝ムナッワラ）＝「輝ける都市」**などと呼ばれるようになる。

そもそもアラビア語の **madīna（مدينة）** は「都市」という意味である。そのため「マディーナ」は、もともと固有名詞というより**「都市」そのものを意味する言葉**である。

## イスラム共同体の成立

メッカ時代のムハンマドは基本的には**宗教を説く預言者**だった。ところがマディーナに移住すると、**宗教指導者＋政治指導者＋軍事指導者**としての性格を強めていく。マディーナを中心としてイスラム教徒の共同体、**ウンマ（Ummah）**が形成される。

だからイスラム史では、

* **メッカ** ＝ イスラム教が誕生した場所
* **マディーナ** ＝ イスラム共同体・イスラム国家の原型が成立した場所

と考えるとかなり分かりやすい。

## メッカとの戦い

マディーナに移ったからといって、メッカ側との対立が終わったわけではない。むしろ、**マディーナのムスリム勢力 vs メッカのクライシュ族**という政治・軍事的な対立に発展する。有名なのが、

**624年 バドルの戦い → 625年 ウフドの戦い → 627年 塹壕の戦い → 630年 ムハンマドによるメッカ征服**

という流れである。最終的にはムハンマド側がメッカを支配し、その後、アラビア半島の多くがイスラム共同体の影響下に入っていった。

## ムハンマドの墓がある

マディーナが現在でもイスラム教の聖地なのは、**ムハンマドがここで亡くなった**ことも非常に大きい。ムハンマドは632年にマディーナで死去した。そして現在の**預言者のモスク（Masjid an-Nabawi / المسجد النبوي）**に墓がある。

このモスクはムハンマド自身がマディーナ移住後の622年に建設に関わったモスクを起源とする。現在では大規模に拡張されていて、**イスラム教でメッカのマスジド・ハラームに次ぐ重要なモスク**とされる。ムハンマドだけでなく、初代正統カリフの**アブー・バクル**、第2代正統カリフの**ウマル**もここに葬られている。

## 初期イスラム国家の首都でもあった

ムハンマドの死後も、マディーナはしばらくイスラム世界の政治的中心だった。**ムハンマド → アブー・バクル → ウマル → ウスマーン**の時代には、基本的にマディーナが政治の中心である。

この時代にイスラム勢力はアラビア半島から猛烈な勢いで拡大して、シリア・パレスチナ・エジプト・イラク・ペルシアなどを征服していく。

ところが第4代正統カリフ**アリー**の時代になると、政治的中心がイラクの**クーファ**へ移る。さらに661年に**ウマイヤ朝**が成立すると首都は**ダマスクス**になる。そして[アッバース朝](../../Domain/文明/アッバース帝国/歴史/アッバース帝国.md)になると、最終的に中心は**バグダード**へ移る。

なので、

* **マディーナ** → 初期イスラム共同体
* **ダマスクス** → ウマイヤ朝
* **バグダード** → アッバース朝

という対応関係を覚えておくと、イスラム史がかなり整理しやすい。

## メッカとマディーナの違い

| | メッカ | マディーナ |
| --- | --- | --- |
| 位置 | サウジアラビア西部 | サウジアラビア西部 |
| イスラムでの位置 | **第1の聖地** | **第2の聖地** |
| ムハンマド | 生誕・布教開始 | 移住・共同体形成・死去 |
| 特に重要な施設 | カアバ神殿 | **預言者のモスク** |
| 歴史的意味 | イスラム発祥 | **イスラム共同体の成立** |
| 大巡礼ハッジ | 中心地 | ハッジそのものの必須行程ではない |

かなり単純化すると、**メッカ＝イスラム教が生まれた聖地／マディーナ＝イスラム教が「共同体・政治勢力」として確立した聖地**という違いである。

## まとめ

世界史を理解するなら、**622年の「ヒジュラ → マディーナでウンマ形成」**が重要である。この出来事によってムハンマドは単なる宗教運動の指導者から、政治共同体の指導者にもなり、そこから正統カリフ時代→ウマイヤ朝→アッバース朝へとつながるイスラム世界の政治史が始まっていく。
