**フリゲート艦（Frigate）**とは、時代によって意味が変化してきた軍艦の種類である。

* **帆船時代（17～19世紀）**：高速・機動力を重視した中型の軍艦。
* **現代**：対潜・対空・護衛任務を主とする中型の水上戦闘艦。

そのため、歴史の本と現代のニュースでは、同じ「フリゲート」でも指す船が異なる。

17～19世紀のフリゲートは、**速度と航続力を重視した軍艦**だった。

### 特徴

* 砲門は通常1層（1砲甲板）
* 大砲：約28～44門
* 乗員：約200～400人
* 高速で航行できる

当時の戦列艦（Ship of the Line）より火力は劣るが、速さでは勝っていた。

### 主な任務

* 偵察
* 哨戒
* 通商破壊
* 船団護衛
* 伝令
* 海賊の取り締まり

敵の主力艦隊と正面から戦うことは避け、単独行動や小規模戦闘で活躍した。

---

## 戦列艦との違い

| フリゲート   | 戦列艦        |
| ------- | ---------- |
| 中型      | 大型         |
| 砲1層     | 砲2～3層      |
| 約28～44門 | 約64～120門以上 |
| 高速      | 火力重視       |
| 偵察・護衛   | 艦隊決戦       |

戦列艦が「主力戦車」なら、フリゲートは「高速戦闘車両」のような役割だった。

第二次世界大戦後、「フリゲート」は**中型の護衛艦**を指すことが多くなった。

### 主な任務

* 対潜戦（潜水艦の探知・攻撃）
* 対空戦
* 艦隊護衛
* 船団護衛
* 海上警備

### 装備

* ミサイル
* 艦砲
* 魚雷
* 対潜ヘリコプター
* レーダー
* ソナー

などを搭載する。

## 駆逐艦との違い

現在では国によって分類基準が異なるため、フリゲートと駆逐艦の境界はあいまいである。

一般的には、

| フリゲート     | 駆逐艦        |
| --------- | ---------- |
| やや小型      | やや大型       |
| 護衛・対潜重視   | 多用途・高性能    |
| 比較的少人数で運用 | より大型の乗員・装備 |

例えば、日本の海上自衛隊は「フリゲート」ではなく「護衛艦」という分類を用いているが、もがみ型護衛艦は海外ではフリゲートに相当する艦とみなされることが多い。

## まとめ

フリゲート艦は、時代によって役割が変化した軍艦である。

* **帆船時代**：高速で単独行動や護衛、偵察を担う中型軍艦。
* **現代**：ミサイルや対潜装備を備え、艦隊や船団を守る多用途護衛艦。

共通しているのは、**主力艦を支え、機動力を生かして幅広い任務をこなす艦**という点である。
