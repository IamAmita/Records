# マムルーク

**マムルーク（Mamluk / مملوك）**とは、イスラム世界で軍人として使われた**奴隷身分出身の軍人（奴隷軍人）**のことである。

特定の民族の名前ではない。「マムルーク族」という民族がいたわけではなく、**奴隷として購入され、軍事教育を受けてエリート軍人になった人々**を指す。

## 「奴隷軍人」とは

「奴隷」と聞くと農場や鉱山などで強制労働させられる人を想像しやすいが、マムルークはかなり性格が違う。

イスラム世界の支配者が、主にイスラム世界の外から若い男性を奴隷として購入し、

**軍事訓練 → イスラム教への改宗 → 支配者直属の軍人として育成 → エリート兵士・軍事官僚になる**

という制度だった。しかも訓練を終えると解放されることも一般的だった。それでも、出自に由来して「マムルーク」と呼ばれ続けた。

## どこの人たちだったのか

時代によって違うが、特に**中央アジアのテュルク系民族**や、後には**コーカサス地方のチェルケス人**などが多かった。イスラム世界の外から連れてきた少年を軍人として育てるという仕組みである。

## なぜ奴隷を軍人にするのか

ここがマムルーク制度の核心である。

普通の有力者を軍人にすると、その人物には家族・部族・土地・地元の有力者・政治的派閥などとのつながりがある。つまり「本当に君主に忠誠を尽くしてくれるのか」という問題が発生する。

ところが外国から少年を連れてきて、支配者の宮廷で軍人として育成すれば、**現地社会との血縁・地縁がほとんどない**。そのため君主としては、**「自分に直接依存する軍隊を作れる」**というメリットがあった。

## アッバース朝との関係

前に出てきた[アッバース朝](../../../Domain/文明/アッバース帝国/歴史/アッバース帝国.md)ともつながる。

特に9世紀ごろからアッバース朝のカリフたちは、**テュルク系の奴隷軍人**を積極的に利用するようになった。彼らは強力な軍事力を持つようになる。ところが当然、問題も起きる。

**軍事力をマムルークに依存する → マムルーク系軍人の政治的発言力が強くなる → カリフより軍人の方が強くなる**

という現象が起こっていく。つまり**「君主に忠実な軍隊を作ろうとしたら、その軍隊が政治を動かすようになった」**ということである。これはイスラム史でかなり重要なパターンである。

## マムルーク朝の成立

その極端な例が**マムルーク朝（マムルーク・スルタン国）**である。1250年、エジプトでマムルークたちが権力を握り、自分たちの政権を成立させた。

**奴隷として購入される → 軍事教育を受ける → エリート軍人になる → 政治的影響力を持つ → 最終的に自分たちが支配者になる**

という展開になった。マムルーク朝は**1250～1517年**にエジプトを中心として存在し、シリアなども支配した。

## モンゴル帝国を破る

マムルーク朝の歴史で特に有名なのが、**1260年のアイン・ジャールートの戦い**である。

直前の1258年、モンゴル軍のフレグがバグダードを攻略していた（アッバース朝滅亡）。モンゴル軍はさらにシリア方面へ進出する。そこでエジプトのマムルーク朝が迎え撃った。

**1260年、アイン・ジャールートの戦い → マムルーク軍がモンゴル軍を撃破**

する。これはモンゴル帝国の西方進出を考えるうえで非常に有名な戦いである。ただし「無敵だったモンゴル軍が史上初めて敗北した」という説明は単純化しすぎなので注意が必要である。

## アッバース朝カリフの復活

1258年にバグダードのアッバース朝カリフはモンゴル軍によって滅ぼされた。ところがマムルーク朝はその後、**アッバース家の人物をカイロに迎えて、カリフとして擁立する**。

ただし実際に政治・軍事を支配しているのは、**マムルーク朝のスルタン**である。

* **カリフ** → 宗教的・象徴的権威
* **マムルーク朝スルタン** → 実際の政治・軍事権力

という構造になった。「カリフと実際の支配者の分離」がさらに明確になった形である。

## 「奴隷なのに支配者」の矛盾

マムルークは購入された時点では奴隷だが、**軍事教育を終えた後に解放されるのが一般的**だった。

**奴隷として購入 → 教育・訓練 → 解放 → 軍人として活動**

という流れになる。そのため「奴隷のままスルタンになった」というより、**「奴隷軍人制度で育成された人物が、解放後に軍事エリートとなり、最終的に支配者になった」**と理解した方が正確である。

## 地位が単純に世襲されない

マムルーク体制のかなり独特なところである。普通の貴族なら「父が貴族→息子も貴族」となりやすい。でもマムルークの息子は、厳密な意味では**マムルークではない**。

なぜならマムルークになるには、**イスラム世界の外部から奴隷として購入され、軍事教育を受ける**という経歴そのものが重要だったからである。そのためマムルーク朝では、新しいマムルークを外部から継続的に購入・育成することで軍事エリート集団を維持した。

もちろん実際にはマムルークの子孫も社会的に重要な地位を持つことはあったので、「一切世襲できない」と考える必要はない。

## オスマン帝国による滅亡

マムルーク朝は約260年間続いた。しかし16世紀になると**オスマン帝国**と衝突する。1516年の**マルジュ・ダービクの戦い**、1517年の**リダニヤの戦い**などで敗北。最終的にエジプトはオスマン帝国に征服され、**1517年、マムルーク朝は滅亡**した。

ただし、マムルークという軍事エリート集団そのものはその後もエジプト社会に残り、オスマン帝国統治下でも大きな影響力を持ち続けた。

## まとめ

「マムルークとは？」に一言で答えるなら、**「イスラム世界で、主に外国出身の少年を奴隷として購入して軍事教育を施したエリート奴隷軍人。その軍人集団が強大化し、最終的にはエジプトを中心に自分たちの王朝まで作った」**という理解でよい。
