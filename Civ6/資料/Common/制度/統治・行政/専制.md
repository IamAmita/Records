# 専制

**専制（せんせい）**とは、

> **一人の支配者、またはごく少数の支配者に政治権力が集中し、その権力を制度的に制限する仕組みが弱い統治のあり方**

のことである。英語では文脈によって **despotism** や **autocracy** などが対応する。

## たとえば何が「専制」なのか

ある国に王がいるとする。王が、

* 「税率をこれにする」
* 「この国と戦争する」
* 「この人物を処罰する」
* 「この法律を作る」

といった重要事項をほぼ自分だけで決定でき、議会・裁判所・憲法などが王の権力を十分に制限できない。こういう状態は**専制的**と言える。

反対に、

* **憲法** … 権力の限界を定める
* **議会** … 法律や予算を決める
* **裁判所** … 政府の行為が法律に反していないか判断する
* **選挙** … 国民が統治者を交代させられる

といった仕組みが存在して権力を制約しているなら、専制からは離れていく。つまり重要なのは、

> **「権力を持っている人を、誰が止められるのか？」**

という問題である。

## 「独裁」との違い

かなり近い言葉だが、ニュアンスが少し違う。

* **専制** … 支配者の権力がほとんど制約されないという**統治の性質**に注目する言葉。
* **[独裁](独裁政治.md)** … 一人または一つの政治勢力に権力が集中した**政治体制**を指すことが多い。

例えば「専制君主」という言い方は自然だが、これは王や皇帝が強大な権力を持つ歴史的な政治体制を説明するときによく使われる。ただし両者の境界は厳密ではなく、文脈によってかなり重なる。

## 「絶対王政＝専制」ではない

ここも世界史では重要である。

17～18世紀ヨーロッパの**絶対王政**では、国王に非常に大きな権力が集中した。例えばフランスのルイ14世は絶対王政を代表する君主として知られている。

ただし、

> **「絶対王政だから王は文字通り何でも自由にできた」**

と考えるのは正確ではない。実際の君主は、既存の法律・慣習・身分制度・教会・貴族・地方社会などに制約されていた。だから歴史学では、「絶対王政」という名称をそのまま「完全に無制限な専制」と理解しない方がよい。

## 「啓蒙専制君主」という言葉

18世紀ヨーロッパでは**啓蒙専制君主**という言葉も出てくる。代表例としてよく挙げられるのが、

* プロイセンのフリードリヒ2世
* オーストリアのヨーゼフ2世
* ロシアのエカチェリーナ2世

などである。彼らは啓蒙思想の影響を受けて、教育・司法・行政などの改革を進めた。

ただし、**国民が政治権力を持つ民主政治にしたわけではない**。あくまで、

> **強力な君主権力を使って、上から社会を合理化・改革する**

という考え方である。だから「啓蒙」＋「専制」という、一見矛盾しているような名称になっている。

## 『君主論』との区別

[マキャヴェッリの『君主論』](../../../Domain/偉人/君主論.md)とも区別した方がよい。

『君主論』は「専制政治を作ろう」という単純な本ではなく、**君主が権力を獲得・維持して国家を安定させるにはどう行動すべきか**を分析したものである。

## 用語の整理

| 用語 | 意味 |
| --- | --- |
| 君主制 | 君主が存在する政治体制 |
| 専制 | 権力への制約が非常に弱い統治 |
| [独裁](独裁政治.md) | 一人・一勢力に政治権力が集中する体制 |
| 絶対王政 | 主に近世ヨーロッパの歴史的な君主制の形態 |

このように分けておくと、世界史の用語がかなり整理しやすくなる。
