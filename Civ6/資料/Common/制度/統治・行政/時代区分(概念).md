# 時代区分（概念）

世界史の時代区分は、人類の歴史を理解しやすくするための分類だ。ただし、**世界共通の絶対的な区分ではなく、主にヨーロッパ史を基準に作られた概念**である。そのため、中国や日本、イスラム世界などには必ずしも当てはまらない。

一般的には次のように区分される。

| 時代   | おおよその時期      | 主な特徴             |
| ---- | ------------ | ---------------- |
| 先史時代 | ～文字の発明まで     | 文字がなく、考古学資料が中心   |
| 古代   | 文字の発明～5世紀頃   | 古代文明・帝国の成立       |
| 中世   | 5～15世紀頃      | 封建社会、宗教勢力の発展     |
| 近世   | 15～18世紀末頃    | 大航海時代、絶対王政、商業の発展 |
| 近代   | 18世紀末～20世紀前半 | 産業革命、国民国家、帝国主義   |
| 現代   | 20世紀中頃～現在    | 世界大戦後、冷戦、グローバル化  |

## 3. 中世

詳細は[中世（概念）](中世(概念).md)を参照。

ヨーロッパでは、

* 封建制度
* キリスト教会
* 騎士

が社会の中心だった。

一方で、

* イスラム世界では科学・医学・交易が発展。
* 中国では隋・唐・宋・元・明が続き、高度な官僚制度や技術が発達。
* 日本では鎌倉・室町幕府が成立し、武士が政治の中心となった。

つまり、「中世」といっても地域によって社会の姿は大きく異なる。

## 地域によって区分は異なる

世界史の時代区分は、地域によって考え方が異なる。

| 地域     | 一般的な区分例                                |
| ------ | -------------------------------------- |
| ヨーロッパ  | 古代 → 中世 → 近世 → 近代 → 現代                 |
| 中国     | 王朝（秦・漢・唐・宋・明・清など）で区分することが多い            |
| 日本     | 縄文・弥生・古墳・飛鳥・奈良・平安・鎌倉…という時代名で区分することが多い  |
| イスラム世界 | 王朝（ウマイヤ朝、アッバース朝、オスマン帝国など）を中心に区分することが多い |

## なぜヨーロッパ基準なのか

「古代・中世・近世・近代・現代」という区分は、ルネサンス期以降のヨーロッパで生まれた歴史観が基礎になっている。そのため、世界史では便利な共通の枠組みとして使われる一方で、研究では各地域固有の歴史の流れや時代区分も重視されている。

つまり、世界史の時代区分は**世界共通の「ものさし」ではなく、世界全体を比較・整理するための便利な枠組み**として理解するのが適切だ。
