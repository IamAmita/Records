# マドラサ

**マドラサ（madrasa / مدرسة）**とは、もともとアラビア語で**「学ぶ場所」「学校」**を意味する言葉である。歴史学では特に、**イスラム世界でイスラム法学などを教えた高等教育機関**を指すことが多い。

中世イスラム世界で発達し、**[ウラマー](../宗教・思想/ウラマー.md)（イスラム学者）を育成する重要な[教育](教育.md)機関**になった。

## ウラマーとの関係

「ウラマー」と直接つながっている。

* **マドラサ** → イスラム学問を学ぶ教育機関
* **ウラマー** → そこで教えたり、学んで専門家になったりするイスラム学者

かなり単純化すれば、**マドラサ＝学校／ウラマー＝そこで活動する学者**と考えてよい。

ただし、マドラサが成立する以前からウラマーは存在しているので、「マドラサがウラマーを生み出した」というわけではない。

## 何を勉強したのか

特に重要だったのが**イスラム法学（フィクフ）**である。そのほか、**クルアーン、ハディース**（→[聖典](../宗教・思想/聖典.md)）、**アラビア語文法、神学**なども学ばれた。

時代や地域、個々のマドラサによっては、数学・医学・天文学などが扱われることもあった。ただし「中世イスラム世界の総合大学」と単純に考えるより、基本的には**イスラム諸学、とりわけ法学を中心とする教育機関**と考えた方がよい。

## いつ頃できたのか

「学校」という意味での madrasa という言葉自体は広いが、歴史上の制度としてのマドラサは**10～11世紀ごろからイスラム世界で広く発達**していった。

特に有名なのが、11世紀の**セルジューク朝**である。宰相**ニザーム・アル＝ムルク**が各地に設立した**ニザーミーヤ学院（Nizamiyya）**が有名で、バグダードのニザーミーヤ学院などが代表例である。

## どういう建物だったのか

典型的なマドラサでは、中庭を中心として、その周囲に、

**講義を行う空間 ＋ 礼拝施設 ＋ 学生の居住スペース**

などが配置された。だから現代日本の「学校」より、**大学＋神学校＋学生寮**を組み合わせたようなイメージの方が近い場合もある。

特に後世の中央アジアやイランなどでは、壮麗なタイル装飾を施したマドラサ建築が多数作られている。西アフリカでも、[ソンガイ帝国](../../../Domain/文明/ソンガイ/歴史/ソンガイ帝国.md)の交易都市トンブクトゥにサンコーレ・モスクを中心とする学問拠点が発達し、各地からイスラム学者や学生が集まった。

## 誰が資金を出したのか

マドラサの運営には、**ワクフ（waqf）**というイスラム社会特有の寄進制度がよく利用された。

たとえば裕福な人物や君主が、「この土地・商店などから得られる収益を、この学校の維持費として永久に使う」と財産を寄進する。その収益から、教師の給与、学生の生活費、建物の維持費などを賄う。

そのためマドラサは単なる学校ではなく、**イスラム社会における宗教・教育・慈善制度と密接につながった施設**だった。

## なぜ支配者がマドラサを作ったのか

純粋な教育振興だけではなく、**政治的な意味**もあった。支配者がマドラサを支援すると、

**イスラム法学者を育成できる → ウラマーとの関係を強化できる → 自分の支配の宗教的・法的正当性にもつながる**

という効果がある。特にセルジューク朝のニザーミーヤ学院は、**スンナ派イスラムの学問・教育を振興する役割**を持ったことで知られている。

## モスクとの違い

* **モスク** → 礼拝する場所
* **マドラサ** → 学習・教育する場所

ただし実際には両者の機能が重なることも多い。そもそも初期イスラム社会では、モスクそのものが重要な教育の場でもあった。その後、教育制度が発達していく中で、**教育を主要機能とするマドラサが広まった**と考えると分かりやすい。

## 現代の「マドラサ」

現代のアラビア語で **madrasa** は普通に**「学校」**という意味でも使われる。だから、madrasa＝イスラム神学校と常に訳せるわけではない。

一方、日本語や英語の歴史・宗教の文脈で「マドラサ」とカタカナ表記されている場合は、たいてい**イスラム教育を行う伝統的な教育機関**を意味している。

## 用語のつながり

**イスラム教 → クルアーンやハディースを研究する → イスラム法（シャリーア）を解釈する学問が発達 → それを専門とするウラマーが形成される → ウラマーが学び・教える教育機関としてマドラサが発達 → ワクフなどによって経済的に支えられる**

という関係である。

## まとめ

世界史で「マドラサ」が出てきたら、まずは**「中世イスラム世界の、ウラマーを育成するイスラム法学中心の高等教育機関」**と覚えておけば十分である。
