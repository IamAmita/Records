# 埠頭

**埠頭（ふとう）**とは、

> **港で、船を接岸させ、人や貨物を積み降ろしするために整備された場所**

のことである。

例えば大型のコンテナ船が港に来たとき、沖に浮かんだままではコンテナを降ろせない。そこで船を岸につけて、クレーンなどで荷物を陸上へ移す。

そのために、

* **船が接岸する岸壁**
* **荷物を置く場所**
* **倉庫やクレーン**
* **道路・鉄道などの輸送設備**

などがまとまって整備された港湾区域が「埠頭」である。

## 「港」と「埠頭」は違う

ここは混同しやすい。

**[港](港.md)（港湾）**はもっと大きな概念で、船が出入り・停泊し、人や貨物を扱うための**区域全体**を指す。その港の中に複数の**埠頭**がある。

イメージとしては、

**港**
→ ○○埠頭 / △△埠頭 / コンテナターミナル / 防波堤 / 航路 / 倉庫 など

という関係である。例えば横浜港にも、本牧ふ頭、大黒ふ頭、山下ふ頭など複数の埠頭がある。

## 「埠頭」と「岸壁」「桟橋」の違い

これも少し違う。

* **岸壁** … 船が直接横付けする、水際の構造物。
* **桟橋** … 陸地から水上へ張り出して造られた構造物。船を接岸させたり、人が歩いたりする。
* **埠頭** … 岸壁・荷役設備・貨物を扱う土地などを含む、より広い港湾施設。

だから、

> **岸壁＝船をつける「面」**
> **埠頭＝その周辺まで含めた「船と陸上輸送をつなぐ場所」**
> **港＝それら全部を含む大きな区域**

くらいに考えると分かりやすい。

ちなみに「埠」という漢字自体が**船着き場・波止場**の意味を持っている。「埠頭」は文字通り、港で船と陸をつなぐ場所である。
