# モスク

**モスク（mosque）**とは、簡単にいえば**イスラム教徒（ムスリム）が礼拝を行うための場所**である。

アラビア語では一般に**マスジド（masjid / مسجد）**という。「モスク」は英語などを経由して広まった呼び方で、日本語では「イスラム礼拝堂」「イスラム寺院」などとも呼ばれる。

## 「マスジド」の意味

語源をたどると、アラビア語の **masjid** は「ひれ伏す場所」という意味を持つ。イスラム教の礼拝では、立ったり、屈んだり、額を地面につけて平伏したりする動作がある。そのため、

**masjid → 神（アッラー）の前に平伏する場所 → 礼拝所**

という意味になった。語根となる *sajada* は「ひれ伏す」という意味である。

## モスクでは何をするのか

中心となるのは当然、**礼拝（サラート）**である。イスラム教徒には原則として**1日5回の礼拝**が定められている。ただし、毎回必ずモスクへ行かなければならないわけではなく、条件を満たした清浄な場所なら礼拝できる。

一方、特に重要なのが**金曜日の集団礼拝**である。イスラム教では金曜日に共同体で行う礼拝が重視されていて、多くのムスリムがモスクに集まる。

## モスクの中には何があるのか

キリスト教の教会をイメージすると少し違う。イスラム教では偶像崇拝を避ける傾向が非常に強いため、基本的に「神の像が置いてあって、それに向かって祈る」という構造ではない。

代わりに非常に重要なのが**礼拝する方向**である。ムスリムは世界のどこにいても、メッカにある**カアバ**の方向を向いて礼拝する。この方向を**キブラ（qibla）**という。

### ミフラーブ

モスクの内部には、**ミフラーブ（mihrab）**という壁のくぼみが設けられていることが多い。これは「メッカはこっちですよ」とキブラの方向を示すものである。つまり、信徒はミフラーブそのものを崇拝しているわけではなく、ミフラーブが示している方向にあるメッカのカアバへ向かって礼拝する。

### ミンバル

もう一つ重要なのが、**ミンバル（minbar）**という説教壇である。階段状になっていることが多く、金曜礼拝などで**イマーム**が説教を行うために使われる。

* **ミフラーブ** → メッカの方向を示す
* **ミンバル** → 説教をするための場所

### ミナレット

モスクの外観で特徴的なのが、**ミナレット（minaret）**という塔である。伝統的にはここから**アザーン（礼拝への呼びかけ）**が行われた。アザーンを唱える人を**ムアッジン（muezzin）**という。

* **ミナレット** → 塔
* **ムアッジン** → 礼拝を呼びかける人
* **アザーン** → 礼拝への呼びかけ

現代ではスピーカーなども使われる。

## イマームとは

モスクで集団礼拝をするとき、その礼拝を先導する人が**イマーム（imam）**である。キリスト教の「司祭」と似て見えるが、完全に同じものではない。

スンナ派イスラムでは、イマームは基本的には**「集団礼拝の先導者」**という性格が強い。前に出てきた[ウラマー](ウラマー.md)と重なる場合もあるが、**イマーム＝ウラマー**とは限らない。

## 礼拝だけの場所ではない

歴史的にはここが重要である。モスクは単なる「お祈り専用施設」ではなく、イスラム共同体の**社会的中心**でもあった。礼拝に加えて、**教育、説教、集会、宗教的相談、慈善活動**などが行われた。

現在のモスクでも、宗教教育、結婚、葬儀、図書館などの機能を持っているところがある。

## マドラサとの違い

[マドラサ](../学問・技術/マドラサ.md)との違いも整理しておく。

| 施設 | 主な役割 |
| --- | --- |
| **モスク（マスジド）** | **礼拝** |
| マドラサ | **教育・学問** |
| ミナレット | モスクに付属する塔 |
| ミフラーブ | キブラを示す壁龕 |
| ミンバル | 説教壇 |

ただし、実際のイスラム社会では**モスクと教育はかなり密接**である。初期にはモスク自体が教育の場でもあり、後世になるとマドラサが発達する。そのため巨大な宗教施設では、**モスク＋マドラサ＋図書館＋墓廟**などが一体化していることもある。

## 特に重要なモスク

イスラム教で最も重要なのが、メッカの**マスジド・ハラーム（聖モスク）**である。その中心に**カアバ**がある。

そして第2の聖地[マディーナ](../../地名/マディーナ.md)には、**預言者のモスク（マスジド・アン＝ナバウィー）**がある。ムハンマドの墓があるのもこちらである。

* **メッカ** → カアバ＋聖モスク
* **マディーナ** → ムハンマド＋預言者のモスク

という対応を覚えておくと分かりやすい。

## まとめ

一言でまとめれば、**モスク＝ムスリムがアッラーに礼拝するための場所であり、同時にイスラム共同体の中心的な施設**である。
