**聖典（せいてん、Sacred Scripture）**とは、**宗教において神聖なものとされ、教えや信仰、儀式の基礎となる書物**のことである。

多くの宗教では、聖典は神の言葉や聖人の教えを記録したものとして尊重され、信仰や倫理のよりどころとなっている。

## 基本情報

聖典には、次のような内容が記されている。

* 教義
* 神話や伝承
* 戒律
* 儀式の方法
* 祈り
* 歴史や人物の記録

宗教によっては、一冊だけでなく複数の書物を合わせて聖典とする場合もある。

## 主な宗教の聖典

| 宗教     | 主な聖典                |
| ------ | ------------------- |
| キリスト教  | 聖書（旧約聖書・新約聖書）       |
| ユダヤ教   | タナハ（特に律法であるトーラーを重視） |
| イスラム教  | クルアーン               |
| 仏教     | 三蔵（経・律・論）           |
| ヒンドゥー教 | ヴェーダ、ウパニシャッド        |

## 聖典の役割

聖典は宗教生活の中心となる。

主な役割は、

* 信仰の基準を示す
* 礼拝や儀式で朗読する
* 道徳や倫理を教える
* 神学や宗教研究の基礎となる

多くの宗教では、聖典を学び、暗唱することが信仰の実践として重視されている。

## 成立

聖典は一人の人物が一度に書いたものとは限らない。

例えば、

* 長い年月をかけて編集されたもの
* 弟子たちが教えを書き残したもの
* 口承（語り伝え）を後に文字化したもの

など、成立の過程は宗教によって異なる。

## 写本と保存

印刷技術が普及する以前、聖典は写本として一冊ずつ手書きで書き写されていた。

そのため、美しい装飾や挿絵が施された写本も多く、宗教的価値だけでなく、美術品・歴史資料としても高く評価されている。

## 豆知識

世界最古級の宗教文献には、古代インドで長く口承によって受け継がれた**ヴェーダ**がある。何世紀にもわたり文字に頼らず、厳格な暗唱法によって内容が伝えられたため、その正確さは現代の言語学や歴史学の研究対象にもなっている。
