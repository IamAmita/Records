# 種目メニュー（5kgダンベル2個＋自重）

[部位分類.md](部位分類.md)の8部位に対応する種目一覧。健康目的なら、難しい種目を増やすより、まずは全身をまんべんなく動かせる構成が向いている。

---

## 1. 胸

### 腕立て伏せ

胸を中心に、肩の前側と上腕三頭筋も鍛えられる。

1. 手を肩幅より少し広く置く
2. 頭からかかとまでを一直線にする
3. 胸を床へ近づける
4. 床を押して戻る

難しければ、膝をついた腕立て伏せや、机・壁に手をつく斜め腕立て伏せで大丈夫。

目安：限界の2～3回手前まで×2～3セット

### ダンベルフロアプレス

床に仰向けになって行うダンベルプレス。

1. 両手にダンベルを持って仰向けになる
2. 肘を軽く外側へ向ける
3. ダンベルを胸の上へ押し上げる
4. 上腕が床につくまでゆっくり下ろす

床があるので肘が深く下がらず、比較的安全に行いやすい。5kgが軽ければ、下ろす動作に3秒ほどかけると効きやすい。

---

## 2. 背中

### ワンハンド・ダンベルロー

広背筋や肩甲骨周辺を鍛える代表的な種目。

1. 片手を机や椅子など、動かない安定した場所につく
2. 背中を丸めず、上体を前に傾ける
3. 反対の手でダンベルを持つ
4. 肘を腰の方向へ引く
5. 肩甲骨を軽く寄せてから、ゆっくり戻す

目安：左右10～20回×2～3セット

腕だけで持ち上げず、「肘を後ろへ運ぶ」意識にすると背中に入りやすい。

### ダンベル・リバースフライ

背中上部と肩の後ろ側に効く。

1. 両手にダンベルを持って前傾する
2. 肘を軽く曲げる
3. 両腕を左右に広げる
4. 肩甲骨を寄せてから戻す

5kgでは重すぎる可能性があるので、片腕ずつ行ったり、ダンベルなしで動作を確認したりしてもいい。勢いを使わず、肩がすくまない範囲で行う。

---

## 3. 肩

### ダンベル・ショルダープレス

肩全体、特に前側と横側を使う。

1. ダンベルを肩の高さで構える
2. 腰を反らさず、頭上へ押し上げる
3. 肘が伸び切る直前まで上げる
4. ゆっくり肩の高さへ戻す

目安：8～15回×2～3セット

腰が反る場合は、立って行うより床や背もたれのある椅子に座ったほうが安定する。

### サイドレイズ

肩の横側を鍛え、肩幅に関係する種目。

1. ダンベルを身体の横に持つ
2. 肘を少し曲げる
3. 腕を左右へ持ち上げる
4. 肩の高さより少し低い位置で止める
5. ゆっくり下ろす

5kgはサイドレイズには重いことがある。肘を強く曲げて負荷を軽くする、片腕ずつ行う、水の入った500mlペットボトルを使う、といった調整がおすすめ。

### リアレイズ

肩の後ろ側を鍛える。リバースフライとほぼ同じ動きなので、背中の種目と兼用できる。

---

## 4. 腕

### ダンベルカール

上腕二頭筋、いわゆる力こぶの部分を鍛える。

1. ダンベルを身体の横に持つ
2. 肘の位置をなるべく動かさずに曲げる
3. 肩の手前まで持ち上げる
4. ゆっくり下ろす

目安：左右10～20回×2～3セット

反動で身体を振らないことが大切。

### ハンマーカール

手のひらを内側に向けたまま行うダンベルカール。上腕筋や前腕も使いやすい。

通常のダンベルカールとどちらか一つでも十分。

### オーバーヘッド・トライセプスエクステンション

上腕三頭筋、腕の後ろ側を鍛える。

1. ダンベル1個を両手で持つ
2. 頭上へ持ち上げる
3. 肘の位置を保ちながら、ダンベルを頭の後ろへ下ろす
4. 肘を伸ばして戻す

目安：10～20回×2～3セット

肩や肘に違和感がある場合は中止して、手幅を狭くした腕立て伏せなどに替える。

### リストカール

前腕や握力を補助的に鍛える。

ただし、ダンベルを握る種目を複数行えば前腕も自然に使われるので、最初から入れる必要性は低い。

---

## 5. 腹部・体幹

### プランク

腹部を中心に、身体を一直線に保つ力を鍛える。

1. 両肘とつま先を床につける
2. 頭からかかとまでを一直線にする
3. 腰が反ったり、お尻が上がったりしない位置を保つ
4. 呼吸を止めずに維持する

目安：20～40秒×2～3セット

長時間我慢するより、正しい姿勢を維持できる時間で終えるほうがいい。

### デッドバグ

腰への負担が比較的小さく、体幹を安定させる練習に向いている。

1. 仰向けになり、両腕を天井へ向ける
2. 股関節と膝を約90度に曲げて脚を上げる
3. 腰が反らないように腹部へ力を入れる
4. 右腕と左脚をゆっくり伸ばす
5. 戻して、反対側も行う

目安：左右各6～12回×2～3セット

### サイドプランク

脇腹と骨盤周辺を鍛える。

最初は膝を曲げ、肘と膝で身体を支える形でも十分。

---

## 6. お尻

### グルートブリッジ／ヒップリフト

お尻と太ももの裏側を鍛える。

1. 仰向けになり、膝を曲げる
2. 足を腰幅程度に置く
3. かかとで床を押しながら腰を上げる
4. 肩から膝までが一直線になったら戻す

目安：15～30回×2～3セット

軽ければ、骨盤の上にダンベルを置く。ただし、タオルを挟み、ダンベルが転がらないよう両手で支える。

### ブルガリアンスクワット

お尻と太ももを強く使う片脚種目。

1. 後ろ足を安定した低い台や椅子に載せる
2. 前足へ体重を乗せる
3. 前脚の膝と股関節を曲げて身体を下ろす
4. 前足で床を押して戻る

最初はダンベルなしでいい。バランスが不安定なので、椅子は足を載せても動かないものを使う必要がある。

---

## 7. 太ももの前側

### スクワット

太ももの前側、お尻、内もも、体幹をまとめて鍛えられる。

1. 足を肩幅程度に開く
2. つま先と膝をだいたい同じ方向へ向ける
3. 椅子に腰掛けるように、膝と股関節を曲げる
4. 足裏全体で床を押して立つ

目安：10～20回×2～3セット

慣れたら、胸の前でダンベルを1個持つ「ゴブレットスクワット」にできる。

### リバースランジ

片脚ずつ後ろへ引くランジ。前へ踏み出すランジより、比較的バランスを取りやすい。

1. 立った状態から片脚を後ろへ引く
2. 前脚の膝と股関節を曲げる
3. 前足で床を押して戻る
4. 左右を交互に行う

目安：左右各6～12回×2～3セット

---

## 8. 太ももの裏・ふくらはぎ

### ダンベル・ルーマニアンデッドリフト

太ももの裏側とお尻を鍛える重要な種目。

1. 両手にダンベルを持って立つ
2. 膝を軽く曲げる
3. お尻を後ろへ引きながら上体を前傾させる
4. ダンベルを脚に沿わせて下ろす
5. 太ももの裏が伸びたところで、お尻を前へ戻して立つ

目安：10～20回×2～3セット

「しゃがむ」のではなく、「お尻を後ろへ突き出す」のがポイント。背中を丸めてダンベルを床まで下ろす必要はない。

### カーフレイズ

ふくらはぎを鍛える。

1. 壁や机に軽く手を添える
2. かかとを持ち上げ、つま先立ちになる
3. 上で一度止める
4. ゆっくりかかとを下ろす

目安：15～30回×2～3セット

軽い場合は片脚で行うか、片手にダンベルを持つ。

## 種目と部位の対応

| 部位 | まず試したい種目 | 補助的な種目 |
| --- | --- | --- |
| 胸 | 腕立て伏せ | ダンベルフロアプレス |
| 背中 | ワンハンド・ダンベルロー | リバースフライ |
| 肩 | ショルダープレス | サイドレイズ、リアレイズ |
| 腕 | ダンベルカール | トライセプスエクステンション |
| 腹部・体幹 | デッドバグ | プランク、サイドプランク |
| お尻 | ヒップリフト | ブルガリアンスクワット |
| 太もも前 | スクワット | リバースランジ |
| 太もも裏・ふくらはぎ | ルーマニアンデッドリフト | カーフレイズ |

---

## 最初に選ぶなら

全部を一度に取り入れる必要はない。全身を効率よく鍛えるなら、最初は次の6種目でかなり広い範囲をカバーできる。

1. スクワット
2. ダンベル・ルーマニアンデッドリフト
3. 腕立て伏せ
4. ワンハンド・ダンベルロー
5. ダンベル・ショルダープレス
6. デッドバグ

各種目を10～15回前後、2セットから始めれば、30分ほどで終えられる。「15回」という数字を絶対視する必要はなく、最後の数回がきついけれどフォームは崩れない程度が基本。5kgで軽すぎる種目は、回数を増やす、ゆっくり下ろす、底で一時停止する、片脚・片腕で行う、といった方法で負荷を調整できる。
